연속 모델의 대수적 재구성

10장에서 연속 표기 \(\mu\in L^2\), \(\mathcal{P}\mu=p\), \(J[\mu]\)를 이산 표기 \(\mathbf{x}\in\mathbb{R}^n\), \(\mathbf{A}\mathbf{x}=\mathbf{b}\), \(J(\mathbf{x})\)와 짝지어 읽는 틀을 세웠습니다. 이 장에서는 그 틀을 실제 알고리즘(최소제곱, Landweber·SIRT, GPBB, Tikhonov, TV)에 하나씩 적용해, 같은 알고리즘이 연속 영역에서 어떻게 보이는지, 그리고 이산 표기로 돌아올 때 무엇이 정확히 결정되는지 봅니다.

이 장은 전체가 심화입니다. 1~8장의 알고리즘은 모두 이산 표기로 완결됩니다. 지금 건너뛰었다면, 나중에 논문에서 연속 모델의 수렴 분석이나 함수 공간의 정규화를 만났을 때 돌아와도 됩니다.

이 장의 진행

  1. 연속 최소제곱과 그 정규방정식을 보고, 왜 항상 풀리지는 않는지(불량조건)를 봅니다(페이지 1~2).
  2. 반복 알고리즘 두 가지(Landweber·SIRT, GPBB)를 힐베르트 공간에서 다시 씁니다(페이지 3~4).
  3. 정규화(Tikhonov, TV)를 연속 공간에서 다시 보고, Tikhonov가 FBP의 램프 필터와 어떻게 이어지는지 봅니다(페이지 5~6).
  4. 이산화로 돌아와 10장이 남긴 "정확한 대응 관계"를 확인하고, 짝이 어긋나는 구체적인 경우를 봅니다(페이지 7~8).
  5. 논문을 읽을 때 쓰는 대응표와, 연속 관점이 주는 것과 한계를 정리합니다(페이지 9).

이 장은 모든 페이지가 "심화"이므로 처음 읽을 때 통째로 건너뛰어도 됩니다.

연속 최소제곱 문제

10장 페이지 2가 적어 둔 연속 목적함수를 다시 씁니다.

\[\mu^{*} = \operatorname*{arg\,min}_{\mu}\ J[\mu], \qquad J[\mu] = \lVert\mathcal{P}\mu-p\rVert^2\]

(정규화 항은 페이지 5~6에서 더합니다.) 3장 페이지 8의 \(J(\mathbf{x})=\lVert\mathbf{A}\mathbf{x}-\mathbf{b}\rVert^2\)를 함수 \(\mu\)에 그대로 적용한 것이고, 계수는 이 책의 규약대로 \(1\)입니다(10장 페이지 7).

연속 모델과 이산 모델이 어떻게 짝지어지는지를 먼저 그림으로 봅니다. 이 장의 이산화는 이 그림의 위쪽 줄에서 아래쪽 줄로 내려오는 일입니다.

연속 정규방정식

10장 페이지 8에서 이미 \(\nabla J[\mu]=2\mathcal{B}(\mathcal{P}\mu-p)\)를 구했습니다. 최솟값에서는 이 기울기가 \(0\)이므로, 다음 식을 만족합니다.

\[\mathcal{B}\mathcal{P}\mu = \mathcal{B}p\]

이 식을 연속 정규방정식이라고 부릅니다. 3장 페이지 4의 정규방정식 \(\mathbf{A}^{\mathsf T}\mathbf{A}\hat{\mathbf{x}}=\mathbf{A}^{\mathsf T}\mathbf{b}\)와 글자만 바뀐 같은 구조입니다 — \(\mathcal{P}\leftrightarrow\mathbf{A}\), \(\mathcal{B}\leftrightarrow\mathbf{A}^{\mathsf T}\).

다른 책의 표기

많은 논문은 이 식을 \(\mathcal{A}^{*}\mathcal{A}f=\mathcal{A}^{*}p\)로 씁니다(10장 페이지 1의 표: \(f\leftrightarrow\mu\), \(\mathcal{A}\leftrightarrow\mathcal{P}\), \(\mathcal{A}^{*}\leftrightarrow\mathcal{B}\)).

3장 페이지 4는 이 식을 기하로도 얻었습니다 — 잔차가 열공간과 수직이라는 사실입니다. 같은 길을 10장 페이지 4의 사영 정리로 다시 밟을 수 있습니다: \(\mathcal{P}\)의 치역(값이 놓이는 공간, Range)을 \(V\)라고 하면, \(\hat\mu\)가 \(J[\mu]\)를 최소로 하는 것은 \(\mathcal{P}\hat\mu-p\)가 \(V\)와 수직인 것과 같습니다.

다만 10장 페이지 4의 사영 정리는 \(V\)가 닫힌 부분공간이어야 성립합니다. 유한 차원에서는 모든 부분공간이 저절로 닫혀 있어 이 조건을 신경 쓸 필요가 없었습니다. 연속에서는 \(\mathcal{P}\)의 치역이 닫혀 있다고 보장되지 않습니다.

다음 페이지에서 보듯 \(\mathcal{B}\mathcal{P}\)가 고주파 방향을 끝없이 눌러서, 아주 작은 \(p\)의 변화로도 치역 안인지 밖인지가 달라질 수 있습니다. 그래서 잡음이 섞인 \(p\)에는 이 정규방정식을 정확히 만족하는 \(\mu\)가 아예 존재하지 않을 수 있습니다. 유한 차원에서는 겪지 않았던 일입니다.

무한 차원의 불량조건: 컴팩트 연산자

3장 페이지 5는 조건수 \(\kappa(\mathbf{A})=\sigma_{\max}/\sigma_{\min}\)를 정의했고, 페이지 6은 "\(\sigma_{\min}=0\)이면 정의할 수 없을 정도로(무한대로) 나빠진다"고 했습니다. 연속 연산자 \(\mathcal{P}\)에서는 이 \(\sigma_{\min}=0\)이 극단적인 예외가 아니라 구조적으로 일어나는 일입니다.

\(N:=\mathcal{B}\mathcal{P}\)로 두면(3장 페이지 5의 \(\mathbf{A}^{\mathsf T}\mathbf{A}\)에 대응), 1편 5장 페이지 6에서 이미 \(N\mu=\mu*\psi\)(\(\psi=1/r\))이고 그 2차원 푸리에 변환이 \(\widehat{N\mu}=\hat\mu/|\omega|\)임을 보였습니다. 평면파 \(e^{i2\pi(\omega_x x+\omega_y y)}\)를 \(N\)에 넣어 보면, \(N\)은 이 방향을 \(1/|\omega|\)배로 늘립니다 — 이것이 \(N\)의 고유값이고, \(\mathcal{P}\)의 특이값은 그 제곱근 \(\sigma(\omega)\propto1/\sqrt{|\omega|}\)입니다.

유한 차원에는 방향이 \(n\)개뿐이라 가장 작은 특이값도 어떤 양수였습니다. 연속에는 방향(주파수 \(\omega\))이 무한히 많고, \(\omega\to\infty\)인 방향에서 \(\sigma(\omega)\to0\)입니다. 양의 하한이 전혀 없으므로 \(\kappa=\sigma_{\max}/\sigma_{\min}\)은 아예 정의되지 않습니다 — 조건수가 나쁜 정도가 아니라, 특이값이 \(0\)에 끝없이 가까워지는 방향이 무수히 있다는 뜻입니다.

이 모양을 \(\sigma(\omega)\propto1/\sqrt{\omega}\)라는 장난감 모형으로 그려 봅니다. 격자가 담는 방향 수 \(n\)을 늘려 가면 가장 작은 특이값이 계속 줄어, 이 모형의 조건수 \(\sqrt{n}\)에 상한이 없습니다. \(n=16\)이면 \(4\), \(n=100\)이면 \(10\), \(n=200\)이면 약 \(14.14\)입니다. 격자를 촘촘하게 할수록 불량조건이 심해지기만 하고, 어느 해상도에서도 사라지지 않습니다.

컴팩트 연산자

이렇게 특이값이 \(0\)으로 가는 수열을 갖는 유계 연산자를 컴팩트 연산자(Compact Operator)라고 부릅니다. 유한 차원 선형사상은 특이값이 유한 개뿐이라 전부 자동으로 컴팩트합니다 — 무한 차원에서야 비로소 뜻이 생기는 성질입니다. \(\mathcal{P}\)가(시야 \(\Omega\)로 제한했을 때) 실제로 컴팩트 연산자라는 사실의 엄밀한 증명은 이 책의 범위를 넘습니다(F. Natterer, The Mathematics of Computerized Tomography, SIAM, 2001). 여기서는 위의 \(1/|\omega|\) 셈으로 특이값이 \(0\)으로 간다는 결론만 직접 확인합니다.

10장 페이지 5는 \(\mathcal{P}\)가 \(L^2(\mathbb{R}^2)\) 전체에서는 유계조차 아니라고 했습니다 — 시야를 반지름 \(R\)인 \(\Omega\)로 제한해야 비로소 유계(\(\lVert\mathcal{P}\rVert\le\sqrt{2\pi R}\))가 됩니다. 그 제한이 유계성에 꼭 필요했던 것과 같은 맥락에서, 컴팩트성도 \(\Omega\)가 유한한 영역일 때만 기대할 수 있는 성질입니다.

이 사실은 두 가지로 이어집니다. 하나는 페이지 1에서 본 "해가 존재하지 않을 수 있다"는 문제이고, 다른 하나는 4장 페이지 1·페이지 2가 이산 모델에서 본 잡음 증폭입니다 — 조건수가 큰 문제에서 작은 잡음이 크게 흔들리는 일이 연속에서는 "항상, 모든 해상도에서" 일어납니다. 격자를 아무리 촘촘하게 잡아도 더 높은 주파수 방향이 계속 남아 있기 때문입니다. 이 증폭을 가라앉히는 두 가지 방법(Tikhonov, TV)을 페이지 5~6에서 연속 공간에 그대로 옮겨 씁니다.

Landweber 반복의 연속형과 SIRT

기울기의 반대 방향으로 내려가는 경사하강법을 \(J[\mu]\)에 그대로 적용합니다(3장 페이지 10과 같은 모양, \(\tau:=2\alpha\)).

\[\mu^{(k+1)} = \mu^{(k)} + \tau\,\mathcal{B}(p-\mathcal{P}\mu^{(k)})\]

이것을 Landweber 반복(Landweber 반복)이라고 부릅니다 — 이름은 2장 페이지 7이 \(\mathbf{D},\mathbf{R}\)가 항등일 때의 경사하강형 갱신을 가리켜 이미 썼습니다. 수렴 조건도 그대로 옮겨집니다: 3장 페이지 10의 \(0<\tau<2/\lambda_{\max}(\mathbf{A}^{\mathsf T}\mathbf{A})\)는 \(0<\tau<2/\lVert\mathcal{P}\rVert^2\)이 됩니다. 10장 페이지 5의 \(\lVert\mathcal{P}\rVert^2\le2\pi R\)을 쓰면 \(\tau<1/(\pi R)\)이 충분조건입니다.

가중 내적을 고르면: SIRT

이 식을 그대로(가중치 없이) 이산화하면 2장 페이지 7의 \(\mathbf{D},\mathbf{R}\)가 둘 다 항등인 경우, 즉 보통의 경사하강법이 나옵니다 — SIRT가 아닙니다. SIRT를 얻으려면 이산화 전에 내적 자체를 바꿔야 합니다.

양의 가중함수 \(r(\theta,s)\), \(d(x,y)\)로 두 공간의 내적을 다시 정의하고, \(J_r[\mu]:=\lVert\mathcal{P}\mu-p\rVert^2_r\) (\(\lVert v\rVert^2_r:=\int\!\int r\,v^2\,ds\,d\theta\))을 \(d\)-가중 내적에서 가장 가파르게 내려가는 방향으로 최소화하면 다음과 같습니다(유도는 접기).

\[\mu^{(k+1)} = \mu^{(k)} + \tau\cdot\frac{1}{d}\,\mathcal{B}\!\Bigl[r\,(p-\mathcal{P}\mu^{(k)})\Bigr]\]

유도: 가중 내적에서의 Gâteaux 미분

보통의(가중치 없는) Gâteaux 미분은 10장 페이지 7·페이지 8과 같은 방식으로 \(J_r'[\mu;\eta]=2\langle r(\mathcal{P}\mu-p),\mathcal{P}\eta\rangle=2\langle\mathcal{B}[r(\mathcal{P}\mu-p)],\eta\rangle\)입니다 (여기서 \(\langle\cdot,\cdot\rangle\)은 보통의 \(L^2\) 내적). \(d\)-가중 내적 \(\langle a,b\rangle_d:=\langle d\,a,b\rangle\)에서 "기울기" \(\nabla_dJ_r[\mu]\)는 모든 \(\eta\)에 대해 \(J_r'[\mu;\eta]=\langle\nabla_dJ_r[\mu],\eta\rangle_d=\langle d\,\nabla_dJ_r[\mu],\eta\rangle\)를 만족해야 하므로, \(d\cdot\nabla_dJ_r[\mu]=2\mathcal{B}[r(\mathcal{P}\mu-p)]\), 즉 \(\nabla_dJ_r[\mu]=\tfrac{2}{d}\mathcal{B}[r(\mathcal{P}\mu-p)]\)입니다. 경사하강 \(\mu^{(k+1)}=\mu^{(k)}-\alpha\nabla_dJ_r[\mu^{(k)}]\)에 \(\tau=2\alpha\)를 넣으면 본문의 식이 됩니다.

이 식을 화소·광선 격자로 이산화하면, \(r(\theta,s)\)는 2장 페이지 5의 \(r_i\)(광선 \(i\)의 길이 합)의 역수로, \(d(x,y)\)는 \(c_j\)(화소 \(j\)의 가중치 합)로 자리를 잡으면서 \(\mathbf{D}=\mathrm{diag}(1/c_j)\), \(\mathbf{R}=\mathrm{diag}(1/r_i)\)와 정확히 일치합니다 — 2장 페이지 7의 SIRT 갱신식 그대로입니다. 즉 SIRT는 "아무 이산화에서나 저절로 나오는 것"이 아니라, 두 공간에 올바른 가중 내적을 골랐을 때 나오는 가중 Landweber 반복입니다.

반복 횟수가 하는 일: 암묵적 정규화

\(\mu^{(0)}=0\)에서 출발한 Landweber 반복을 \(\mathcal{P}\)의 특이값 방향으로 전개하면, \(k\)번째 반복의 성분은 \(f_k(\sigma)=1-(1-\tau\sigma^2)^k\)만큼만 참값 성분이 살아난 모습입니다(유한 차원에서는 같은 식이 SVD 성분별로 정확히 성립합니다). 특이값이 작은 방향(페이지 2의 고주파)일수록 \(f_k\)가 \(1\)에 가까워지는 데 반복이 더 많이 걸립니다. 그래서 초반 반복은 믿을 만한(특이값이 큰) 방향부터 빠르게 채우고, 잡음이 들어오는 방향은 한참 뒤에야 커집니다 — 2장 페이지 8의 반 수렴이 바로 이 지연의 결과입니다. 이 \(f_k\)는 페이지 5의 Tikhonov 필터 인자 \(\sigma^2/(\sigma^2+\lambda)\)와 같은 역할(특이값이 작은 방향을 누르는 필터)을 반복 횟수로 흉내 낸 것입니다.

필터 인자 \(f_k\)를 반복 횟수 \(k\)별로 그려 봅니다. 걸음 크기는 \(\tau\sigma_{\max}^2=1\)로 두어 \(f_k\)가 \(0\)과 \(1\) 사이에 머물게 했습니다. \(\sigma=0.1\sigma_{\max}\)인 방향은 \(k=10\)에서 \(0.096\)만 살아나고, \(k=100\)에서 \(0.634\), \(k=1000\)에서 거의 \(1\)이 됩니다. \(\sigma=0.3\sigma_{\max}\)인 방향은 \(k=10\)에서 이미 \(0.611\)입니다. 반복이 길어질수록 곡선이 왼쪽(작은 특이값)으로 밀려 가며 더 많은 방향이 살아납니다.

GPBB를 힐베르트 공간으로 그대로 옮기기

7장 페이지 2의 기울기 사영(GP)과 페이지 4의 BB 스텝·비단조 선 탐색은 벡터의 성분·내적·사영만 쓰므로, \(L^2(\Omega)\)로 옮길 때 바꿀 것이 거의 없습니다. 먼저 한 반복에서 값이 흐르는 순서를 연속 모델과 이산 모델에서 나란히 봅니다.

\[\mu^{(k+1)} = P_C\bigl(\mu^{(k)}-\alpha\,\nabla J[\mu^{(k)}]\bigr), \qquad P_C(\nu)(x,y) := \max(\nu(x,y),\ 0)\]

\(C=\{\mu:\mu\ge0\ \text{거의 모든 곳에서}\}\)는 \(L^2(\Omega)\)의 닫힌 볼록 부분집합이고, \(P_C\)는 그 위로의 사영입니다 (6장 페이지 2와 같은 모양). \(\nabla J[\mu]\)는 정규화까지 더한 페이지 6의 식을 씁니다.

BB 스텝(6장 페이지 4)도 내적만 \(L^2\) 내적으로 바꾸면 그대로입니다.

\[s_k:=\mu^{(k)}-\mu^{(k-1)},\quad y_k:=\nabla J[\mu^{(k)}]-\nabla J[\mu^{(k-1)}],\quad \gamma_k=\frac{\langle s_k,y_k\rangle}{\langle s_k,s_k\rangle},\quad \alpha_k:=\frac{1}{\gamma_k}\]

비단조 선 탐색(7장 페이지 4)의 받아들임 조건도 같은 식입니다. 방향 \(u^{(k)}:=P_C(\mu^{(k)}-\alpha_k\nabla J[\mu^{(k)}])-\mu^{(k)}\)과 걸음 길이 \(\eta\in(0,1]\)에 대해(페이지 1의 기호표),

\[J\bigl[\mu^{(k)}+\eta\,u^{(k)}\bigr] \ \le\ \max(\text{최근 10회의 }J) + 10^{-4}\,\eta\,\bigl\langle\nabla J[\mu^{(k)}],u^{(k)}\bigr\rangle\]

바뀐 것은 덧셈·스칼라곱·내적·최댓값이 전부 함수 공간의 것으로 해석된다는 점뿐입니다. 식의 모양, 수렴에 대한 직관(걸음이 스스로 곡률을 어림한다는 것, 매 반복 줄어들 필요는 없다는 것)도 그대로 넘어옵니다 — 7장이 \(J\)가 볼록함수라고 확인했던 것도 (7장 페이지 1) \(L^2\)에서 똑같이 성립하는 성질입니다.

다만 페이지 2의 사실이 여기서도 영향을 줍니다. \(\gamma_k\)를 추정하는 두 점 \(s_k,y_k\)에 고주파 성분(잡음)이 섞이면, 그 방향의 곡률은 \(0\)에 가까워 \(\gamma_k\)가 들쑥날쑥해지기 쉽습니다. 유한 차원에서는 비단조 선 탐색을 쓴 BB 계열의 수렴이 알려져 있지만, 무한 차원 \(L^2\)에서의 엄밀한 증명은 이 책이 다루지 않습니다. 실제로 이 식들이 쓰이는 곳은 결국 이산화한 뒤(페이지 7)이고, GPBB가 잘 동작한다는 것은 이산 문제에서 확인한 경험적 사실입니다.

연속 Tikhonov 정규화와 필터 역투영

4장 페이지 2의 Tikhonov 정규화 \(J(\mathbf{x})=\lVert\mathbf{A}\mathbf{x}-\mathbf{b}\rVert^2+\lambda\lVert\mathbf{x}\rVert^2\)를 그대로 연속에 옮기면, 정규방정식은 다음과 같습니다.

\[(\mathcal{B}\mathcal{P}+\lambda I)\,\mu_\lambda = \mathcal{B}p\]

다른 책의 표기

논문에서는 흔히 \((\mathcal{A}^{*}\mathcal{A}+\alpha I)f=\mathcal{A}^{*}p\)로 씁니다. 이 책은 정규화 강도를 4장 페이지 2부터 \(\lambda\)로 썼으므로 그대로 \(\lambda\)를 씁니다. 단위에 주의해야 합니다 — \(\mathcal{B}p\)는 \(\mu\cdot\mathrm{cm}\) 단위이므로(\(\mathcal{B}\mathcal{P}\mu=\mu*\psi\)가 넓이 적분을 한 번 더 하는 것과 같은 이유), \(\lambda\mu_\lambda\)가 같은 단위이려면 \(\lambda\)의 단위는 cm(길이)입니다 — \(\omega\)의 단위가 \(\mathrm{cm}^{-1}\)이므로 아래 식의 \(\lambda|\omega|\)가 무차원이 되는 것과 같은 이야기입니다.

이 식을 풀면 다음과 같습니다. \(\mu_\lambda=\mathcal{B}q_\lambda\)이고,

\[q_\lambda(\theta,s) = \int P_\theta(\omega)\,H_\lambda(\omega)\,e^{i2\pi\omega s}\,d\omega, \qquad H_\lambda(\omega) := \frac{|\omega|}{1+\lambda|\omega|}\]

즉 연속 Tikhonov 해 \(\mu_\lambda\)는 1편 5장 페이지 1의 FBP 공식에서 램프 필터 \(|\omega|\)를 \(H_\lambda(\omega)\)로 바꿔 끼운 것과 똑같습니다. \(\lambda\to0\)이면 \(H_\lambda\to|\omega|\)(보통의 FBP), \(\omega\to0\)이면 \(H_\lambda\to0\)(직류 제거, 1편 5장 페이지 3·5와 같은 성질)이지만, \(\omega\to\infty\)에서는 \(|\omega|\)처럼 끝없이 커지지 않고 \(1/\lambda\)로 머뭅니다 — 고주파(잡음이 실리는 방향, 페이지 2)의 증폭에 상한을 그은 것입니다.

아래 그림에서 \(\lambda\)를 바꿔 봅니다. \(\lambda=0.1\ \mathrm{cm}\)이면 \(\omega=1,\ 10,\ 100\ \mathrm{cm}^{-1}\)에서 \(H_\lambda\)가 \(0.909,\ 5.000,\ 9.091\)이고, 상한은 \(1/\lambda=10\)입니다. 램프 필터는 같은 자리에서 \(1,\ 10,\ 100\)이므로, \(\omega\)가 작을 때는 거의 같고 클수록 크게 눌립니다.

0.5

유도: 주파수별로 정규방정식 풀기

이 접기 안의 \(b\)는 역투영한 함수를 가리키는 임시 이름이며, 이산 벡터 \(\mathbf{b}\)(측정값)와는 무관합니다.

1단계. 임의의 sinogram을 역투영한 함수의 2차원 변환. 임의의 \(q(\theta,s)\)에 대해 \(b:=\mathcal{B}q\)라고 하면, \(b(x,y)=\int_0^\pi\!\int Q_\theta(\omega)e^{i2\pi\omega s}\,d\omega\,d\theta\)입니다(\(Q_\theta\)는 \(q(\theta,\cdot)\)의 1차원 변환, Fourier 역변환을 바로 대입한 것). 한편 1편 5장 페이지 2의 식 (B)는 임의의 2차원 함수 \(b\)와 그 변환 \(\hat b\)에 대해 \(b(x,y)=\int_0^\pi\!\int\hat b(\omega\cos\theta,\omega\sin\theta)e^{i2\pi\omega s}|\omega|\,d\omega\,d\theta\)라고 말합니다 (극좌표로 2차원 역변환을 다시 쓴 것일 뿐이라, \(b\)가 어떤 함수든 성립합니다). 두 식의 피적분 함수를 맞추면 \(\hat b(\omega\cos\theta,\omega\sin\theta)=Q_\theta(\omega)/|\omega|\)를 얻습니다.

2단계. \(N=\mathcal{B}\mathcal{P}\)의 대입. 페이지 2에서 \(\widehat{N\mu}(\omega_x,\omega_y)=\hat\mu(\omega_x,\omega_y)/|\omega|\)임을 보였습니다(1편 5장 페이지 6). \(b:=\mathcal{B}p\)에 1단계를 쓰면 \(\hat b(\omega\cos\theta,\omega\sin\theta)=P_\theta(\omega)/|\omega|\)입니다.

3단계. 방정식을 주파수별로 풀기. \((N+\lambda I)\mu_\lambda=b\)의 2차원 변환은 각 \((\omega_x,\omega_y)\)에서 \(\bigl(\tfrac{1}{|\omega|}+\lambda\bigr)\hat\mu_\lambda = \hat b\)입니다. \(\omega_x=\omega\cos\theta,\omega_y=\omega\sin\theta\) 위에서 2단계의 \(\hat b\)를 넣으면 \(\hat\mu_\lambda(\omega\cos\theta,\omega\sin\theta) = \dfrac{P_\theta(\omega)/|\omega|}{1/|\omega|+\lambda} = \dfrac{P_\theta(\omega)}{1+\lambda|\omega|}\)입니다.

4단계. 다시 역투영 꼴로. 1단계의 일반 공식을 \(\mu_\lambda\)에 적용하면 \(\mu_\lambda(x,y)=\int_0^\pi\!\int P_\theta(\omega)\cdot\dfrac{|\omega|}{1+\lambda|\omega|}\cdot e^{i2\pi\omega s}\,d\omega\,d\theta\)이고, 이것이 바로 본문의 \(q_\lambda\)를 역투영한 것입니다.

이 결과는 4장 페이지 2의 필터 인자 \(f_k=\sigma_k^2/(\sigma_k^2+\lambda)\)와 같은 그림을 주파수 언어로 다시 그린 것입니다 — \(\sigma(\omega)^2\propto1/|\omega|\)를 그 식에 넣으면 \(f(\omega)\propto1/(1+\lambda|\omega|)\)가 나오고, 이것이 \(H_\lambda(\omega)=|\omega|\cdot f(\omega)\)의 꼴로 램프 필터에 곱해집니다. 결국 Tikhonov 정규화는 1편 5장 페이지 9의 윈도우 필터(Ram-Lak, Hamming 등)와 똑같은 일(고주파를 깎아 잡음을 누르는 것)을, 창을 직접 고르는 대신 정규화 강도 \(\lambda\) 하나로 수학적으로 유도해 낸 것입니다.

연속 TV 정규화: 최적성 조건과 기울기 흐름

10장 페이지 7의 \(\mathrm{TV}[\mu]\)를 평활화해(10장 페이지 9) 더하면, 이 장에서 실제로 최소화할 목적함수는 다음과 같습니다(7장 페이지 1의 \(J(\mathbf{x})\)와 같은 모양).

\[J[\mu] = \lVert\mathcal{P}\mu-p\rVert^2 + \lambda\,\mathrm{TV}_\delta[\mu], \qquad \min_{\mu\ge0}\ J[\mu]\]

기울기는 10장이 각 항에서 구한 두 결과를 더한 것입니다.

\[\nabla J[\mu] = 2\,\mathcal{B}(\mathcal{P}\mu-p)\ -\ \lambda\,\operatorname{div}\!\left(\frac{\nabla\mu}{\max(\lvert\nabla\mu\rvert,\delta)}\right)\]

(첫 항은 10장 페이지 8, 둘째 항은 10장 페이지 9.) 제약이 없다면 최적성 조건은 \(\nabla J[\mu]=0\)인데, 이것을 풀어 쓴 미분방정식이 바로 10장 페이지 9의 오일러-라그랑주 방정식입니다 — Rudin, Osher, Fatemi(1992, 4장 페이지 4에서 이미 인용)가 원래 연속 공간에서 다룬 것은 \(\mathcal{P}\) 자리에 항등 연산자를 둔 같은 꼴의 방정식(영상 잡음 제거, 데이터항 \(\lVert\mu-f\rVert^2\))입니다. \(\mu\ge0\) 제약이 있으면 조건은 등식이 아니라 부등식(변분 부등식, 6장 페이지 2의 사영 조건과 같은 구조)이 됩니다 — 실제로 이 조건에 닿는 방법이 페이지 4의 GP입니다.

기울기 흐름

가상의 시간 변수를 하나 두고, \(\mu\)가 그 시간에 따라 \(\nabla J[\mu]\)의 반대 방향으로 변한다고 하면 다음과 같은 미분방정식(기울기 흐름, Gradient Flow)을 얻습니다.

\[\frac{\partial\mu}{\partial(\text{시간})} = -\nabla J[\mu] = -2\mathcal{B}(\mathcal{P}\mu-p) + \lambda\operatorname{div}\!\left(\frac{\nabla\mu}{\max(\lvert\nabla\mu\rvert,\delta)}\right)\]

이 흐름을 시간 간격 \(\Delta t\)로 명시적 오일러법(explicit Euler)으로 이산화하면 \(\mu^{(k+1)}=\mu^{(k)}+\Delta t\bigl(-\nabla J[\mu^{(k)}]\bigr)\)인데, 정규화 없는 데이터 항만 두면 이것이 \(\tau=2\Delta t\)로 둔 페이지 3의 Landweber 반복이고(페이지 3의 \(\tau:=2\alpha\) 규약과 같은 이유로, 기울기의 계수 \(2\)를 시간 간격 쪽으로 옮긴 것입니다), 비음수 제약과 BB 스텝까지 더하면 페이지 4의 GPBB입니다. 즉 고정 걸음의 Landweber 반복은 이 연속 시간 흐름을 시간 방향으로 이산화한 것이고, GPBB는 걸음을 매번 바꾸고 사영을 더한 변형으로 볼 수 있습니다(엄밀한 등가는 아닙니다). 그리고 페이지 7~8에서 보는 이산화는 그와 별개로 공간 방향(화소·검출기 격자)의 이산화입니다 — 둘은 독립적인 선택입니다.

흐름의 모양을 1차원 예로 봅니다. \(\mathcal{P}\) 자리에 항등을 둔 것(Rudin-Osher-Fatemi의 영상 잡음 제거 꼴)이고, 길이 \(64\)인 계단 신호에 표준편차 \(0.2\)의 잡음을 더했습니다. 아래 버튼은 \(\Delta t=0.05\)씩 흐름을 진행시킨 시간입니다. \(t=0\)에서 \(t=2\)까지 \(J\)는 \(2.455\), \(1.965\)(\(t=0.1\)), \(1.456\)(\(t=0.5\)), \(1.390\)(\(t=2\))으로 줄고, \(J\)는 \(t=2\) 이후 소수 셋째 자리까지 변하지 않아 정지 상태에 가깝습니다. 이 정지 상태가 최적성 조건 \(\nabla J=0\)을 만족하는 점에 대응합니다. 참값과의 rmse는 \(0.1846\)에서 \(0.1133\)(\(t=2\))으로 줄고 \(t=10\)에서 \(0.1127\)까지 조금 더 줄지만, 경계의 높이는 \(1.029\)에서 \(1.007\)로 거의 그대로 남습니다. 평활화된 TV는 평평한 구간의 잡음만 깎고 큰 계단은 지우지 않습니다.

시간 \(t\)

명시적 오일러법은 \(\Delta t\)가 크면 불안정합니다. 이 예에서는 \(\Delta t(2+4\lambda/\delta)<2\), 즉 \(\Delta t<0.111\)이면 충분하고, \(\Delta t=0.05\)로 \(5000\)번 진행하는 동안 \(J\)가 한 번도 늘지 않는 것을 확인했습니다.

이산화로 돌아오기: 격자가 시스템 행렬과 기울기를 만드는 방식

10장 페이지 8은 \(\nabla J[\mu]=2\mathcal{B}(\mathcal{P}\mu-p)\)와 \(\nabla J(\mathbf{x})=2\mathbf{A}^{\mathsf T}(\mathbf{A}\mathbf{x}-\mathbf{b})\)가 "구조는 같지만 값이 정확히 같다고는 말할 수 없다"고 하며 정확한 대응을 이 장으로 미뤘습니다. 이제 화소 기저로 직접 확인합니다.

먼저 화소 격자가 시스템 행렬을 어떻게 만드는지 그림으로 봅니다.

화소 쪽: 정확한 비례

화소 기저 \(\varphi_j\)(1장 페이지 1)는 서로 겹치지 않으므로, \(\mu=\sum_jx_j\varphi_j\), \(\nu=\sum_jy_j\varphi_j\)이면 다음이 정확히 성립합니다(근사가 아닙니다).

\[\langle\mu,\nu\rangle = \sum_jx_jy_j\,\lVert\varphi_j\rVert^2 = (\Delta x)^2\sum_jx_jy_j = (\Delta x)^2\langle\mathbf{x},\mathbf{y}\rangle\]

(\(\Delta x\)는 화소 한 변의 길이, 1편 6장 페이지 12의 영상 격자 \(\Delta x\)입니다.) 화소 기저를 쓰는 것만으로 연속 내적과 유클리드 내적 사이에 상수 \((\Delta x)^2\)(화소의 넓이)가 끼어듭니다.

sinogram 쪽: 근사(사각형 공식)

검출기 값은 1편 3장 페이지 10부터 "화소 중심 샘플"로 다루었습니다. 그래서 \(a_{ij}=\int_{\text{광선 }i}\varphi_j\,d\ell\)(1장 페이지 2)로 만든 \((\mathbf{A}\mathbf{x})_i\)는 각도 \(\theta_k=k\Delta\theta\), 검출기 \(s_n\)에서의 점 샘플 \((\mathcal{P}\mu)(\theta_k,s_n)\)과 정확히 같습니다 (\(\mu\)가 화소마다 상수이기 때문입니다). 두 연속 sinogram의 내적은 이 샘플들로 사각형 공식(rectangle rule)을 쓰면 다음과 같이 근사됩니다.

\[\langle p,q\rangle = \int_0^\pi\!\int p\,q\,ds\,d\theta \ \approx\ \Delta\theta\,\Delta s\sum_{k,n}p[k,n]\,q[k,n] = \Delta\theta\,\Delta s\,\langle\mathbf{p},\mathbf{q}\rangle\]

(\(\Delta\theta=\pi/N_\theta\), 1편 3장 페이지 10. \(\Delta s\)는 검출기 간격, 1편 2장 페이지 1.)

수반 관계로 비례상수 확인하기

이제 \(\langle\mathcal{P}\mu,q\rangle=\langle\mu,\mathcal{B}q\rangle\)(10장 페이지 6)에 위 두 근사를 넣습니다. 왼쪽은 \(\Delta\theta\,\Delta s\langle\mathbf{A}\mathbf{x},\mathbf{d}\rangle=\Delta\theta\,\Delta s\langle\mathbf{x},\mathbf{A}^{\mathsf T}\mathbf{d}\rangle\)이고(\(\mathbf{d}\)는 \(q\)의 점 샘플), 오른쪽은 \(\mathcal{B}q\)를 화소 중심에서 다시 사각형 공식으로 근사한 값 \((\mathbf{B}\mathbf{d})_j\approx\Delta\theta\sum_kd[k,n(j,k)]\)(화소 \(j\)의 중심을 지나는 광선의 값을 각도마다 하나씩 집는 최근접 역투영, "화소 기여" 방식과 같은 생각입니다, 1장 페이지 4)를 써서 \((\Delta x)^2\langle\mathbf{x},\mathbf{B}\mathbf{d}\rangle\)입니다. 모든 \(\mathbf{x},\mathbf{d}\)에 대해 두 쪽이 같아야 하므로,

\[\mathbf{B} \approx \frac{\Delta\theta\,\Delta s}{(\Delta x)^2}\,\mathbf{A}^{\mathsf T}\]

즉 연속 역투영 \(\mathcal{B}\)를 화소 중심의 최근접 샘플로 그대로 이산화한 행렬 \(\mathbf{B}\)는, ray-driven으로 만든 \(\mathbf{A}\)의 전치와 상수 \(\Delta\theta\,\Delta s/(\Delta x)^2\)배만큼 다릅니다. 같은 비례상수가 기울기에도 그대로 옮겨집니다.

\[\nabla J[\mu]\Big|_{\text{화소 중심 샘플}} \ \approx\ \frac{\Delta\theta\,\Delta s}{(\Delta x)^2}\,\nabla J(\mathbf{x})\]

이것이 10장 페이지 8이 미뤄 둔 "정확한 대응 관계"입니다 — 두 기울기는 같은 방향을 가리키지만 크기가 \(\Delta\theta\,\Delta s/(\Delta x)^2\)배 다릅니다. 경사하강형 알고리즘에서는 이 상수가 걸음 크기 \(\tau\)에 흡수되므로(\(\tau\)를 \(\Delta\theta\,\Delta s/(\Delta x)^2\)배 다시 맞추면 같은 걸음이 됩니다) 치명적이지 않습니다. 그런데 \(\mathbf{B}\)가 \(\mathbf{A}^{\mathsf T}\)의 "상수배"라는 것 자체도 \(\mathbf{B}\)를 \(\mathbf{A}^{\mathsf T}\)와 같은 방식으로 이산화했을 때만 성립합니다 — 다음 페이지에서 이 조건이 깨지는 경우를 봅니다.

이산화 방식에 따른 차이: 상수배와 구조적 어긋남

페이지 7의 \(\mathbf{B}\approx(\Delta\theta\,\Delta s/(\Delta x)^2)\mathbf{A}^{\mathsf T}\)는 순투영(ray-driven)과 역투영(화소 중심 최근접)이 같은 사각형 공식으로 연속 \(\mathcal{P},\mathcal{B}\)를 근사했기 때문에 나온 결과입니다. 양수 상수배 \(\mathbf{B}=c\mathbf{A}^{\mathsf T}\ (c>0)\)는 사실 무해합니다 — 2장 페이지 7의 고정점 조건 \(\mathbf{B}\mathbf{A}\mathbf{x}^{*}=\mathbf{B}\mathbf{b}\)에 넣으면 \(c\mathbf{A}^{\mathsf T}\mathbf{A}\mathbf{x}^{*}=c\mathbf{A}^{\mathsf T}\mathbf{b}\)이고, \(c\)로 나누면 원래의 정규방정식과 똑같습니다. 상수배는 걸음 크기만 바꿀 뿐, 수렴하는 자리는 바꾸지 않습니다 — 1장 페이지 6의 matched라고 봐도 됩니다.

기저 선택이 만드는 구조적 어긋남

순투영과 역투영을 서로 다른 계산 모델로 만들면 이 상수배 관계가 깨집니다. 예를 들어 순투영은 ray-driven(교차 길이, \(\mathbf{A}\))으로 만들고, 역투영은 pixel-driven이 아니라 distance-driven(경계 겹침, 1장 페이지 4)으로 독립적으로 구현했다고 합시다. 두 모델은 서로 다른 근사 방식으로 같은 연속 연산자를 근사하기 때문에, 오차의 형태가 다르고(ray-driven은 화소 경계에서 계단형 오차, distance-driven은 더 매끄러운 오차), 그 결과 어떤 양수 \(c\)를 곱해도 \(\mathbf{B}=c\mathbf{A}^{\mathsf T}\)가 되지 않을 수 있습니다. 이것이 1장 페이지 6의 unmatched이고, 2장 페이지 7에서 본 것처럼 \(\mathbf{B}\mathbf{A}\)가 대칭이 아니게 되어 고정점이 달라지거나 수렴이 깨질 수 있습니다.

이것이 10장 페이지 2가 "이산화한 뒤 최적화"와 "최적화한 뒤 이산화"가 같은 답을 준다고 가정할 수 없다고 한 말의 구체적인 모습입니다. 연속에서는 \(\mathcal{B}=\mathcal{P}^{\mathsf T}\)가 정확한 사실이지만(10장 페이지 6), 순투영과 역투영을 각자 편한 모델로 따로 짜면 그 사실이 이산화 뒤에 자동으로 보존되지 않습니다. 1장 페이지 7의 on-the-fly 연산자가 "순투영과 역투영이 같은 가중치 계산을 공유하면 저절로 matched가 된다"고 한 것은, 바로 이렇게 양쪽을 같은 이산화 방식으로 맞추라는 뜻이었습니다.

선택 읽기 — 기저 자체가 직교하지 않을 때

화소 indicator 기저는 서로 겹치지 않아(10장 페이지 4) \(\langle\varphi_i,\varphi_j\rangle=0\ (i\ne j)\)였습니다. 매끄러운 기저(예: blob, B-스플라인)를 쓰면 이웃 기저끼리 겹쳐 \(\langle\varphi_i,\varphi_j\rangle=:G_{ij}\ne0\)인 그람 행렬(Gram Matrix) \(\mathbf{G}\)가 생깁니다. 이때 \(\langle\mu,\nu\rangle=\mathbf{x}^{\mathsf T}\mathbf{G}\mathbf{y}\)이고, 계수 \(\mathbf{x}\)에 대한 "올바른"(연속 내적과 맞는) 기울기는 페이지 3의 유도와 같은 방식으로 \(\mathbf{G}^{-1}\)이 한 번 더 끼어든 \(\mathbf{G}^{-1}(2\mathbf{A}^{\mathsf T}(\mathbf{A}\mathbf{x}-\mathbf{b}))\)가 됩니다 — \(\mathbf{x}\)를 그냥 숫자 벡터로 보고 쓰는 보통의 \(\nabla J(\mathbf{x})=2\mathbf{A}^{\mathsf T}(\mathbf{A}\mathbf{x}-\mathbf{b})\)와 다릅니다. 화소 기저가 \(\mathbf{G}=(\Delta x)^2\mathbf{I}\)(상수배의 항등)여서 이 차이가 페이지 7에서는 보이지 않았을 뿐입니다. 기저를 바꾸는 것은 곧 연산자뿐 아니라 "기울기가 무엇인가"까지 바꾸는 선택입니다.

연속 관점이 주는 것

페이지 2의 불량조건 논증은 화소 수나 각도 수를 한 번도 쓰지 않았습니다 — \(N=\mathcal{B}\mathcal{P}\)의 주파수 응답 \(1/|\omega|\) 하나로 끝났습니다. 이산 모델에서는 격자를 바꿀 때마다 3장 페이지 6의 조건수 \(\kappa(\mathbf{A})\)를 다시 계산해야 했지만, 연속 모델의 결론(특이값이 \(0\)으로 간다)은 해상도와 무관하게 항상 참입니다. 알고리즘을 설계하거나 왜 잘 동작하는지 이해할 때, 특정 격자에 매달리지 않고 생각할 수 있다는 것이 연속 관점의 가장 큰 쓸모입니다.

또 하나는 통일된 시각입니다. 페이지 3의 반복 횟수 필터 \(f_k(\sigma)=1-(1-\tau\sigma^2)^k\), 페이지 5의 Tikhonov 필터 \(H_\lambda(\omega)=|\omega|/(1+\lambda|\omega|)\), 4장 페이지 2의 SVD 필터 \(\sigma^2/(\sigma^2+\lambda)\)는 모두 "특이값(또는 주파수)이 작은 방향을 누른다"는 같은 생각의 다른 표현입니다. 겉보기에 다른 알고리즘(조기 종료, Tikhonov, 윈도우 필터)이 수학적으로는 거의 같은 일을 한다는 것이, 이산 표기만 봤을 때보다 연속 표기에서 훨씬 선명하게 드러납니다.

한계

실제 측정은 늘 유한합니다 — 검출기 칸 수, 투영 각도 수는 항상 정해진 숫자입니다. "연속"이라고 부를 수 있는 쪽은 재구성하려는 영상 \(\mu\)에 대한 모델링의 선택일 뿐, 데이터 \(p\) 쪽은 처음부터 끝까지 이산입니다. 그래서 이 장의 모든 결과는 결국 페이지 7~8처럼 이산화를 통과해야 계산할 수 있고, 그 통과 과정이 공짜가 아니라는 것도 페이지 8에서 보았습니다.

또한 이 장이 쓴 힐베르트 공간의 정리들(사영 정리, 완비성, 리즈 표현, Natterer의 컴팩트성)은 모두 "결과만 받아들였습니다" (10장 페이지 4, 페이지 8, 이 장 페이지 2). 그 증명은 함수해석학 교재에서 다룰 내용이고, 이 책은 이 결과들을 CT 재구성에 어떻게 쓰는지까지만 다룹니다.

11장 마무리

핵심 요약

  1. (심화) 연속 최소제곱 \(\mu^{*}=\operatorname*{arg\,min}\lVert\mathcal{P}\mu-p\rVert^2\)의 1차 조건은 연속 정규방정식 \(\mathcal{B}\mathcal{P}\mu=\mathcal{B}p\)이고, 3장의 \(\mathbf{A}^{\mathsf T}\mathbf{A}\hat{\mathbf{x}}=\mathbf{A}^{\mathsf T}\mathbf{b}\)와 같은 구조입니다 — 다만 해가 늘 존재한다고는 말할 수 없습니다.
  2. (심화) \(\mathcal{B}\mathcal{P}\)는 주파수에서 \(1/|\omega|\)를 곱하는 연산이라, 고주파 방향의 특이값이 \(0\)으로 가는 컴팩트 연산자입니다 — 유한 차원에 없던, 해상도와 무관한 불량조건입니다.
  3. (심화) Landweber 반복과 GPBB는 힐베르트 공간의 경사하강형 갱신이고, 가중 내적을 고르면 정확히 SIRT가 나옵니다. 둘 다 같은 기울기 흐름을 시간 방향으로 이산화한 것입니다.
  4. (심화) 연속 Tikhonov 정규화는 램프 필터 \(|\omega|\)를 \(|\omega|/(1+\lambda|\omega|)\)로 바꾸는 필터 역투영이고, TV 정규화의 최적성 조건은 오일러-라그랑주 방정식입니다.
  5. (심화) 격자·기저를 고르는 순간 연속 기울기와 이산 기울기 사이에 비례상수(\(\Delta\theta\,\Delta s/(\Delta x)^2\))가 끼어들고, 순투영·역투영을 서로 다른 모델로 이산화하면 그 상수배 관계조차 깨져 정말로 짝이 어긋납니다(unmatched).

\(\mathcal{B}\mathcal{P}\)가 주파수에서 \(1/|\omega|\)를 곱하는 연산이라는 사실이 뜻하는 것으로 가장 알맞은 것은 무엇일까요?

  1. 고주파(큰 \(|\omega|\)) 방향마다 이 값이 \(0\)에 가까워져, 특이값의 하한이 없어 조건수를 정의할 수 없다.
  2. \(|\omega|=0\)인 한 점에서만 값이 정의되지 않을 뿐이라, 실제 계산에는 영향이 없다.
  3. 모든 주파수에서 똑같이 \(1\)을 곱하는 셈이라, \(\mathcal{B}\mathcal{P}\)는 항등 연산자와 다름없다.
  4. 이 사실은 \(\mathcal{P}\)가 유계가 아님을 보여 줄 뿐이고, 조건수와는 별개다.

이 성질은 화소 수나 각도 수를 정하기 전부터 참입니다 — 페이지 9에서 본 "해상도와 무관한" 결론의 가장 분명한 예입니다.

연속 Tikhonov 정규화 \((\mathcal{B}\mathcal{P}+\lambda I)\mu_\lambda=\mathcal{B}p\)의 해와 FBP의 관계를 가장 잘 설명한 것은 무엇일까요?

  1. \(\mu_\lambda\)는 램프 필터 \(|\omega|\) 대신 \(H_\lambda(\omega)\)를 쓰는 필터 역투영이고, 고주파에서 필터 값이 \(1/\lambda\)를 넘지 않는다.
  2. \(\mu_\lambda\)는 역투영 없이, FBP와는 전혀 다른 방식으로 계산된다.
  3. \(\mu_\lambda\)는 FBP에 윈도우 필터를 그대로 곱한 것과 정확히 같은 결과를 준다.
  4. \(\lambda\)를 \(0\)으로 보내면 \(H_\lambda(\omega)\)는 \(1\)로 수렴해 필터 없는 단순 역투영이 된다.

같은 필터 인자 이야기를 4장 페이지 2는 SVD 언어(\(\sigma^2/(\sigma^2+\lambda)\))로, 이 장은 주파수 언어(\(H_\lambda(\omega)\))로 했을 뿐 — \(\sigma(\omega)^2\propto1/|\omega|\)를 넣으면 두 식이 같은 모양이 됩니다.

순투영을 ray-driven으로, 역투영을 그와 독립적으로 distance-driven으로 이산화했을 때 일어나는 일로 가장 알맞은 것은 무엇일까요?

  1. 둘 다 같은 연속 연산자를 근사하므로, 상수배까지 포함해 항상 \(\mathbf{B}=c\mathbf{A}^{\mathsf T}\) 관계가 유지된다.
  2. 화소 크기 \(\Delta x\)를 \(0\)으로 보내면 이 차이는 항상 사라진다.
  3. 이 경우에는 반드시 ART 갱신만 발산하고 SIRT 갱신은 항상 수렴한다.
  4. 두 이산화는 근사 방식이 달라, \(\mathbf{B}\)가 어떤 상수를 곱해도 \(\mathbf{A}^{\mathsf T}\)와 같아지지 않을 수 있다(unmatched).

반대로 양쪽을 같은 모델로(또는 on-the-fly로 같은 가중치를 공유해서) 이산화하면 상수배 관계가 지켜집니다 (페이지 7). 어긋남은 모델 자체의 차이에서 오지, 격자를 촘촘히 한다고 저절로 사라지지 않습니다.

  1. (심화) \(\lambda=0.5\ \mathrm{cm}\)일 때 \(H_\lambda(\omega)=|\omega|/(1+\lambda|\omega|)\)를 \(\omega=1,\ 10,\ 100\ \mathrm{cm}^{-1}\)에서 각각 계산하고, 순수 램프 필터 \(|\omega|\)와 비교하세요.
  2. (심화) \(\Delta x=0.5\ \mathrm{cm}\), \(N_\theta=60\)(\(\Delta\theta=\pi/60\)), \(\Delta s=0.4\ \mathrm{cm}\)인 격자에서 페이지 7의 비례상수 \(\Delta\theta\,\Delta s/(\Delta x)^2\)를 계산하세요.
  3. (심화) \(\partial\mu/\partial(\text{시간})=-\nabla J[\mu]\)에서 \(J[\mu]=\lVert\mathcal{P}\mu-p\rVert^2\)(정규화 없음)일 때, 이 흐름을 시간 간격 \(\Delta t\)로 명시적 오일러법으로 이산화하고 \(\tau=2\Delta t\)로 두면 페이지 3의 어떤 식이 나오는지 써 보세요.
모범답안과 흔한 실수

1번. \(H_{0.5}(1)=1/(1+0.5)=0.667\)(순수 램프 \(1\)), \(H_{0.5}(10)=10/(1+5)=1.667\)(순수 램프 \(10\)), \(H_{0.5}(100)=100/(1+50)\approx1.961\)(순수 램프 \(100\)). 비율(\(H_\lambda/|\omega|\))은 \(0.667,\ 0.167,\ 0.0196\)으로 주파수가 커질수록 작아지고, \(H_\lambda\)는 \(\omega\to\infty\)에서 \(1/\lambda=2\)에 가까워집니다 — 고주파일수록 억제 효과가 커지고, 결국 상한에 머뭅니다.

2번. \(\Delta\theta\,\Delta s/(\Delta x)^2=(\pi/60)(0.4)/(0.5)^2\approx0.05236\times0.4/0.25\approx0.0838\)입니다. 순투영을 ray-driven으로, 역투영을 화소 중심 최근접으로(같은 방식으로) 이산화했다면, 역투영 결과 \(\mathbf{B}\)를 \(\mathbf{A}^{\mathsf T}\) 자리에 쓰면 걸음이 \(0.0838\)배(약 \(1/11.9\))로 줄어듭니다.

3번. \(\mu^{(k+1)}=\mu^{(k)}+\Delta t\cdot(-\nabla J[\mu^{(k)}])=\mu^{(k)}-2\Delta t\,\mathcal{B}(\mathcal{P}\mu^{(k)}-p)=\mu^{(k)}+2\Delta t\,\mathcal{B}(p-\mathcal{P}\mu^{(k)})\)입니다. 페이지 3의 \(\tau:=2\alpha\) 규약을 시간 간격에도 적용해 \(\Delta t=\alpha\)로 두면(\(\tau=2\Delta t\)), 정확히 페이지 3의 \(\mu^{(k+1)}=\mu^{(k)}+\tau\mathcal{B}(p-\mathcal{P}\mu^{(k)})\)가 됩니다 — Landweber 반복은 이 흐름을 시간 간격 \(\alpha\)로 이산화한 명시적 오일러법입니다.

흔한 실수.

  • 1번에서 \(H_\lambda(\omega)\)가 \(\omega\to\infty\)에서 \(0\)으로 간다고 착각하는 것입니다. \(H_\lambda\)는 램프 필터보다 훨씬 천천히 커지다가 \(1/\lambda\)에서 거의 멈추는 것이지, \(0\)이 되는 것이 아닙니다(\(0\)이 되는 자리는 \(\omega=0\) 한 점뿐입니다).
  • 2번에서 \(\Delta\theta\)에 \(N_\theta\)를 바로 곱하거나(\(\Delta\theta\)는 \(\pi/N_\theta\)이지 \(N_\theta\) 자체가 아닙니다), \(\Delta x\)를 제곱하지 않고 쓰는 것입니다.
  • 3번에서 \(\tau=2\alpha\)(3장 페이지 10)와 이 장 자체의 \(2\)(기울기의 계수)를 혼동해, \(\Delta t=\tau\)로 바로 두고 식에 \(4\)가 곱해진 답을 내는 것입니다.
