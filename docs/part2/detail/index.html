CT 재구성 알고리즘 2편

CT 재구성 알고리즘2 - 대수적 재구성편

재구성을 연립방정식 Ax = b로 세우고, 반복 계산으로 푸는 방법을 배웁니다.
ART·SIRT 같은 고전적 반복법에서 TV 기반 압축 센싱(GPBB·ASD-POCS) 재구성까지 다루며, 9장(심화)에서 다른 최적화 방식을 살피고, 마지막 두 장(심화)에서는 같은 내용을 연속 모델로 다시 봅니다.

대상 독자 0편(기초편)을 읽었고 1편의 투영·역투영·FBP를 알며, 선형대수의 기초를 배운 적이 있는 분에게 맞습니다. 주 참고서는 참고문헌 페이지에 있습니다.

읽기 전에

페이지 머리에 "심화"가 붙은 페이지는 처음 읽을 때 건너뛰어도 됩니다. 먼저 0편 — 기초편에서 CT의 물리 모델과 재구성의 두 갈래를, 이어서 1편 — 해석적 재구성편에서 해석적 재구성을 읽어 두면 좋습니다. 특히 1편의 투영과 역투영, 내적(4장)이 2편의 바탕이 됩니다. 행렬 도구(랭크, 최소제곱, SVD·조건수)는 3장에서 최적화 기초와 함께 복습하고, 6장에서 최적화 알고리즘으로서의 GPBB를 배우고, 8장에서 잡음 크기를 제약으로 쓰는 ASD-POCS를 배웁니다.
