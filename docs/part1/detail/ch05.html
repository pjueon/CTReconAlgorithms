5장 · 페이지 1

필터 역투영(FBP) 공식 유도해 보기 (연속)

4장에서는 투영마다 \(|\omega|\)를 곱한 뒤 역투영하면 값이 고르게 쌓인다는 직관을 얻었습니다. 이 장에서는 그 직관을 식으로 확인합니다. 푸리에 슬라이스 정리와 좌표변환만으로 필터 역투영(FBP)의 공식을 유도하고, 이 식이 정확히 성립하는 조건과 깨지는 경우, 실제 데이터에서 필터를 고쳐 쓰는 이유를 봅니다.

FBP 공식

평행빔 투영 \(p(\theta, s)\)가 \(0 \le \theta < \pi\)의 모든 각도와 모든 검출기 위치 \(s\)에서 주어지면, 영상 \(\mu(x, y)\)는 다음 두 식으로 얻어집니다.

\[\begin{aligned}q(\theta, s) &= \int_{-\infty}^{\infty} P_\theta(\omega)\,|\omega|\,e^{i2\pi\omega s}\,d\omega,\\ \mu(x, y) &= (\mathcal{B}q)(x, y)\\ &= \int_{0}^{\pi} q(\theta,\ x\cos\theta + y\sin\theta)\,d\theta\end{aligned}\]

  • \(P_\theta(\omega)\)는 각도 \(\theta\)의 투영 \(p(\theta, s)\)를 \(s\)에 대해 1차원 푸리에 변환한 것입니다(4장 페이지 1).
  • \(|\omega|\)는 램프 필터의 주파수 응답입니다. \(P_\theta(\omega)\)에 이것을 곱해 역변환한 \(q(\theta, s)\)가 필터링한 투영입니다(4장 페이지 8).
  • \(\mathcal{B}\)는 역투영입니다(4장 페이지 6). 점 \((x, y)\)를 지나는 광선의 검출기 좌표는 각도마다 \(s = x\cos\theta + y\sin\theta\)입니다.
  • 식에 \(2\pi\)나 \(1/2\) 같은 상수는 붙지 않습니다. 2장에서 정한 푸리에 규약(\(\omega\)는 1 cm당 반복 횟수이고 \(2\pi\)는 지수 안)을 쓰기 때문입니다.

한 줄 요약

투영마다 1차원 푸리에 변환에 \(|\omega|\)를 곱해 필터링하고, 그 결과를 역투영해 모든 각도에 대해 더하면 영상이 됩니다.

4장 페이지 8에서는 각도 \(K\)개의 직선 사이 간격이 \(\pi|\omega|/K\)라는 것에서 \(|\omega|\)를 곱해야 한다는 직관을 얻었습니다. 그 논증은 각도가 유한한 경우의 어림이었습니다. 이 장은 같은 결론을 좌표변환의 야코비안으로 다시 얻고, 곱하는 상수가 왜 1인지, 식이 어떤 조건에서 정확히 영상이 되는지를 확인합니다.

이 식은 \(\omega\)와 \(s\)를 모든 실수에 대해 적분합니다. 실제 장치는 검출기 폭이 유한하므로, 이 식이 그대로 성립하는지와 유한한 물체와 시야(FOV)의 관계는 페이지 10~11에서 따로 확인합니다.

이 장의 진행

처음 읽을 때는 머리에 "심화"가 붙은 페이지(7, 8, 12)를 건너뛰어도 FBP의 핵심은 이해됩니다. FBP 공식과 그 의미는 페이지 1~6에 있고, 페이지 9~11은 필터를 실제로 고르는 법과 데이터가 모자랄 때의 한계를 다룹니다. 페이지 9~11은 첫머리의 상자에 페이지 7~8에서 가져다 쓰는 결과를 정리해 두었으므로 7~8을 읽지 않아도 이어서 읽을 수 있습니다. 페이지 7~9의 결과는 6장에서 가져다 씁니다.

  1. 푸리에 평면의 극좌표 변수변환에서 \(|\omega|\)가 나오는 과정을 따라가 FBP 공식을 유도합니다(페이지 2~3).
  2. 알고리즘의 순서와 램프 필터가 하는 일을 봅니다(페이지 4~5).
  3. 필터 없이 역투영하면 왜 흐린지, \(|\omega|\)를 곱하면 왜 되돌아오는지를 식으로 봅니다(페이지 6).
  4. 필터를 공간 영역의 컨볼루션으로 쓰는 방법을 봅니다(페이지 7, 심화).
  5. \(|\omega|\)를 그대로 쓰기 어려운 이유(잡음)와 윈도우 필터를 봅니다(페이지 8~9. 페이지 8은 심화).
  6. 작은 검출기로 찍으면 안쪽이 정확히 재구성되는지, 식이 정확히 성립하는 조건과 각도가 모자라거나 검출기가 물체를 덮지 못할 때의 한계를 봅니다(페이지 10~11).
  7. 필터링을 다르게 쓰는 유도 하나를 소개합니다(페이지 12, 심화).
  8. 요약, 퀴즈, 직접 해보기(페이지 13)

5장 · 페이지 2

푸리에 평면의 극좌표 변수변환

푸리에 슬라이스 정리는 영상의 2차원 푸리에 변환 \(F\)를, 원점을 지나는 직선 위에서 읽은 값 \(P_\theta(\omega) = F(\omega\cos\theta,\ \omega\sin\theta)\)로 알려 줍니다(4장 페이지 2). 영상을 되찾는 적분이 이 직선들을 따라 쓰여 있으면 투영 데이터를 바로 넣을 수 있습니다. 그렇다면 2장에서 본 2차원 역변환을 어떻게 직선을 따라 쓸 수 있을까요?

주파수 평면의 좌표를 극좌표로 바꾸면 됩니다. 2차원 역변환은 다음과 같고(2장 페이지 6), 이 식에는 직교 좌표 \((\omega_x, \omega_y)\)가 쓰였습니다.

\[\mu(x, y) = \iint F(\omega_x, \omega_y)\,e^{i2\pi(\omega_x x + \omega_y y)}\,d\omega_x\,d\omega_y\]

\(\omega_x = \omega\cos\theta,\ \omega_y = \omega\sin\theta\)로 바꾸면 2장 페이지 6의 극좌표 형태가 됩니다. 지수는 \(\omega(x\cos\theta + y\sin\theta)\)가 되어, 점 \((x, y)\)를 지나는 각도 \(\theta\)의 광선의 검출기 좌표 \(s = x\cos\theta + y\sin\theta\)를 써서 \(\omega s\)로 쓸 수 있습니다.

\[\mu(x, y) = \int_{0}^{2\pi}\!\!\int_{0}^{\infty} F(\omega\cos\theta,\ \omega\sin\theta)\,e^{i2\pi\omega s}\,\omega\,d\omega\,d\theta,\qquad s = x\cos\theta + y\sin\theta \tag{A}\]

이 식에서 \(\omega\,d\omega\,d\theta\)는 극좌표의 야코비안에서 나왔습니다(1장 페이지 2). 아래 그림은 이 인자의 뜻을 보여 줍니다.

반 바퀴로 접기

식 (A)에서 \(\theta\)는 \(0\)부터 \(2\pi\)까지 한 바퀴를 돕니다. 그런데 \(\theta\)와 \(\theta + \pi\)는 같은 직선을 서로 반대쪽에서 읽습니다. 4장 페이지 2에서 본 것처럼 \(P_{\theta+\pi}(\omega) = P_\theta(-\omega)\)입니다. 그러므로 \(\theta\)를 \(0\)부터 \(\pi\)까지만 돌리고, 대신 \(\omega\)가 음수인 쪽도 포함하면 같은 적분이 됩니다.

\[\mu(x, y) = \int_{0}^{\pi}\!\!\int_{-\infty}^{\infty} F(\omega\cos\theta,\ \omega\sin\theta)\,e^{i2\pi\omega s}\,|\omega|\,d\omega\,d\theta,\qquad s = x\cos\theta + y\sin\theta \tag{B}\]

  • \(\omega\)의 범위가 \(0 \le \omega < \infty\)에서 \(-\infty < \omega < \infty\)로 바뀌고, \(\theta\)의 범위는 \(0 \le \theta < \pi\)로 줄었습니다.
  • 야코비안 자리의 \(\omega\)가 \(|\omega|\)로 바뀝니다. 넓이는 음수가 될 수 없으므로, \(\omega\)가 음수인 쪽에서도 곱해지는 인자는 양수여야 합니다.
식 (A)에서 식 (B)로 넘어가는 전개

1단계. 적분 구간 나누기. \(\theta\)에 대한 적분을 \(0 \le \theta < \pi\)와 \(\pi \le \theta < 2\pi\)로 나눕니다. 앞의 절반은 그대로 둡니다.

2단계. 뒤의 절반에서 각도 바꾸기. \(\theta = \theta' + \pi\)로 놓으면 \(\theta'\)는 \(0\)부터 \(\pi\)까지입니다. \(\cos(\theta' + \pi) = -\cos\theta'\), \(\sin(\theta' + \pi) = -\sin\theta'\)이므로 다음이 됩니다.

\[\begin{aligned}F(\omega\cos\theta,\ \omega\sin\theta) &= F(-\omega\cos\theta',\ -\omega\sin\theta'),\\ \omega(x\cos\theta + y\sin\theta) &= -\omega\,(x\cos\theta' + y\sin\theta')\end{aligned}\]

3단계. 부호 바꾸기. \(\omega' = -\omega\)로 놓으면 \(0 \le \omega < \infty\)는 \(-\infty < \omega' \le 0\)이 됩니다. 앞 단계의 두 식은 \(F(\omega'\cos\theta',\ \omega'\sin\theta')\)와 \(\omega'(x\cos\theta' + y\sin\theta')\)가 됩니다.

4단계. 야코비안 바꾸기. 변수 \(\omega\)에 대한 적분 \(\int_0^\infty g(\omega)\,\omega\,d\omega\)에서 \(\omega = -\omega'\)이면 \(d\omega = -d\omega'\)이고 적분 구간의 방향이 뒤집힙니다. 두 부호가 상쇄하고 \(\omega = -\omega' = |\omega'|\)이므로 다음과 같습니다.

\[\int_{0}^{\infty} g(\omega)\,\omega\,d\omega = \int_{-\infty}^{0} g(-\omega')\,|\omega'|\,d\omega'\]

5단계. 합치기. 뒤의 절반은 같은 \(\theta'\)에서 \(\omega'\)가 \(-\infty\)부터 \(0\)까지인 적분이 되고, 앞의 절반은 \(\omega\)가 \(0\)부터 \(\infty\)까지입니다. 두 적분의 피적분 함수가 같은 꼴 \(F(\omega\cos\theta,\ \omega\sin\theta)\,e^{i2\pi\omega s}\,|\omega|\)이므로, \(\omega\)가 \(-\infty\)부터 \(\infty\)까지인 하나의 적분으로 합쳐집니다. 이것이 식 (B)입니다.

4장의 직관과의 연결

4장 페이지 8에서는 각도 \(K\)개가 직선 사이 간격 \(\pi|\omega|/K\)를 만든다는 것에서 \(|\omega|\)를 곱해야 한다고 보았습니다. 같은 사실이 식 (B)에서는 극좌표의 넓이 요소 \(|\omega|\,d\omega\,d\theta\)로 나타납니다. \(\Delta\theta = \pi/K\)인 직선 하나가 맡는 조각의 넓이가 \(|\omega|\,\Delta\theta\,d\omega\)이고, 각도 \(K\)개를 더하는 \(\sum_k \Delta\theta\)가 \(K \to \infty\)에서 \(\int_0^\pi d\theta\)가 됩니다. 그러므로 \(|\omega|\)를 곱하는 것은 직관이 아니라 변수변환에서 나오는 정확한 인자입니다.

5장 · 페이지 3

램프 필터 \(|\omega|\)는 어디서 나왔을까요? 슬라이스 정리의 대입

페이지 2의 마지막 결론은 식 (B)였습니다. 이 식에는 영상의 푸리에 변환 \(F\)가 들어 있습니다. 측정한 것은 \(F\)가 아니라 투영이므로, 푸리에 슬라이스 정리 \(F(\omega\cos\theta,\ \omega\sin\theta) = P_\theta(\omega)\)를 넣어 \(F\)를 \(P_\theta\)로 바꿉니다. 식 (B)는 \(\omega\)가 음수인 쪽까지 포함하는데, 슬라이스 정리도 \(\omega\)가 실수 전체에서 성립합니다(4장 페이지 2).

\[\begin{aligned} \mu(x, y) &= \int_{0}^{\pi}\int_{-\infty}^{\infty} F(\omega\cos\theta,\ \omega\sin\theta)\,|\omega|\,e^{i2\pi\omega s}\,d\omega\,d\theta \qquad \text{(식 (B))} \\[1.4ex] &= \int_{0}^{\pi}\left[\int_{-\infty}^{\infty} P_\theta(\omega)\,|\omega|\,e^{i2\pi\omega s}\,d\omega\right]_{s = x\cos\theta + y\sin\theta} d\theta \qquad \text{(슬라이스 정리: } F \to P_\theta\text{)} \end{aligned}\]

대괄호 안의 적분은 각도 \(\theta\)마다 \(s\)의 함수입니다. 이 함수에 이름을 붙이겠습니다. \(P_\theta(\omega)\)에 \(|\omega|\)를 곱한 것을 \(Q_\theta(\omega)\)라고 하면 \(Q_\theta(\omega) = |\omega|P_\theta(\omega)\)이고, 대괄호 안은 \(Q_\theta\)의 1차원 역변환입니다. 이것이 4장 페이지 8에서 예고한 \(q(\theta, s)\)입니다.

\[q(\theta, s) = \int_{-\infty}^{\infty} Q_\theta(\omega)\,e^{i2\pi\omega s}\,d\omega = \int_{-\infty}^{\infty} P_\theta(\omega)\,|\omega|\,e^{i2\pi\omega s}\,d\omega\]

이제 \(\mu\)는 \(\theta\)마다 \(q\)를 \(s = x\cos\theta + y\sin\theta\)에서 읽어 \(0\)부터 \(\pi\)까지 더한 값입니다. 이 연산이 역투영 \(\mathcal{B}\)이므로(4장 페이지 6), 페이지 1의 FBP 공식이 얻어집니다.

\[\mu(x, y) = \int_{0}^{\pi} q(\theta,\ x\cos\theta + y\sin\theta)\,d\theta = (\mathcal{B}q)(x, y)\]

필터의 정체

\(P_\theta(\omega)\)에 \(|\omega|\)를 곱하는 일을, 주파수 성분마다 정해진 배수를 곱하는 필터링이라고 합니다(4장 페이지 8). 곱하는 배수 \(|\omega|\)를 주파수 응답으로 가지는 필터가 램프 필터(Ramp Filter)입니다. 이 필터는 Ram-Lak 필터라고도 부르는데, 엄밀히 Ram-Lak은 \(|\omega|\)를 \(W\)에서 자른 형태를 가리킵니다. 이 필터는 영상을 더 선명하게 하려고 설계한 것이 아닙니다. 페이지 2의 변수변환에서 야코비안으로 나온 인자가 그대로 필터가 됩니다.

  • 필터를 곱하는 곳은 \(F\)가 아니라 투영의 푸리에 변환 \(P_\theta\)입니다. 슬라이스 정리 덕분에 이 둘은 같은 값이고, 투영만으로 필터링할 수 있습니다.
  • 필터링은 검출기 방향의 1차원 계산입니다. 영상은 2차원이지만 2차원 푸리에 변환이나 보간은 필요하지 않습니다(직접 푸리에 재구성처럼 극좌표 위의 값을 직교 격자로 보간하고 2차원 역푸리에 변환을 할 필요가 없습니다. 자세한 비교는 4장 페이지 4, 심화).
  • \(P_\theta\)는 2장의 규약에서 \(\int p\,e^{-i2\pi\omega s}\,ds\)이고, 역변환에도 상수가 붙지 않으므로 곱하는 상수는 정확히 1입니다.

왜 꼭 \(|\omega|\)를 곱해야 할까요?

필터 없이 투영을 그대로 역투영하면 점 하나도 영상 전체에 \(1/r\)로 번져서 흐려집니다. 주파수로 보면 영상의 푸리에 변환 \(F\)가 \(F/|\omega|\)로 바뀐 것이어서, 낮은 주파수는 부풀고 윤곽을 만드는 높은 주파수는 줄어든 상태입니다. 여기에 \(|\omega|\)를 곱하면 정확히 원래의 \(F\)로 돌아옵니다.

유도의 가정

  1. \(0 \le \theta < \pi\)의 모든 각도, 모든 검출기 위치 \(s\)에서 투영값이 있습니다.
  2. 투영값에 오차나 잡음이 없습니다.
  3. \(\mu\)가 적분 가능하고 유한한 영역 밖에서 0이어서 푸리에 변환들이 존재하고, 적분 순서를 바꾸어도 됩니다.
  4. 필터가 \(|\omega|\)를 어떤 주파수에서도 자르지 않고 그대로 곱합니다.

가정 3에서 경계가 불연속인 영상이 수렴하는 방식까지 다루지는 않습니다.

식이 맞는지 계산 하나로 확인할 수 있습니다. 반지름 \(R\)이고 값이 1인 원판의 투영을 필터링하면 원판 안의 모든 \(s\)에서 \(q = 1/\pi\)가 됩니다. 원판 안의 어느 점에서도 모든 각도의 광선이 원판 안을 지나므로 \(\mu = \int_0^\pi (1/\pi)\,d\theta = 1\)로, 원판의 값과 정확히 같습니다.

다른 책의 표기

각주파수 \(\Omega = 2\pi\omega\)를 쓰는 책에서는 투영의 푸리에 변환을 \(\tilde{P}_\theta(\Omega) = \int p\,e^{-i\Omega s}\,ds\)로 쓰고, 상수가 붙은 다음 식이 나옵니다. \(\omega = \Omega/(2\pi)\)로 바꾸면 이 책의 식과 같은 식입니다.

\[\mu(x, y) = \frac{1}{4\pi^{2}}\int_{0}^{\pi}\!\!\int_{-\infty}^{\infty} \tilde{P}_\theta(\Omega)\,|\Omega|\,e^{i\Omega s}\,d\Omega\,d\theta\]

또 \(\theta\)를 \(0\)부터 \(2\pi\)까지 쓰는 책(팬빔 식 등)에서는 같은 직선을 두 번 더하므로 앞에 \(1/2\)이 붙습니다. 허수 단위를 \(j\)로 쓰는 책도 있습니다.

필터링과 역투영의 순서

페이지 3의 공식을 계산 순서로 바꾸면 아래 의사코드가 됩니다. 연속 데이터를 가정한 것입니다.

필터 역투영(연속)의 의사코드입력  p(θ, s)    (0 ≤ θ < π, 모든 s)
출력  μ(x, y)

 1  μ(x, y) ← 0
 2  각 각도 θ 에 대해 되풀이한다:
 3      P(ω) ← p(θ, ·) 의 1차원 푸리에 변환
 4      Q(ω) ← |ω| · P(ω)
 5      q(s) ← Q(ω) 의 1차원 역변환
 6      영상의 모든 점 (x, y) 에 대해:
 7          μ(x, y) ← μ(x, y) + q(x cosθ + y sinθ) · dθ
  1. 1행 영상을 0으로 시작해서 각도마다 더해 갑니다. 각도 하나를 처리한 뒤에는 그 각도의 투영을 버려도 됩니다.
  2. 3~5행 각도 \(\theta\) 하나의 필터링, 곧 sinogram의 행 하나를 처리하는 일입니다. 세 줄 모두 검출기 방향(\(s\))의 1차원 계산이고, 5행의 \(q(s)\)는 \(q(\theta, s)\)입니다.
  3. 6~7행 역투영입니다. 점마다 그 점을 지나는 광선의 좌표 \(s = x\cos\theta + y\sin\theta\)에서 \(q\)를 읽어 더합니다. \(d\theta\)는 각도 간격이고, 연속에서는 적분의 미소량입니다.

이 순서에는 4장에서 본 직접 푸리에 재구성과 다른 점이 있습니다.

  • 각도마다 따로 처리합니다. 각도 하나의 측정이 끝나면 바로 필터링하고 영상에 더할 수 있어서, 모든 각도가 모일 때까지 기다리지 않아도 됩니다(직접 푸리에 재구성과의 비교는 4장 페이지 4, 심화).
  • 필터링이 1차원입니다. 영상 격자에서 푸리에 변환하거나 극좌표 격자를 보간하지 않습니다(직접 푸리에 재구성과의 비교는 4장 페이지 4, 심화).
  • 영상의 점끼리 서로 독립입니다. 6~7행은 점마다 따로 계산해도 됩니다.

필터링과 역투영을 반대 순서로 하는 방법도 있습니다. 투영을 먼저 역투영하고 그 영상에 2차원 필터를 적용하는 것인데, 같은 결과를 줍니다.

램프 필터의 효과

램프 필터는 투영의 주파수 성분마다 \(|\omega|\)를 곱합니다. 이 곱셈이 투영 곡선을 어떻게 바꾸는지 먼저 정리하고, 원판 하나로 계산해서 확인합니다.

세 가지 효과

  • 직류 성분의 제거. \(\omega = 0\)에서 \(|\omega| = 0\)이므로 \(Q_\theta(0) = 0\)이고, 2장 페이지 3의 원점 값 성질에 따라 \(\int q(\theta, s)\,ds = Q_\theta(0) = 0\)입니다. 투영값은 모두 0 이상이지만 필터링한 \(q\)에는 음수인 부분이 반드시 있습니다.
  • 높은 주파수의 강조. 주파수가 2배, 4배가 되면 곱해지는 값도 2배, 4배가 됩니다. 경계처럼 급하게 변하는 부분은 강조되고, 완만하게 변하는 부분은 상대적으로 줄어듭니다. 투영에 섞인 잡음의 높은 주파수 성분도 함께 커집니다.
  • 경계 바깥의 음수. 앞의 두 효과가 합쳐지면, \(q\)는 물체의 경계 근처에서 크게 흔들리고 경계 바로 바깥에서 음수로 내려갑니다.

원판 하나의 필터링한 투영

반지름 \(R\), 값 1인 원판의 투영은 \(p(\theta, s) = 2\sqrt{R^{2} - s^{2}}\ (|s| < R)\)입니다. 중심에서 거리 \(s\)인 광선이 원판을 지나는 구간(현)의 길이가 \(2\sqrt{R^{2} - s^{2}}\)이고, 값이 1이므로 선적분은 이 길이와 같습니다. 원판은 어느 방향에서 보아도 같으므로 각도 \(\theta\)에 관계없습니다. 이 투영에 램프 필터를 적용한 결과는 다음과 같습니다.

\[q(\theta, s) = \begin{cases} \dfrac{1}{\pi} & (|s| < R) \\[2ex] \dfrac{1}{\pi}\left(1 - \dfrac{|s|}{\sqrt{s^{2} - R^{2}}}\right) & (|s| > R) \end{cases}\]

  • 원판 안쪽에서는 \(R\)에 관계없이 \(1/\pi \approx 0.318\)로 일정합니다.
  • 경계에 안쪽에서 다가갈 때는 \(1/\pi\)로 유한하지만, 바깥쪽에서 다가갈 때는 \(-\infty\)로 내려갑니다. 이 발산은 적분 가능합니다.
  • 경계에서 멀어지면 바깥쪽의 값은 \(-R^{2}/(2\pi s^{2})\)에 가까워지며 0으로 돌아옵니다.
원판의 필터링한 투영의 넓이 계산

1단계. 안쪽. \(|s| < R\)에서 \(q = 1/\pi\)이므로 \(\displaystyle\int_{-R}^{R} q\,ds = \frac{2R}{\pi}\)입니다.

2단계. 바깥쪽. \(s > R\)와 \(s < -R\)는 대칭이므로 \(s > R\)만 계산해 2배 합니다. 미분해 보면 \(\dfrac{d}{ds}\bigl(s - \sqrt{s^{2} - R^{2}}\bigr) = 1 - \dfrac{s}{\sqrt{s^{2} - R^{2}}}\)이므로 다음이 성립합니다.

\[2\int_{R}^{\infty} \frac{1}{\pi}\left(1 - \frac{s}{\sqrt{s^{2} - R^{2}}}\right) ds = \frac{2}{\pi}\Bigl[s - \sqrt{s^{2} - R^{2}}\Bigr]_{R}^{\infty} = \frac{2}{\pi}\,(0 - R) = -\frac{2R}{\pi}\]

\(s \to \infty\)에서 \(s - \sqrt{s^{2} - R^{2}} \to 0\)이고 \(s = R\)에서는 \(R\)입니다.

3단계. 합. 안쪽의 \(2R/\pi\)와 바깥쪽의 \(-2R/\pi\)가 상쇄하여 \(\int q\,ds = 0\)입니다. 필터를 적용하기 전의 넓이는 원판의 넓이 \(\pi R^{2}\)였지만, 필터링하면 넓이가 사라지고 안쪽의 양수와 바깥쪽의 음수만 남습니다.

음수 값의 역할

FBP는 \(q\)를 광선 방향으로 칠해서 더합니다(4장 페이지 5). 한 각도에서 보면 원판을 지나는 광선에는 양수가, 원판 바로 옆을 지나는 광선에는 음수가 칠해집니다. 원판 바깥의 점은 각도에 따라 두 경우를 모두 받습니다. 어떤 각도에서는 원판을 지나는 광선 위에 있어 양수를 받고, 다른 각도에서는 원판 옆을 지나는 광선 위에 있어 음수를 받습니다.

아래 위젯에서 이것을 확인합니다. 왼쪽은 원판(\(R = 0.5\))의 \(p(s)\)와 \(q(s)\)입니다. 점 \((r, 0)\)을 고르면 오른쪽에 각도 \(\theta\)를 \(0\)부터 \(\pi\)까지 바꾸며 그 점을 지나는 광선의 \(q\)를 읽은 값 \(q(\theta,\ r\cos\theta)\)가 그려집니다. 이 곡선의 넓이가 그 점의 역투영 값입니다.

0.80

  • \(r < 0.5\)(원판 안). 모든 각도에서 광선이 원판 안을 지나므로 \(q = 1/\pi\)로 일정하고, 넓이 \(\pi \times (1/\pi) = 1\)은 원판의 값과 같습니다.
  • \(r > 0.5\)(원판 밖). 가운데 각도들에서는 광선이 원판을 지나 양수를 받고, 양 끝 각도들에서는 원판 옆을 지나 음수를 받습니다. 두 넓이가 같아서 합이 0입니다. 원판 바깥을 0으로 되돌리는 것은 이 음수입니다.

필터를 적용하지 않은 단순 역투영에서는 \(q\) 대신 \(p\)를 칠하므로 음수가 없고, 바깥의 점에는 양수만 쌓입니다(4장 페이지 9에서 본 물체 밖의 값). 이 쌓임을 지우는 것이 필터링한 투영의 음수입니다. 이 쌓임이 정확히 어떤 모양이고 \(|\omega|\)가 어떻게 이것을 되돌리는지는 다음 페이지에서 봅니다.

단순 역투영이 흐린 이유

4장 페이지 9에서 단순 역투영은 각도를 180개로 늘려도 흐렸습니다. 필터 역투영 공식에는 \(|\omega|\)를 곱하는 단계가 있습니다. 이 페이지에서는 거꾸로, 단순 역투영이 정확히 어떻게 흐린 영상을 만드는지 식으로 보고, \(|\omega|\)를 곱하는 것이 그 흐림을 되돌리는 계산임을 확인합니다.

점 하나의 단순 역투영

가장 단순한 영상은 점 하나입니다. 원점에 놓인 점 \(\mu(x, y) = \delta(x)\,\delta(y)\)의 투영은 모든 각도에서 \(p(\theta, s) = \delta(s)\)입니다(3장 페이지 3의 델타 표기). 이 투영을 단순 역투영하면 점에서 퍼져 나가는 영상이 나옵니다.

\[(\mathcal{B}p)(x, y) = \int_{0}^{\pi}\delta(x\cos\theta + y\sin\theta)\,d\theta = \frac{1}{r},\qquad r = \sqrt{x^{2} + y^{2}}\]

점 하나가 영상 전체에 \(1/r\)로 번집니다. 번진 정도는 \(r = 1\)에서 1, \(r = 2\)에서 0.5, \(r = 10\)에서 0.1이고, 점에서 멀어져도 천천히 줄어듭니다. 반지름 \(R\)인 원판 안의 번짐을 모두 더하면 \(\int_0^R (1/r)\,2\pi r\,dr = 2\pi R\)이어서, 범위를 넓힐수록 번짐의 총량이 커집니다. 점 하나를 영상에 넣었을 때 결과 영상에 나타나는 모양을 점 퍼짐 함수(Point Spread Function, PSF)라고 하고, 단순 역투영의 점 퍼짐 함수를 \(\psi(x, y) = 1/r\)로 쓰겠습니다. 램프 필터의 공간 커널 \(h\)와 다른 함수입니다.

점 하나의 단순 역투영 계산

1단계. 극좌표로 쓰기. 점 \((x, y) = (r\cos\varphi,\ r\sin\varphi)\)에서 \(x\cos\theta + y\sin\theta = r\cos(\theta - \varphi)\)입니다(3장 페이지 6). 구하는 값은 \(\int_0^\pi \delta\bigl(r\cos(\theta - \varphi)\bigr)\,d\theta\)입니다.

2단계. 델타 함수가 고르는 각도. \(\theta\)가 \([0, \pi)\)에서 움직일 때 \(\cos(\theta - \varphi) = 0\)이 되는 각도는 \(\theta - \varphi = \pm\pi/2\) 가운데 \([0, \pi)\) 안에 드는 하나뿐이고, 이를 \(\theta_0\)라고 하겠습니다. \(\theta_0\)에서 \(\theta\)에 대한 \(r\cos(\theta - \varphi)\)의 기울기는 \(-r\sin(\theta_0 - \varphi) = \mp r\)이므로 기울기의 크기는 \(r\)입니다.

3단계. 스케일 인자. 3장 페이지 3의 \(\delta(cx - b) = \delta(x - b/c)/|c|\)에서 \(|c| = r\)이므로 \(\delta\bigl(r\cos(\theta - \varphi)\bigr) = \delta(\theta - \theta_0)/r\)입니다. 이것을 \(\theta\)에 대해 적분하면 \(1/r\)이고, \(\varphi\)에는 관계없습니다. 점이 \((x_0, y_0)\)에 있으면 \(1/\sqrt{(x - x_0)^{2} + (y - y_0)^{2}}\)입니다.

아래 그림의 왼쪽은 이것을 수치로 확인한 것입니다. 점 대신 반지름 0.02인 작은 원판의 투영을 수치 적분으로 역투영해 원판의 넓이로 나눈 값(주황 점)이 \(1/r\)(파란 선)과 겹칩니다. 오른쪽은 다음 절에서 보는 주파수 쪽 그림입니다. 두 그림 모두 양쪽 눈금이 로그입니다.

컨볼루션 표현

투영과 역투영은 선형입니다. 영상을 점들의 합으로 보면, 영상 \(\mu\)의 투영을 단순 역투영한 결과는 점마다 자기 위치를 중심으로 한 \(\psi\)를 \(\mu\)의 값만큼 키워 더한 것입니다. 이것은 \(\mu\)와 \(\psi\)의 2차원 컨볼루션입니다.

\[\mathcal{B}\mathcal{P}\mu = \mu * \psi,\qquad (\mu * \psi)(x, y) = \iint \mu(t, u)\,\frac{1}{\sqrt{(x - t)^{2} + (y - u)^{2}}}\,dt\,du\]

2장 페이지 3에서 \(f * g\)는 \(g\)가 좁은 봉우리이면 \(f\)를 봉우리 폭만큼 흐린 함수라고 했습니다. \(\psi\)는 봉우리가 아니라 꼬리가 긴 함수여서 먼 곳까지 번지고, 그래서 4장 페이지 9에서 물체 바깥에도 값이 남았습니다.

주파수 영역의 번짐

컨볼루션은 주파수에서 곱입니다(2장 페이지 3의 컨볼루션 정리를 2장 페이지 6의 2차원 푸리에 변환에 쓴 것). 단순 역투영한 영상 \(g = \mathcal{B}\mathcal{P}\mu\)의 2차원 푸리에 변환을 \(G\)라고 하면, \(G\)는 \(F\)에 \(\psi\)의 푸리에 변환을 곱한 것입니다. 그 값은 페이지 2~3의 유도를 거꾸로 읽으면 바로 나옵니다.

\[g(x, y) = \int_0^\pi\!\!\int_{-\infty}^{\infty} P_\theta(\omega)\,e^{i2\pi\omega s}\,d\omega\,d\theta = \iint \frac{F(\omega_x, \omega_y)}{|\omega|}\,e^{i2\pi(\omega_x x + \omega_y y)}\,d\omega_x\,d\omega_y\]

  • 첫 번째 등호는 \(\mathcal{B}\)의 정의에 \(p\)의 1차원 역변환을 넣은 것입니다.
  • 두 번째 등호는 페이지 2의 극좌표 변환을 반대로 쓴 것입니다. \(d\omega\,d\theta = d\omega_x\,d\omega_y/|\omega|\)이고 \(P_\theta(\omega) = F(\omega\cos\theta,\ \omega\sin\theta)\)입니다.

그러므로 \(G(\omega_x, \omega_y) = F(\omega_x, \omega_y)/|\omega|\)이고, \(\psi\)의 푸리에 변환은 \(1/|\omega|\)입니다. 점 하나의 \(F\)는 1이므로 \(G = 1/|\omega|\)이고, 이것은 점의 역투영이 \(1/r\)이라는 앞의 결과와 같은 사실을 주파수 쪽에서 본 것입니다. 번짐의 크기는 \(\omega = 0.5\ \mathrm{cm}^{-1}\)에서 2, \(\omega = 2\ \mathrm{cm}^{-1}\)에서 0.5이어서, 높은 주파수 성분이 낮은 주파수에 비해 4배 줄어듭니다. 줄어든 높은 주파수는 윤곽의 선명함을 만드는 성분이므로 영상이 흐려집니다.

곱셈에 의한 복원

\(G = F/|\omega|\)이므로 \(|\omega|\)를 곱하면 \(F\)가 돌아옵니다. 곱하는 인자 \(|\omega|\)는 원점 한 점에서만 0이어서 정보를 잃지 않습니다. 곱하는 방법은 두 가지가 있습니다.

  1. 단순 역투영한 영상에 곱하기. \(\mathcal{B}p\)를 2차원 푸리에 변환하고 \(|\omega|\)를 곱한 뒤 역변환합니다.
  2. 투영마다 곱한 뒤 역투영하기. 필터링한 투영 \(q\)를 역투영합니다. 이것이 FBP입니다.

두 방법은 같은 결과를 줍니다. 4장 페이지 7에서 한 각도의 역투영은 주파수 평면의 원점을 지나는 직선 위에 \(P_\theta(\omega)\)를 놓는 일이었습니다. 이 직선 위의 점 \((\omega\cos\theta,\ \omega\sin\theta)\)에서 원점까지의 거리는 \(|\omega|\)이므로, 2차원 주파수 평면에서 거리를 곱하는 것은 직선 위의 값에 \(|\omega|\)를 곱하는 것과 같습니다.

첫 번째 방법은 \(\psi\)가 멀리까지 퍼지므로 계산할 영상 영역을 물체보다 훨씬 넓게 잡아야 하고, 영역을 자르면 오차가 생깁니다. 또 영상 전체에 대한 큰 2차원 푸리에 변환이 필요합니다. 두 번째 방법은 투영 하나(1차원)마다 필터링하므로 이런 부담이 없습니다. 이 때문에 CT에서는 두 번째 방법, 곧 FBP를 씁니다.

컨볼루션 커널로 쓴 램프 필터

핵심 결과

\(|\omega| \le W\)로 자른 램프 필터는 공간에서 커널 \(h_W(s) = 2W^{2}\,\mathrm{sinc}(2Ws) - W^{2}\,\mathrm{sinc}^{2}(Ws)\)와의 컨볼루션이고, 가운데(\(s = 0\))는 양수 봉우리 \(W^{2}\), 양옆은 천천히 줄어드는 음수 꼬리이며, 전체 넓이는 0입니다. 이 페이지의 나머지(성질, 닫힌 식 전개, 위젯)는 건너뛰어도 됩니다.

필터링은 주파수 영역에서 \(|\omega|\)를 곱하는 계산이었습니다. 2장 페이지 3의 컨볼루션 정리에 따르면 주파수의 곱은 공간의 컨볼루션과 같으므로, 같은 필터링을 공간 영역에서도 쓸 수 있습니다. 공간 영역의 필터링은 투영 \(p(\theta, \cdot)\)에 어떤 함수 \(h\)를 컨볼루션하는 계산이며, 이 \(h\)를 커널(Kernel)이라고 합니다.

형태계산식
주파수 영역푸리에 변환한 뒤 \(|\omega|\)를 곱하고 역변환\(Q_\theta(\omega) = |\omega|\,P_\theta(\omega)\)
공간 영역커널 \(h\)와 컨볼루션\(q(\theta, s) = \displaystyle\int p(\theta, t)\,h(s - t)\,dt\)

두 형태가 같으려면 \(h\)의 푸리에 변환이 \(|\omega|\)여야 합니다. 이 \(h\)를 구해 봅시다. \(h\)는 \(|\omega|\)를 역변환한 \(h(s) = \int |\omega|\,e^{i2\pi\omega s}\,d\omega\)입니다. 그런데 피적분 함수의 크기 \(|\omega|\)가 \(\omega\)가 커질수록 끝없이 커져서, 이 적분은 수렴하지 않습니다. 그래서 \(h\)는 보통의 함수로 구해지지 않습니다.

대역을 제한한 램프 필터의 커널

주파수 범위를 정해 주면 적분이 수렴합니다. \(|\omega| \le W\)인 곳에서만 \(|\omega|\)를 곱하고 그 밖에서는 0으로 하는 필터를 생각합니다. 이 책에서는 이것을 \(H_W(\omega)\)라고 쓰고, 그 커널을 \(h_W(s)\)라고 하겠습니다.

\[H_W(\omega) = \begin{cases} |\omega| & (|\omega| \le W) \\ 0 & (|\omega| > W) \end{cases}\]

\[h_W(s) = \int_{-W}^{W} |\omega|\,e^{i2\pi\omega s}\,d\omega = 2W^{2}\,\mathrm{sinc}(2Ws) - W^{2}\,\mathrm{sinc}^{2}(Ws)\]

\(\mathrm{sinc}(x) = \sin(\pi x)/(\pi x)\)는 2장의 정의입니다. 이 커널에는 다음 성질이 있습니다.

  • 모양은 \(W\)로 크기만 바뀝니다. \(h_W(s) = W^{2}\,h_1(Ws)\)이고, \(h_1(x) = 2\,\mathrm{sinc}(2x) - \mathrm{sinc}^{2}(x)\)는 \(W = 1\)일 때의 커널입니다. \(W\)를 키우면 폭은 \(1/W\)에 비례해 좁아지고 높이는 \(W^{2}\)에 비례해 커집니다.
  • 중심에 양수 봉우리가 있습니다. \(h_W(0) = W^{2}\)이고, 봉우리의 반치폭(Full Width at Half Maximum, FWHM, 높이가 절반이 되는 두 지점 사이의 폭)은 약 \(0.48/W\)입니다. 처음 0이 되는 곳은 \(s \approx \pm 0.37/W\)입니다.
  • 양옆에 음수 꼬리가 있습니다. 가장 깊은 곳은 \(s \approx \pm 0.65/W\)에서 약 \(-0.59\,W^{2}\)입니다. 멀리 가면 \(h_W(s) = \dfrac{W\sin(2\pi Ws)}{\pi s} - \dfrac{\sin^{2}(\pi Ws)}{\pi^{2}s^{2}}\)에서 첫 항은 진동하며 줄어들고, 둘째 항의 평균은 \(-1/(2\pi^{2}s^{2})\)입니다.
  • 넓이는 0입니다. \(\int h_W\,ds = H_W(0) = 0\)이므로 양수 봉우리와 음수 꼬리의 넓이가 같습니다. 페이지 5의 \(\int q\,ds = 0\)과 같은 사실입니다.

\(W\)를 한없이 키우면 첫 항은 아주 빠르게 진동해 평균이 0이 되고, \(s \ne 0\)에서 커널은 \(-1/(2\pi^{2}s^{2})\)에 가까워집니다. 반면 \(s = 0\)의 봉우리는 \(W^{2}\)처럼 한없이 커집니다. 극한의 \(h\)가 보통 함수가 아닌 것은 이 봉우리 때문입니다. 그래서 실제 계산에서는 어떤 \(W\)를 정해 \(h_W\)를 씁니다.

커널의 닫힌 식 전개

1단계. 짝함수로 정리하기. \(|\omega|\)는 짝함수이므로 허수부는 상쇄하고 코사인만 남습니다.

\[h_W(s) = 2\int_{0}^{W} \omega\cos(2\pi\omega s)\,d\omega\]

2단계. 부분적분. \(\omega\cos(2\pi\omega s)\)에서 \(\omega\)를 미분하고 \(\cos\)를 적분합니다.

\[2\int_{0}^{W} \omega\cos(2\pi\omega s)\,d\omega = 2\left[\frac{\omega\sin(2\pi\omega s)}{2\pi s}\right]_{0}^{W} - 2\int_{0}^{W}\frac{\sin(2\pi\omega s)}{2\pi s}\,d\omega\]

3단계. 남은 적분. \(\displaystyle\int_{0}^{W}\sin(2\pi\omega s)\,d\omega = \frac{1 - \cos(2\pi W s)}{2\pi s}\)이므로 다음이 됩니다.

\[h_W(s) = \frac{W\sin(2\pi Ws)}{\pi s} - \frac{1 - \cos(2\pi Ws)}{2\pi^{2}s^{2}}\]

4단계. sinc로 쓰기. 첫 항은 \(\dfrac{W\sin(2\pi Ws)}{\pi s} = 2W^{2}\,\dfrac{\sin(2\pi Ws)}{2\pi Ws} = 2W^{2}\,\mathrm{sinc}(2Ws)\)입니다. 둘째 항은 \(1 - \cos(2\pi Ws) = 2\sin^{2}(\pi Ws)\)를 써서 \(\dfrac{\sin^{2}(\pi Ws)}{\pi^{2}s^{2}} = W^{2}\,\mathrm{sinc}^{2}(Ws)\)입니다. 따라서 \(h_W(s) = 2W^{2}\,\mathrm{sinc}(2Ws) - W^{2}\,\mathrm{sinc}^{2}(Ws)\)이고, \(s = 0\)에서 \(2W^{2} - W^{2} = W^{2}\)입니다.

두 형태의 비교

아래 위젯의 왼쪽은 \(W\)에 따른 커널 \(h_W(s)\)입니다. 가로축은 \(\pm 6/W\) 범위이고, 세로축은 \(W^{2}\) 단위입니다. 점선은 먼 곳의 평균적인 꼬리 \(-1/(2\pi^{2}s^{2})\)입니다. 오른쪽은 페이지 5의 원판(\(R = 0.5\)) 투영에 필터를 적용한 \(q(s)\)입니다. 파란 선은 주파수 영역에서 \(H_W\)를 곱한 결과이고, 주황 점은 같은 간격 0.01 cm로 샘플한 \(p\)에 \(h_W\)를 직접 컨볼루션한 결과입니다.

20

  • 두 형태가 일치합니다. 파란 선과 주황 점이 겹치고, 안쪽에서의 차이는 \(10^{-2}\) 이하입니다. 남는 차이는 주파수 곱 쪽이 길이 10.24 cm의 배열이 반복된다고 보고 계산하기 때문이며(2장 페이지 5의 원형 컨볼루션), 배열을 늘리면 줄어듭니다.
  • \(W\)가 작을수록 곡선이 부드럽습니다. 중심 봉우리가 넓어져서 경계가 둥글어지고, 안쪽 값이 \(1/\pi\)(약 0.318) 둘레에서 출렁입니다. \(W\)를 키우면 이 출렁임은 경계 가까이의 더 좁은 구간으로 모이지만 없어지지는 않습니다.

5장 · 페이지 8 · 심화

차단 주파수와 잡음

핵심 결과

차단 주파수 \(W\)는 나이퀴스트 주파수 \(1/(2\Delta s)\) 이하여야 합니다. \(W\)를 올릴수록 해상도는 좋아지지만 백색잡음의 표준편차는 \(W^{3/2}\)에 비례해 커지고, 급하게 자르면 경계에 물결(링잉)이 생깁니다. 그래서 \(|\omega|\)를 서서히 줄이는 윈도우 필터를 씁니다(다음 페이지). 이 페이지의 나머지는 이 결과의 이유와 위젯입니다.

페이지 7에서 커널을 정하려면 차단 주파수 \(W\)가 필요했습니다. 그렇다면 \(W\)를 무한히 크게 둔 \(|\omega|\)를 실제 데이터에 그대로 쓰면 안 되는 이유는 무엇일까요? 이유는 세 가지입니다.

이유 1. 커널이 보통의 함수로 존재하지 않음

페이지 7에서 본 대로 \(|\omega|\)를 끝없이 곱한 필터의 역변환은 적분이 수렴하지 않아서, 공간 영역의 커널 \(h\)를 보통의 함수로 쓸 수 없습니다. 컨볼루션으로 계산하려면 \(W\)로 잘라서 \(h_W\)를 만들어야 합니다. 다만 연속 FBP 식 자체는 \(W\) 없이도 성립합니다. 식에서 적분되는 것은 \(P_\theta(\omega)|\omega|\)이고, 매끄러운 물체의 \(P_\theta\)는 높은 주파수에서 빠르게 줄어 수렴하기 때문입니다. 또 \(|\omega|\)의 역변환은 일반화 함수로는 존재하며(먼 곳의 꼬리 \(-1/(2\pi^{2}s^{2})\)). 그러므로 이 이유는 "수식이 틀려서"가 아니라 "커널을 실제로 계산하려면 잘라야 해서"입니다.

이유 2. 나이퀴스트 주파수

검출기 간격이 \(\Delta s\)이면 투영을 \(\Delta s\)마다 샘플링한 것이므로, 담을 수 있는 가장 높은 주파수는 나이퀴스트 주파수 \(1/(2\Delta s)\)입니다(2장 페이지 4). 그 위의 주파수 성분은 샘플링한 뒤 낮은 주파수로 섞여 들어가 에일리어싱이 되고, 되돌릴 수 없습니다. 그러므로 실제로 곱할 수 있는 범위는 \(W \le 1/(2\Delta s)\)입니다.

이유 3. 잡음의 증폭

투영값에는 측정 잡음이 섞여 있습니다(0편 2장 페이지 8). 검출기 칸마다 독립이므로 잡음은 모든 주파수에 비슷한 세기로 들어 있다고 볼 수 있고, 이런 잡음을 백색잡음(White Noise)이라고 합니다. 반면 물체의 투영은 주파수가 높아질수록 줄어듭니다. 그래서 어떤 주파수부터는 신호보다 잡음이 큽니다. 램프 필터는 높은 주파수일수록 크게 곱하므로 신호가 없는 높은 주파수의 잡음을 가장 많이 키웁니다.

크기를 계산해 봅니다. 잡음의 스펙트럼 밀도(Spectral Density)를 모든 주파수에서 \(N_0\)로 두면, \(|\omega| \le W\)의 램프 필터를 거친 뒤 \(q\)에 남는 잡음의 분산은 다음과 같습니다.

\[\mathrm{Var} = N_0\int_{-W}^{W} \omega^{2}\,d\omega = \frac{2}{3}\,N_0\,W^{3}\]

표준편차는 분산의 제곱근이므로 \(W^{3/2}\)에 비례합니다. \(W\)를 2배로 올리면 잡음의 표준편차는 \(2^{3/2} \approx 2.8\)배가 됩니다. 신호는 \(W\)를 올려도 \(W\) 근처의 주파수 성분이 조금 더해질 뿐입니다.

분산 식의 근거

1단계. 백색잡음의 뜻. 서로 다른 위치의 값이 독립이고 분산이 같은 잡음은, 모든 주파수에 같은 세기 \(N_0\)가 들어 있는 잡음입니다.

2단계. 필터를 지난 잡음. 이런 잡음을 주파수 응답이 \(H(\omega)\)인 선형 필터에 통과시키면, 출력 잡음의 분산은 \(N_0\int |H(\omega)|^{2}\,d\omega\)입니다. 이 책에서는 이 결과를 증명하지 않고 씁니다. 2장의 Parseval 정리 \(\int |f|^{2}dx = \int |F|^{2}d\omega\)가 같은 형태의 관계입니다.

3단계. 램프 필터 대입. \(H = H_W\)이면 \(|H_W|^{2} = \omega^{2}\)이고 \(|\omega| \le W\)에서만 0이 아니므로 \(N_0\int_{-W}^{W}\omega^{2}\,d\omega = N_0\cdot\dfrac{2W^{3}}{3}\)입니다.

급하게 자를 때의 물결

\(W\)에서 필터를 갑자기 0으로 자르는 것에도 문제가 있습니다. \(H_W\)는 \(|\omega| = W\)에서 값이 끊기고, 이런 필터의 커널 \(h_W\)는 \(\mathrm{sinc}\) 꼴로 진동하는 꼬리를 가집니다(페이지 7). 이 꼬리를 컨볼루션하면 경계 근처에서 \(q\)가 출렁입니다. 주파수 영역에서 갑자기 자르면 공간 영역에 진동이 생기는 현상을 깁스 현상(Gibbs Phenomenon)이라고 하고, 영상에서는 경계 가까이의 물결 모양 줄무늬로 나타납니다. 이 줄무늬를 링잉(Ringing)이라고 부릅니다.

차단 주파수 조절

아래 위젯은 페이지 7의 원판 투영에 표본마다 독립인 정규 잡음을 더한 뒤 \(H_W\)를 적용합니다. 잡음은 난수의 시작값(시드, seed)을 고정해 만들었으므로 같은 값이 다시 나옵니다. 왼쪽의 파란 선은 잡음이 없을 때의 \(q\)이고 주황 선은 잡음이 있을 때의 \(q\)입니다. 오른쪽은 주파수별 크기를 로그 눈금으로 나타낸 것이며, 두 곡선 모두 \(|\omega|\)를 곱한 뒤의 크기입니다.

20

  • \(W\)를 올리면 잡음이 \(W^{3/2}\)로 늘어납니다. 위젯 아래 줄에서 \(W = 10\)일 때와의 비가 \((W/10)^{1.5}\)에 가깝게 나옵니다.
  • \(W\)가 작으면 잡음은 줄지만 경계가 둥글어지고 물결이 보입니다. 원판 안쪽의 값이 \(1/\pi\)(약 0.318)에서 벗어나 출렁이는 것이 깁스 현상입니다.
  • 교차하는 주파수 위는 신호가 없습니다. 그 위의 성분은 필터가 키워 봐야 잡음만 늘립니다. 잡음 수준이 높을수록 교차점이 낮아집니다.

그러므로 \(|\omega|\)를 그대로 쓰지 않고, 높은 주파수 쪽에서 서서히 줄이는 것이 좋습니다. 가까이 있는 작은 구조를 구분해 보이는 정도를 해상도(Resolution)라고 하며, 높은 주파수를 줄이면 해상도가 낮아집니다. 해상도를 얼마나 희생하고 잡음을 얼마나 줄일지는 선택의 문제이며, 다음 페이지에서 그 방법을 봅니다.

해상도와 잡음, 어떻게 절충할까요? 윈도우 필터

페이지 7~8(심화)을 건너뛰었다면

이 페이지에서 쓰는 앞 결과는 다음뿐입니다. 필터는 \(|\omega| \le W\)에서만 \(|\omega|\)를 곱하고, 차단 주파수 \(W\)는 나이퀴스트 주파수 \(1/(2\Delta s)\) 이하입니다. \(W\)를 올릴수록 해상도(가까이 있는 작은 구조를 구분해 보이는 정도)는 좋아지고 잡음은 커집니다. \(W\)에서 갑자기 0으로 자르면 잡음이 크고 경계에 물결(링잉)이 생깁니다. 이 필터의 공간 영역 커널 \(h_W\)는 가운데가 양수 봉우리, 양옆이 음수 꼬리이고 전체 넓이는 0입니다.

페이지 8에서 \(W\)에서 갑자기 자르는 필터는 잡음을 크게 키우고 경계에 물결을 만들었습니다. 높은 주파수 쪽에서 \(|\omega|\)를 서서히 줄이면 이 둘이 모두 완화됩니다. \(|\omega|\)에 높은 주파수에서 줄어드는 윈도우 함수(Window Function) \(A(\omega)\)를 곱한 필터를 윈도우 필터(Window Filter)라고 합니다.

\[H(\omega) = |\omega|\,A(\omega)\ \ (|\omega| \le W),\qquad H(\omega) = 0\ \ (|\omega| > W)\]

\(A\)는 \(\omega = 0\) 근처에서 1이고 \(|\omega| = W\)에서 작아지는 함수입니다. 이 책에서 쓰는 네 가지는 다음과 같습니다. \(A \equiv 1\)인 첫 번째는 페이지 7의 \(H_W\)이고, 이것을 Ram-Lak 필터(Ram-Lak Filter)라고 부릅니다.

이 \(A(\omega)\)에 \(|\omega|\)를 곱한 것이 필터의 주파수 응답 \(H(\omega)\)입니다. 점선은 자르지 않은 \(|\omega|\)이고, 색마다 어디에서 얼마나 줄어드는지, \(W\)를 넘으면 어떻게 0이 되는지를 보면 됩니다.

  • Ram-Lak은 Ramachandran과 Lakshminarayanan이 컨볼루션으로 재구성하는 방법을 제안한 데서 온 이름입니다(Ramachandran과 Lakshminarayanan, 1971년). Shepp-Logan 필터는 Shepp과 Logan의 1974년 논문에서 왔고(3장 페이지 4에서 인용한 논문), cosine과 Hamming은 신호처리의 윈도우 함수를 \(|\omega|\)에 곱한 것입니다.
  • 표의 반치폭은 \(H\)의 커널 \(h(s) = \int H(\omega)\,e^{i2\pi\omega s}\,d\omega\)의 중심 봉우리를 페이지 7과 같은 방법으로 잰 값이고, 잡음의 표준편차는 페이지 8의 \(\sqrt{\int H^{2}\,d\omega}\)를 Ram-Lak의 값으로 나눈 비입니다. 두 열 모두 \(W\)를 같게 두었을 때의 값입니다.

해상도와 잡음의 절충

표에서 아래로 갈수록 \(A\)가 높은 주파수를 더 많이 줄입니다. 그래서 잡음의 표준편차는 줄어들지만 중심 봉우리가 넓어져 작은 구조가 흐려집니다. 앞 페이지에서 정의한 해상도(가까이 있는 작은 구조를 구분해 보이는 정도)로 말하면, Ram-Lak은 해상도가 가장 높고 잡음이 가장 크며, Hamming은 잡음이 가장 작고 해상도가 가장 낮습니다. 표의 커널 반치폭이 해상도의 척도이고, 반치폭이 작을수록 해상도가 높습니다. 해상도와 잡음을 동시에 좋게 하는 필터는 없고, 이 사이에서 선택하게 됩니다. 아래 위젯은 Shepp-Logan 팬텀을 각도 180개의 투영으로 재구성합니다. 투영값마다 같은 시드의 독립 잡음을 더하고, 필터와 \(W\)만 바꿉니다.

작은 검출기로 찍으면, 그 안쪽은 정확히 재구성될까요?

페이지 7~8(심화)을 건너뛰었다면

이 페이지에서 쓰는 앞 결과는 다음뿐입니다. \(|\omega|\)를 곱하는 필터링은 공간 영역에서 커널 \(h\)와의 컨볼루션 \(q(\theta, s_0) = \int p(\theta, t)\,h(s_0 - t)\,dt\)로도 쓸 수 있습니다. 실제 계산에서는 차단 주파수 \(W\)를 정해 \(|\omega| \le W\)만 쓰고, 이때의 커널을 \(h_W\)라고 씁니다. 커널은 가운데(\(s = 0\))가 양수 봉우리, 양옆이 \(-1/(2\pi^{2}s^{2})\)처럼 천천히 줄어드는 음수 꼬리이고, 전체 넓이는 0입니다.

실제로 자주 나오는 질문을 이 페이지에서 따져 봅니다.

관심 있는 부분이 물체 안쪽의 작은 영역(관심 영역, Region of Interest, ROI)일 때, 검출기를 그 영역만 덮을 만큼 줄여서 찍는 경우를 생각합니다. 안쪽의 점은 어느 각도에서도 그 점을 지나는 광선이 검출기에 잡히므로, 안쪽은 정확히 재구성될 것처럼 보입니다. 그러나 FBP로 재구성하면 안쪽 값도 틀어집니다. 값이 1인 원판을 반지름의 0.7배 폭 검출기로 찍은 예에서는 원판 중심의 재구성값이 약 1.14로, 참값 1보다 14% 높습니다. 한 점의 값이 그 점에서 멀리 떨어진 광선의 값에도 의존하는 이 성질을 FBP의 비국소성(Non-Locality)이라고 합니다.

이 페이지는 이유를 두 관점으로 봅니다. 해석적 관점에서는 필터링이 먼 곳의 투영값까지 쓰기 때문이고, 대수적 관점에서는 안쪽을 지나는 광선만으로는 방정식이 모자라기 때문입니다. 위의 판단(안쪽도 틀어진다)은 FBP로 계산할 때의 것이고, 대수적 관점의 판단은 안쪽에 대한 추가 정보가 없을 때의 것입니다. 추가 정보가 있는 경우는 마지막 절에서 짧게 다룹니다.

해석적 관점: 필터링에 쓰이는 먼 곳의 투영값

역투영은 국소적입니다. 영상의 한 점 \((x, y)\)는 그 점을 지나는 광선 위의 \(q\) 값만 읽습니다. 비국소성은 그 \(q\)를 만드는 필터링에서 생깁니다. 필터링을 컨볼루션 형태로 쓰면 다음과 같습니다(페이지 7).

\[q(\theta, s_0) = \int p(\theta, t)\,h(s_0 - t)\,dt\]

커널 \(h\)는 \(-1/(2\pi^{2}s^{2})\)처럼 천천히 줄어드는 꼬리를 가지므로(페이지 7), \(s_0\)에서 멀리 떨어진 곳의 투영값도 조금씩 \(q(\theta, s_0)\)에 들어갑니다. 거리 \(d\)만큼 떨어진 곳의 투영값이 \(q(\theta, s_0)\)에 미치는 영향은 평균적으로 \(1/d^{2}\)에 비례합니다. 커널에는 \(W/(\pi d)\) 정도의 진동하는 항도 있어 이 항은 더 천천히 줄어듭니다. 그래서 \(s_0\) 근처의 값만 쓰면 결과가 달라집니다.

  • 역투영은 국소적입니다. 점 \((x, y)\)는 그 점을 지나는 광선 위의 \(q\) 값만 씁니다.
  • 필터링은 비국소적입니다. 각 \(q(\theta, s_0)\)는 그 각도 투영의 모든 \(s\)에 걸친 값에서 나옵니다.

푸리에 변환으로 보아도 같습니다. \(P_\theta(\omega)\)는 투영을 모든 \(s\)에 걸쳐 적분해 얻으므로(페이지 1), 투영 일부가 빠지면 모든 주파수 성분이 달라집니다.

대수적 관점: 방정식이 모자란 연립방정식

같은 문제를 0편 3장의 \(\mathbf{A}\mathbf{x} = \mathbf{b}\)로 보면 이유가 더 단순합니다. 광선 하나가 방정식 하나이고 화소값이 미지수입니다. 안쪽을 지나는 광선만 재면 식의 수가 미지수의 수보다 모자랄 수 있고, 그러면 해가 하나로 정해지지 않습니다.

3×3 화소로 이 상황을 만들어 보겠습니다. 화소값을 왼쪽 위부터 가로로 \(x_1, \dots, x_9\)라고 하고, 검출기가 가운데 화소 \(x_5\)를 지나는 광선 네 개(가운데 가로줄, 가운데 세로줄, 대각선 두 개)만 잰다고 하겠습니다. 광선 하나는 화소 세 개를 지나며 측정값은 그 합입니다.

\[x_4 + x_5 + x_6 = b_1,\quad x_2 + x_5 + x_8 = b_2,\quad x_1 + x_5 + x_9 = b_3,\quad x_3 + x_5 + x_7 = b_4\]

미지수는 9개인데 식은 4개입니다. \(\mathbf{A}\)를 만들어 계산하면, 어느 식도 다른 식들의 합이나 배수로 만들 수 없는 식이 4개뿐입니다. 아래 두 영상은 다른 영상인데도 네 광선의 합이 모두 같습니다.

(나)는 (가)의 가운데 화소에 2를 더하고 바깥 여덟 화소에서 1씩 뺀 것입니다. 네 광선은 각각 가운데 화소와 바깥 화소 두 개를 지나므로, 광선마다 \(+2\)와 \(-1, -1\)이 상쇄되어 합이 변하지 않습니다. 측정값 \(8, 8, 6, 6\)만으로는 가운데 화소가 4인지 6인지 정할 수 없습니다.

추가 정보가 있는 경우

정리하면 두 가지입니다. FBP로 계산하면 안쪽 값이 틀어집니다. 그리고 안쪽에 대한 추가 정보가 없으면, 어떤 방법을 써도 안쪽을 지나는 광선만으로는 안쪽 값이 하나로 정해지지 않습니다.

안쪽 일부의 값을 이미 알고 있는 것과 같은 추가 정보가 있으면 안쪽이 하나로 정해지는 경우가 연구되어 있습니다. 한편 대수적 방법에서 영상이 가질 만한 성질을 식에 더해 푸는 정규화는 2편 4장의 주제입니다.

페이지 7~8(심화)을 건너뛰었다면

이 페이지에서 쓰는 앞 결과는 다음뿐입니다. 실제 계산에서는 차단 주파수 \(W\)를 정해 \(|\omega| \le W\)에서만 \(|\omega|\)를 곱하고, \(W\)를 올릴수록 해상도는 좋아지고 잡음은 커집니다. 이 필터링은 공간 영역에서 커널 \(h_W\)와의 컨볼루션으로도 쓸 수 있으며, \(h_W\)는 가운데가 양수 봉우리, 양옆이 음수 꼬리이고 전체 넓이는 0입니다.

검출기가 물체보다 작을 때의 결과(절단)는 실제 장치에서도 자주 만나는 상황입니다.

한 줄 규칙

각도 부족

4장 페이지 2에서 \(0 \le \theta < \Theta\)만 측정하고 \(\Theta < 180^{\circ}\)이면 주파수 평면에 직선이 하나도 지나지 않는 빈 부채꼴이 생긴다고 했습니다. 이 빈 부채꼴 안의 \(F\)는 투영 데이터에 없습니다.

빈 부채꼴 방향으로 진동하는 성분은 그 방향으로 값이 바뀌는 구조, 즉 법선이 그 방향인 경계를 이룹니다. 이런 경계는 투영 각도 \(\theta\)가 경계의 법선 방향과 같을 때, 즉 광선이 경계를 따라 나란히 지나갈 때 선명하게 측정됩니다. 그 각도를 측정하지 않으면 이 경계가 흐려집니다. 예를 들어 \(120^{\circ}\)까지만 측정하면 법선 방향이 \(0^{\circ}\)~\(120^{\circ}\)인 경계의 정보는 남고 법선 방향이 \(120^{\circ}\)~\(180^{\circ}\)인 경계의 정보가 빠집니다.

FBP 공식에서는 \(\int_0^\pi d\theta\)가 \(\int_0^\Theta d\theta\)로 줄어든 것입니다. 그 방향을 측정한 값이 데이터에 없으므로, 필터나 식을 바꿔도 이 방향의 정보를 안정적으로 되살릴 수는 없습니다. 이 한계는 FBP만의 한계가 아닙니다.

적분 범위와 시야(FOV)

페이지 1의 FBP 식은 \(\omega\)를 \(-\infty\)부터 \(\infty\)까지 적분하고, 그 안의 \(P_\theta(\omega)\)도 투영을 모든 \(s\)에 대해 적분해 얻습니다. 3장 페이지 3의 Radon 변환(직선마다 선적분을 모은 변환)도 광선 위의 거리 \(\ell\)을 \(-\infty\)부터 \(\infty\)까지 적분합니다. 실제 물체는 크기가 유한하므로 이 범위를 줄일 수 있습니다. 물체가 회전 중심을 중심으로 하는 반지름 \(R\)인 원 안에 있다고 하면, 원 밖에서는 \(\mu = 0\)이고 \(|s| > R\)인 직선은 원과 만나지 않아 투영값이 0입니다. 따라서 \(\ell\)과 \(s\)에 대한 적분은 \(-R\)부터 \(R\)까지면 됩니다.

\[\begin{aligned} p(\theta, s) &= \int_{-R}^{R} \mu\bigl(s\cos\theta - \ell\sin\theta,\ \ s\sin\theta + \ell\cos\theta\bigr)\,d\ell \\ P_\theta(\omega) &= \int_{-R}^{R} p(\theta, s)\,e^{-i2\pi\omega s}\,ds \\ q(\theta, s) &= \int_{-R}^{R} p(\theta, t)\,h(s - t)\,dt \end{aligned}\]

  • 세 번째 식은 필터링을 공간 영역의 컨볼루션으로 쓴 것입니다. \(h\)는 \(|\omega|\)에 대응하는 커널이며 페이지 7에서 다룹니다.
  • 영상도 원 안에서만 계산하면 됩니다. 원 안의 점이 각도마다 읽는 \(s = x\cos\theta + y\sin\theta\)는 \(|s| \le R\)이므로, 역투영에 필요한 \(q\)도 \(|s| \le R\)의 값뿐입니다.

그러므로 재구성에 필요한 측정값은 \(|s| \le R\)의 투영뿐입니다. 검출기가 \(|s| \le D_{\mathrm{det}}\)인 직선을 잰다고 하겠습니다. \(D_{\mathrm{det}}\)는 검출기 반폭으로 3장 페이지 10의 \(N_s\Delta s/2\)와 같고, 반지름 \(D_{\mathrm{det}}\)인 원이 그 페이지에서 정의한 시야(FOV)입니다. 물체가 시야 안에 있으면, 곧 \(R \le D_{\mathrm{det}}\)이면 검출기가 잰 범위만으로 위 적분이 모두 계산됩니다. 유한한 크기의 검출기로도 FBP가 정확한 재구성을 주는 것은 이 때문입니다.

\(\omega\)에 대한 적분은 이렇게 줄일 수 없습니다. 0이 아닌 함수가 공간에서 유한한 구간에만 값이 있으면, 그 푸리에 변환은 어떤 주파수 위에서 모두 0이 될 수 없기 때문입니다. 실제 계산에서는 차단 주파수 \(W\)를 정해 \(|\omega| \le W\)만 씁니다(페이지 8).

적분 범위를 줄이는 근거

1단계. \(\ell\) 적분. 광선 위의 점 \((s\cos\theta - \ell\sin\theta,\ s\sin\theta + \ell\cos\theta)\)과 회전 중심 사이 거리의 제곱을 계산하면 두 제곱에서 나오는 \(-2s\ell\sin\theta\cos\theta\)와 \(+2s\ell\sin\theta\cos\theta\)가 상쇄되어 다음이 남습니다.

\[(s\cos\theta - \ell\sin\theta)^{2} + (s\sin\theta + \ell\cos\theta)^{2} = s^{2} + \ell^{2}\]

\(\mu\)는 이 값이 \(R^{2}\) 이하인 곳에서만 0이 아니므로 피적분 함수는 \(|\ell| \le \sqrt{R^{2} - s^{2}}\)에서만 0이 아닙니다. 이 구간은 \([-R, R]\) 안에 있습니다. \(|s| > R\)이면 이런 \(\ell\)이 없어서 \(p(\theta, s) = 0\)입니다.

2단계. \(s\) 적분. \(|s| > R\)에서 \(p(\theta, s) = 0\)이므로 \(P_\theta(\omega)\)의 피적분 함수도 그 밖에서 0입니다. 컨볼루션의 \(t\) 적분도 같은 이유로 \(|t| \le R\)만 남습니다. 필터링한 \(q(\theta, s)\) 자체는 \(|s| > R\)에서도 0이 아닐 수 있지만(페이지 5의 원판에서 바깥의 음수 값), 그 값은 원 안의 영상을 계산하는 데 쓰이지 않습니다.

3단계. 역투영. 점 \((x, y)\)를 극좌표로 \((r\cos\phi,\ r\sin\phi)\)라고 쓰면 \(x\cos\theta + y\sin\theta = r\cos(\theta - \phi)\)이므로 \(|s| \le r\)입니다. 원 안의 점(\(r \le R\))은 \(|s| \le R\)의 \(q\)만 읽습니다. 이때 컨볼루션의 \(s\)와 \(t\)가 모두 \([-R, R]\) 안에 있으므로 커널은 \(|s - t| \le 2R\)의 값만 쓰입니다.

4단계. \(\omega\) 적분. 2장 페이지 2의 사각 함수는 유한한 구간에만 값이 있지만, 그 푸리에 변환인 sinc는 아무리 높은 주파수에서도 정수 주파수를 빼면 0이 아닙니다. 일반적으로 0이 아닌 함수가 공간과 주파수 양쪽에서 동시에 유한한 범위에만 값을 가질 수는 없습니다. 그래서 물체의 크기가 유한하면 \(P_\theta(\omega)\)는 높은 주파수까지 이어지고, \(\omega\) 적분의 범위는 데이터에서 정해지지 않습니다.

절단

검출기가 \(|s| \le D_{\mathrm{det}}\)인 직선만 덮는다고 하겠습니다. 검출기의 폭이 물체보다 좁으면 \(|s| > D_{\mathrm{det}}\)인 직선의 투영값이 없습니다(3장 페이지 10). FBP는 모든 \(s\)의 값을 요구하므로, 없는 값을 어떻게든 채워야 합니다. 아래 위젯은 없는 값을 0으로 두고 그대로 필터링합니다. 이때 두 가지가 일어납니다(아래 그림).

  • 투영이 \(|s| = D_{\mathrm{det}}\)에서 갑자기 0이 되는 계단이 생기고, 필터가 이 계단에 크게 반응해 밝은 띠를 만듭니다.
  • 잘려 나간 곳의 투영값은 평균적으로 커널의 음수 꼬리를 통해 \(q\)를 낮췄을 것입니다(페이지 10). 이 값이 없으므로 이 원판에서는 \(q\)가 커져서, 영상 안쪽의 값이 올라가는 쪽으로 치우칩니다.

반지름 \(D_{\mathrm{det}}\)인 원 안의 점은 모든 각도의 광선이 검출기 안을 지나므로 데이터가 있습니다. 이 원이 앞 절에서 말한 시야(FOV)입니다. 원 밖의 점은 일부 각도의 광선이 검출기 밖을 지나 값이 빠집니다.

이렇게 투영이 잘려 생기는 오류를 절단 아티팩트(Truncation Artifact)라고 합니다. 필터링은 각도마다 투영 전체의 값을 쓰므로(페이지 10의 비국소성), 시야 밖만이 아니라 시야 안의 값도 영향을 받습니다. 절단 아티팩트를 줄이는 보정 방법은 이 책에서 다루지 않습니다. 시야 안의 점은 모든 각도의 데이터가 있지만, 위의 두 현상으로 필터링한 값 \(q\)가 달라지므로 정확히 재구성되지 않습니다.

힐베르트 변환 형의 역변환

선택 읽기

이 페이지는 건너뛰어도 뒤의 내용이 이어집니다. 필터링을 다른 방법으로 쓰는 것이며, 페이지 5에서 결과만 쓴 원판의 \(q\)를 계산하는 데 씁니다.

\(|\omega|\)를 곱하는 필터링은 두 연산으로 나눌 수 있습니다. 하나는 미분이고, 다른 하나는 힐베르트 변환입니다. 먼저 \(|\omega|\)를 다음과 같이 씁니다.

\[|\omega| = \frac{1}{2\pi}\,\bigl(i2\pi\omega\bigr)\bigl(-i\,\mathrm{sgn}(\omega)\bigr)\]

  • \(i2\pi\omega\)를 곱하는 것은 \(s\)에 대한 미분입니다. \(f'(s)\)의 푸리에 변환이 \(i2\pi\omega F(\omega)\)이기 때문입니다(2장 페이지 3).
  • \(-i\,\mathrm{sgn}(\omega)\)를 곱하는 것은 힐베르트 변환(Hilbert Transform)입니다. \(\mathrm{sgn}\)은 \(\omega > 0\)에서 1, \(\omega < 0\)에서 \(-1\)인 부호 함수(Sign Function)입니다. 공간에서는 \(1/(\pi s)\)와의 컨볼루션이며 다음과 같이 씁니다.

\[(\mathcal{H}f)(s) = \frac{1}{\pi}\,\mathrm{p.v.}\!\int_{-\infty}^{\infty} \frac{f(t)}{s - t}\,dt\]

p.v.는 \(t = s\) 둘레의 양쪽을 같은 폭으로 빼고 적분한 극한(코시 주값, Cauchy Principal Value)입니다. 그러므로 필터링한 투영은 다음과 같고, FBP 공식은 이 식을 역투영한 것입니다.

\[q(\theta, s) = \frac{1}{2\pi}\,\mathcal{H}\!\left[\frac{\partial p}{\partial t}\right](\theta, s) = \frac{1}{2\pi^{2}}\,\mathrm{p.v.}\!\int_{-\infty}^{\infty} \frac{\partial p(\theta, t)/\partial t}{s - t}\,dt\]

\[\mu(x, y) = \frac{1}{2\pi^{2}}\int_{0}^{\pi}\mathrm{p.v.}\!\int_{-\infty}^{\infty} \frac{\partial p(\theta, t)/\partial t}{x\cos\theta + y\sin\theta - t}\,dt\,d\theta\]

힐베르트 변환의 주파수 응답

1단계. 커널의 푸리에 변환. \(1/(\pi s)\)의 푸리에 변환은 \(\displaystyle\int \frac{e^{-i2\pi\omega s}}{\pi s}\,ds = \int \frac{\cos(2\pi\omega s)}{\pi s}\,ds - i\int\frac{\sin(2\pi\omega s)}{\pi s}\,ds\)입니다.

2단계. 코사인 항. \(\cos\)은 짝함수이고 \(1/s\)는 홀함수여서 피적분 함수가 홀함수이므로 주값은 0입니다.

3단계. 사인 항. \(\displaystyle\int_{-\infty}^{\infty}\frac{\sin(as)}{s}\,ds = \pi\,\mathrm{sgn}(a)\)이므로 \(\displaystyle\int\frac{\sin(2\pi\omega s)}{\pi s}\,ds = \mathrm{sgn}(\omega)\)입니다. 따라서 푸리에 변환은 \(-i\,\mathrm{sgn}(\omega)\)이고, 컨볼루션 정리로 \(\mathcal{H}\)의 주파수 응답이 됩니다.

식의 뜻

  • 미분은 국소적입니다. \(\partial p/\partial t\)는 그 점 근처의 값만으로 정해집니다.
  • 비국소성은 힐베르트 변환에서 옵니다. \(1/(s - t)\)는 멀리까지 이어지는 꼬리이며, 페이지 7에서 본 \(-1/(2\pi^{2}s^{2})\)가 이 커널을 미분한 것입니다.
  • 필터링을 두 단계로 나눠 순서를 바꾸는 방법이 있습니다. 미분한 투영을 먼저 역투영하고 힐베르트 변환을 나중에 하는 방법들이 투영이 일부만 있을 때를 다루는 연구에서 쓰이며, 이 책에서는 다루지 않습니다.

원판 계산

페이지 5의 원판(반지름 \(R\), 값 1)에서 \(p(t) = 2\sqrt{R^{2} - t^{2}}\)이므로 \(p'(t) = -2t/\sqrt{R^{2} - t^{2}}\)입니다. 위 식에 넣고 \(\dfrac{t}{s - t} = -1 + \dfrac{s}{s - t}\)로 나누면 다음이 됩니다.

\[q(s) = \frac{1}{2\pi^{2}}\cdot(-2)\int_{-R}^{R}\frac{t}{(s - t)\sqrt{R^{2} - t^{2}}}\,dt = \frac{1}{\pi} - \frac{s}{\pi^{2}}\,J(s)\]

\[J(s) = \mathrm{p.v.}\!\int_{-R}^{R}\frac{dt}{(s - t)\sqrt{R^{2} - t^{2}}}\]

주값 적분의 값과 원판 결과

1단계. 앞의 식 정리. \(\displaystyle\int_{-R}^{R}\frac{dt}{\sqrt{R^{2} - t^{2}}} = \pi\)이므로 \(\displaystyle\int_{-R}^{R}\frac{t\,dt}{(s - t)\sqrt{R^{2} - t^{2}}} = -\pi + s\,J(s)\)이고, 여기에 \(-1/\pi^{2}\)를 곱하면 위의 식이 됩니다.

2단계. \(|s| > R\)인 곳. \(t = R\cos u\)로 치환하면 \(J(s) = \displaystyle\int_0^\pi\frac{du}{s - R\cos u}\)이고, \(s > R\)에서 이 적분은 알려진 값 \(\pi/\sqrt{s^{2} - R^{2}}\)입니다. 이것은 \(\int_0^\pi du/(a - b\cos u) = \pi/\sqrt{a^{2} - b^{2}}\)(\(a > b > 0\))에 \(a = s,\ b = R\)을 넣은 것이고, 이 공식은 적분표에 실린 표준 공식이어서 이 책에서는 증명하지 않습니다. \(s < -R\)에서는 부호가 반대이므로 \(J(s) = \pi\,\mathrm{sgn}(s)/\sqrt{s^{2} - R^{2}}\)입니다.

3단계. \(|s| < R\)인 곳. 분모가 0이 되는 \(t = s\)가 적분 구간 안에 있어서 주값을 취해야 하고, 알려진 결과로 \(J(s) = 0\)입니다. 이 값은 수치 적분으로도 확인했습니다.

4단계. 결과. \(|s| < R\)에서는 \(q = 1/\pi\)이고, \(|s| > R\)에서는 \(s\,\mathrm{sgn}(s) = |s|\)이므로 다음과 같습니다.

\[q(s) = \frac{1}{\pi} - \frac{|s|}{\pi\sqrt{s^{2} - R^{2}}} = \frac{1}{\pi}\left(1 - \frac{|s|}{\sqrt{s^{2} - R^{2}}}\right)\]

페이지 5에서 쓴 원판의 \(q\)와 같습니다. 이 식을 \(\theta\)에 대해 \(0\)부터 \(\pi\)까지 더하면 원판 안에서는 \(\pi \times (1/\pi) = 1\), 밖에서는 0이 되어 원판이 정확히 재구성됩니다(페이지 5의 위젯에서 수치 적분으로 확인할 수 있습니다).

5장 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. 모든 각도 \(0 \le \theta < \pi\)와 모든 \(s\)에서 투영이 주어지면 영상은 \(q(\theta, s) = \int P_\theta(\omega)\,|\omega|\,e^{i2\pi\omega s}\,d\omega\)와 \(\mu = \int_0^\pi q(\theta,\ x\cos\theta + y\sin\theta)\,d\theta\)로 정확히 얻어지며 상수는 붙지 않습니다. \(|\omega|\)는 푸리에 평면의 극좌표 변환에서 나온 야코비안이고, 한 바퀴를 반 바퀴(\(\omega\)는 실수 전체)로 접으면 \(\omega\)가 \(|\omega|\)가 됩니다.
  2. 램프 필터는 직류를 없애 \(\int q\,ds = 0\)으로 만들고 높은 주파수를 키웁니다. 필터링한 투영의 음수는 역투영할 때 물체 바깥으로 번지는 양수를 상쇄합니다. (심화) 공간 영역에서는 \(|\omega| \le W\)로 자른 필터의 커널 \(h_W(s) = 2W^{2}\mathrm{sinc}(2Ws) - W^{2}\mathrm{sinc}^{2}(Ws)\)와의 컨볼루션입니다.
  3. 윈도우 필터는 \(|\omega|\)를 서서히 줄여 해상도와 잡음을 절충합니다. (심화) \(W\)는 나이퀴스트 주파수 이하여야 하고, 백색잡음의 표준편차는 \(W^{3/2}\)에 비례합니다.
  4. 식이 정확한 것은 각도·검출기 범위가 완전하고 잡음이 없을 때입니다. 각도가 모자라면 법선이 빈 방향인 경계가 흐려지고, 절단이 있으면 밝은 테두리와 안쪽 값의 치우침이 생깁니다.
  5. 필터링은 비국소적이어서, 작은 검출기로 안쪽만 찍으면 FBP로 구한 안쪽 값이 틀어집니다. 안쪽에 대한 추가 정보가 없으면 안쪽을 지나는 광선만으로는 안쪽 값이 하나로 정해지지 않습니다.
  6. 단순 역투영은 \(\mu\)를 점 퍼짐 함수 \(1/r\)로 컨볼루션한 것이고, 주파수에서는 \(F/|\omega|\)입니다. 여기에 \(|\omega|\)를 곱해 되돌리는 방법 가운데 투영마다 곱하는 것이 FBP입니다.

마무리 퀴즈 1

FBP 공식에서 투영의 푸리에 변환에 곱해지는 \(|\omega|\)는 어디에서 나온 인자일까요?

  1. 잡음을 줄이려고 저역통과 필터로 설계해서 넣은 인자
  2. 푸리에 변환의 정의에서 나오는 상수를 맞추는 인자
  3. 역투영이 투영의 수반 연산이라는 성질에서 나온 인자
  4. 푸리에 평면의 극좌표 변환에서 나온 야코비안 인자

같은 구조는 3차원에서도 나타납니다. 3차원 푸리에 공간을 거리 \(\omega\)와 두 각도로 나타내는 구면 좌표로 바꾸면 부피 요소에 \(\omega^{2}\)가 곱해집니다. 3차원에서 평면 적분으로 영상을 재구성하는 공식에 \(\omega^{2}\)에 해당하는 인자가 나오는 것도 좌표를 바꾸는 데서 오는 같은 종류의 인자입니다.

마무리 퀴즈 2

필터링한 투영 \(q\)에 음수인 부분이 반드시 생기는 이유와, 역투영에서 그 음수가 하는 일로 알맞은 것은 무엇일까요?

  1. 측정 잡음이 음수로 나타난 것이므로, 역투영하기 전에 0으로 바꾸어야 한다
  2. 램프 필터가 높은 주파수를 줄여서 생기고, 영상을 부드럽게 만들어 준다
  3. \(\int q\,ds = 0\)이어서 생기며, 바깥으로 번지는 양수를 상쇄한다
  4. 영상에 \(\mu < 0\)인 물질이 있기 때문이고, 그 물질의 위치를 알려 준다

음수를 0으로 잘라 역투영하면 \(\int q\,ds\)가 0이 아니게 되어 상쇄가 깨지고, 물체 바깥에 양수가 남아 영상 전체가 밝아집니다.

마무리 퀴즈 3

(심화) 차단 주파수 \(W\)를 2배로 올리면, 램프 필터를 거친 백색잡음의 표준편차는 대략 몇 배가 될까요?

  1. 2.8배(\(W^{3/2}\)에 비례)
  2. 2.0배(\(W\)에 비례)
  3. 4.0배(\(W^{2}\)에 비례)
  4. 1.4배(\(W^{1/2}\)에 비례)

분산은 \(W^{3}\)에 비례해 8배가 되지만 표준편차는 그 제곱근이어서 약 2.8배입니다. 영상에서는 각도 \(K\)개를 더하므로 잡음이 대략 \(1/\sqrt{K}\)로 줄어듭니다. 이 평균은 \(W\)가 커질 때 잡음이 늘어나는 비율을 바꾸지 못합니다. 그래서 각도를 늘려서 얻는 잡음 감소와 \(W\)를 낮춰서 얻는 잡음 감소는 따로 계산합니다.

마무리 퀴즈 4

측정 각도가 \(0^{\circ}\)~\(120^{\circ}\)뿐일 때 FBP 영상에서 흐려지는 경계는 어느 것일까요?

  1. 법선이 \(0^{\circ}\)~\(120^{\circ}\)인 경계
  2. 경계의 방향과 관계없이 모든 경계가 같은 정도로 흐려진다
  3. 법선이 \(120^{\circ}\)~\(180^{\circ}\)인 경계
  4. 회전 중심에서 멀리 떨어진 곳에 있는 경계

이 한계는 측정하지 않은 방향에 대한 값이 데이터에 없다는 데서 오므로, 필터나 재구성 공식을 바꿔도 그 방향의 경계를 안정적으로 되살릴 수는 없습니다. 영상의 성질에 대한 가정을 더해 이 부족을 일부 보충하는 정규화는 2편 4·5장에서 다룹니다.

직접 해보기

  1. (심화) 검출기 간격이 \(\Delta s = 0.05\ \mathrm{cm}\)인 투영에서 차단 주파수를 나이퀴스트 주파수로 잡았습니다. \(W\)는 얼마이고, \(h_W(0)\), 중심 봉우리의 반치폭(\(0.48/W\)), 처음 0이 되는 곳(\(0.37/W\))은 각각 얼마일까요? \(W\)를 절반으로 낮추면 백색잡음의 표준편차는 몇 배가 될까요?
  2. 값이 \(\rho = 0.2\)이고 반지름이 \(R = 3\ \mathrm{cm}\)인 원판의 투영은 \(p(\theta, s) = 2\rho\sqrt{R^{2} - s^{2}}\)입니다. 필터링한 투영은 페이지 5의 결과를 \(\rho\)배 한 것입니다. \(|s| < R\)에서 \(q\)의 값을 구하고, \(s = 4.5\ \mathrm{cm}\)에서 \(q\)의 값을 구하세요. 원판 중심에서 \(\int_0^\pi q\,d\theta\)가 \(\rho\)와 같은지 확인하고, \(\int q\,ds = 0\)에서 안쪽과 바깥쪽의 넓이를 각각 구하세요.
  3. 각주파수 \(\Omega = 2\pi\omega\)를 쓰는 책에서는 투영의 푸리에 변환을 \(\tilde{P}_\theta(\Omega) = \int p(\theta, s)\,e^{-i\Omega s}\,ds\)로 정의하고, \(\theta\)를 \(0\)부터 \(2\pi\)까지 적분합니다. 이 책의 FBP 식에서 출발해 그 책의 식 앞에 붙는 상수를 구하세요. \(0\)부터 \(2\pi\)까지 적분하려면 \(q(\theta + \pi, -s) = q(\theta, s)\)가 필요한데, 이 관계가 왜 성립하는지도 설명하세요.
모범답안과 흔한 실수

1번. \(W = 1/(2\Delta s) = 1/0.1 = 10\ \mathrm{cm}^{-1}\)입니다. \(h_W(0) = W^{2} = 100\ \mathrm{cm}^{-2}\), 반치폭은 \(0.48/W = 0.048\ \mathrm{cm}\), 처음 0이 되는 곳은 \(0.37/W = 0.037\ \mathrm{cm}\)입니다. 반치폭 \(0.048\ \mathrm{cm}\)은 검출기 간격 \(0.05\ \mathrm{cm}\)와 거의 같습니다. \(W\)를 \(5\ \mathrm{cm}^{-1}\)로 낮추면 표준편차는 \((1/2)^{3/2} \approx 0.35\)배가 되고, 반치폭은 2배가 됩니다.

2번. 안쪽(\(|s| < 3\))에서는 \(q = \rho/\pi = 0.2/\pi \approx 0.0637\)이고 \(R\)에 관계없습니다. \(s = 4.5\)에서는 \(\sqrt{s^{2} - R^{2}} = \sqrt{20.25 - 9} = \sqrt{11.25} \approx 3.354\)이고 \(|s|/\sqrt{s^{2} - R^{2}} \approx 1.342\)이므로 \(q = (0.2/\pi)(1 - 1.342) \approx -0.0218\)입니다. 원판 중심에서는 모든 각도에서 \(s = 0\)이어서 \(q = 0.2/\pi\)이고, \(\int_0^\pi (0.2/\pi)\,d\theta = 0.2 = \rho\)로 같습니다. \(\int q\,ds\)의 안쪽은 \(2R\rho/\pi = 1.2/\pi \approx 0.382\), 바깥쪽은 \(-2R\rho/\pi \approx -0.382\)이고 합이 0입니다.

3번. \(\omega = \Omega/(2\pi)\)이므로 \(d\omega = d\Omega/(2\pi)\), \(|\omega| = |\Omega|/(2\pi)\)이고 \(P_\theta(\omega) = \tilde{P}_\theta(\Omega)\)입니다. 이것을 \(q(\theta, s) = \int P_\theta(\omega)\,|\omega|\,e^{i2\pi\omega s}\,d\omega\)에 넣으면 다음이 됩니다.

\[q(\theta, s) = \int \tilde{P}_\theta(\Omega)\,\frac{|\Omega|}{2\pi}\,e^{i\Omega s}\,\frac{d\Omega}{2\pi} = \frac{1}{4\pi^{2}}\int \tilde{P}_\theta(\Omega)\,|\Omega|\,e^{i\Omega s}\,d\Omega\]

이것은 \(\theta\)를 \(0\)부터 \(\pi\)까지 적분하는 식의 상수입니다. \(q(\theta + \pi, -s) = \int P_\theta(-\omega)\,|\omega|\,e^{-i2\pi\omega s}\,d\omega\)에서 \(\omega \to -\omega\)로 바꾸면 \(q(\theta, s)\)가 됩니다. \(P_{\theta+\pi}(\omega) = P_\theta(-\omega)\)(4장 페이지 2)에서 \(q(\theta + \pi, -s) = q(\theta, s)\)이고, 점 \((x, y)\)에서 읽는 값은 \(\theta\)와 \(\theta + \pi\)에서 같으므로 \(\int_0^{2\pi} d\theta = 2\int_0^{\pi} d\theta\)입니다. 따라서 \(0\)부터 \(2\pi\)까지 적분하는 책에서는 앞에 붙는 상수가 \(\dfrac{1}{2}\cdot\dfrac{1}{4\pi^{2}} = \dfrac{1}{8\pi^{2}}\)입니다.

흔한 실수.

  • 1번에서 나이퀴스트 주파수를 \(1/\Delta s\)로 쓰는 것입니다. 간격 \(\Delta s\)로 샘플링하면 담을 수 있는 가장 높은 주파수는 \(1/(2\Delta s)\)입니다(2장 페이지 4).
  • 1번에서 표준편차의 변화를 \(1/2\)배나 \(1/8\)배로 쓰는 것입니다. 분산이 \(W^{3}\)에 비례하므로 표준편차는 \(W^{3/2}\)에 비례합니다.
  • 2번에서 안쪽 값을 원판의 값 \(\rho\)로 쓰는 것입니다. \(q\)는 \(\rho/\pi\)이고, \(\theta\)에 대해 \(0\)부터 \(\pi\)까지 더해야 \(\rho\)가 됩니다.
  • 2번에서 \(s = 4.5\)에서도 \(q\)를 양수로 두는 것입니다. 원판 바깥의 \(q\)는 음수입니다.
  • 3번에서 \(1/(2\pi)\)만 붙이는 것입니다. \(|\omega| = |\Omega|/(2\pi)\)와 \(d\omega = d\Omega/(2\pi)\)에서 각각 \(1/(2\pi)\)가 나옵니다.
