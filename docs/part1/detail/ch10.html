10장 · 페이지 1

데이터는 얼마나 있어야 충분할까요? 대칭성과 데이터 완전성

선원을 한 바퀴 돌리려면 시간이 들고, 그동안 환자가 움직이면 영상이 흐려집니다. 그렇다면 정말 한 바퀴를 다 돌아야 할까요? 8장의 공식은 선원 각을 \(0\)에서 \(2\pi\)까지 더했지만, 3장에서 평행빔은 \(180^{\circ}\)만 측정해도 모든 직선을 얻었습니다. 이 장에서는 팬빔이 같은 직선을 두 번 재는 광선의 짝을 찾고, 그 짝으로 정확한 재구성에 필요한 데이터의 범위와 남는 데이터를 합치는 조건을 정합니다.

평행빔에서 같은 직선

3장 페이지 9에서 평행빔의 좌표 \((\theta, s)\)와 \((\theta + \pi,\ -s)\)는 같은 직선을 가리켰습니다. 두 광선은 진행 방향만 반대이고 선적분은 같으므로 다음이 성립합니다.

\[p(\theta + \pi,\ -s) = p(\theta, s)\]

그래서 \(\theta\)를 \(0 \le \theta < \pi\)로만 돌려도 모든 직선이 한 번씩 측정되고, \(0\)~\(2\pi\)를 돌리면 모든 직선을 두 번씩 잽니다.

팬빔에서 같은 직선

팬빔의 광선은 모두 선원에서 출발하므로, 같은 직선을 재는 두 광선은 선원이 서로 다른 위치에 있을 때 나옵니다. 선원은 회전 중심 O를 중심으로 반지름 \(D\)인 원 위를 돌고, 이 원 안을 지나는 직선은 원과 두 점에서 만납니다. 선원이 한 교점 S에 있을 때 직선을 따라 나가는 광선이 이 직선을 재고, 선원이 다른 교점 S′에 있을 때 반대 방향으로 나가는 광선이 같은 직선을 한 번 더 잽니다.

이렇게 같은 직선을 재는 두 광선을 중복 광선(Redundant Ray)라고 하며, 두 광선은 서로의 짝입니다. 평행빔에서는 선원 각 \(\theta\)가 \(180^{\circ}\) 다른 광선이 짝이었지만, 위 그림의 짝은 선원 각이 \(40^{\circ}\)와 \(250^{\circ}\)로 \(210^{\circ}\) 떨어져 있습니다.

중복 광선의 성질

  • 두 측정값이 같습니다. 이상적인 데이터에서 두 광선이 지나는 경로가 같은 직선이므로 선적분이 같습니다.
  • 잡음은 서로 독립입니다. 두 측정에 독립인 잡음이 얹히므로 둘을 평균하면 잡음의 표준편차가 \(1/\sqrt{2}\)배가 됩니다(3장 페이지 9).
  • 같은 정보가 두 번 들어 있습니다. 한 광선을 측정하지 않아도 직선의 값은 짝에서 얻을 수 있습니다. 중복 덕분에 스캔 범위를 줄일 수 있습니다.

이 장의 진행

  1. 짝 광선의 좌표를 기하로 구합니다(페이지 2).
  2. 짝이 \(\beta\)–\(\gamma\) 평면의 어디에 놓이는지 보고(페이지 3), 정확한 재구성에 필요한 스캔 범위를 정합니다(페이지 4). 그 범위가 나오는 이유를 선원 궤도 위에서 따라가는 설명은 페이지 5(심화)에 있습니다.
  3. 두 번 잰 데이터를 합치는 가중이 만족할 조건을 세우고(페이지 6~8), 위젯으로 확인합니다(페이지 9).

10장 · 페이지 2

짝 광선의 좌표

선원 각 \(\beta\), 팬 각 \(\gamma\)인 광선과 같은 직선을 재는 광선은 선원 각과 팬 각이 얼마일까요? 7장 페이지 6에서는 그림에서 읽은 답을 썼습니다. 이 페이지에서는 그 답을 기하로 유도합니다. 답은 다음과 같습니다.

\[(\beta,\ \gamma)\ \longleftrightarrow\ (\beta + \pi + 2\gamma,\ -\gamma)\]

선원 각은 \(2\pi\)를 법으로 읽습니다. \(360^{\circ}\)를 더하거나 빼도 같은 선원 위치이기 때문입니다.

이등변삼각형에서 구하기

직선이 선원 궤도와 만나는 두 점이 S와 S′입니다. 아래 그림은 \(D = 3\) cm, \(\beta = 40^{\circ}\), \(\gamma = 15^{\circ}\)인 광선의 예입니다.

  1. OS와 OS′는 모두 궤도의 반지름 \(D\)이므로 삼각형 OSS′는 이등변삼각형입니다.
  2. S에서 광선과 중심 광선 SO가 이루는 각은 팬 각의 크기 \(|\gamma|\)입니다. 이등변삼각형의 두 밑각은 같으므로 S′에서 광선과 S′O가 이루는 각도 \(|\gamma|\)이고, 삼각형의 내각의 합이 \(\pi\)이므로 O의 각은 \(\pi - 2|\gamma|\)입니다.
  3. \(\gamma > 0\)이면 광선은 중심 광선에서 반시계 방향으로 기울어 있고, S′는 S에서 시계 방향으로 \(\pi - 2\gamma\)만큼 떨어진 곳에 있습니다. 선원 각은 반시계 방향으로 재므로 \(\beta' = \beta - (\pi - 2\gamma)\)이고, \(2\pi\)를 법으로 읽으면 \(\beta' = \beta + \pi + 2\gamma\)입니다.
  4. S′에서 광선은 S를 향합니다. 삼각형은 O와 선분 SS′의 중점을 잇는 직선에 대해 좌우 대칭이므로, S′에서의 광선은 S에서와 반대 방향으로 중심 광선에서 기울어 있습니다. 그러므로 \(\gamma' = -\gamma\)입니다.

그림의 예(\(\beta = 40^{\circ}\), \(\gamma = 15^{\circ}\))로 확인하면, O의 각은 \(180^{\circ} - 2 \times 15^{\circ} = 150^{\circ}\)이고 S′는 S에서 시계 방향으로 \(150^{\circ}\) 떨어진 선원 각 \(40^{\circ} - 150^{\circ} + 360^{\circ} = 250^{\circ} = \beta + 180^{\circ} + 2\gamma\)에 있습니다.

\(\gamma\)의 부호에 관계없이 같은 식이 성립한다는 것은 아래 접기의 좌표 계산에서 확인합니다.

S′의 좌표 계산

선원은 \(\mathrm{S} = (-D\sin\beta,\ D\cos\beta)\)이고 광선의 방향은 \(\mathbf{d} = (\sin(\beta + \gamma),\ -\cos(\beta + \gamma))\)입니다(7장 페이지 4). 직선 위의 점 \(\mathrm{S} + t\,\mathbf{d}\)가 선원 궤도(\(|\cdot| = D\)) 위에 있으려면 \(|\mathrm{S}|^{2} + 2t\,\mathrm{S}\cdot\mathbf{d} + t^{2} = D^{2}\)이어야 하고, \(|\mathrm{S}| = D\)이므로 \(t = 0\)(점 S) 또는 \(t = -2\,\mathrm{S}\cdot\mathbf{d}\)입니다.

  1. \(\mathrm{S}\cdot\mathbf{d} = -D\sin\beta\sin(\beta + \gamma) - D\cos\beta\cos(\beta + \gamma) = -D\cos\gamma\)이므로 \(t = 2D\cos\gamma\)입니다. 이 값은 궤도 안을 지나는 현 SS′의 길이입니다.
  2. 곱을 합으로 바꾸면 \(2\cos\gamma\sin(\beta + \gamma) = \sin(\beta + 2\gamma) + \sin\beta\)이고 \(2\cos\gamma\cos(\beta + \gamma) = \cos(\beta + 2\gamma) + \cos\beta\)입니다.
  3. 따라서 \(\mathrm{S}' = \mathrm{S} + 2D\cos\gamma\,\mathbf{d} = \bigl(D\sin(\beta + 2\gamma),\ -D\cos(\beta + 2\gamma)\bigr)\)입니다. \(\beta' = \beta + 2\gamma + \pi\)로 두면 \(-\sin\beta' = \sin(\beta + 2\gamma)\), \(\cos\beta' = -\cos(\beta + 2\gamma)\)이므로 \(\mathrm{S}' = (-D\sin\beta',\ D\cos\beta')\)입니다.
  4. S′에서 S를 향하는 방향은 \(-\mathbf{d} = (\sin(\beta + \gamma + \pi),\ -\cos(\beta + \gamma + \pi))\)입니다. 선원 각 \(\beta'\)에서 팬 각 \(\gamma'\)인 광선의 방향은 \((\sin(\beta' + \gamma'),\ -\cos(\beta' + \gamma'))\)이므로 \(\beta' + \gamma' = \beta + \gamma + \pi\)이고, \(\gamma' = -\gamma\)입니다.

이 계산은 \(\gamma\)의 부호를 가정하지 않았으므로 \(\gamma < 0\)인 광선에도 성립합니다.

수치로 확인하기

\(D = 3\) cm, \(\beta = 40^{\circ}\), \(\gamma = 15^{\circ}\)인 광선의 짝은 \((250^{\circ},\ -15^{\circ})\)입니다. 두 광선을 3장의 직선 좌표 \(\theta = \beta + \gamma\), \(s = D\sin\gamma\)(7장 페이지 4)로 바꾸면 다음과 같습니다.

\((\beta, \gamma)\)\(\theta = \beta + \gamma\)\(s = D\sin\gamma\)
S의 광선\((40^{\circ},\ 15^{\circ})\)\(55^{\circ}\)\(+0.776\) cm
S′의 광선\((250^{\circ},\ -15^{\circ})\)\(235^{\circ}\)\(-0.776\) cm

\(235^{\circ} = 55^{\circ} + 180^{\circ}\)이고 \(s' = -s\)이므로 두 광선은 3장 페이지 9의 \((\theta + \pi,\ -s)\)로 같은 직선입니다. 컴퓨터로 다음 세 가지를 확인했습니다.

  • \(\beta\)를 \(0\)~\(2\pi\), \(\gamma\)를 \(\pm 40^{\circ}\)에서 무작위로 고른 광선 20000개로, 직선과 선원 궤도의 두 번째 교점을 직접 구해 선원 각을 재면 위의 식과 최대 \(3 \times 10^{-15}\) rad 차이였고, 그 점에서 S를 향하는 광선의 팬 각은 \(-\gamma\)와 최대 \(8 \times 10^{-16}\) rad 차이였습니다. 현의 길이는 \(2D\cos\gamma\)와 \(3 \times 10^{-15}\) cm 이내로 일치했습니다.
  • Shepp-Logan 팬텀(\(D = 3\) cm, \(|\gamma| \le 20^{\circ}\))에서 \(\beta\)와 \(\gamma\)를 무작위로 고른 광선 100개에 대해 두 광선을 따라 \(\mu\)를 중점 합으로 수치 적분하면, 적분 보폭 0.001 cm에서 최대 0.0030, 0.0002 cm에서 최대 0.0006 차이였습니다. 차이가 보폭에 비례해 줄어드는 것은 적분의 이산화 오차이고, 두 광선의 선적분이 같다는 것과 일치합니다.
  • 짝의 짝은 \((\beta + \pi + 2\gamma) + \pi + 2(-\gamma) = \beta + 2\pi\)로 처음 광선입니다. 짝 관계는 서로 하나씩 대응합니다.

선원 각의 차이 살펴보기

짝과의 선원 각 차이는 \(\pi + 2\gamma\)입니다. 중심 광선(\(\gamma = 0\))의 짝은 정확히 \(180^{\circ}\) 뒤에 있고, 팬의 양 끝 광선(\(\gamma = \pm\gamma_m\))의 짝은 \(180^{\circ} \pm 2\gamma_m\) 뒤에 있습니다. 평행빔에서 항상 \(\pi\)였던 차이가 팬빔에서는 광선마다 다르기 때문에, 중복 영역은 직사각형이 아니라 삼각형이 됩니다.

β–γ 평면의 중복 영역

광선 하나는 선원 각 \(\beta\)와 팬 각 \(\gamma\) 두 수로 정해지므로 \(\beta\)–\(\gamma\) 평면의 점 하나입니다. 가로를 \(\gamma\), 세로를 \(\beta\)(위에서 아래로)로 놓으면 7장 페이지 5의 팬빔 sinogram과 같은 배치입니다. 이 평면에서 짝을 찾는 변환은 다음과 같습니다.

\[(\gamma,\ \beta)\ \longmapsto\ (-\gamma,\ \beta + \pi + 2\gamma)\]

\(\gamma\)의 부호를 뒤집고 \(\beta\)를 \(\pi + 2\gamma\)만큼 옮기는 변환이며, 두 번 적용하면 \(\beta\)가 \(2\pi\)만 달라져 제자리로 돌아옵니다.

8장의 팬빔 FBP 공식은 선원 각 \(\beta\)를 \(0\)에서 \(2\pi\)까지 돌리고 모든 광선에 똑같이 \(\tfrac{1}{2}\)을 곱했습니다. 평행빔(3장 페이지 9)에서는 짝의 선원 각 차이가 항상 \(\pi\)였으므로 \(\pi\)만 돌려도 모든 직선을 한 번씩 얻었지만, 팬빔에서는 짝의 선원 각이 \(\beta + \pi + 2\gamma\)이어서(페이지 2) 그 차이 \(\pi + 2\gamma\)가 팬 각 \(\gamma\)마다 다릅니다. 그래서 팬빔은 얼마나 돌려야 충분한지 알려면, 이 \(\beta\)–\(\gamma\) 평면에서 중복 영역이 어디인지부터 봐야 합니다.

최소 스캔 범위의 영역

선원이 \(\beta = 0\)에서 \(\beta = B\)까지만 돈다고 합시다. \(B\)를 스캔 범위라고 하며, 여기서는 \(B = \pi + 2\gamma_m\)으로 둡니다(\(\gamma_m\)은 팬 반각입니다). 측정되는 광선은 \(0 \le \beta \le B\)인 띠 안의 점입니다. 이 띠에서 두 번 측정되는 곳, 곧 짝도 띠 안에 있는 곳은 삼각형 둘이고 나머지는 한 번만 측정됩니다.

  • 시작 삼각형. \(0 \le \beta \le 2(\gamma_m - \gamma)\). 짝의 선원 각 \(\beta + \pi + 2\gamma\)가 \(B\) 이하여야 한다는 조건 \(\beta \le B - \pi - 2\gamma = 2(\gamma_m - \gamma)\)에서 나옵니다.
  • 끝 삼각형. \(\pi - 2\gamma \le \beta \le B\). 시작 삼각형의 점 \((\gamma, \beta)\)의 짝은 \(\gamma' = -\gamma\), \(\beta' = \beta + \pi + 2\gamma\)이고, \(0 \le \beta \le 2(\gamma_m - \gamma)\)에서 \(\pi - 2\gamma' \le \beta' \le \pi + 2\gamma_m = B\)가 되므로 끝 삼각형의 점입니다. 거꾸로도 마찬가지여서 두 삼각형은 서로의 짝으로만 이루어져 있습니다.

시작 삼각형은 \(\gamma = -\gamma_m\) 쪽에서 \(\beta\)의 폭이 \(4\gamma_m\)으로 가장 넓고 \(\gamma = \gamma_m\)에서 폭이 0입니다. 끝 삼각형은 이 모양을 \(180^{\circ}\) 돌린 것입니다. 도형은 직사각형의 중심에 대해 점대칭이지만 한 점의 짝은 중심에 대한 대칭점이 아닙니다. 예를 들어 A \((-15^{\circ},\ 20^{\circ})\)의 짝 A′은 \((15^{\circ},\ 20^{\circ} + 180^{\circ} - 30^{\circ} = 170^{\circ})\)이고, 중심 \((0^{\circ},\ 110^{\circ})\)에 대한 대칭점 \((15^{\circ},\ 200^{\circ})\)과 다릅니다.

스캔 범위에 따른 측정 횟수

스캔 범위가 달라지면 측정 횟수의 분포가 달라집니다. 아래 그림은 \(\gamma_m = 20^{\circ}\)에서 스캔 범위가 \(180^{\circ}\), \(220^{\circ}\), \(360^{\circ}\)일 때 평면 전체(\(\beta\)는 \(0\)~\(360^{\circ}\))를 칠한 것입니다. 색은 그 광선이 가리키는 직선이 몇 번 측정되는지를 뜻합니다. 스캔하지 않는 광선(빗금)이라도 짝이 측정되면 그 직선은 한 번 측정된 것입니다.

  • \(180^{\circ}\). 두 번 측정되는 곳은 작은 삼각형 둘입니다. 빗금 영역의 두 모서리(빨강)에는 짝도 스캔하지 않는 광선이 남고, 이 광선이 가리키는 직선은 한 번도 측정되지 않습니다.
  • \(220^{\circ} = \pi + 2\gamma_m\). 한 번도 측정되지 않는 곳이 없습니다. 두 번 측정되는 삼각형은 \(180^{\circ}\)일 때보다 커집니다.
  • \(360^{\circ}\). 모든 직선을 두 번 측정합니다. 8장의 공식에서 \(\tfrac{1}{2}\)을 곱한 경우입니다.

직선의 개수로 센 비율

이 영역을 직선의 개수로 세면 다음과 같습니다(8장 페이지 6에서 쓴 값입니다. 유도는 생략하며 아래 표의 격자 집계와 같은 값입니다). 직선을 \(\theta\)와 \(s\)에 고르게 놓았을 때 \(\gamma_m = 20^{\circ}\)이면 \(180^{\circ}\)에서 한 번도 못 잰 직선이 5.5%(\((\gamma_m\sin\gamma_m + \cos\gamma_m - 1)/(\pi\sin\gamma_m)\))이고, \(220^{\circ}\)에서 두 번 잰 직선은 22.2%(\(2\gamma_m/\pi\)), 한 번만 잰 직선은 나머지 77.8%입니다.

데이터는 언제 충분하다고 할까요? 데이터 완전성의 조건

선원을 얼마나 돌려야 충분할까요? 평행빔이라면 \(\pi\)면 됩니다. 이 페이지는 평행빔에서 필요한 데이터를 팬빔의 좌표로 옮겨 그려서, 팬빔은 얼마나 돌려야 하는지 봅니다.

데이터 완전성의 정의

재구성에 필요한 것은 영상 영역을 지나는 직선마다의 선적분입니다. 이 모든 직선을 적어도 한 번씩 측정한 데이터를 완전하다고 하고, 이 조건을 데이터 완전성(Data Sufficiency)이라고 합니다. 모든 직선의 선적분을 알면 Radon 변환 \(p(\theta, s)\)가 모든 \((\theta, s)\)에서 주어진 것이므로 5장의 FBP로 영상을 정확히 얻을 수 있습니다. 한 번 측정하면 충분하고, 두 번째 측정은 같은 정보여서 완전성에 더하는 것이 없습니다.

팬 반각 \(\gamma_m\)과 시야

팬빔 장치의 검출기는 팬 각이 \(-\gamma_m\)에서 \(\gamma_m\)인 광선만 받습니다. \(\gamma_m\)은 팬 반각으로, 검출기의 크기와 선원까지의 거리가 정하는 값입니다(7장 페이지 3). 선원이 어디에 있든 팬의 양 끝 광선은 O를 중심으로 한 같은 원에 접하고, 이 원 안을 지나는 직선만 잴 수 있으므로 이 원이 장치의 시야(FOV)입니다(7장 페이지 4). 접점에서 반지름과 접선이 직각이므로 시야의 반지름은 다음과 같습니다.

\[(\text{시야 반지름}) = D\sin\gamma_m\]

필요한 데이터: 평행빔 sinogram의 직사각형

시야 밖을 지나는 직선은 물체를 지나지 않으므로(선적분이 \(0\)), 시야를 지나는 직선, 곧 \(|s| \le D\sin\gamma_m\)인 직선만 있으면 됩니다. 또 \((\theta, s)\)와 \((\theta + \pi,\ -s)\)는 같은 직선이므로(3장 페이지 9) \(\theta\)는 \(0\)에서 \(\pi\)까지면 됩니다. 그래서 평행빔 sinogram에서 \(|s| \le D\sin\gamma_m\), \(0 \le \theta \le \pi\)인 직사각형이 필요한 데이터 전부이고, 평행빔은 \(\pi\)만큼 돌려 이 직사각형을 얻습니다.

직사각형을 팬빔 sinogram으로 옮기면 평행사변형

평행빔의 직선 \((\theta, s)\)는 팬빔에서 팬 각 \(\gamma = \arcsin(s/D)\), 선원 각 \(\beta = \theta - \gamma\)인 광선입니다(7장 페이지 4의 대응을 거꾸로 쓴 것). 직사각형의 네 변이 어디로 가는지 보면 다음과 같습니다.

  • 세로 변 \(s = \pm D\sin\gamma_m\)는 \(\gamma = \pm\gamma_m\)인 세로 변이 됩니다. 시야의 가장자리에 닿는 직선을 재는 광선이 바로 팬의 양 끝 광선이기 때문입니다.
  • 위 변 \(\theta = 0\)은 \(\beta = -\gamma\), 아래 변 \(\theta = \pi\)는 \(\beta = \pi - \gamma\)가 되어, 둘 다 \(\gamma\)에 따라 기울어집니다.

팬빔 장치는 선원 각 \(\beta\)마다 \(\gamma\)의 한 줄(\(-\gamma_m\)~\(\gamma_m\))을 통째로 찍으므로, 팬빔 sinogram에서 스캔한 데이터는 위아래로 긴 띠입니다. 이 띠가 평행사변형을 손실 없이 담으려면 가장 위 꼭짓점 B′(\(\beta = -\gamma_m\))부터 가장 아래 꼭짓점 D′(\(\beta = \pi + \gamma_m\))까지 찍어야 합니다.

결론: 필요한 스캔 범위

기하필요한 스캔 범위이유
평행빔\(\pi\) (\(180^{\circ}\))필요한 데이터가 직사각형이어서 높이 \(\pi\)만큼이면 됩니다.
팬빔(팬 반각 \(\gamma_m\))\(\pi + 2\gamma_m\)같은 데이터가 평행사변형이 되어 위아래로 \(\gamma_m\)씩 늘어납니다.

\(\gamma_m\)이 \(10^{\circ}\), \(20^{\circ}\), \(30^{\circ}\)이면 필요한 범위는 \(200^{\circ}\), \(220^{\circ}\), \(240^{\circ}\)입니다. \(\gamma_m \to 0\)이면 평행사변형이 직사각형으로 돌아가 \(\pi\)가 됩니다. 스캔을 시작하는 각은 어디로 잡아도 됩니다(평행사변형을 위아래로 옮긴 것과 같습니다). 평행사변형을 담고 남는 띠의 두 모서리(삼각형)는 평행사변형 안의 직선을 한 번 더 잰 중복 측정입니다.

물체가 시야보다 작아서 반지름 \(r_0\)(\(< D\sin\gamma_m\))인 원 안에만 있다면, 그 원을 지나는 직선만 있으면 되므로 위 그림에서 \(\gamma_m\) 대신 \(\arcsin(r_0/D)\)를 쓴 범위로 충분합니다. 예를 들어 \(D = 3\) cm, \(r_0 = 1\) cm이면 \(\arcsin(1/3) = 19.47^{\circ}\)이므로, 팬 반각이 이보다 커도 \(218.9^{\circ}\)만 돌리면 이 물체는 완전한 데이터를 얻습니다.

\(\pi + 2\gamma_m\)보다 덜 돌면 평행사변형의 한쪽 꼭짓점 부근을 찍지 못하고, 그 자리의 직선은 한 번도 측정되지 않습니다. 이런 직선을 이 장에서는 빈 직선이라고 부르겠습니다. 빈 직선은 언제나 \(|\gamma|\)가 큰 쪽, 곧 회전 중심에서 먼 직선이며, \(180^{\circ}\)만 돌리면 \(\gamma_m = 20^{\circ}\)에서 직선의 5.5%가 빕니다(페이지 3).

왜 하필 \(\pi + 2\gamma_m\)인지 궤도에서 보기

같은 결론을 선원이 도는 궤도 위에서 한 직선씩 따라가는 설명이 다음 페이지 5(심화)에 있습니다. 처음 읽을 때는 이 페이지의 그림과 결론만으로 충분합니다. 다만 13장의 3차원 데이터 완전성(Tuy 조건)은 페이지 5의 생각을 3차원으로 넓힌 것이므로, 13장을 읽기 전에는 페이지 5를 읽어 두기를 권합니다.

이렇게 필요한 최소 범위 \(\pi + 2\gamma_m\)만 도는 스캔을 short scan(Short Scan)이라고 합니다. 이 데이터를 정확히 재구성하는 대표적인 가중인 Parker 가중(Parker Weight)은 11장에서 다룹니다.

조건의 범위

  • 한 평면의 2차원 조건입니다. 선원이 원 궤도를 도는 하나의 평면과 영상 전체를 정확히 구하려는 경우만 다룹니다. 3차원에서 같은 질문은 13장에서 다룹니다.
  • 정보가 있는지에 대한 조건입니다. 한 번만 측정된 직선은 두 번 측정된 직선과 달리 잡음을 평균하는 효과가 없습니다. 완전한 데이터라도 영상의 잡음이 고르지 않을 수 있습니다.
  • 영상 전체가 필요하다는 전제입니다. 영상의 일부 영역만 구하려면 더 적은 직선으로도 재구성하는 방법이 알려져 있습니다(예: F. Noo, R. Clackdoyle, J. D. Pack, A two-step Hilbert transform method for 2D image reconstruction, Physics in Medicine and Biology 49(17), 2004, 3903–3923). 여기서는 영상 전체를 구하는 경우만 다룹니다.

10장 · 페이지 5 · 심화

왜 \(\pi + 2\gamma_m\)일까요? 선원 궤도에서 보기

페이지 4는 필요한 스캔 범위가 \(\pi + 2\gamma_m\)이라는 것을 평행빔과 팬빔의 sinogram을 대조해 확인했습니다. 이 페이지는 같은 결론을 선원이 도는 궤도 위에서 한 직선씩 따라가며 얻습니다. 페이지 4의 평행사변형이 왜 위아래로 \(\gamma_m\)씩 늘어나는지가 여기서 보이고, 이 생각은 13장의 3차원 데이터 완전성(Tuy 조건)의 1단계가 됩니다.

\(\gamma_m\)은 검출기가 정하는 팬 반각이고(7장 페이지 3), 시야(반지름 \(D\sin\gamma_m\), 페이지 4)를 지나는 직선은 모두 \(|\gamma| \le \gamma_m\)인 광선으로 잽니다. 이 페이지에서 "모든 직선"은 시야를 지나는 직선을 뜻합니다. 예는 모두 \(\gamma_m = 20^{\circ}\)입니다.

1단계: 직선 하나를 측정할 기회는 두 번뿐입니다

측정은 선원에서 나간 광선으로만 할 수 있습니다. 그래서 어떤 직선의 선적분을 재려면 선원이 그 직선 위에 있어야 합니다. 그때 선원이 내보내는 팬 가운데 한 광선이 그 직선을 따라가기 때문입니다. 선원은 반지름 \(D\)인 원(선원 궤도) 위만 움직이고, 영상 영역을 지나는 직선은 이 원과 꼭 두 점에서 만납니다. 이 두 점이 페이지 2의 S와 S′입니다.

기억할 것

S와 S′는 직선마다 정해지는 두 선원 위치입니다. 스캔을 시작하는 위치나 끝내는 위치를 뜻하는 것이 아닙니다. 직선 하나를 측정할 기회는 선원이 S를 지날 때와 S′를 지날 때, 이 두 번뿐입니다.

스캔하는 동안 선원은 \(\beta = 0\)에서 \(\beta = B\)까지의 호를 지나갑니다. 이 호를 스캔하는 호, 나머지 \(2\pi - B\)를 스캔하지 않는 호라고 부르겠습니다. S와 S′가 어느 호 위에 있느냐에 따라 그 직선이 몇 번 측정되는지가 정해집니다.

S와 S′ 가운데 하나만 스캔하는 호 위에 있음1번

데이터가 완전하다는 것은 빈 직선이 하나도 없다는 뜻입니다. 그러므로 질문은 이렇게 바뀝니다. "\(B\)를 얼마로 하면 S와 S′가 둘 다 스캔하지 않는 호 위에 놓이는 직선이 없어질까?"

2단계: S와 S′는 O에서 보아 얼마나 벌어져 있을까요?

S와 S′가 O에서 보아 벌어진 각, 곧 두 점 사이의 짧은 쪽 호의 중심각은 직선마다 다릅니다. 페이지 2에서 본 삼각형 OSS′는 OS와 OS′가 모두 반지름 \(D\)인 이등변삼각형이고, S에서의 밑각이 그 직선을 재는 광선의 팬 각 \(|\gamma|\)입니다(광선 SS′와 중심 광선 SO 사이의 각). 두 밑각이 같고 세 각의 합이 \(\pi\)이므로, O에서의 각은 다음과 같습니다.

\[\angle \mathrm{SOS'} = \pi - 2|\gamma|\]

시야를 지나는 직선은 \(|\gamma| \le \gamma_m\)이므로, 중심각이 가장 작은 직선은 \(|\gamma| = \gamma_m\)인 광선(팬의 양 끝 광선)으로 재는 직선, 곧 시야의 가장자리에 닿는 직선이고 그 중심각은 \(\pi - 2\gamma_m\)입니다(\(\gamma_m = 20^{\circ}\)이면 \(140^{\circ}\)).

각으로 재는 이유

이 페이지에서 두 점이 "벌어진 정도"는 직선거리가 아니라 O에서 잰 각(중심각)입니다. 선원 궤도의 반지름은 \(D\)이므로 실제 호의 길이는 \(D \times\)(중심각)이지만, 이 페이지는 두 호를 서로 비교하기만 하므로 각만 있으면 됩니다. 스캔 범위 \(B\)도 선원 각이 도는 양이어서 중심각입니다.

3단계: 언제 두 기회를 모두 놓칠까요?

이제 어떤 직선을 한 번도 측정하지 못하는 경우, 곧 선원이 S도 S′도 지나가지 않는 경우를 생각해 봅니다. 1단계의 표에서 그런 직선은 S와 S′가 둘 다 스캔하지 않는 호 위에 놓인 직선이었습니다.

두 점이 함께 스캔하지 않는 호 위에 놓이려면, 두 점의 중심각이 그 호보다 크면 안 됩니다. 길이가 \(150\)인 막대를 길이 \(160\)인 칸에는 넣을 수 있지만 길이 \(140\)인 칸에는 넣을 수 없는 것과 같습니다. 스캔하지 않는 호의 중심각은 \(2\pi - B\)이므로, 직선이 빌 수 있는 조건은 다음과 같습니다.

\[\pi - 2|\gamma| \;\le\; 2\pi - B \qquad\Longleftrightarrow\qquad B \;\le\; \pi + 2|\gamma|\]

\(B = 200^{\circ}\)로 예를 들어 봅니다. 스캔하지 않는 호의 중심각은 \(160^{\circ}\)입니다.

  • \(|\gamma| = 15^{\circ}\)인 직선. 두 점의 중심각은 \(180^{\circ} - 30^{\circ} = 150^{\circ}\)로 \(160^{\circ}\)보다 작아서, 자리만 맞으면 둘 다 스캔하지 않는 호 위에 놓입니다. 그림의 빨간 직선은 S가 \(355^{\circ}\), S′가 \(205^{\circ}\)에 있습니다. 선원이 \(0^{\circ}\)에서 \(200^{\circ}\)까지 도는 동안 한 번도 이 직선 위에 오지 않으므로 이 직선은 비어 있습니다.
  • \(|\gamma| = 5^{\circ}\)인 직선. 두 점의 중심각은 \(170^{\circ}\)로 \(160^{\circ}\)보다 커서, 어디에 놓여도 한 점은 스캔하는 호 위에 걸칩니다. 그림의 파란 직선은 S가 \(300^{\circ}\), S′가 \(130^{\circ}\)에 있어 선원이 \(130^{\circ}\)를 지날 때 측정됩니다.
  • 경계. 중심각이 정확히 \(160^{\circ}\)인 직선은 \(|\gamma| = 10^{\circ}\)입니다. 그래서 \(B = 200^{\circ}\)에서 빌 수 있는 직선은 \(|\gamma| > 10^{\circ}\)인 광선으로 재는 직선, 곧 시야의 가장자리 쪽 직선뿐입니다. 일반적으로는 \(|\gamma| > (B - \pi)/2\)입니다.

이제 \(B\)를 늘려 봅니다. 가장 작은 중심각은 \(|\gamma| = \gamma_m\)인 직선의 \(\pi - 2\gamma_m\)이었습니다(2단계). 이 가장 작은 중심각조차 스캔하지 않는 호보다 작지 않으면, 어떤 직선도 두 점이 함께 그 호 위에 놓일 수 없습니다.

\[\pi - 2\gamma_m \;\ge\; 2\pi - B \qquad\Longleftrightarrow\qquad B \;\ge\; \pi + 2\gamma_m\]

\(B = \pi + 2\gamma_m\)이면 \(|\gamma| = \gamma_m\)인 직선의 중심각이 스캔하지 않는 호와 똑같아, 두 점이 그 호의 양 끝에 정확히 놓이는 직선이 생깁니다. 그런데 양 끝은 스캔을 시작한 점과 끝낸 점이므로 측정됩니다. 그래서 이때도 빈 직선은 없습니다(아래 그림의 실선 현).

4단계: 페이지 4의 평행사변형과 짝짓기

페이지 4에서 평행빔의 직사각형을 팬빔 sinogram으로 옮기면 평행사변형이 되었습니다. 그 평행사변형의 위 변(\(\theta = 0\))과 아래 변(\(\theta = \pi\))은 사실 같은 직선들입니다. 위 변의 점 \((\gamma,\ -\gamma)\)의 짝은 \((-\gamma,\ -\gamma + \pi + 2\gamma) = (-\gamma,\ \pi + \gamma)\)로, 아래 변 위에 있습니다. 곧 한 직선의 두 측정 기회 S, S′가 평행사변형의 위 변과 아래 변에 하나씩 놓입니다.

두 기회의 선원 각 차이는 \(\pi + 2\gamma\)이고, 이것은 궤도에서 S와 S′ 사이의 긴 쪽 호의 중심각(\(2\pi - (\pi - 2|\gamma|)\))입니다. 차이가 가장 큰 것은 \(|\gamma| = \gamma_m\)인 가장자리 직선이고, 그 두 기회가 평행사변형의 꼭짓점 B′(\(\beta = -\gamma_m\))와 D′(\(\beta = \pi + \gamma_m\))입니다. 두 그림은 같은 사실을 다르게 그린 것입니다.

3차원으로 이어지는 생각

이 페이지의 출발점은 "직선 하나를 재려면 선원이 그 직선 위에 있어야 하고, 그러려면 그 직선이 스캔한 궤도와 만나야 한다"는 것이었습니다. 3차원 콘빔에서는 같은 생각을 직선 대신 평면에 적용합니다. 물체 안의 점을 지나는 평면이 선원 궤도와 만나지 않으면, 그 평면의 정보가 데이터에 들어오지 않습니다. 이것이 13장 페이지 6~7(심화)의 Tuy 조건입니다. 2차원에서 "모든 직선이 스캔한 궤도와 만나는가"를 물었다면, 3차원에서는 "모든 평면이 궤도와 만나는가"를 묻습니다.

10장 · 페이지 6

두 번 잰 직선은 어떻게 합칠까요? 중복 데이터를 합치는 가중

스캔 범위를 \(\pi + 2\gamma_m\)으로 줄이면 어떤 직선은 두 번, 어떤 직선은 한 번 측정됩니다. 8장의 공식은 모든 직선이 두 번 측정되었다는 전제로 모든 광선에 \(\tfrac{1}{2}\)을 곱했습니다. 이 전제가 깨지면 곱해야 할 값은 광선마다 달라집니다.

광선마다 다른 가중

9장의 이산 알고리즘에서 이 \(\tfrac{1}{2}\)은 각도 합의 상수 \(\pi/N_\beta = \tfrac{1}{2}\Delta\beta\)에 들어 있습니다. 광선마다 다른 가중 \(w(\beta, \gamma)\)를 쓰면 다음과 같이 바뀝니다.

\[\tilde R[k, n] = R[k, n]\,w(\beta_k, \gamma_n)\,\frac{D}{\sqrt{D^{2} + t_n^{2}}},\qquad \mu(x, y) \approx \Delta\beta\sum_{k} \frac{q_k(t')}{U^{2}}\]

  • \(w(\beta_k, \gamma_n)\). 선원 각 번호 \(k\), 칸 번호 \(n\)인 광선의 가중입니다. 광선에만 의존하므로 코사인 가중과 같이 필터링 앞에서 곱합니다.
  • \(\Delta\beta\). 선원 각의 간격입니다. \(\tfrac{1}{2}\)은 따로 곱하지 않습니다. \(w\)에 이미 들어 있기 때문이며, 곱하면 두 번 곱하게 됩니다.
  • \(w = \tfrac{1}{2}\)이면 \(\Delta\beta \cdot \tfrac{1}{2} = \pi/N_\beta\)여서 9장의 알고리즘과 같습니다. 나머지 기호는 9장 페이지 4와 같습니다.

한 직선의 총 가중

8장 페이지 2~3에서 한 바퀴의 공식은 평행빔 공식을 변수 바꿈한 것이었습니다. 짝 광선에서는 이 식의 피적분 함수가 같은 값을 갖습니다. 근거는 세 가지입니다.

  • 투영값이 같습니다.
  • 커널 \(h\)가 짝함수입니다.
  • 야코비안 \(D\cos\gamma\)는 \(\gamma\)의 부호가 바뀌어도 같습니다.

그러므로 한 직선이 영상에 주는 기여는 한 광선분의 기여에 두 가중의 합을 곱한 것입니다. 한 바퀴의 데이터에서는 \(w = \tfrac{1}{2}\) 둘의 합이 1이어서 영상이 정확했습니다. 정확한 영상이 되려면 모든 직선에서 합이 1이어야 합니다.

\[w(\beta,\ \gamma) + w(\beta + \pi + 2\gamma,\ -\gamma) = 1\]

짝 광선의 가중 \(w(\beta + \pi + 2\gamma,\ -\gamma)\)를 \(w'\)로 줄여 씁니다. 측정하지 않은 광선의 가중은 0입니다. 직선을 한 번만 측정했다면 이 식은 측정한 광선의 가중이 1이라는 뜻입니다.

불연속 가중과 줄무늬

합이 1이 되는 가장 단순한 가중은 두 번 측정되는 광선에 \(\tfrac{1}{2}\), 한 번 측정되는 광선에 1을 곱하는 것입니다. 이 가중을 계단 가중이라고 하겠습니다. 한 번 잰 직선의 총 가중은 1이고 두 번 잰 직선은 \(\tfrac{1}{2} + \tfrac{1}{2} = 1\)이어서 모든 직선에서 합이 1입니다(무작위 광선 20만 개에서 \(w + w'\)와 1의 차이는 0이었습니다). 그런데 이 가중으로 재구성하면 영상이 맞지 않습니다.

10장 · 페이지 8

가중 설계의 두 원리

페이지 6와 6의 결과는 가중이 만족할 두 조건으로 모입니다. 하나는 영상의 값이 정확하기 위한 조건이고, 다른 하나는 필터링을 거쳐도 줄무늬가 생기지 않기 위한 조건입니다.

원리 1. 짝의 가중 합이 1

\[w(\beta,\ \gamma) + w(\beta + \pi + 2\gamma,\ -\gamma) = 1\]

측정하지 않은 광선의 가중은 0으로 둡니다. 그러면 짝이 측정되지 않은 광선의 가중은 1이어야 하고, 어느 쪽도 측정되지 않은 직선에서는 이 식을 만족할 수 없습니다. 페이지 4에서 본 대로 빈 직선은 가중으로 채울 수 없다는 말과 같습니다.

원리 2. 광선 위치에 따라 끊김 없이 변하는 가중

필터링은 한 선원 각의 행 안에서 이루어지므로 \(\gamma\) 방향으로 점프하는 가중은 줄무늬를 만듭니다(페이지 7). 가중이 평면 전체에서 연속이면 점프가 없습니다. \(\gamma\) 방향과 \(\beta\) 방향 모두에서, 가중이 바뀌는 정도(변화)의 가장 높은 주파수 성분이 필터가 \(|\omega| \le W\)까지만 곱하는 차단 주파수 \(W\)(5장 페이지 9) 이하로 들어올 만큼 가중이 부드럽게 변해야 합니다. 기울기까지 이어져야 하는지는 선형 램프와 매끄러운 램프로 재구성해 비교합니다.

이 두 원리를 만족하는 가중은 하나로 정해지지 않습니다. 두 원리만 만족하면 이상적인(잡음 없는 2차원) 데이터에서는 정확한 재구성이 가능합니다. 페이지 6~7에서 비교한 모두 1, 모두 \(\tfrac{1}{2}\), 계단 가중은 둘 중 한 원리를 어겨 영상이 어긋났고, 아래에서 비교하는 선형 램프와 매끄러운 램프는 서로 다른 함수이면서도 둘 다 두 원리를 만족합니다. 다음 페이지 9의 \(\beta\)–\(\gamma\) 평면 위젯에서 스캔 범위를 \(180^{\circ} + 2\gamma_m\)으로 두고 계단 · 선형 램프 · 매끄러운 램프를 번갈아 골라 보면, "\(w + w' \ne 1\)인 광선" 비율은 셋 다 0.0%이지만 평면에 칠한 가중의 경계가 계단에서만 갑자기 바뀌는 것을 직접 볼 수 있습니다.

두 원리를 함께 만족하는 구성

원리 1의 식은 두 번 측정되는 영역의 광선 쌍마다 하나씩이고, 두 영역은 시작 삼각형과 끝 삼각형으로 서로의 짝입니다. 그러므로 시작 삼각형의 가중을 정하면 끝 삼각형의 가중도 함께 정해집니다. 구성은 다음과 같습니다(\(B = \pi + 2\gamma_m\)).

  • 시작 삼각형. \(\lambda = \dfrac{\beta}{2(\gamma_m - \gamma)}\)로 두고 \(w = f(\lambda)\).
  • 끝 삼각형. \(\lambda' = \dfrac{B - \beta}{2(\gamma_m + \gamma)}\)로 두고 \(w = f(\lambda')\).
  • 그 밖에 측정되는 광선. \(w = 1\). 스캔하지 않는 광선은 \(w = 0\).

\(\lambda\)는 삼각형 안에서 스캔의 가장자리 변(시작 삼각형은 \(\beta = 0\), 끝 삼각형은 \(\beta = B\))에서 빗변까지의 위치를 \(0\)에서 \(1\)로 나타낸 값입니다. 경사 함수 \(f(\lambda)\)는 \(f(0) = 0\), \(f(1) = 1\)이고 \(f(\lambda) + f(1 - \lambda) = 1\)을 만족하는 함수입니다. 이 구성이 두 원리를 만족하는 이유는 다음과 같습니다.

  • 합이 1입니다. 시작 삼각형의 광선 \((\gamma, \beta)\)의 짝은 끝 삼각형에 있고 그 위치는 \(\lambda' = 1 - \lambda\)입니다(아래 접기). 그래서 \(w + w' = f(\lambda) + f(1 - \lambda) = 1\)입니다.
  • 가중이 이어집니다. 시작 삼각형의 가장자리 변(\(\lambda = 0\))에서 \(w = f(0) = 0\)이어서 스캔하지 않는 광선의 0과 이어지고, 빗변(\(\lambda = 1\))에서 \(w = f(1) = 1\)이어서 한 번만 측정되는 광선의 1과 이어집니다. 끝 삼각형도 같습니다.
짝의 위치가 \(\lambda' = 1 - \lambda\)인 계산

시작 삼각형의 광선 \((\gamma, \beta)\)의 짝은 \(\gamma' = -\gamma\), \(\beta' = \beta + \pi + 2\gamma\)입니다. 끝 삼각형의 위치는 다음과 같습니다.

\[\lambda' = \frac{B - \beta'}{2(\gamma_m + \gamma')} = \frac{\pi + 2\gamma_m - \beta - \pi - 2\gamma}{2(\gamma_m - \gamma)} = \frac{2(\gamma_m - \gamma) - \beta}{2(\gamma_m - \gamma)} = 1 - \lambda\]

\(f(\lambda) + f(1 - \lambda) = 1\)이 필요한 이유가 여기에 있습니다. 끝 삼각형의 점에서 시작하면 같은 계산으로 \(\lambda = 1 - \lambda'\)입니다.

β–γ 평면의 스캔 범위와 가중

팬 반각, 스캔 범위, 가중의 종류를 바꾸면서 \(\beta\)–\(\gamma\) 평면의 가중과 짝의 합을 확인합니다. 위젯에서 볼 수 있는 결과는 다음과 같습니다.

핵심 요약

  1. 같은 직선을 재는 두 광선(중복 광선)의 좌표는 \((\beta, \gamma)\)와 \((\beta + \pi + 2\gamma,\ -\gamma)\)입니다. 선원 궤도의 두 교점 S, S′와 중심 O로 이루어진 이등변삼각형에서 나오며, 평행빔과 달리 두 선원 각의 차이 \(\pi + 2\gamma\)가 광선마다 다릅니다.
  2. 데이터 완전성은 영상 영역의 모든 직선을 적어도 한 번 측정하는 조건입니다. 평행빔은 \(\pi\), 팬빔은 \(\pi + 2\gamma_m\)이 필요하고, 물체가 반지름 \(r_0\)의 원 안에 있으면 \(\pi + 2\arcsin(r_0/D)\)로 충분합니다. 이보다 짧으면 팬 가장자리의 직선이 비고 가중으로 채울 수 없습니다.
  3. 스캔 범위 \(\pi + 2\gamma_m\)에서 \(\beta\)–\(\gamma\) 평면의 두 번 측정되는 영역은 시작 삼각형과 끝 삼각형이고 서로의 짝입니다. 나머지는 한 번 측정됩니다.
  4. 가중 \(w(\beta, \gamma)\)는 두 원리를 만족해야 합니다. 짝의 합이 1이어야 하고(측정하지 않은 광선은 0), 광선 위치에 따라 점프 없이 변해야 합니다. 합이 1이어도 계단 가중은 필터링에서 점프가 커져 줄무늬가 생깁니다(안쪽 rms 0.0735, 이어지는 가중은 0.0016).
  5. 가중은 \(\tilde R = R\,w\,D/\sqrt{D^{2} + t^{2}}\)로 필터링 앞에서 곱하고 각도 합에는 \(\Delta\beta\)를 씁니다. \(\tfrac{1}{2}\)을 따로 곱하지 않으며, \(w = \tfrac{1}{2}\)이면 9장의 \(\pi/N_\beta\)입니다.

  2. \((250^{\circ},\ -25^{\circ})\)
  3. \((200^{\circ},\ -25^{\circ})\)
