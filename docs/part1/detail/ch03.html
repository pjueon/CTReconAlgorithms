3장 · 페이지 1

찍은 데이터는 어떤 모양일까요? Radon 변환과 sinogram

0편 2장에서는 광선 하나의 투영값과, 한 방향에서 모은 투영 한 장을 보았습니다. 이 장에서는 방향을 바꿔 가며 모은 투영 전체가 어떤 구조를 갖는지 봅니다. 광선이 모두 나란한 평행빔을 기준으로 합니다.

평행빔 스캔에서 측정되는 것

광선이 모두 같은 방향으로 나란히 나아가는 스캔 방식을 평행빔(Parallel Beam)이라고 합니다. 0편 2장 페이지 5의 그림이 평행빔의 한 방향이었습니다. 초기의 CT 장치는 가는 X선 빔 하나를 옆으로 옮겨 가며 재고, 장치를 조금 돌린 뒤 같은 측정을 되풀이하는 방식으로 평행빔 데이터를 얻었습니다. 지금의 장치는 대부분 한 점에서 퍼지는 팬빔을 쓰지만, 팬빔 데이터도 평행빔 데이터로 재배열할 수 있습니다. 그래서 평행빔에서 세운 식이 뒷장 전체의 기준이 됩니다.

한 방향의 측정을 먼저 봅시다. 나란한 광선이 물체를 지나 검출기에 닿고, 검출기 칸마다 광선 하나의 투영값 \(p\)가 정해집니다. 이 값들을 검출기 위의 위치 순서로 이은 것이 0편 2장에서 본 투영 한 장입니다.

장치가 돌면 검출기의 방향 \(\theta\)가 바뀌고, 각도마다 투영 곡선이 하나씩 생깁니다. 그러므로 측정 데이터 전체는 두 숫자, 즉 각도와 검출기 위의 위치로 정해지는 값의 모음입니다. 이 모음을 식으로 쓰고, 영상처럼 그려서 읽는 방법을 배우는 것이 이 장의 목표입니다.

이 장의 진행

  1. 평행빔의 광선 하나를 두 숫자 \((\theta, s)\)로 나타냅니다.
  2. 투영값을 \((\theta, s)\)의 함수로 쓰고(Radon 변환), 델타 함수로 쓰는 표기를 익힙니다.
  3. 기준 영상인 Shepp-Logan 팬텀을 소개하고, 타원 하나의 투영값을 식으로 구합니다(페이지 4~5, 심화).
  4. 투영값 전체를 영상으로 그린 sinogram을 읽고, 위젯으로 직접 확인합니다.
  5. Radon 변환의 성질과 대칭성을 정리하고, 180° 측정이 왜 충분한지 봅니다.
  6. 실제 장치가 주는 이산 sinogram의 모양을 봅니다.

페이지 머리에 "심화"가 붙은 페이지(4, 5, 8)는 처음 읽을 때 건너뛰어도 됩니다.

3장 · 페이지 2

광선의 좌표

평행빔에서 광선 하나를 정하려면 숫자가 몇 개 필요할까요? 먼저 장치가 어느 방향을 보고 있는지, 즉 각 하나가 필요합니다. 그 방향의 나란한 광선 가운데 어느 것인지, 즉 검출기 위의 위치가 하나 더 필요합니다. 그래서 숫자 두 개면 충분합니다.

두 숫자의 정의

검출기가 놓인 방향, 다시 말해 광선에 수직인 방향을 \(x\) 축에서 반시계 방향으로 잰 각을 \(\theta\)라고 하겠습니다. 원점 \(O\)에서 이 방향으로 잰 광선까지의 거리를 \(s\)라고 하고, 광선이 원점의 반대쪽에 있으면 \(s\)는 음수입니다. \(\theta\)를 투영 각도, \(s\)를 검출기 좌표라고 부릅니다. 원점은 0편 3장의 규약대로 장치의 회전 중심입니다.

1장 페이지 1의 회전 좌표로 보면, \(\theta\)만큼 돌린 \(x'\) 축이 검출기 방향이고 광선은 \(x' = s\)인 직선입니다. 식으로는 다음과 같습니다.

\[x\cos\theta + y\sin\theta = s\]

광선 위의 점

광선 위의 점은 회전 좌표에서 \(x' = s\)이고, 광선을 따라 잰 위치가 \(y'\)입니다. 이 위치를 0편 2장처럼 \(\ell\)로 쓰고 1장의 역변환에 \(x' = s,\ y' = \ell\)을 넣으면 다음과 같습니다.

\[x = s\cos\theta - \ell\sin\theta,\qquad y = s\sin\theta + \ell\cos\theta\]

이 식은 0편 2장 페이지 4의 매개변수화에서 기준점을 \((x_0, y_0) = (s\cos\theta,\ s\sin\theta)\)로, 방향을 \((u_x, u_y) = (-\sin\theta,\ \cos\theta)\)로 잡은 것과 같습니다. 기준점은 원점에서 광선에 내린 수선의 발 \(F\)입니다. 대입해서 확인하면 \(x\cos\theta + y\sin\theta = s\cos^{2}\theta + s\sin^{2}\theta = s\)이고, \(\ell\)이 든 항은 서로 상쇄됩니다.

투영 각도와 광선 방향

\(\theta\)는 광선이 나아가는 방향이 아니라 광선에 수직인 방향의 각입니다. 광선 자체는 \(\theta + 90^{\circ}\) 방향으로 나아갑니다. 그래서 \(\theta = 0\)이면 검출기가 \(x\) 축 방향으로 놓이고, 광선은 \(y\) 방향으로 나아가는 세로 광선입니다.

0편 2장의 정사각형 두 개(한 변 1 cm, 중심 \((-2, 2)\)와 \((2, -2)\))에 쓴 광선을 이 좌표로 옮기면 다음과 같습니다.

0편 2장의 광선\((\theta, s)\)확인
세로 광선 \(x = -2\)\((0,\ -2)\)\(\theta = 0\)이면 식이 \(x = s\)
가로 광선 \(y = 2\)\((\pi/2,\ 2)\)\(\theta = \pi/2\)이면 식이 \(y = s\)
대각선 광선 \(y = -x\)\((\pi/4,\ 0)\)\((x + y)/\sqrt2 = 0\)이고 원점을 지남

물체가 원점을 중심으로 하는 반지름 \(R\)인 원 안에 있으면, 물체를 지나는 광선은 \(|s| \le R\)인 것뿐입니다. 각은 장치가 한 바퀴 도는 동안 \(0 \le \theta < 2\pi\)를 지납니다. 다만 같은 직선을 두 가지 \((\theta, s)\)로 나타낼 수 있어서, 실제로 필요한 각의 범위는 더 좁습니다.

3장 · 페이지 3

투영 전체를 식 하나로: Radon 변환과 델타 함수 표기

이제 광선마다의 투영값을 \((\theta, s)\)의 함수로 쓸 수 있습니다. 0편 2장 페이지 4의 선적분에 페이지 2의 광선 위의 점을 넣으면 다음과 같습니다.

\[p(\theta, s) = \int_{-\infty}^{\infty} \mu\bigl(s\cos\theta - \ell\sin\theta,\ \ s\sin\theta + \ell\cos\theta\bigr)\,d\ell\]

영상 \(\mu(x, y)\)를 넣으면 모든 직선의 선적분 \(p(\theta, s)\)가 나오는 이 변환을 Radon 변환(Radon Transform)이라고 합니다. 수학자 Radon이 1917년 논문에서 한 함수의 모든 직선 위 적분을 알면 원래 함수를 되찾을 수 있음을 보이고, 그 역공식을 제시했습니다(J. Radon, Über die Bestimmung von Funktionen durch ihre Integralwerte längs gewisser Mannigfaltigkeiten, Berichte über die Verhandlungen der Sächsischen Akademie der Wissenschaften zu Leipzig, Mathematisch-Physische Klasse, 69, 262–277, 1917). 0편 2장의 투영 연산자 \(\mathcal{P}\)가 평행빔에서는 Radon 변환이 되고, 광선 하나의 투영값 \(p\)를 광선의 각도 \(\theta\)와 위치 \(s\)로 나타낸 \(p(\theta, s)\)가 이 함수입니다.

위 식은 광선마다 매개변수 \(\ell\)을 따로 써야 합니다. 영상 전체에 대한 적분과 순서를 바꿔 계산할 때는 \(\mu\)를 영상 전체에서 적분하는 이중적분으로 쓰는 편이 편하고, 이때 델타 함수가 쓰입니다. 식으로 쓰면 다음과 같습니다.

\[p(\theta, s) = \iint \mu(x, y)\,\delta(x\cos\theta + y\sin\theta - s)\,dx\,dy\]

이 식을 읽으려면 델타 함수 \(\delta\)가 무엇을 하는지 알아야 합니다.

델타 함수와 Sifting 성질

2장 페이지 2에서는 델타 함수를 넓이를 1로 유지하면서 폭을 0으로 좁힌 봉우리로 생각했습니다. 이 직관을 식으로 옮겨 봅니다. 폭 \(\varepsilon\), 높이 \(1/\varepsilon\)인 사각형 봉우리 \(\delta_\varepsilon(x) = \mathrm{rect}(x/\varepsilon)/\varepsilon\)는 넓이가 1입니다. 함수 \(f\)에 이 봉우리를 \(a\)로 옮겨 곱하고 적분하면 다음과 같습니다.

\[\int f(x)\,\delta_\varepsilon(x - a)\,dx = \frac{1}{\varepsilon}\int_{a-\varepsilon/2}^{a+\varepsilon/2} f(x)\,dx\]

오른쪽은 \(a\) 근처 폭 \(\varepsilon\)에서 \(f\)의 평균이므로, \(f\)가 연속이면 \(\varepsilon \to 0\)에서 \(f(a)\)로 갑니다. 이 극한을 델타 함수(Dirac Delta Function) \(\delta\)로 씁니다.

\[\int_{-\infty}^{\infty} f(x)\,\delta(x - a)\,dx = f(a)\]

델타 함수는 보통의 함수가 아닙니다. \(x = 0\)에서의 값이 정해지지 않고, 위 식처럼 다른 함수와 곱해 적분했을 때의 결과로 정의됩니다. 적분하면 \(a\)에서의 값만 남는 이 성질을 Sifting 성질(값을 골라내는 성질)이라고 합니다.

델타 함수 안의 변수에 상수가 곱해지면 인자가 하나 붙습니다. \(c \ne 0\)이면 다음과 같습니다.

\[\delta(cx - b) = \frac{1}{|c|}\,\delta\!\left(x - \frac{b}{c}\right)\]

봉우리 \(\delta_\varepsilon(cx - b)\)는 \(x = b/c\)에 있고 폭이 \(\varepsilon/|c|\)로 줄지만 높이는 \(1/\varepsilon\) 그대로여서, 넓이가 \(1/|c|\)이기 때문입니다. 이 인자는 타원의 투영과 대칭성을 다룰 때 씁니다.

Sifting 성질과 스케일 인자의 전개

1단계. Sifting 성질. \(f\)가 \(a\)에서 연속이면, 폭 \(\varepsilon\) 구간에서 \(f\)의 최솟값 \(m_\varepsilon\)과 최댓값 \(M_\varepsilon\)은 모두 \(\varepsilon \to 0\)에서 \(f(a)\)로 갑니다. 평균은 둘 사이에 있습니다.

\[m_\varepsilon \le \frac{1}{\varepsilon}\int_{a-\varepsilon/2}^{a+\varepsilon/2} f(x)\,dx \le M_\varepsilon\]

그래서 평균도 \(f(a)\)로 갑니다. 이것이 \(\int f(x)\,\delta(x - a)\,dx = f(a)\)의 뜻입니다.

2단계. 스케일 인자. \(\int f(x)\,\delta(cx - b)\,dx\)에서 \(t = cx - b\)로 치환합니다. \(dx = dt/c\)이고 \(x = (t + b)/c\)입니다. \(c > 0\)이면 적분 구간이 그대로입니다.

\[\int f(x)\,\delta(cx - b)\,dx = \frac{1}{c}\int f\!\left(\frac{t + b}{c}\right)\delta(t)\,dt = \frac{1}{c}\,f\!\left(\frac{b}{c}\right)\]

\(c < 0\)이면 치환할 때 적분 구간의 위아래가 바뀌어 부호가 하나 더 붙으므로 \(1/|c|\)가 됩니다(2장 페이지 3의 스케일 성질과 같은 이유입니다). 결과가 \(\int f(x)\,\tfrac{1}{|c|}\,\delta(x - b/c)\,dx\)와 같으므로 두 델타 함수는 같은 것입니다.

이중적분 속 델타 함수와 직선

2차원에서 \(\delta(y)\)를 곱해 적분하면 어떻게 될까요? \(\delta(y)\)는 \(y\)에만 의존하므로, \(x\)마다 \(y\)에 대한 적분이 \(y = 0\)의 값만 남깁니다.

\[\iint f(x, y)\,\delta(y)\,dx\,dy = \int f(x, 0)\,dx\]

결과는 직선 \(y = 0\)을 따라 잰 선적분입니다. 같은 방식으로 \(\delta(x\cos\theta + y\sin\theta - s)\)는 직선 \(x' = s\) 위의 값만 남기므로, 맨 위의 이중적분은 그 직선의 선적분 \(p(\theta, s)\)가 됩니다.

0편 2장의 정사각형으로 확인해 봅니다. \(\theta = 0,\ s = -2\)이면 델타 함수는 \(\delta(x + 2)\)이고 \(x = -2\)의 값만 남습니다. 정사각형 안에서 \(y\)는 1.5에서 2.5까지이므로 \(p(0, -2) = \int_{1.5}^{2.5} 0.45\,dy = 0.45\)이고, 0편 2장 페이지 6의 값과 같습니다.

델타 함수 표기와 선적분이 같은 이유

1단계. 회전 좌표로 치환. 이중적분에서 \(x' = x\cos\theta + y\sin\theta,\ y' = -x\sin\theta + y\cos\theta\)로 변수를 바꿉니다. 1장 페이지 2의 행렬식은 \(\cos^{2}\theta + \sin^{2}\theta = 1\)이어서 \(dx\,dy = dx'\,dy'\)입니다.

\[\begin{aligned}&\iint \mu(x, y)\,\delta(x\cos\theta + y\sin\theta - s)\,dx\,dy\\ &= \iint \mu\bigl(x'\cos\theta - y'\sin\theta,\ x'\sin\theta + y'\cos\theta\bigr)\,\delta(x' - s)\,dx'\,dy'\end{aligned}\]

2단계. Sifting 성질. \(x'\)에 대한 적분이 \(x' = s\)의 값만 남깁니다.

\[= \int \mu\bigl(s\cos\theta - y'\sin\theta,\ s\sin\theta + y'\cos\theta\bigr)\,dy'\]

3단계. 비교. 적분 변수 \(y'\)을 \(\ell\)로 바꾸면 이 페이지 맨 위의 정의와 같습니다. 회전 좌표에서 \(x' = s\)인 직선이 광선이고 \(y'\)은 그 직선을 따라 잰 위치이므로, 광선 하나를 따라 더하는 적분은 \(y'\)에 대한 적분입니다.

다른 책의 표기

주 참고서(Kak & Slaney)는 투영을 \(P_\theta(t)\), 영상을 \(f(x, y)\)로 씁니다. 이 책은 대문자를 푸리에 변환에 쓰므로(2장) 투영을 소문자 \(p(\theta, s)\)로, 영상을 \(\mu\)로 씁니다. Radon 변환을 연산자 기호 \(\mathcal{R}\)로 쓰는 책도 있습니다. 또 책에 따라 각을 광선의 진행 방향으로 재기도 하므로, 식을 옮길 때는 각이 법선 방향인지 진행 방향인지 먼저 확인하세요. 두 각은 \(90^{\circ}\) 다릅니다.

Shepp-Logan 팬텀과 타원 매개변수

재구성 방법이 제대로 동작하는지 보려면 정답을 아는 영상이 필요합니다. 시험용으로 정해 둔 이런 영상이나 모형을 팬텀(Phantom)이라고 합니다. 이 책은 끝까지 한 팬텀을 기준으로 씁니다. Shepp과 Logan이 1974년에 머리 단면을 흉내 내어 만든 Shepp-Logan 팬텀이며(L. A. Shepp, B. F. Logan, The Fourier reconstruction of a head section, IEEE Transactions on Nuclear Science, NS-21(3), 21–43, 1974), 주 참고서도 같은 팬텀을 씁니다.

이 팬텀은 타원 열 개를 겹쳐 만듭니다. 타원을 쓰는 이유는 타원 하나의 Radon 변환을 식 하나로 정확히 계산할 수 있기 때문입니다. 그래서 근사 없이 정확한 투영 데이터를 만들 수 있고, 재구성 결과를 정답과 바로 비교할 수 있습니다.

타원 매개변수

타원이 겹치는 곳은 값을 더합니다. 그래서 실제 영상의 값은 다음과 같습니다. 타원 a 안이면서 b 밖인 얇은 테두리가 두개골로 2.00이고, b 안쪽의 뇌는 \(2.00 - 0.98 = 1.02\)입니다. 검은 두 타원 c, d(뇌실)는 \(1.02 - 0.02 = 1.00\)이고, 작은 구조 e~j는 \(1.02 + 0.01 = 1.03\)입니다. f의 위쪽 절반은 e와 겹쳐 1.04입니다.

이 책에서 쓰는 단위

원전의 좌표는 팬텀 전체가 \(-1 \le x, y \le 1\) 안에 들어가도록 정규화한 값이고, \(\rho\)는 두개골과 뇌의 비가 약 2 대 1이 되도록 정한 상대값입니다. 이 책은 Shepp-Logan 팬텀을 쓸 때 원전의 숫자를 단위 없이 그대로 씁니다. 그래서 이 팬텀의 투영값도 단위 없는 숫자입니다. 실제 머리 크기로 생각하려면 길이 1을 약 10 cm로 읽으면 되고, 그러면 팬텀의 크기는 약 18 cm × 14 cm입니다.

뇌와 뇌실의 차이는 2%뿐입니다. 실제 연부조직 사이의 감쇠계수 차이도 이 정도로 작아서, 팬텀은 재구성이 이런 작은 차이를 살려 내는지 시험하도록 만들어졌습니다. 위 오른쪽 그림처럼 밝기 범위를 좁혀야 내부가 보이는 것도 같은 이유입니다.

값을 바꾼 변형

내부 구조를 잘 보이게 하려고 \(\rho\)를 \(1,\ -0.8,\ -0.2,\ -0.2,\ 0.1,\ \dots\)처럼 키운 변형도 널리 쓰입니다. 타원의 위치와 크기는 같고 값만 다릅니다. 다른 자료의 그림이나 수치와 비교할 때는 어느 값을 썼는지 먼저 확인하세요. 이 책은 위 표의 원래 값을 씁니다.

타원 하나의 Radon 변환

원점이 중심이고 반축이 \(x\) 축 방향으로 \(A\), \(y\) 축 방향으로 \(B\)인 타원 \(x^{2}/A^{2} + y^{2}/B^{2} \le 1\)을 생각합니다. 타원 안의 값은 \(\rho\), 밖은 0입니다. 이 타원의 Radon 변환은 다음과 같습니다.

\[p(\theta, s) = \begin{cases}\dfrac{2\rho AB}{a(\theta)^{2}}\sqrt{a(\theta)^{2} - s^{2}} & (|s| \le a(\theta))\\[2mm] 0 & (|s| > a(\theta))\end{cases},\qquad a(\theta)^{2} = A^{2}\cos^{2}\theta + B^{2}\sin^{2}\theta\]

  • \(a(\theta)\)는 각도 \(\theta\)에서 타원의 그림자가 검출기 위에 차지하는 폭의 절반입니다. 투영값은 \(-a(\theta) \le s \le a(\theta)\)에서만 0이 아닙니다.
  • \(s\)에 대한 모양은 \(\sqrt{a^{2} - s^{2}}\), 즉 반타원 모양입니다. 가운데에서 가장 크고 그림자 끝에서 0이 됩니다.

\(\theta = 0\)으로 확인합니다. \(a(0) = A\)이므로 \(p(0, s) = 2\rho(B/A)\sqrt{A^{2} - s^{2}}\)입니다. 세로 광선 \(x = s\)는 타원을 \(y = \pm B\sqrt{1 - s^{2}/A^{2}}\)에서 자르므로, 광선이 타원 안에서 지나는 길이는 \(2B\sqrt{1 - s^{2}/A^{2}}\)입니다. 여기에 \(\rho\)를 곱한 값이 위 식과 같습니다. 원(\(A = B = R\))이면 \(a(\theta) = R\)이어서 \(p = 2\rho\sqrt{R^{2} - s^{2}}\)이고, 어느 각도에서 보아도 같은 투영입니다.

중심이 옮겨지고 기울어진 타원

Shepp-Logan 팬텀의 타원은 중심이 \((x_0, y_0)\)에 있고 반축 \(A\)가 \(\alpha\) 방향을 향합니다. 이런 타원의 투영은 위 식(이것을 \(p_0\)으로 씁니다)에서 각과 위치만 바꾸면 됩니다.

\[p(\theta, s) = p_0\bigl(\theta - \alpha,\ \ s - x_0\cos\theta - y_0\sin\theta\bigr)\]

  • 타원을 \(\alpha\)만큼 돌리면 그 타원을 보는 상대적인 각이 \(\theta - \alpha\)가 됩니다.
  • 중심을 옮기면 그림자 전체가 검출기 위에서 중심의 검출기 좌표 \(x_0\cos\theta + y_0\sin\theta\)만큼 옮겨집니다.

투영은 선형이므로(0편 2장 페이지 5), 팬텀 전체의 투영은 타원 열 개의 투영을 더한 값입니다. 예를 들어 Shepp-Logan 팬텀에서 원점을 지나는 세로 광선은 \(p(0, 0) \approx 1.974\)입니다. 타원 a가 \(2\times2\times0.92 = 3.68\)을 주고, b가 \(-0.98\times2\times0.874 \approx -1.713\)을 빼며, e, f, g, i가 합쳐서 약 0.007을 더합니다. c, d, h, j는 이 광선에 닿지 않습니다.

타원의 Radon 변환 전개

페이지 3의 델타 함수 표기와 1장 페이지 2의 변수변환을 씁니다.

1단계. 델타 함수 표기. 타원 안에서만 \(\rho\)이므로 다음과 같습니다.

\[p(\theta, s) = \rho\iint_{x^2/A^2 + y^2/B^2 \le 1}\delta(x\cos\theta + y\sin\theta - s)\,dx\,dy\]

2단계. 단위 원으로 옮기기. \(x = Au,\ y = Bv\)로 치환하면 야코비안이 \(AB\)이고 타원은 단위 원판 \(u^{2} + v^{2} \le 1\)이 됩니다(타원을 단위 원판으로 옮기는 치환입니다. 이 장에서는 타원의 반축을 \(A,\ B\)로 쓰고, \(a\)는 그림자 폭의 절반에 씁니다).

\[p(\theta, s) = \rho AB\iint_{u^2 + v^2 \le 1}\delta(Au\cos\theta + Bv\sin\theta - s)\,du\,dv\]

3단계. 계수를 길이와 방향으로 나누기. \((A\cos\theta)^{2} + (B\sin\theta)^{2} = a^{2}\)이므로 \(\cos\psi = A\cos\theta/a,\ \sin\psi = B\sin\theta/a\)인 각 \(\psi\)가 있습니다. 그러면 \(Au\cos\theta + Bv\sin\theta = a\,(u\cos\psi + v\sin\psi)\)입니다.

4단계. 스케일 인자. 페이지 3의 \(\delta(cx - b) = \delta(x - b/c)/|c|\)에 \(c = a\)를 넣습니다.

\[\delta\bigl(a(u\cos\psi + v\sin\psi) - s\bigr) = \frac{1}{a}\,\delta\!\left(u\cos\psi + v\sin\psi - \frac{s}{a}\right)\]

5단계. 단위 원판의 선적분. 남은 이중적분은 값이 1인 단위 원판에서 직선 \(u\cos\psi + v\sin\psi = s/a\)를 따라 잰 길이입니다. 원점에서 거리 \(d = |s|/a\)인 직선이 단위 원을 자르는 현의 길이는 \(2\sqrt{1 - d^{2}}\)이고, \(d > 1\)이면 0입니다.

6단계. 정리.

\[p(\theta, s) = \rho AB\times\frac{1}{a}\times2\sqrt{1 - \frac{s^{2}}{a^{2}}} = \frac{2\rho AB}{a^{2}}\sqrt{a^{2} - s^{2}}\qquad(|s| \le a)\]

7단계. 검산. 넓이를 구하면 \(\int_{-a}^{a}\sqrt{a^{2} - s^{2}}\,ds = \pi a^{2}/2\)(반지름 \(a\)인 반원의 넓이)이므로 \(\int p\,ds = \rho\pi AB\)입니다. 타원의 넓이 \(\pi AB\)에 \(\rho\)를 곱한 값이고 \(\theta\)와 무관합니다.

sinogram은 왜 사인 곡선일까요?

0편 2장 페이지 5에서 방향을 바꿔 가며 모은 투영들을 정리하는 방법은 뒷장에서 다룬다고 했습니다. 투영값 \(p(\theta, s)\)는 두 변수의 함수이므로 영상처럼 그릴 수 있습니다. 가로축을 검출기 좌표 \(s\), 세로축을 각도 \(\theta\)로 두고 값을 밝기로 나타냅니다. \(\theta = 0\)이 맨 위이고 아래로 갈수록 커집니다. 가로 한 줄이 각도 하나의 투영 한 장입니다. 이 그림 위의 점 하나는 \((\theta, s)\) 두 값으로 정해지는 직선 하나, 곧 광선 하나를 뜻하고, 그 점의 밝기는 그 직선을 따라 잰 선적분 \(p(\theta, s)\)입니다. 이렇게 그린 투영 데이터를 sinogram이라고 합니다. sinogram은 재구성한 영상이 아니라 측정 데이터를 늘어놓은 배열입니다.

작은 물체가 그리는 곡선

이 이름은 sinogram에 나타나는 곡선 모양에서 왔습니다. 위치 \((x_0, y_0)\)의 아주 작은 물체를 생각합시다. 각도 \(\theta\)에서 이 물체를 지나는 광선의 \(s\)는 다음과 같습니다.

\[s = x_0\cos\theta + y_0\sin\theta = r\cos(\theta - \phi)\]

여기서 \((r, \phi)\)는 물체 위치의 극좌표입니다(1장 페이지 1). 1장에서는 극좌표의 각을 \(\theta\)로 썼지만, 이 장에서 \(\theta\)는 투영 각도이므로 물체 위치의 각을 \(\phi\)로 씁니다.

곡선에서 물체의 위치를 그대로 읽을 수 있습니다.

  • 진폭은 \(r\)입니다. 회전 중심에서 먼 물체일수록 좌우로 크게 흔들리고, 중심에 있는 물체는 \(s = 0\)의 세로선이 됩니다.
  • 가장 오른쪽은 \(\theta = \phi\)입니다. 검출기 방향이 물체 쪽을 향할 때이고, 이때 물체가 가장 큰 \(s\)인 \(s = r\)에 비칩니다.
  • \(s = 0\)을 지나는 곳은 \(\theta = \phi \pm 90^{\circ}\)입니다. 이 각도에서는 물체를 지나는 광선이 원점도 지납니다.

크기가 있는 물체는 띠가 됩니다

점이 아니라 크기가 있는 물체도 같은 방식으로 그립니다. 0편 2장의 정사각형 두 개(한 변 1 cm, \(\mu = 0.45\), 중심 \((-2, 2)\)와 \((2, -2)\))로 확인합니다. 정사각형의 중심은 점 물체처럼 사인 곡선을 그립니다. 중심 \((-2, 2)\)는 \(s = -2\cos\theta + 2\sin\theta = 2\sqrt2\cos(\theta - 3\pi/4)\)이고, 중심 \((2, -2)\)는 부호만 반대인 곡선입니다.

그런데 정사각형은 크기가 있어서, 같은 각도에서도 광선이 정사각형을 서로 다른 \(s\)에서 지납니다. 그래서 곡선 하나가 아니라 곡선 둘레의 띠가 됩니다. 띠의 폭은 그 각도에서 정사각형이 검출기에 드리우는 그림자의 폭 \(|\cos\theta| + |\sin\theta|\)이고 1 cm에서 \(\sqrt2\) cm 사이입니다. 띠 안의 값은 \(0.45\)에 광선이 정사각형을 지나는 길이를 곱한 값입니다.

0편 2장의 결론을 sinogram에서 다시 보기

0편 2장 페이지 7에서는 가로·세로 광선만으로는 실제 배치(중심 \((-2, 2)\), \((2, -2)\))와 다른 배치(중심 \((-2, -2)\), \((2, 2)\))를 구분할 수 없었고, 대각선 광선을 하나 더하면 구분되었습니다. 이 사실이 sinogram에서는 어떻게 보일까요? 두 배치의 sinogram을 한 그림에 겹쳐 봅니다.

가로줄 하나가 그 각도에서 얻는 투영 하나입니다. 줄마다 파란 띠와 주황 띠가 같은 자리에 있는지 보면 됩니다.

  • \(\theta = 0^{\circ}\)와 \(90^{\circ}\). 두 띠가 정확히 겹칩니다. 두 배치가 같은 \(s = \pm2\)에서 같은 값 \(0.45\)를 줍니다. 세로 광선과 가로 광선만으로는 두 배치를 구분할 수 없다는 0편 2장의 결과가 이것입니다.
  • \(\theta = 45^{\circ}\). 실제 배치의 두 띠는 \(s = 0\)에서 만나고, 다른 배치의 띠는 \(s = \pm2\sqrt2\)로 멀리 떨어져 있습니다. 띠가 만나는 자리는 두 정사각형을 함께 지나는 대각선 광선이며 값은 0편 2장에서 구한 \(0.45\times2\sqrt2 \approx 1.27\)입니다. 다른 배치에서는 이 자리의 값이 0이어서 두 배치가 구분됩니다.
  • \(\theta = 135^{\circ}\). 반대로 다른 배치의 두 띠가 \(s = 0\)에서 만나고, 실제 배치의 띠는 검출기 양 끝 \(s = \pm2\sqrt2\)에 비칩니다. 이때 광선은 \(y = x\) 방향으로 나아갑니다.

두 방향만 가졌을 때는 구분되지 않던 것이, 방향을 더하면 sinogram에서 띠가 갈라지는 모습으로 나타납니다.

일반적인 물체는 작은 조각들의 합이고 투영은 선형이므로, sinogram은 조각마다의 사인 곡선을 그 값만큼 겹친 것입니다. sinogram의 가로 한 줄은 그 각도의 투영 하나이고, 세로 한 줄은 검출기의 한 위치가 장치가 도는 동안 읽은 값의 기록입니다.

질량 보존\(\iint \mu\,dx\,dy\)모든 \(\theta\)에서 \(\int p(\theta, s)\,ds\)와 같음
대칭(영상과 무관)\(p(\theta + \pi,\ -s) = p(\theta, s)\)

선형

0편 2장 페이지 5의 투영의 선형성이 그대로 성립합니다. Shepp-Logan 팬텀의 투영을 타원 열 개의 투영의 합으로 계산한 것(페이지 5)이 이 성질을 쓴 것입니다.

이동

영상을 \((x_0, y_0)\)만큼 옮기면 모든 점의 검출기 좌표가 \(x_0\cos\theta + y_0\sin\theta\)만큼 바뀝니다. 그래서 각도마다 투영 곡선이 그만큼 옆으로 옮겨집니다. 옮기는 양이 \(\theta\)에 따라 사인 곡선으로 변하므로, sinogram 전체는 좌우로 사인 곡선을 따라 휘어집니다. 페이지 6에서 작은 물체가 사인 곡선을 그린 것과 같은 이유입니다.

회전

물체를 반시계 방향으로 \(\phi\)만큼 돌리는 것은 장치를 반대 방향으로 \(\phi\)만큼 돌리는 것과 같습니다. 그래서 돌린 물체를 각도 \(\theta\)에서 본 투영은 원래 물체를 각도 \(\theta - \phi\)에서 본 투영입니다. sinogram에서는 그림 전체가 세로축(\(\theta\))을 따라 \(\phi\)만큼 아래로 옮겨집니다. 회전 방향과 각의 규약은 2장 페이지 6의 회전 성질과 같습니다.

질량 보존

한 각도의 투영을 검출기 전체에서 적분하면, 나란한 광선들의 선적분을 모두 더한 것이 되어 영상 전체의 적분과 같습니다. 이 값은 각도와 무관합니다.

\[\int_{-\infty}^{\infty} p(\theta, s)\,ds = \iint \mu(x, y)\,dx\,dy\qquad(\text{모든 }\theta)\]

페이지 7 위젯의 "곡선 아래 넓이"가 각도를 바꿔도 그대로였던 이유입니다. Shepp-Logan 팬텀에서는 타원마다 \(\rho\pi AB\)를 더한 약 2.20이고, 정사각형 두 개에서는 \(2\times0.45\times1 = 0.90\)입니다. 2장의 표기로 보면 왼쪽은 투영의 1차원 푸리에 변환 \(P_\theta(\omega) = \int p(\theta, s)\,e^{-i2\pi\omega s}\,ds\)의 원점 값 \(P_\theta(0)\)이고, 오른쪽은 영상의 2차원 푸리에 변환의 원점 값 \(F(0, 0)\)입니다. 푸리에 슬라이스 정리 \(P_\theta(\omega) = F(\omega\cos\theta,\ \omega\sin\theta)\)에서 \(\omega = 0\)인 경우입니다.

대칭

대칭은 영상과 무관하게 언제나 성립하는 성질입니다. 같은 직선을 두 가지 좌표로 부르기 때문에 생깁니다.

이동·회전·질량 보존의 전개

이동. 옮긴 영상의 Radon 변환에서 \(x = \tilde x + x_0,\ y = \tilde y + y_0\)로 치환합니다. \(dx\,dy = d\tilde x\,d\tilde y\)입니다.

\[\begin{aligned}&\iint \mu(x - x_0,\ y - y_0)\,\delta(x\cos\theta + y\sin\theta - s)\,dx\,dy\\ &= \iint \mu(\tilde x, \tilde y)\,\delta\bigl(\tilde x\cos\theta + \tilde y\sin\theta - (s - x_0\cos\theta - y_0\sin\theta)\bigr)\,d\tilde x\,d\tilde y\end{aligned}\]

오른쪽은 원래 영상의 Radon 변환을 \(s - x_0\cos\theta - y_0\sin\theta\)에서 읽은 값입니다.

회전. 2장 페이지 6처럼 돌린 영상을 \(g(x, y) = \mu(x\cos\phi + y\sin\phi,\ -x\sin\phi + y\cos\phi)\)로 씁니다. \(u = x\cos\phi + y\sin\phi,\ v = -x\sin\phi + y\cos\phi\)로 치환하면 행렬식이 1이고, 역변환 \(x = u\cos\phi - v\sin\phi,\ y = u\sin\phi + v\cos\phi\)를 델타 함수 안에 넣으면 다음과 같습니다.

\[\begin{aligned}x\cos\theta + y\sin\theta &= u\,(\cos\phi\cos\theta + \sin\phi\sin\theta) + v\,(\cos\phi\sin\theta - \sin\phi\cos\theta)\\ &= u\cos(\theta - \phi) + v\sin(\theta - \phi)\end{aligned}\]

따라서 \(g\)의 Radon 변환은 \(\iint \mu(u, v)\,\delta\bigl(u\cos(\theta - \phi) + v\sin(\theta - \phi) - s\bigr)\,du\,dv = p(\theta - \phi,\ s)\)입니다.

질량 보존. \(s\)에 대한 적분을 안쪽으로 넣습니다. 델타 함수를 \(s\)로 적분하면 넓이 1이 남습니다.

\[\int p(\theta, s)\,ds = \iint \mu(x, y)\left[\int \delta(x\cos\theta + y\sin\theta - s)\,ds\right]dx\,dy = \iint \mu(x, y)\,dx\,dy\]

Shepp-Logan 팬텀으로 검산하면 \(\sum_k \rho_k\pi A_kB_k \approx 3.9886 - 1.7824 - 0.0063 + 0.0019 \approx 2.2018\)입니다(차례로 타원 a, b, 뇌실 c·d, 작은 구조 e~j).

3장 · 페이지 9

왜 180°만 찍어도 될까요? 대칭성

장치가 한 바퀴 돌면 각도는 \(0\)에서 \(2\pi\)까지 지납니다. 그런데 이 동안 같은 직선을 두 번 재게 됩니다. 어떤 두 측정이 같은 직선일까요?

같은 직선의 두 좌표

\((\theta + \pi,\ -s)\)인 직선을 쓰면 \(\cos(\theta + \pi) = -\cos\theta,\ \sin(\theta + \pi) = -\sin\theta\)이므로 다음과 같습니다.

\[x\cos(\theta + \pi) + y\sin(\theta + \pi) = -s\quad\Longleftrightarrow\quad x\cos\theta + y\sin\theta = s\]

두 좌표는 같은 직선을 가리킵니다. 법선 방향을 반대로 잡았으니 원점에서의 부호 있는 거리도 부호가 바뀐 것입니다. 광선이 나아가는 방향은 반대가 되지만, 0편 2장 페이지 4에서 본 것처럼 방향을 바꿔도 선적분은 같습니다.

\[p(\theta + \pi,\ -s) = p(\theta, s)\]

델타 함수 표기로는 \(\delta\bigl(-(x\cos\theta + y\sin\theta - s)\bigr) = \delta(x\cos\theta + y\sin\theta - s)\)이고, 페이지 3의 스케일 인자에 \(c = -1\)을 넣은 것입니다.

sinogram에서 보이는 모양

이 관계 때문에 \(360^{\circ}\) sinogram의 아래쪽 절반(\(\pi \le \theta < 2\pi\))은 위쪽 절반을 좌우로 뒤집은 것입니다. 페이지 7 위젯에서 \(180^{\circ}\) 점선의 위아래를 비교해 보면 확인할 수 있습니다. 다시 말해 \(0 \le \theta < \pi\)의 측정에서 모든 직선이 정확히 한 번씩 나옵니다. 평행빔은 \(180^{\circ}\)만 측정하면 모든 직선의 값을 얻습니다. 끝점 \(\theta = \pi\)는 \(\theta = 0\)과 같은 직선들이므로 빼고 \(0 \le \theta < \pi\)로 잡습니다.

  • \(360^{\circ}\)를 측정한 경우. 모든 직선을 두 번 잰 셈입니다. 잡음이 서로 무관하다면 두 값을 평균해 잡음의 표준편차를 \(1/\sqrt2\)배로 줄일 수 있습니다. 새로운 직선의 정보가 생기는 것은 아닙니다.
  • \(180^{\circ}\)보다 적게 측정한 경우. 어떤 방향의 직선은 한 번도 측정되지 않습니다. 이 빈자리가 재구성에 무엇을 남기는지는 푸리에 슬라이스 정리로 보면 분명해집니다.

팬빔의 같은 직선 쌍

팬빔에서는 한 선원 위치의 광선들이 나란하지 않습니다. 그래서 같은 직선을 두 번 재는 측정의 짝이 \((\theta, s)\)와 \((\theta + \pi,\ -s)\)처럼 단순하지 않고, 선원이 \(180^{\circ}\)만 돌아서는 모든 직선을 얻지 못합니다. 필요한 회전 범위와, 두 번 잰 값을 어떻게 합칠지는 이 페이지의 관계를 팬빔 좌표로 옮겨야 정할 수 있습니다.

3장 · 페이지 10

이산 sinogram

지금까지 \(p(\theta, s)\)를 모든 각도와 모든 위치에서 값을 갖는 연속 함수로 다루었습니다. 실제 장치는 정해진 각도에서만 측정하고, 검출기도 칸 수만큼의 값만 줍니다. 그래서 실제 데이터는 숫자를 격자로 늘어놓은 배열입니다.

샘플링 격자

\(180^{\circ}\)를 \(N_\theta\)개의 각도로, 검출기를 간격 \(\Delta s\)인 \(N_s\)개의 칸으로 나눕니다. 0편 3장의 규약대로 이산 값은 대괄호로 씁니다.

\[\theta_k = k\,\Delta\theta,\quad \Delta\theta = \frac{\pi}{N_\theta},\qquad s_n = \left(n - \frac{N_s - 1}{2}\right)\Delta s,\qquad p[k, n] = p(\theta_k,\ s_n)\]

  • \(k = 0, 1, \dots, N_\theta - 1\)은 각도 번호, \(n = 0, 1, \dots, N_s - 1\)은 검출기 칸 번호입니다.
  • \(s_n\)은 검출기 칸의 중심 위치입니다. 검출기의 한가운데가 \(s = 0\), 즉 회전 중심에 오도록 번호를 매겼습니다.
  • 간격 기호에는 샘플링하는 축의 이름을 붙입니다. \(\Delta s\)는 검출기 위의 거리(cm)로 2장의 표본 간격 \(\Delta x\)를 검출기 좌표 \(s\)에 쓴 것이고, \(\Delta\theta\)는 각도(라디안)입니다. 팬빔에서는 \(\Delta t\), \(\Delta\gamma\), \(\Delta\beta\)가 같은 규칙으로 나옵니다.
  • 이산 sinogram은 \(N_\theta\)행 \(N_s\)열의 배열이고, 행 하나가 각도 하나의 투영입니다.

배열의 값 하나는 광선 하나이므로, 값의 개수 \(N_\theta N_s\)는 0편 3장의 광선 수 \(m\)과 같습니다. 0편 3장의 예시처럼 각도 720개와 검출기 칸 736개이면 약 53만 개이고, 값마다 4바이트로 저장하면 단면 하나에 약 2 MB입니다.

이산화에서 정할 것

  • 검출기 칸의 폭. 실제 검출기 칸은 폭이 있어서 읽는 값은 칸 안의 평균에 가깝습니다. 이 책은 이 값을 칸 중심에서의 샘플 \(p(\theta_k, s_n)\)으로 봅니다.
  • 검출기가 덮는 범위. 검출기의 전체 폭은 \(N_s\Delta s\)입니다. 이 폭이 물체를 다 덮어야 하며, 덮이는 영역은 아래의 "시야(FOV)"에서 봅니다.
  • 간격의 크기. 검출기 간격 \(\Delta s\)는 투영의 나이퀴스트 주파수 \(1/(2\Delta s)\)를 정합니다(2장 페이지 4). 위 왼쪽 그림처럼 간격이 크면 작은 구조가 그리는 가는 곡선이 사라집니다.
  • 회전 중심. 위 식은 검출기의 한가운데가 회전 중심이라고 가정합니다. 그러면 페이지 9의 대칭이 번호 \(n\)과 \(N_s - 1 - n\)의 짝으로 나타납니다(\(s_{N_s - 1 - n} = -s_n\)).

시야(FOV)

검출기는 \(|s| \le N_s\Delta s/2\)인 직선만 잽니다. 그렇다면 영상의 어느 점이 모든 각도에서 측정될까요? 점 \((x, y)\)를 지나는 광선의 검출기 좌표는 각도마다 \(s = x\cos\theta + y\sin\theta\)입니다(페이지 2). 이 값은 각도에 따라 바뀌고, 크기가 가장 클 때 점과 회전 중심 사이의 거리 \(\sqrt{x^{2} + y^{2}}\)와 같습니다. 그러므로 다음 원 안의 점은 모든 각도에서 광선이 검출기 안을 지나고, 원 밖의 점은 어떤 각도에서 광선이 검출기 밖을 지납니다.

\[\sqrt{x^{2} + y^{2}} \le \frac{N_s\Delta s}{2}\]

회전 중심을 중심으로 하고 반지름이 검출기 폭의 절반인 이 원을 시야(Field of View, FOV)라고 합니다. 물체가 반지름 \(R\)인 원 안에 있을 때 \(N_s\Delta s \ge 2R\)이면 물체 전체가 시야 안에 들어옵니다.

실제 장치에서는 이 원을 스캔 시야(Scan FOV)라고 부릅니다. 영상으로 재구성해 보여 줄 영역은 스캔 시야 안에서 따로 고르며, 이 영역을 재구성 시야(Display FOV)라고 부르기도 합니다.

물체가 시야보다 크면 그림 (b)처럼 일부 각도에서 물체를 지나는 광선이 검출기 밖으로 나가, 그 직선의 투영값이 아예 없습니다. 이렇게 투영의 일부가 잘리는 것을 절단(Truncation)이라고 합니다.

여기까지가 평행빔이 주는 데이터의 구조입니다. 4장에서는 이 데이터의 각 행을 1차원 푸리에 변환하면 영상의 2차원 푸리에 변환과 어떻게 이어지는지 봅니다.

이 관계를 써서 데이터의 회전 중심이 맞는지 점검할 수 있습니다. \(\theta\)의 투영과 \(\theta + 180^{\circ}\)의 투영을 좌우로 뒤집은 것을 겹쳐 보았을 때 어긋나 있으면, 검출기의 한가운데가 회전 중심과 맞지 않는다는 뜻입니다.

직접 해보기

  1. (심화) 원점이 중심이고 \(A = 3,\ B = 2,\ \rho = 0.2\), \(\alpha = 0\)인 타원이 있습니다. 페이지 5의 식으로 \(p(0, 0)\), \(p(\pi/2, 0)\), \(p(\pi/4, 0)\)을 구하고, \(\int p(\theta, s)\,ds\)의 값을 쓰세요. 이 타원을 중심이 \((1, 0)\)이 되도록 옮기면 \(p(0, 1)\)은 얼마일까요?
  2. 어떤 작은 물체가 sinogram에서 \(s = 3\cos(\theta - \pi/3)\)을 그립니다. 물체의 위치 \((x, y)\)를 구하세요. \(0 \le \theta < \pi\)에서 이 곡선이 \(s = 0\)을 지나는 각도를 구하고, 그 각도의 광선이 무엇을 지나는지 설명하세요.
  3. 평행빔으로 \(360^{\circ}\)를 \(1^{\circ}\) 간격으로 측정하고 검출기 칸은 512개입니다(\(s_n = (n - 255.5)\Delta s\)). 측정값은 모두 몇 개이고, 서로 다른 직선은 몇 개일까요? 각도 \(200^{\circ}\), 칸 번호 \(n = 100\)과 같은 직선을 \(0^{\circ}\)~\(179^{\circ}\) 범위에서 찾아 각도와 칸 번호로 쓰세요.
모범답안과 흔한 실수

1번. 그림의 ①은 \(\theta = \pi/2\)인 가로 광선, ②는 \(\theta = 0\)인 세로 광선, ③은 \(\theta = \pi/4\)인 대각선 광선입니다. \(\theta = 0\)이면 \(a = A = 3\)이고 \(p(0, 0) = 2\rho AB/a = 2\times0.2\times6/3 = 0.8\)입니다. 세로 광선이 타원을 지나는 길이 \(2B = 4\)에 \(\rho\)를 곱한 값과 같습니다. \(\theta = \pi/2\)이면 \(a = B = 2\)이고 \(p(\pi/2, 0) = 2.4/2 = 1.2\)로, 가로 길이 \(2A = 6\)에 \(\rho\)를 곱한 값입니다. \(\theta = \pi/4\)이면 \(a^{2} = (9 + 4)/2 = 6.5\), \(a \approx 2.550\)이고 \(p(\pi/4, 0) = 2.4/2.550 \approx 0.941\)입니다. 넓이는 각도와 무관하게 \(\rho\pi AB = 1.2\pi \approx 3.77\)입니다. 중심을 \((1, 0)\)으로 옮기면 \(p(\theta, s) = p_0(\theta,\ s - \cos\theta)\)이므로 \(p(0, 1) = p_0(0, 0) = 0.8\)입니다. 옮긴 중심을 지나는 세로 광선이기 때문입니다.

2번. \(s = r\cos(\theta - \phi)\)와 비교하면 \(r = 3,\ \phi = \pi/3\)이므로 물체는 \((3\cos60^{\circ},\ 3\sin60^{\circ}) = (1.5,\ 3\sqrt3/2) \approx (1.5,\ 2.598)\)에 있습니다. \(s = 0\)이 되려면 \(\theta - \pi/3 = \pi/2\)이므로 \(\theta = 5\pi/6\)(\(150^{\circ}\))입니다. 이 각도에서 \(s = 0\)인 광선은 회전 중심을 지나고, 같은 광선이 물체도 지납니다. 광선은 \(\theta + 90^{\circ} = 240^{\circ}\) 방향, 즉 \(\pm(0.5,\ 0.866)\) 방향으로 나아가며, 물체의 위치가 원점에서 이 방향으로 3만큼 간 점이기 때문입니다.

3번. 측정값은 \(360\times512 = 184{,}320\)개입니다. 페이지 9의 대칭에 따라 모든 직선을 두 번 쟀으므로 서로 다른 직선은 절반인 \(92{,}160\)개입니다. \(p(200^{\circ}, s_{100}) = p(20^{\circ}, -s_{100})\)이고 \(s_{100} = -155.5\Delta s\)이므로 \(-s_{100} = 155.5\Delta s = s_{411}\)입니다. 답은 각도 \(20^{\circ}\), 칸 번호 411이며, 일반적으로 \(n\)의 짝은 \(511 - n\)입니다.

흔한 실수.

  • 1번에서 \(a(\theta)\)를 \(A\cos\theta + B\sin\theta\)로 계산하는 것입니다. 제곱을 더한 뒤 제곱근을 취해야 하므로 \(\theta = \pi/4\)에서 \(a \approx 2.550\)이고 \(3.536\)이 아닙니다.
  • 1번에서 \(\theta = 0\)의 투영이 가로 길이 \(2A\)를 쓴다고 생각하는 것입니다. \(\theta = 0\)은 세로 광선이므로 세로 길이 \(2B\)를 지납니다.
  • 2번에서 \(s = 0\)이 되는 각도를 \(\phi = \pi/3\)으로 쓰는 것입니다. \(\theta = \phi\)는 \(s\)가 가장 큰 각도이고, \(s = 0\)은 그보다 \(90^{\circ}\) 뒤입니다.
  • 3번에서 짝을 \(512 - n = 412\)로 쓰는 것입니다. 번호가 0부터 시작하므로 \(s_n\)과 부호만 다른 화소는 \(N_s - 1 - n\)입니다.
