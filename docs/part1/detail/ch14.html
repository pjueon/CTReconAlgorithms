팬빔 FBP를 3차원에 쓰려면? FDK 알고리즘

원형 궤도의 콘빔 데이터는 일반적으로 정확한 재구성의 조건(Tuy 조건, 13장 페이지 6~7 심화)을 만족하지 못합니다. 그런데도 원형 궤도 장치의 3차원 영상 재구성에는 FDK 알고리즘(FDK Algorithm)을 널리 씁니다. 이 장은 8장의 팬빔 공식에서 FDK 공식을 유도하고, 어느 슬라이스에서 정확하며 어디서 어긋나는지를 3차원 Shepp-Logan 팬텀으로 확인합니다.

검출기 한 행이 이루는 평면

13장 페이지 1에서 검출기의 행마다 8장의 팬빔 공식을 적용하면 가운데 행만 정확하다는 것을 보았습니다. 위쪽 행의 광선은 기울어져 있어서 한 슬라이스 안에 머물지 않기 때문입니다. 그런데 한 행의 광선만 모아 보면 모양이 단순합니다. 행 위의 점들은 가상 검출기 위의 한 직선에 놓이고, 선원과 직선은 평면 하나를 정하므로 한 행의 모든 광선은 그 평면 안에 있습니다.

각 평면 안에서 보면 광선은 점광원에서 부채꼴로 퍼지는 팬빔입니다. 이 평면을 기울어진 팬(Tilted Fan)이라고 하겠습니다. \(v = 0\)인 행은 궤도 평면 \(z = 0\)을 이루므로 8장의 팬빔 그대로입니다.

기울어진 팬에 8장 공식을 적용하는 근사

FDK의 아이디어는 모든 행을 각자의 기울어진 팬으로 보고 8장의 평면 검출기 공식을 적용하는 것입니다. 팬빔 공식을 그대로 쓰려면 두 가지가 달라집니다.

  • 선원–검출기 거리. 행 \(v\)의 직선은 선원에서 \(\sqrt{D^{2} + v^{2}}\) 떨어져 있어 \(D\)보다 멉니다.
  • 선원 각 간격. 선원이 \(d\beta\)만큼 돌 때 이동하는 길이가 기울어진 팬의 거리에 비해 달라집니다.

이렇게 얻은 식은 근사입니다. 기울어진 팬의 평면은 선원 각 \(\beta\)마다 다르므로, 서로 다른 평면에서 얻은 팬빔 데이터를 한 장의 2차원 영상의 데이터처럼 취급하는 것이기 때문입니다. \(v = 0\)인 행에서는 평면이 \(z = 0\) 하나이므로 이 취급이 정확합니다.

원 논문과 이 장의 유도

이 알고리즘은 L. A. Feldkamp, L. C. Davis, J. W. Kress가 원형 궤도의 콘빔 데이터를 위한 실용적 알고리즘으로 제안했고, 제안자 세 사람의 머리글자를 따서 FDK라고 부릅니다(L. A. Feldkamp, L. C. Davis, J. W. Kress, Practical cone-beam algorithm, Journal of the Optical Society of America A 1(6), 1984, 612–619). 이 장의 식은 8장의 팬빔 공식에서 위의 근사로 직접 유도한 것입니다. 원 논문의 분석을 바탕으로 한 주 참고서 Kak & Slaney 3.6.2절의 식 (175)~(177)과 비교하면 사전 가중, 행별 필터, 거리 가중 역투영의 구조가 같고, \(\tfrac{1}{2}\)을 필터 안에 두는지 밖에 두는지만 다릅니다.

FDK 공식

원형 궤도(\(0 \le \beta < 2\pi\))의 콘빔 데이터 \(p(\beta, u, v)\)에서 영상 \(\mu(x, y, z)\)를 구하는 FDK 공식은 세 줄입니다.

\[\tilde p(\beta, u, v) = p(\beta, u, v)\,\frac{D}{\sqrt{D^{2} + u^{2} + v^{2}}}\]

\[q(\beta, u, v) = \int_{-\infty}^{\infty} \tilde p(\beta, u_1, v)\,h(u - u_1)\,du_1\]

\[\mu(x, y, z) \approx \frac{1}{2}\int_{0}^{2\pi} \frac{1}{U^{2}}\; q(\beta, u', v')\,d\beta\]

  • \(p(\beta, u, v)\). 선원 각 \(\beta\)에서 가상 검출기의 점 \((u, v)\)로 가는 광선의 투영값입니다(13장 페이지 5). 가운데 행 \(v = 0\)에서는 8장의 \(R_\beta(t)\)와 같습니다.
  • \(D\). 선원에서 회전 중심까지의 거리입니다.
  • \(h(u - u_1)\). 램프 필터의 커널입니다(5장 페이지 7). 둘째 줄은 행 \(v\)마다 \(u\) 방향으로만 컨볼루션합니다. \(u_1\)은 적분 변수입니다.
  • \(U\), \(u'\), \(v'\). 영상의 점 \((x, y, z)\)와 선원 각 \(\beta\)에서 정해지는 값입니다. \(\xi = x\cos\beta + y\sin\beta\), \(\eta = x\sin\beta - y\cos\beta\)로 두면 \(U = (D + \eta)/D\), \(u' = \xi/U\), \(v' = z/U\)입니다. \(u'\)은 8장의 \(t'\)와 같은 양이고, \((u', v')\)는 13장 페이지 5에서 \((u, v)\)로 쓴 값과 같으며 이 장에서는 검출기 위의 좌표 \((u, v)\)와 구분하려고 프라임 기호(′)를 붙입니다.
  • \(\tfrac{1}{2}\). 선원이 한 바퀴 돌면 같은 직선을 두 번 재므로 반으로 나눕니다(8장 페이지 2). 한 바퀴가 아닐 때는 이 상수를 광선마다 정한 가중으로 바꿉니다.

세 단계의 순서

3차원 영상은 격자의 칸마다 값을 갖고, 이 칸을 복셀(Voxel)이라고 합니다. 2차원 영상의 화소에 해당하는 3차원의 칸입니다.

다른 책의 표기

FDK 식은 책마다 검출기를 회전 중심에 두는지 실제 위치에 두는지, 선원 각의 시작과 방향, \(\tfrac{1}{2}\)을 어디에 넣는지가 다릅니다. 이 장은 13장 페이지 4의 규약(가상 검출기, \(\mathbf{S}(\beta) = (-D\sin\beta,\ D\cos\beta,\ 0)\))을 따르고 \(\tfrac{1}{2}\)은 식 밖에 둡니다. 주 참고서 Kak & Slaney의 3장 3.6절(Three-Dimensional Reconstructions)이 3차원 확장을 다루며, 3.6.2절의 식 (175)~(177)이 이 장의 식과 같은 구조입니다. 그 책은 검출기를 회전축 위치로 축소해 쓰고 \(\tfrac{1}{2}\)을 필터 \(h/2\)에 넣습니다.

좌표 정리: 행, 기울어진 팬, 복셀의 위치

13장 페이지 4~5에서 정한 좌표를 그대로 씁니다. 선원은 \(\mathbf{S}(\beta) = (-D\sin\beta,\ D\cos\beta,\ 0)\)에 있고, 가상 검출기는 회전 중심 O를 지나며 중심 광선에 수직입니다. 가상 검출기의 가로 좌표 \(u\)의 방향은 \(\mathbf{e}_u = (\cos\beta, \sin\beta, 0)\), 세로 좌표 \(v\)의 방향은 \(\mathbf{e}_z\)입니다. 영상의 점 \((x, y, z)\)에는 \(\xi = x\cos\beta + y\sin\beta\), \(\eta = x\sin\beta - y\cos\beta\), \(U = (D + \eta)/D\)를 둡니다.

행 하나의 기울어진 팬

가상 검출기의 행 \(v\)는 점 \((0, v)\), 곧 회전축 위의 높이 \(v\)인 점을 지나는 직선입니다. 선원에서 이 직선까지의 거리는 선원에서 \((0, v)\)까지의 거리와 같고, 직선이 중심 광선에 수직이므로 다음과 같습니다.

\[D_v = \sqrt{D^{2} + v^{2}}\]

따라서 행 \(v\)의 기울어진 팬은 선원 S, 회전축 위의 점 \((0, 0, v)\), 두 점 사이의 거리 \(D_v\)로 정해지는 팬빔이고, 팬 안의 검출기 좌표는 \(u\) 그대로입니다. 중심 광선의 기울기는 \(\tan\kappa_v = v/D\)입니다. \(D = 80\) cm에서 몇 개의 행을 비교하면 다음과 같습니다.

복셀이 읽는 행과 위치

영상의 복셀 \((x, y, z)\)에서 FDK는 어느 값을 읽을까요? 선원 각 \(\beta\)에서 복셀을 지나는 광선은 가상 검출기의 \((u', v')\)에 닿습니다. 13장 페이지 5의 결과를 옆에서 본 그림으로 다시 보면 다음과 같습니다.

  • \(u' = \xi/U = D\xi/(D + \eta)\)
  • \(v' = z/U = Dz/(D + \eta)\)

두 식의 한 가지 성질이 FDK의 근사를 정당화합니다. 복셀은 높이 \(v'\)인 행의 기울어진 팬 안에 놓입니다. 선원과 복셀을 잇는 광선이 \((0, v')\)행의 직선을 지나고, 이 광선과 \(\mathbf{e}_u\)가 이루는 평면이 곧 그 행의 팬이기 때문입니다. 그 팬 안에서 복셀의 깊이와 위치는 다음과 같습니다.

  • 팬의 깊이 비(8장의 \(U\)에 해당하는 값)는 \(U\)와 같습니다.
  • 팬 안에서 복셀이 읽는 검출기 좌표는 \(u'\)과 같습니다.
전개: 기울어진 팬 안의 깊이 비

중심 광선의 방향을 \(\mathbf{n}_c = (\sin\beta,\ -\cos\beta,\ 0)\)이라고 하면 \(\mathbf{P} - \mathbf{S} = (D + \eta)\,\mathbf{n}_c + \xi\,\mathbf{e}_u + z\,\mathbf{e}_z\)입니다(\(\mathbf{P}\)는 복셀의 위치). 행 \(v'\)의 팬의 중심축 방향은 \(\hat{\mathbf{c}} = (D\,\mathbf{n}_c + v'\,\mathbf{e}_z)/D_{v'}\)이고 \(\mathbf{e}_u\)와 수직입니다.

\(z = v'U = v'(D + \eta)/D\)를 \(\mathbf{P} - \mathbf{S}\)에 넣으면 \(\mathbf{n}_c\)와 \(\mathbf{e}_z\) 성분이 \(\dfrac{D + \eta}{D}\,(D\,\mathbf{n}_c + v'\,\mathbf{e}_z)\)로 묶이므로 \(\mathbf{P} - \mathbf{S} = \xi\,\mathbf{e}_u + \dfrac{(D + \eta)D_{v'}}{D}\,\hat{\mathbf{c}}\)입니다. 곧 복셀은 \(\mathbf{e}_u\)와 \(\hat{\mathbf{c}}\)가 이루는 평면 안에 있습니다.

중심축 방향의 깊이는 \((D + \eta)D_{v'}/D\)이고 이것을 \(D_{v'}\)로 나눈 깊이 비는 \((D + \eta)/D = U\)입니다. 팬의 검출기까지 거리가 \(D_{v'}\)이므로 읽는 위치는 \(\xi\,D_{v'}\big/\big[(D + \eta)D_{v'}/D\big] = D\xi/(D + \eta) = u'\)입니다.

8장의 팬빔 공식에 \(D\) 대신 \(D_{v'}\)를 넣어도 \(U\)와 \(u'\)이 달라지지 않으므로, 역투영 단계의 모양이 그대로 남습니다.

단계 1: 사전 가중

8장 페이지 5에서 평면 검출기 팬빔의 사전 가중은 \(D/\sqrt{D^{2} + t^{2}}\)였습니다. 행 \(v\)의 기울어진 팬에 같은 공식을 적용해 FDK의 사전 가중이 어떤 모양이 되는지 구해 보겠습니다.

두 인자의 곱

기울어진 팬의 선원–검출기 거리가 \(D_v\)이므로 8장의 사전 가중은 \(D_v/\sqrt{D_v^{2} + u^{2}}\)가 됩니다. 여기에 선원 각 간격의 차이가 곱해집니다. 8장의 적분 \(d\beta\)는 선원이 반지름 \(D_v\)인 원 위를 도는 각입니다. 실제 선원은 반지름 \(D\)인 원 위를 돌고, \(d\beta\)만큼 돌면 \(D\,d\beta\)만큼 이동하며 이 이동 방향 \(\mathbf{e}_u\)는 기울어진 팬의 중심축에 수직입니다. 반지름 \(D_v\)의 원에서 같은 길이를 이동하는 각은 다음과 같습니다.

\[d\beta_v = \frac{D}{D_v}\,d\beta\]

이렇게 각을 바꿔 쓰는 것은 팬빔 공식이 반지름 \(D_v\)의 원 위를 한 평면 안에서 도는 선원을 전제하기 때문입니다. 실제 선원은 반지름 \(D\)의 원 위를 돌고 기울어진 팬의 평면은 \(\beta\)마다 다릅니다. 근사는 이 치환 자체가 아니라, 평면이 \(\beta\)마다 달라지는 이동을 한 평면 위의 이동으로 보는 데 있습니다. 두 인자를 곱하면 사전 가중이 정해집니다.

\[\frac{D}{D_v}\cdot\frac{D_v}{\sqrt{D_v^{2} + u^{2}}} = \frac{D}{\sqrt{D^{2} + u^{2} + v^{2}}}\]

\(D_v^{2} = D^{2} + v^{2}\)이므로 \(D_v\)가 약분되어 사라지고 FDK의 사전 가중이 남습니다. \(v = 0\)이면 8장의 \(D/\sqrt{D^{2} + t^{2}}\)입니다.

가중의 기하학적 의미

이 값은 광선이 중심 광선과 이루는 각의 코사인입니다. 광선의 방향 벡터 \((u,\ v,\ D)\)(검출기 좌표와 중심 광선 방향의 성분)와 중심 광선 방향 \((0,\ 0,\ 1)\)의 내적을 길이로 나누면 \(D/\sqrt{D^{2} + u^{2} + v^{2}}\)가 됩니다. 8장의 \(\cos\gamma\)가 팬 평면 안에서 잰 같은 각이었으므로, 3차원에서는 \(v\) 방향의 기울기가 더해진 각의 코사인입니다.

단계 2: 행별 램프 필터

사전 가중을 곱한 \(\tilde p(\beta, u, v)\)는 행마다 \(u\) 방향으로 램프 필터링합니다. 행 \(v\)의 기울어진 팬은 평면 검출기 팬빔이므로, 8장 페이지 2에서 보았듯이 필터 커널은 평행빔과 같은 \(h\)입니다.

\[q(\beta, u, v) = \int_{-\infty}^{\infty} \tilde p(\beta, u_1, v)\,h(u - u_1)\,du_1\]

행과 행은 섞이지 않습니다. 한 행의 \(q\)는 그 행의 \(\tilde p\)로만 정해지고, 행 방향(\(v\))으로는 필터링하지 않습니다.

이산 계산

가상 검출기의 칸 간격을 \(\Delta u\)(가로)와 \(\Delta v\)(세로)라고 하겠습니다. 실제 검출기의 칸 간격이 \(\Delta d\)이면 \(\Delta u = \Delta d\,D/\mathrm{SDD}\)이고 세로도 같은 비율입니다(9장 페이지 2). 선원 각 하나의 행 하나에 9장 페이지 3과 같은 계산을 합니다.

  • 커널은 6장의 Ram-Lak 커널을 \(\Delta u\) 간격으로 만든 \(h[0] = 1/(4\Delta u^{2})\), 짝수 \(n\)에서 0, 홀수 \(n\)에서 \(-1/(\pi^{2}n^{2}\Delta u^{2})\)입니다. 윈도우 필터를 쓰면 이 커널만 바뀝니다.
  • \(q[j, i] = \Delta u \sum_{m} \tilde p[j, m]\,h[i - m]\)입니다. \(j\)는 행 번호이고 \(i\), \(m\)은 칸 번호입니다.
  • FFT로 계산할 때는 행 하나의 길이 \(N_u\)에 대해 제로 패딩(Zero Padding) 길이를 \(M \ge 2N_u - 1\)로 잡습니다.
  • 선원 각 \(N_\beta\)개와 행 \(N_v\)개를 곱한 \(N_\beta N_v\)개의 행(\(N_u\)는 행의 칸 수, \(N_v\)는 행의 수)이 서로 독립이라 어떤 순서로든 병렬로 계산할 수 있습니다.

단계 3: 3차원 가중 역투영

필터링한 \(q(\beta, u, v)\)를 영상으로 되돌리는 단계입니다. 역투영 방식은 9장 페이지 4와 같은 Pixel-driven(화소 기준) 방식을 3차원으로 옮긴 것으로, 복셀을 하나씩 돌며 선원 각마다 그 복셀이 찍히는 \((u', v')\)에서 \(q\)를 읽어 더합니다.

\[\mu(x, y, z) \approx \frac{1}{2}\int_{0}^{2\pi} \frac{1}{U^{2}}\; q(\beta, u', v')\,d\beta, \qquad U = \frac{D + \eta}{D},\quad u' = \frac{\xi}{U},\quad v' = \frac{z}{U}\]

1/U² 의 출처

8장 페이지 4에서 \(1/U^{2}\)은 램프 커널의 스케일 성질 \(h(as) = h(s)/a^{2}\)에서 나왔고, 여기서 \(U\)는 복셀이 팬 안에서 갖는 깊이 비였습니다. 기울어진 팬 안에서 복셀의 깊이 비가 \(U\)와 같고 읽는 위치가 \(u'\)이라는 것은 페이지 3에서 보았으므로, 역투영의 거리 가중도 \(1/U^{2}\) 그대로입니다. 그래서 \(D\) 대신 \(D_v\)를 쓴 팬빔 공식에서도 역투영 단계의 모양은 달라지지 않습니다. 선원 각 간격의 인자 \(D/D_v\)는 페이지 4의 사전 가중에 이미 들어갔습니다.

읽는 위치의 이동

복셀이 선원 각마다 읽는 위치는 \(\beta\)에 따라 검출기 위에서 이동합니다. \(u'\)뿐 아니라 \(v'\)도 \(U\)를 거쳐 \(\beta\)에 의존하므로, 복셀 하나가 읽는 행은 선원 각마다 바뀝니다. 아래 위젯은 \(D = 80\) cm에서 복셀이 한 바퀴 동안 가상 검출기 위에 그리는 자취입니다.

중앙 슬라이스에서 2차원 팬빔과 같은 이유

FDK가 근사라는 말은 모든 슬라이스에서 틀린다는 뜻이 아닙니다. 궤도 평면 \(z = 0\)에서는 8장의 팬빔 FBP와 같은 결과가 나옵니다. 세 단계를 \(z = 0\)에서 하나씩 확인해 보겠습니다.

  • 읽는 행. \(z = 0\)이면 \(v' = z/U = 0\)이므로 모든 선원 각에서 \(v = 0\) 행만 읽습니다.
  • 그 행의 데이터. \(v = 0\)인 광선은 궤도 평면 안에 있어서 \(p(\beta, u, 0)\)은 슬라이스 \(\mu(x, y, 0)\)의 팬빔 투영 \(R_\beta(t)\)입니다(13장 페이지 5). 다른 높이의 물체는 이 값에 들어오지 않습니다.
  • 가중. \(v = 0\)에서 \(D_v = D\)이고 사전 가중은 \(D/\sqrt{D^{2} + u^{2}} = \cos\gamma\)입니다. 역투영의 \(1/U^{2}\)도 8장과 같습니다.

그러므로 \(z = 0\)에서 FDK의 세 줄은 8장 페이지 1의 식과 글자까지 같고, 입력도 슬라이스 \(\mu(x, y, 0)\)의 팬빔 데이터입니다. 근사가 들어가는 곳은 서로 다른 평면의 데이터를 한 평면의 것처럼 취급하는 단계(페이지 4)인데, \(z = 0\)에서는 모든 평면이 \(z = 0\) 하나여서 근사가 없습니다. 13장 페이지 7(심화)에서 궤도 평면 안의 점이 정확한 재구성의 조건(Tuy 조건)을 만족한다고 한 것과 일치합니다.

높이에 따라 변하지 않는 물체

정확한 곳이 하나 더 있습니다. 물체가 \(z\)에 따라 변하지 않는 기둥(\(\mu(x, y, z) = \mu_2(x, y)\))이면 FDK는 모든 높이에서 2차원 결과와 같습니다. 이유는 세 단계로 따라갈 수 있습니다.

  • 데이터. 광선이 \(xy\) 평면에 비추는 그림자의 길이는 같은 광선의 3차원 길이에 \(\cos(\text{고도각})\)를 곱한 값이고, 고도각의 코사인은 \(\sqrt{D^{2} + u^{2}}/\sqrt{D^{2} + u^{2} + v^{2}}\)입니다. 그래서 \(p(\beta, u, v) = p_2(\beta, u)\,\sqrt{D^{2} + u^{2} + v^{2}}/\sqrt{D^{2} + u^{2}}\)이고, \(p_2\)는 \(\mu_2\)의 팬빔 투영입니다.
  • 사전 가중. \(\tilde p = p\,D/\sqrt{D^{2} + u^{2} + v^{2}} = p_2\,D/\sqrt{D^{2} + u^{2}}\)로 모든 행이 2차원 사전 가중 데이터와 같아집니다.
  • 나머지 단계. 모든 행의 \(q\)가 같은 2차원 \(q\)이므로 어느 행을 읽어도 값이 같고, \(1/U^{2}\)은 2차원과 같으므로 결과가 2차원 FBP입니다.

길이 방향이 매우 긴 타원체(\(z\) 반축 2000)로 만든 기둥 두 개를 \(D = 4\)에서 재구성하니, 반지름 1.1 안의 모든 복셀(\(|z| \le 1\))에서 높이에 따른 차이의 최댓값이 \(6.6 \times 10^{-6}\)이었습니다. 반면 사전 가중에서 \(v\) 항을 뺀 결과는 \(z = 0.8\)에서 0.031 어긋났습니다(페이지 4).

두 정확한 경우의 의미

FDK의 오차는 \(z\) 방향의 변화에서 생깁니다. 원형 궤도는 궤도 평면 밖의 점에서 정확한 재구성에 필요한 정보가 일부 모자라고, 그 모자란 푸리에 성분은 높이 방향의 변화에 해당하는 \(\omega_z\)축 근처에 있습니다(13장 페이지 8, 심화). FDK의 오차는 이것과 방향이 같습니다. \(z\)에 무관한 물체의 푸리에 변환은 \(\omega_z = 0\) 평면에만 있어서 그 모자란 성분과 겹치지 않습니다. 이 장은 두 경우의 정확성을 위 계산으로 확인했을 뿐이며, 모자란 성분과 FDK 오차의 크기가 같은 원인에서 나오는지는 증명하지 않습니다.

  • 복셀마다 독립. Pixel-driven(화소 기준) 방식에서는 복셀이 자기 값만 갱신하므로 서로 다른 복셀이 같은 메모리에 쓰는 충돌이 없습니다. 수많은 복셀을 동시에 맡기는 병렬 장치에 맞는 구조입니다.
  • 읽기 위주의 접근. 갱신마다 \(q\) 영상 한 장에서 이웃 네 값을 읽는 이중 선형 보간입니다. 이런 읽기를 하드웨어로 보간해 주는 장치가 많고, 그 경우 17~19행이 읽기 한 번으로 바뀝니다.
  • 열 단위 재사용. \(U\), \(u'\), 칸 번호는 높이와 무관해서 같은 \((x, y)\)의 복셀들이 한 번 계산한 값을 나눠 씁니다(10~13행).

short scan FDK: Parker 가중의 확장

11장에서 선원을 \(B = \pi + 2\gamma_m\)만 돌려도(short scan) 모든 직선이 한 번 이상 측정되고, 두 번 측정되는 직선의 가중 합을 1로 하는 Parker 가중 \(w(\beta, \gamma)\)(Parker Weight)를 곱하면 한 바퀴와 같은 영상이 나왔습니다. FDK의 사전 가중에 이 가중을 더해 같은 방식으로 확장합니다.

바뀌는 줄

10장 페이지 6의 규약을 따라 \(w\)는 광선에만 의존하므로 사전 가중과 함께 필터링 앞에서 곱하고, \(\tfrac{1}{2}\)은 \(w\)에 들어 있으므로 각도 합의 상수를 \(\Delta\beta\)로 둡니다. 팬 각은 행에 상관없이 \(\gamma = \arctan(u/D)\)로 정하고 \(\gamma_m\)은 검출기의 가로 반폭에서 \(\gamma_m = \arctan(u_{\max}/D)\)입니다. \(u_{\max}\)는 검출기의 가로 끝 좌표입니다.

중앙 슬라이스 밖에서 달라지는 것

Parker 가중의 합이 1이라는 조건은 같은 직선을 잰 두 광선 \((\beta, \gamma)\)와 \((\beta + \pi + 2\gamma, -\gamma)\)에 대한 것이었습니다(10장 페이지 2). 콘빔에서 \(v = 0\)인 광선은 궤도 평면 안에 있어서 이 짝이 같은 직선입니다. \(v \ne 0\)인 광선은 다릅니다.

기울어진 직선은 궤도 평면과 선원 한 점에서만 만납니다. 직선이 선원 \(\mathbf{S}(\beta)\)를 지나 올라가므로, 짝 위치의 선원 \(\mathbf{S}(\beta + \pi + 2\gamma)\)가 같은 직선 위에 있을 수 없습니다. \(u = 0\)이면 짝 위치의 선원 위에서 직선의 높이가 \(2v\)이고, 일반적으로는 \(2vD^{2}/(D^{2} + u^{2})\)입니다(\(D = 80\) cm, \(v = 15\) cm에서 \(u = 0, 20, 40\) cm일 때 30, 28, 24 cm). 따라서 \(v \ne 0\)에서는 같은 직선을 두 번 재는 쌍이 없고, 합이 1이라는 조건은 서로 다른 직선의 광선에 적용된 근사입니다. 이것은 페이지 4의 기울어진 팬 근사와 같은 종류의 취급입니다.

오프셋 검출기 FDK: Wang 가중의 확장

12장에서 검출기를 중심 광선에서 한쪽으로 옮긴 오프셋 검출기(Displaced Detector)는 같은 칸 수로 시야를 넓히고, 선원을 한 바퀴 돌려 중복 구간 \(|t| \le t_o\)의 두 측정을 합쳤습니다. 콘빔에서 검출기를 수평으로 옮기면(가로 \(u\) 방향) 같은 확장이 가능합니다. 이 페이지에서 \(t_o\)는 12장의 기호를 그대로 써서 가상 검출기의 \(u\) 방향 좌표 \(u = -t_o\)가 짧은 쪽 끝이라는 뜻입니다.

Wang 가중은 모든 행에서 같다

12장 페이지 5의 Wang 가중(Wang Weight)은 검출기의 가로 위치만의 함수였고 선원 각 \(\beta\)에는 의존하지 않았습니다. 검출기를 수평으로만 옮기면 모든 행이 같은 가로 범위 \([-t_o, u_{\max}]\)(\(u_{\max}\)는 검출기의 가로 끝 좌표)를 덮으므로 가중이 \(u\)만의 함수로 모든 행에서 같습니다.

\[w(u) = \begin{cases} 0, & u < -t_o\\[1mm] \sin^{2}\!\Big(\dfrac{\pi}{4}\,\dfrac{\gamma + \gamma_o}{\gamma_o}\Big), & -t_o \le u \le t_o\\[2mm] 1, & u > t_o \end{cases} \qquad \gamma = \arctan\frac{u}{D},\quad \gamma_o = \arctan\frac{t_o}{D}\]

이 식은 12장 페이지 5의 \(w(t)\)에서 \(t\)를 \(u\)로 바꾼 것입니다. 팬 각은 페이지 9와 같이 행에 상관없이 \(\gamma = \arctan(u/D)\)로 정하므로 모든 행에서 같은 한 줄입니다. 식에 \(D\)가 들어 있어서 같은 \(t_o = 0.30\)이라도 \(D = 4\)인 이 페이지의 가중은 12장(\(D = 3\))의 가중과 아주 조금(0.001 미만) 다릅니다. 사전 가중에 곱해 \(\tilde p = p\,w(u)\,D/\sqrt{D^{2} + u^{2} + v^{2}}\)로 쓰고, 한 바퀴를 돌므로 각도 합의 상수는 \(\Delta\beta = 2\pi/N_\beta\)입니다(\(\tfrac{1}{2}\)은 \(w\)에 들어 있습니다). 한 줄 \(w[i]\)를 한 번만 계산해 모든 행에 쓰는 것이 9장·12장의 구조와 같습니다.

한계: 원뿔각이 커질 때의 오차

13장 페이지 6~8(심화)을 건너뛰었다면

이 페이지에서 쓰는 13장의 결론은 다음뿐입니다. 원형 궤도의 콘빔 데이터는 궤도 평면(\(z = 0\)) 위의 점에서는 정확한 재구성에 충분하지만, 궤도 평면 밖의 점에서는 정확한 재구성에 필요한 정보가 일부 모자랍니다. 회전축 위 높이 \(z\)의 점이라면, 그 점을 지나는 평면 가운데 법선이 \(z\)축과 고도각 \(\kappa_0 = \arctan(|z|/D)\) 이내인 평면이 궤도와 만나지 않기 때문이며, 놓치는 법선의 비율은 높이가 작을 때 약 \(z^{2}/(2D^{2})\)입니다. 이 모자람은 높이 방향의 변화, 곧 푸리에 공간에서 \(\omega_z\)축 근처의 성분에서 드러납니다. 자세한 이유는 13장 페이지 6~8(심화)에서 다룹니다.

페이지 7에서 FDK가 정확한 곳을 확인했습니다. 그 밖의 곳에서 오차가 얼마나 되는지는 높이 \(z\)와 선원 거리 \(D\)가 정합니다. 13장 페이지 8의 "두 종류의 오차"가 모두 들어 있으므로 영상의 오차만으로 원인을 나눌 수는 없습니다. 하나는 기울어진 팬 근사에서 오는 오차(페이지 4)이고, 다른 하나는 원형 궤도가 놓치는 평면(13장 페이지 7)의 정보 부족입니다.

측정 방법

3차원 Shepp-Logan 팬텀의 팬빔·콘빔 데이터를 닫힌 식으로 계산했습니다. 영상은 \(96 \times 96 \times 89\) 복셀(간격 \(2.2/96\)), 선원 각 360개, 검출기 칸 간격 0.02이고, 검출기의 가로 반폭은 1.25, 세로는 영상의 모든 복셀이 들어오도록 \(D\)마다 정했습니다. 높이 \(z\)의 이 페이지의 오차는 FDK 결과에서 같은 높이 슬라이스를 따로 재구성한 2차원 결과를 뺀 값(2차원 기준 대비)으로 쟀습니다. 2차원 결과는 선원을 그 높이의 평면 안에서 돌리고(수평 광선만 사용) 9장 페이지 4의 알고리즘으로 계산했으므로, 복셀 간격과 칸 간격에서 오는 샘플링 오차가 FDK 쪽과 같이 들어 있습니다. 비교 영역은 머리 안쪽, 곧 타원체 \(x^{2}/0.6^{2} + y^{2}/0.8^{2} + z^{2}/0.75^{2} \le 1\) 안의 복셀이며 그 높이의 슬라이스에서 rms를 구했습니다.

이 장에는 rms가 두 가지로 나옵니다. 참값 대비 rms는 같은 영역의 복셀에서 FDK 값에서 복셀 중심의 팬텀 값(참값)을 뺀 차이의 rms이고, 페이지 6, 7, 9, 10, 12에서 씁니다. 2차원 기준 대비 rms는 위의 2차원 재구성을 뺀 차이의 rms이고, 샘플링 오차를 제외한 원뿔 오차를 보이려고 이 페이지의 표, 그래프, \(1.2\,(z/D)^{2}\)에서만 씁니다. 같은 \(D = 4\)의 같은 층에서 두 값은 조금 다릅니다(층 높이 0.2063, 0.3896, 0.5958에서 참값 대비 0.00360, 0.01164, 0.02639, 2차원 기준 대비 0.0033, 0.0114, 0.0264).

14장 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. FDK는 검출기의 각 행을 기울어진 팬빔으로 보고 8장의 공식을 적용한 근사입니다. 사전 가중 \(D/\sqrt{D^{2} + u^{2} + v^{2}}\), 행마다 \(u\) 방향 램프 필터링, \((u', v')\)를 읽어 \(1/U^{2}\)을 곱하는 3차원 역투영의 세 단계입니다.
  2. 기울어진 팬의 거리는 \(D_v = \sqrt{D^{2} + v^{2}}\)이고 선원 각 간격은 \(D/D_v\)배가 됩니다. 복셀의 깊이 비와 읽는 위치는 기울어진 팬 안에서도 \(U\), \(u'\)이어서 역투영 단계는 8장과 같습니다. 근사는 \(\beta\)마다 다른 평면의 데이터를 한 평면의 것처럼 취급하는 데 있습니다.
  3. \(z = 0\)과 \(z\)에 무관한 물체에서는 정확합니다. 그 밖에서는 이 장의 3차원 팬텀에서 오차가 약 \(1.2\,(z/D)^{2}\)로 늘고 밝기가 낮아지며, 높이 방향으로 얇은 구조에서는 훨씬 큽니다.
  4. 이산 구현은 선원 각마다 행별 필터링과 복셀 열 단위의 역투영으로 이루어지고 계산량은 대부분 역투영입니다. (심화) short scan과 오프셋 검출기는 광선마다 정한 가중을 사전 가중에 곱하고 각도 합을 \(\Delta\beta\)로 바꾸며, 중앙 슬라이스 밖에서는 같은 직선의 짝이 없어 근사입니다.

FDK의 사전 가중은 무엇입니까?

  1. \(D/\sqrt{D^{2} + u^{2}}\)
  2. \(D/\sqrt{D^{2} + u^{2} + v^{2}}\)
  3. \(\sqrt{D^{2} + v^{2}}/\sqrt{D^{2} + u^{2} + v^{2}}\)

\(D = 80\) cm, \(u = 40\) cm, \(v = 30\) cm인 광선에서 세 식의 값은 순서대로 0.894, 0.848, 0.906이고 정확한 값(둘째)과 5%~7% 차이가 납니다. 한 광선의 차이가 영상에서 얼마나 눈에 띄는 오차가 되는지는 따로 확인해야 합니다. 페이지 4의 \(z\)에 무관한 물체에서는 \(v\) 항을 빼자 \(z = 0.8\)에서 밝기가 약 2% 어긋났습니다.

궤도 평면(\(z = 0\))의 복셀에서 FDK가 2차원 팬빔 FBP와 같은 결과를 주는 이유는 무엇입니까?

  1. 모든 행의 사전 가중이 같은 값이 되어서
  2. z = 0인 평면에서는 필터링을 하지 않아서
  3. v′ = 0이어서 궤도 평면의 광선만 읽어서

중앙 슬라이스에서 조금 벗어난 층(복셀 한 칸 위)의 오차는 샘플링 오차 수준이어서 중앙 슬라이스와 구분되지 않습니다. 오차는 높이를 올릴수록 \(z/D\)의 제곱으로 늘어납니다.

FDK의 역투영 가중이 8장과 같은 \(1/U^{2}\)인 이유는 무엇입니까?

  1. 기울어진 팬 안에서 깊이 비가 \(U\)와 같아서
  2. 필터링이 \(v\) 방향으로도 이루어져서
  3. 선원에 가까운 복셀의 선량을 맞추려고

반지름 0.92(팬텀 단위)의 머리가 \(D = 4\)에 있으면 \(1/U^{2}\)은 선원에 가장 가까운 복셀에서 1.69, 가장 먼 복셀에서 0.66이어서 2.5배 차이가 납니다. 페이지 6에서 이 가중을 빠뜨리면 \(z = 0\)에서도 rms가 0.0016에서 0.0256으로 16배가 되었습니다.

이 장의 3차원 팬텀에서 같은 높이 \(z\)의 오차는 \(D\)를 4에서 8로 늘리면 어떻게 달라지겠습니까?

  1. 약 두 배로 늘었다
  2. 거의 변하지 않았다
  3. 약 4분의 1로 줄었다

\(D\)가 클수록 오차가 작다고 \(D\)를 마음대로 키울 수는 없습니다. 같은 영상 영역을 덮는 검출기의 크기와 선원의 출력도 함께 바뀌므로, 이 팬텀의 규칙(\(z\)와 \(D\)의 비로만 정해짐)은 기하만 본 결과입니다. 계수 1.2도 이 팬텀과 영역에서 맞춘 값입니다.

  2. 같은 \(D = 80\) cm에서 검출기의 행 \(v = 15\) cm에 대해 \(D_v\), \(D/D_v\), 중심 광선의 기울기 \(\kappa_v\)를 구하고, 이 행의 \(u = 30\) cm 칸의 사전 가중을 \(\cos\gamma\cos\kappa\)의 곱과 \(D/\sqrt{D^{2} + u^{2} + v^{2}}\) 두 가지로 계산해 같은지 확인하세요.

모범답안과 흔한 실수

1번. \(\beta = 0^{\circ}\): \(\xi = 12\), \(\eta = -20\), \(U = 60/80 = 0.75\)이므로 \(u' = 12/0.75 = 16\) cm, \(v' = 10/0.75 = 13.33\) cm, \(1/U^{2} = 1.778\)입니다. 사전 가중은 \(80/\sqrt{6400 + 256 + 177.8} = 80/82.67 = 0.968\)입니다. \(\beta = 90^{\circ}\): \(\xi = 20\), \(\eta = 12\), \(U = 92/80 = 1.15\)이므로 \(u' = 17.39\) cm, \(v' = 8.70\) cm, \(1/U^{2} = 0.756\)입니다. 같은 복셀이 선원에 가까우면(\(\beta = 0^{\circ}\)) 검출기에서 더 높은 행을 읽고 가중이 큽니다.

2번. \(D_v = \sqrt{6400 + 225} = 81.39\) cm, \(D/D_v = 0.983\), \(\kappa_v = \arctan(15/80) = 10.6^{\circ}\)입니다. \(u = 30\)에서 \(\cos\gamma = 80/\sqrt{6400 + 900} = 0.9363\), \(\cos\kappa = \sqrt{6400 + 900}/\sqrt{6400 + 900 + 225} = 0.9850\)이므로 곱은 0.9222이고, \(80/\sqrt{7525} = 0.9222\)로 같습니다.

3번. 데이터: 광선이 \(xy\) 평면에 비추는 그림자의 길이에 \(1/\cos(\text{고도각})\)를 곱한 것이 3차원 길이이므로 \(p(\beta, u, v) = p_2(\beta, u)\sqrt{D^{2} + u^{2} + v^{2}}/\sqrt{D^{2} + u^{2}}\)입니다. 사전 가중: 이 값에 \(D/\sqrt{D^{2} + u^{2} + v^{2}}\)를 곱하면 \(p_2\,D/\sqrt{D^{2} + u^{2}}\)가 되어 모든 행이 2차원 사전 가중 데이터와 같습니다. 나머지: 모든 행의 필터링 결과가 같으므로 \(v'\)이 어디든 같은 \(q\)를 읽고, 거리 가중도 2차원과 같아서 결과가 2차원 FBP입니다.

흔한 실수.

  • 1번에서 \(\beta = 90^{\circ}\)의 \(\xi\)와 \(\eta\)를 바꿔 쓰는 것입니다. \(\xi = x\cos\beta + y\sin\beta\)이므로 \(\beta = 90^{\circ}\)에서 \(\xi = y\), \(\eta = x\)입니다.
  • 1번에서 \(v' = z\)로 두는 것입니다. \(v' = z/U\)이며 \(U \ne 1\)이면 달라집니다.
  • 2번에서 사전 가중의 분자를 \(D_v\)로 쓰는 것입니다. 분자는 \(D\)이고, \(D_v\)는 약분됩니다(페이지 4).
  • 3번에서 "높이가 같은 물체라서 정확하다"고만 쓰는 것입니다. 사전 가중이 \(\sqrt{D^{2} + u^{2} + v^{2}}\)를 포함해야 행마다 같은 2차원 데이터가 되므로, 이 항 없이는 성립하지 않습니다.
