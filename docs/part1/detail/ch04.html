4장 · 페이지 1

투영에서 영상으로: 푸리에 슬라이스 정리와 역투영

3장에서는 평행빔 데이터 \(p(\theta, s)\)가 각도와 검출기 위치로 정해지는 값의 모음이라는 것을 보았습니다. 이 장에서는 이 데이터에서 영상을 만드는 두 방법을 비교합니다. 하나는 푸리에 공간에서 바로 영상을 만드는 방법이고, 다른 하나는 영상 공간에서 측정값을 되돌려 더하는 역투영입니다. 두 방법을 푸리에 공간에서 겹쳐 보면 필터 역투영(FBP)의 원리가 보입니다.

투영의 1차원 푸리에 변환

3장 페이지 10의 이산 sinogram에서 행 하나는 각도 하나의 투영이었습니다. 연속으로 보면 각도 \(\theta\)를 고정한 \(p(\theta, s)\)는 \(s\)의 1차원 함수이므로, 2장의 규약대로 \(s\)에 대해 푸리에 변환할 수 있습니다.

\[P_\theta(\omega) = \int_{-\infty}^{\infty} p(\theta, s)\,e^{-i2\pi\omega s}\,ds\]

  • \(\omega\)는 검출기 방향의 주파수이며, 2장의 규약대로 1 cm당 반복 횟수(\(\mathrm{cm}^{-1}\))입니다.
  • \(P_\theta(\omega)\)는 각도 \(\theta\)의 투영에 주파수 \(\omega\)인 파동이 얼마나 들어 있는지를 나타냅니다.

그렇다면 \(P_\theta(\omega)\)는 영상 \(\mu(x, y)\)의 무엇에 해당할까요? 영상의 주파수 성분은 2차원 푸리에 변환 \(F(\omega_x, \omega_y)\)가 나타내므로(2장 페이지 6), \(P_\theta\)가 \(F\)의 어느 부분인지를 찾으면 됩니다.

세로 광선의 투영

가장 단순한 각도부터 계산해 봅니다. \(\theta = 0\)이면 광선은 세로 직선 \(x = s\)이고, 광선 위의 거리 \(\ell\)은 \(y\)입니다(3장 페이지 2). 따라서 투영은 영상을 \(y\) 방향으로 적분한 것입니다.

\[p(0, s) = \int_{-\infty}^{\infty} \mu(s, y)\,dy\]

이것을 \(s\)에 대해 푸리에 변환하고, 적분 변수 \(s\)를 \(x\)로 바꿔 쓰면 다음과 같습니다.

\[P_0(\omega) = \int\!\left[\int \mu(x, y)\,dy\right] e^{-i2\pi\omega x}\,dx = \iint \mu(x, y)\,e^{-i2\pi\omega x}\,dx\,dy\]

마지막 식은 2차원 푸리에 변환의 정의에 \(\omega_x = \omega,\ \omega_y = 0\)을 넣은 것입니다. 그러므로 \(P_0(\omega) = F(\omega, 0)\)입니다.

세로 광선의 투영을 1차원 푸리에 변환하면, 영상의 2차원 푸리에 변환을 \(\omega_x\) 축 위에서 읽은 값이 나옵니다. \(y\) 방향으로 진동하는 성분은 \(y\)로 적분하면 0이 되고, \(y\) 방향으로 진동하지 않는 성분(\(\omega_y = 0\))만 투영에 남기 때문입니다. 3장 페이지 7의 질량 보존(투영 한 장의 합이 어느 각도에서나 영상 전체의 합과 같다는 사실, 증명은 페이지 8의 심화)을 푸리에 변환으로 쓴 \(P_\theta(0) = F(0, 0)\)은 이 직선의 원점 값입니다.

줄무늬 영상으로 두 경우를 비교하면 다음과 같습니다. \(\omega_x\) 축 위의 점은 \(x\) 방향으로만 변하는 세로 줄무늬이고, 세로 광선은 줄 하나를 따라 지나므로 투영에 같은 무늬가 그대로 남습니다. 반대로 \(y\) 방향으로 변하는 가로 줄무늬는 광선 하나가 짙은 줄과 옅은 줄을 같은 만큼 지나므로 더하면 0입니다.

다른 각도에서는 어떻게 될까요? 광선 방향을 돌리면 적분으로 사라지는 방향도 함께 돌아갑니다. 그래서 투영의 푸리에 변환은 주파수 평면에서 같은 각만큼 돌아간 직선 위의 값이 될 것으로 짐작할 수 있습니다. 이 짐작이 맞다는 것이 다음 페이지의 푸리에 슬라이스 정리입니다.

이 장의 진행

  1. 투영의 푸리에 변환이 영상의 2차원 푸리에 변환의 한 직선임을 보이고 증명합니다(푸리에 슬라이스 정리, 페이지 2~3. 증명인 페이지 3은 심화). 투영 각도가 180°에 못 미칠 때 주파수 평면에 생기는 빈 곳도 봅니다(페이지 2).
  2. 이 정리로 바로 재구성하는 방법과 그 어려움을 봅니다(페이지 4, 심화).
  3. 영상 공간에서 측정값을 되돌려 더하는 역투영을 직관과 식으로 설명합니다(페이지 5~6).
  4. 역투영이 푸리에 공간에서 하는 일을 보고, 필터 역투영의 원리를 알아봅니다(페이지 7~8).
  5. Shepp-Logan 팬텀으로 단순 역투영과 필터 역투영을 비교합니다(페이지 9).

페이지 머리에 "심화"가 붙은 페이지(3, 4)는 처음 읽을 때 건너뛰어도 됩니다.

4장 · 페이지 2

투영 하나는 주파수 평면의 직선 하나: 푸리에 슬라이스 정리

페이지 1에서 \(\theta = 0\)일 때 얻은 결과는 모든 각도에서 성립합니다. 각도 \(\theta\)의 투영을 1차원 푸리에 변환한 것은, 영상의 2차원 푸리에 변환을 주파수 평면의 원점을 지나 \(\theta\) 방향으로 놓인 직선 위에서 읽은 값과 같습니다.

\[P_\theta(\omega) = F(\omega\cos\theta,\ \omega\sin\theta),\qquad -\infty < \omega < \infty\]

  • \(\theta\)는 3장의 투영 각도, 즉 광선의 법선 방향 각입니다. 주파수 평면의 직선도 같은 \(\theta\) 방향이며, 이 방향은 검출기 방향(회전 좌표의 \(x'\) 축)입니다.
  • \(\omega\)는 그 직선 위에서 원점으로부터 잰 부호 있는 위치입니다. 음수이면 원점의 반대쪽입니다.
  • \(P_\theta\)는 투영의 1차원 푸리에 변환(페이지 1), \(F\)는 영상 \(\mu\)의 2차원 푸리에 변환입니다.

푸리에 슬라이스 정리(Fourier Slice Theorem)가 이 식입니다. 2차원 함수를 원점을 지나는 직선으로 잘라 낸 단면을 슬라이스라고 부르는 데서 이름이 왔고, 중심 단면 정리(Central Slice Theorem) 또는 투영 단면 정리(Projection-Slice Theorem)라고도 합니다. 전파 천문학에서 Bracewell이 1956년에 이 관계를 썼습니다(R. N. Bracewell, Strip integration in radio astronomy, Australian Journal of Physics 9, 198–217, 1956). 2장에서 \(2\pi\)를 지수 안에 두는 규약을 정했으므로 식에 상수가 붙지 않습니다.

2장 페이지 6에서 본 것처럼, 주파수 평면에서 \(\theta\) 방향 직선 위의 점은 모두 \(\theta\) 방향으로 변하는 줄무늬(파동)의 성분이고, 이 줄무늬의 줄은 광선과 나란합니다. 각도 \(\theta\)의 광선은 \(\theta\)에 수직인 방향을 따라 적분하므로, 다른 방향으로 변하는 줄무늬는 광선이 짙은 줄과 옅은 줄을 함께 지나 더하면 상쇄됩니다. 투영 한 장에는 광선과 나란한 줄무늬 성분만 남고, 그래서 투영 한 장은 주파수 평면에서 정확히 직선 하나의 정보를 줍니다.

정사각형 하나의 예

중심이 원점이고 한 변이 1, 값이 1인 정사각형으로 정리를 확인해 봅니다. 식으로는 \(\mu(x, y) = \mathrm{rect}(x)\,\mathrm{rect}(y)\)이고, \(\mathrm{rect}(x)\)는 \(|x| < 1/2\)에서 1, 나머지에서 0인 사각 함수입니다. 2장의 변환 쌍 \(\mathrm{rect} \longleftrightarrow \mathrm{sinc}\)를 \(x\)와 \(y\) 두 방향에 쓰면 영상의 푸리에 변환은 \(F(\omega_x, \omega_y) = \mathrm{sinc}(\omega_x)\,\mathrm{sinc}(\omega_y)\)입니다. 여기서 \(\mathrm{sinc}(\omega) = \sin\pi\omega\,/\,\pi\omega\)입니다.

두 방향의 결과는 다음과 같습니다.

  • \(\theta = 0\). 투영은 폭 1, 높이 1인 사각형이고 \(P_0(\omega) = \mathrm{sinc}(\omega)\)입니다.
  • \(\theta = 45^{\circ}\). 투영은 밑변과 높이가 모두 \(\sqrt2\)인 삼각형이고 \(P_{45^{\circ}}(\omega) = \mathrm{sinc}^{2}(\omega/\sqrt2)\)입니다.

두 식은 각각 주파수 평면의 해당 직선 위에서 \(F\)를 읽은 값 \(F(\omega, 0)\), \(F(\omega/\sqrt2,\ \omega/\sqrt2)\)와 같습니다. 계산은 아래 접기에 있습니다.

\(\omega = 1\)에서 \(\theta = 0\)의 값 \(\mathrm{sinc}(1)\)은 0이지만, \(\theta = 45^{\circ}\)의 값 \(\mathrm{sinc}^{2}(1/\sqrt2)\)는 약 0.128입니다. 같은 영상이라도 방향마다 주파수 성분이 다르고, 각 투영은 자기 방향의 성분만 알려 줍니다.

두 방향의 계산

\(\theta = 0\). 세로 광선이 정사각형을 지나는 길이는 \(|s| < 1/2\)에서 1이므로 \(p(0, s) = \mathrm{rect}(s)\)이고 \(P_0(\omega) = \mathrm{sinc}(\omega)\)입니다. 정리의 오른쪽은 \(F(\omega, 0) = \mathrm{sinc}(\omega)\,\mathrm{sinc}(0) = \mathrm{sinc}(\omega)\)로 같습니다.

\(\theta = 45^{\circ}\). 광선이 지나는 길이는 \(s = 0\)에서 대각선 길이 \(\sqrt2\)이고, 양쪽으로 곧게 줄어 \(|s| = \sqrt2/2\)에서 0이 되는 삼각형입니다. 이 삼각형은 폭 \(\sqrt2/2\), 높이 1인 사각형 둘을 컨볼루션해 2배 한 모양이므로, 2장 페이지 3의 컨볼루션 정리로 \(P_{45^{\circ}}(\omega) = \mathrm{sinc}^{2}(\omega/\sqrt2)\)입니다. 정리의 오른쪽은 \(F(\omega/\sqrt2,\ \omega/\sqrt2) = \mathrm{sinc}(\omega/\sqrt2)\,\mathrm{sinc}(\omega/\sqrt2)\)로 같습니다.

영상에서 넓게 퍼진 방향일수록 주파수 평면에서는 좁게 모입니다(2장 페이지 3의 스케일 성질). 정사각형은 가로와 세로의 폭이 같아 \(F\)가 두 축 방향에서 같은 모양이지만, 폭이 다른 직사각형에서는 이 차이가 드러납니다. 다음 위젯에서 확인합니다.

각도를 바꿔 가며 확인

두 방향만으로는 정리가 모든 각도에서 성립하는지 알 수 없습니다. 아래 위젯은 \(\theta\)를 \(0^{\circ}\)에서 \(179^{\circ}\)까지 바꾸며 같은 비교를 합니다. 그래프의 점은 투영 곡선을 수치 적분으로 1차원 푸리에 변환한 \(|P_\theta(\omega)|\)이고, 선은 \(F\)의 식에 직선 위의 점을 넣은 값입니다. 영상은 앞의 예와 같은 정사각형이 기본이며, 선택 상자에서 가로 2 cm, 세로 1 cm인 직사각형으로 바꿀 수 있습니다.

  • 영상의 광선과 검출기, 주파수 평면의 초록 직선이 같은 \(\theta\)로 함께 돕니다. \(\theta = 0\)이면 직선은 \(\omega_x\) 축, \(\theta = 90^{\circ}\)이면 \(\omega_y\) 축입니다.
  • 모든 각도에서 점(투영에서 계산)과 선(영상의 2차원 변환)이 겹칩니다. 슬라이더 아래에 둘의 가장 큰 차이가 적힙니다.
  • 정사각형에서는 \(\theta = 0^{\circ}\)와 \(90^{\circ}\)의 그래프가 같습니다(\(\omega = 1\)에서 0). 직사각형으로 바꾸면 \(\theta = 0^{\circ}\)에서는 영상이 넓은 가로 방향이어서 그래프가 \(\omega = 0.5\)에서 0이 되고, \(\theta = 90^{\circ}\)에서는 \(\omega = 1\)에서 0이 됩니다. 영상에서 넓은 방향일수록 주파수 평면에서는 좁게 모입니다.

180° 측정과 주파수 평면

3장 페이지 9의 대칭 \(p(\theta + \pi, -s) = p(\theta, s)\)를 \(s\)에 대해 푸리에 변환하면 \(P_{\theta+\pi}(\omega) = P_\theta(-\omega)\)입니다. \(\theta + \pi\) 방향의 직선은 \(\theta\) 방향의 직선을 반대쪽(\(\omega < 0\))에서 읽은 같은 직선이므로, 두 투영은 같은 정보를 줍니다.

그러므로 \(0 \le \theta < \pi\)의 직선들은 \(\omega\)를 음수까지 포함하면 원점을 뺀 주파수 평면의 모든 점을 한 번씩 지납니다. 3장에서 평행빔은 \(180^{\circ}\)로 충분하다고 한 결론을 주파수 평면에서 다시 확인한 것입니다.

각도가 모자랄 때의 빈 부채꼴

측정 각도가 모자라면 생기는 문제는 특정한 재구성 방법이 아니라 모든 재구성에 공통인 한계입니다. 이 한계는 주파수 평면에서 가장 분명하게 보입니다. 위에서 본 것처럼 \(0 \le \theta < \pi\)의 직선은 주파수 평면 전체를 덮습니다. 그런데 \(0 \le \theta < \Theta\)만 측정하고 \(\Theta < 180^{\circ}\)이면, 방향이 \(\Theta\)부터 \(180^{\circ}\) 사이인 직선은 한 번도 측정되지 않습니다(반대 방향은 같은 직선입니다). 직선이 하나도 지나지 않는 이 영역을 빈 부채꼴이라고 부르겠습니다.

3장 페이지 9에서 이 빈자리가 재구성에 무엇을 남기는지는 푸리에 슬라이스 정리로 보면 분명해진다고 했습니다. 슬라이스 정리에 따라 각도 하나의 투영은 주파수 평면의 직선 하나를 채우므로, 빈 부채꼴은 채우지 못한 영역입니다. 빈 부채꼴 안의 \(F\)는 투영 데이터 어디에도 들어 있지 않습니다. 그래서 필터나 보간 같은 일반적인 방법으로는 안정적으로 되살릴 수 없습니다.

푸리에 슬라이스 정리의 증명

페이지 1에서 \(\theta = 0\)인 경우를 이미 계산했습니다. 영상을 돌려 다른 각도를 \(\theta = 0\)인 경우로 바꾸면 증명이 끝납니다. 앞장에서 본 회전 성질 두 가지를 씁니다.

  1. 영상 \(\mu\)를 시계 방향으로 \(\theta\)만큼 돌린 영상을 \(g\)라고 하겠습니다. 3장 페이지 8의 회전 성질에 따라, \(g\)를 각도 0에서 본 투영은 \(\mu\)를 각도 \(\theta\)에서 본 투영과 같습니다. 그러므로 페이지 1의 결과에서 \(P_\theta(\omega) = G(\omega, 0)\)입니다. \(G\)는 \(g\)의 2차원 푸리에 변환입니다.
  2. 2장 페이지 6의 회전 성질에 따라 \(G\)는 \(F\)를 같은 방향(시계 방향)으로 \(\theta\)만큼 돌린 것입니다. 따라서 \(G\)의 \(\omega_x\) 축 위의 점 \((\omega, 0)\)에는, \(F\)에서 그 점을 반시계 방향으로 \(\theta\) 돌린 자리 \((\omega\cos\theta,\ \omega\sin\theta)\)의 값이 옵니다.

아래 그림은 이 두 성질이 하는 일을 직사각형 영상으로 보인 것입니다. 영상과 주파수 평면을 함께 시계 방향으로 \(\theta\) 돌리면 광선은 세로가 되고, 원래의 \(\theta\) 방향 직선은 \(\omega_x\) 축에 놓입니다.

두 사실을 합치면 \(P_\theta(\omega) = F(\omega\cos\theta,\ \omega\sin\theta)\)입니다. 회전 성질을 거치지 않고 정의에서 바로 전개할 수도 있습니다. 1장의 회전 좌표로 변수를 한 번 바꾸면 되고, 3장의 델타 함수 표기로는 더 짧습니다. 두 전개는 아래 접기에 있으며, 건너뛰어도 뒤의 내용은 이어집니다.

정의에서 바로 하는 전개

1단계. 정의 넣기. 3장 페이지 3의 Radon 변환(직선마다 선적분을 모은 변환)을 페이지 1의 정의에 넣습니다.

\[P_\theta(\omega) = \int\!\left[\int \mu\bigl(s\cos\theta - \ell\sin\theta,\ \ s\sin\theta + \ell\cos\theta\bigr)\,d\ell\right] e^{-i2\pi\omega s}\,ds\]

2단계. 회전 좌표로 변수 바꾸기. \((s, \ell)\)은 1장 페이지 1의 회전 좌표 \((x', y')\)이고, \(\mu\) 안의 두 식은 회전 좌표의 역변환 \(x = x'\cos\theta - y'\sin\theta,\ y = x'\sin\theta + y'\cos\theta\)입니다. 그래서 적분 변수를 \((s, \ell)\)에서 \((x, y)\)로 바꿉니다. 이 변환의 행렬식은 \(\cos^{2}\theta + \sin^{2}\theta = 1\)이므로 \(ds\,d\ell = dx\,dy\)이고(1장 페이지 2), 지수 안의 \(s\)는 \(x' = x\cos\theta + y\sin\theta\)입니다.

\[P_\theta(\omega) = \iint \mu(x, y)\,e^{-i2\pi\omega(x\cos\theta + y\sin\theta)}\,dx\,dy\]

3단계. 정의와 비교. 2차원 푸리에 변환 \(F(\omega_x, \omega_y) = \iint \mu(x, y)\,e^{-i2\pi(\omega_x x + \omega_y y)}\,dx\,dy\)에 \(\omega_x = \omega\cos\theta,\ \omega_y = \omega\sin\theta\)를 넣으면 지수가 2단계의 식과 같습니다. 따라서 \(P_\theta(\omega) = F(\omega\cos\theta,\ \omega\sin\theta)\)입니다.

4단계. 쓴 가정. 적분 순서를 바꾸려면 \(\mu\)의 절댓값을 적분한 값이 유한해야 합니다. CT 영상은 장치의 측정 영역 밖에서 0이고 값이 유한하므로 이 조건을 만족합니다. \(\omega\)에는 아무 가정도 하지 않았으므로 음수에서도 성립합니다.

델타 함수 표기로 쓴 전개. 3장 페이지 3의 이중적분 표기를 넣고 \(s\)에 대한 적분을 안쪽으로 옮깁니다.

\[\begin{aligned}P_\theta(\omega) &= \int\!\left[\iint \mu(x, y)\,\delta(x\cos\theta + y\sin\theta - s)\,dx\,dy\right] e^{-i2\pi\omega s}\,ds\\ &= \iint \mu(x, y)\left[\int \delta(x\cos\theta + y\sin\theta - s)\,e^{-i2\pi\omega s}\,ds\right] dx\,dy\\ &= \iint \mu(x, y)\,e^{-i2\pi\omega(x\cos\theta + y\sin\theta)}\,dx\,dy\end{aligned}\]

가운데 줄의 괄호는 Sifting 성질에 따라 \(s = x\cos\theta + y\sin\theta\)에서의 지수 값만 남깁니다. 3장 페이지 3에서 영상 전체에 대한 적분과 순서를 바꿔 계산할 때 델타 함수 표기가 편하다고 한 것이 이런 계산입니다.

중심에서 벗어난 물체

정리는 물체가 회전 중심에 있지 않아도 그대로 성립합니다. 중심이 \((x_0, y_0)\)인 가우시안 함수 \(\mu(x, y) = e^{-\pi((x - x_0)^{2} + (y - y_0)^{2})}\)로 확인해 봅니다.

  • 영상 쪽. 2장의 변환 쌍 \(e^{-\pi x^{2}} \longleftrightarrow e^{-\pi\omega^{2}}\)를 두 방향에 쓰고 이동 성질(2장 페이지 3)을 쓰면 \(F(\omega_x, \omega_y) = e^{-\pi(\omega_x^{2} + \omega_y^{2})}\,e^{-i2\pi(\omega_x x_0 + \omega_y y_0)}\)입니다.
  • 투영 쪽. 중심까지의 거리는 회전 좌표에서도 같으므로, 광선을 따라 적분하면 \(\int e^{-\pi\ell^{2}}\,d\ell = 1\)이 곱해집니다. 그래서 \(p(\theta, s) = e^{-\pi(s - s_0)^{2}}\)이고, \(s_0 = x_0\cos\theta + y_0\sin\theta\)는 3장 페이지 6의 사인 곡선입니다. 1차원 변환은 \(P_\theta(\omega) = e^{-\pi\omega^{2}}\,e^{-i2\pi\omega s_0}\)입니다.

\(F\)에 \(\omega_x = \omega\cos\theta,\ \omega_y = \omega\sin\theta\)를 넣으면 \(\omega_x x_0 + \omega_y y_0 = \omega s_0\)이므로 두 식이 같습니다. 물체를 옮기면 양쪽 모두 크기는 그대로이고 위상만 바뀝니다. 회전 중심에서 먼 물체일수록 \(F\)의 위상이 주파수 평면에서 빠르게 돕니다.

다른 책의 표기

주 참고서(Kak & Slaney)는 투영 자체를 \(P_\theta(t)\)로 씁니다(3장 페이지 3). 그 책의 \(P_\theta\)는 이 책의 \(p(\theta, s)\)에 해당하고, 투영의 푸리에 변환에는 다른 글자를 씁니다. 두 책을 함께 볼 때는 \(P_\theta\)가 투영인지 그 변환인지 먼저 확인하세요. 각주파수를 쓰는 책에서도, 변환의 정의 앞에 상수를 붙이지 않는다면 위 전개가 그대로여서 정리에 상수가 붙지 않습니다.

직접 푸리에 재구성

푸리에 슬라이스 정리를 그대로 이어 가면 재구성 방법 하나가 만들어집니다.

  1. 모든 각도의 투영을 1차원 푸리에 변환합니다. 각도 하나의 결과는 주파수 평면에서 원점을 지나는 직선 하나를 채웁니다(페이지 2).
  2. \(0 \le \theta < \pi\)의 직선을 모두 모으면 주파수 평면 전체의 \(F\)를 알게 됩니다.
  3. \(F\)를 2차원 역변환하면 영상 \(\mu\)가 나옵니다(2장 페이지 6).

연속 함수로 생각하면 이 과정에는 근사가 없어 수학적으로 영상이 정확히 재구성됩니다. 이처럼 투영의 푸리에 변환으로 주파수 평면을 채운 뒤 2차원 역변환으로 영상을 얻는 방법을 직접 푸리에 재구성(Direct Fourier Reconstruction)이라고 합니다.

그러나 컴퓨터로 구현하면 한계가 생깁니다. 투영의 각도와 검출기 샘플이 이산적이어서, 측정한 값은 극좌표 격자(원점을 지나는 직선들) 위에만 있습니다. 반면 빠른 2차원 역변환(2차원 역 FFT)은 가로·세로로 일정한 간격의 직교 격자 위의 값을 요구합니다. 두 격자가 어긋나므로 극좌표 점의 값으로 직교 격자점의 값을 만드는 보간이 필요합니다. 이산이라는 것만으로 보간이 필요한 것은 아닙니다. 측정점이 처음부터 직교 격자 위에 있다면 보간은 필요 없습니다. 아래 그림은 구현의 계산 순서이고, 이 순서에서 어려움이 세 군데 나옵니다(어려움 1~3).

어려움 1. 극좌표에서 직교 격자로의 보간

그림에서 주황 밑줄을 친 두 단계가 가장 까다롭습니다. 검출기 칸 \(N_s\)개의 투영을 DFT하면 주파수 간격 \(1/(N_s\Delta s)\)마다 값을 얻습니다(2장 페이지 5). 이 점들은 각도마다 원점을 지나는 직선 위에 놓이므로, 전체는 원점에서 방사형으로 퍼진 극좌표 격자가 됩니다. 이 극좌표 격자를 2차원 역 FFT가 요구하는 직교 격자(2장 페이지 6)로 옮기는 것이 보간입니다.

어려움 1의 보간이 까다로운 이유는 다시 세 가지로 나뉩니다.

  • 밀도가 고르지 않습니다. 직선이 모두 원점을 지나므로 중심 근처에는 값이 빽빽하고 바깥으로 갈수록 성깁니다. 가장자리의 격자점은 두 칸 넘게 떨어진 측정값으로 보간됩니다(계산은 목록 아래).
  • 위상이 빠르게 돕니다. 페이지 3에서 본 것처럼 회전 중심에서 거리 \(d\)만큼 떨어진 물체의 \(F\)는 위상이 주파수 \(1/d\)마다 한 바퀴 돕니다. 이웃한 측정값 사이의 간격이 이보다 넓으면, 두 값을 잇는 보간은 위상의 회전을 따라가지 못합니다. 그래서 같은 간격이라도 중심에서 먼 물체일수록 보간 오차가 큽니다.
  • 오차가 영상 전체로 퍼집니다. 주파수 평면의 값 하나는 영상 전체에 걸친 파동 하나의 크기입니다. 보간이 한 주파수에서 틀리면 그 오차는 영상의 한 곳이 아니라 전체에 걸친 줄무늬로 나타납니다. 보간 간격이 넓은 높은 주파수에서 오차가 크므로, 가는 줄무늬가 영상 전체에 겹칩니다.

밀도의 계산은 다음과 같습니다. 반지름 \(\omega\)에서 이웃한 두 직선 사이의 거리는 호의 길이 \(\omega\,\Delta\theta\)입니다. \(180^{\circ}\)를 각도 \(N_\theta\)개로 나누면 \(\Delta\theta = \pi/N_\theta\)이므로, 나이퀴스트 주파수에서 이 거리는 \(\pi/(2\Delta s N_\theta)\)입니다.

직교 격자의 간격 \(1/(N_s\Delta s)\)에 대한 비는 \(\pi N_s/(2N_\theta)\)이고, \(N_\theta = 180,\ N_s = 256\)이면 약 2.2입니다.

또 측정한 직선들은 나이퀴스트 반지름의 원 안만 덮으므로, 직교 격자의 네 구석에는 값이 없어 0으로 채웁니다.

어려움 2. 별도의 큰 2차원 역변환

보간의 정확도를 높이려면 투영의 양 끝에 0을 채워(2장 페이지 5의 제로 패딩) 주파수 간격을 촘촘하게 하는 방법이 흔히 쓰입니다. 그러면 직교 격자도 촘촘해지고, 2차원 역 FFT의 크기가 영상보다 커집니다. 이 변환은 주파수 평면 전체의 값을 한꺼번에 받으므로, 큰 2차원 배열 하나를 통째로 메모리에 두어야 합니다.

어려움 3. 모든 각도가 모여야 시작

2차원 역변환은 주파수 평면 전체가 채워진 뒤에야 할 수 있습니다. 모든 각도의 투영을 측정하고 변환하고 보간을 마칠 때까지 영상은 한 장도 나오지 않습니다. 뒤에서 볼 필터 역투영(FBP)은 각도 하나의 투영이 들어올 때마다 처리해서 영상에 더해 가면 되므로, 측정과 계산을 겹쳐 진행할 수 있고 메모리에는 영상 하나와 투영 한 장만 있으면 됩니다.

보간 방법을 개선한 연구가 많고, MRI에서는 방사형이나 나선형으로 측정하는 경우에 이처럼 주파수 평면에서 보간하는 기법이 널리 쓰입니다.

직접 푸리에 재구성의 연산량

계산이 오래 걸려서 쓰이지 않는다고 생각하기 쉽지만, 연산량 자체는 불리하지 않습니다. 영상이 \(N\times N\), 각도가 \(N\)개 정도라고 하겠습니다.

  • 투영마다 하는 1차원 FFT는 모두 합쳐 \(N^{2}\log N\)에 비례합니다.
  • 보간은 격자점마다 정해진 개수의 이웃만 쓰므로 \(N^{2}\)에 비례합니다.
  • 2차원 FFT도 \(N^{2}\log N\)에 비례합니다.

전체가 \(N^{2}\log N\) 정도입니다. 필터 역투영은 각도 \(N\)개마다 화소 \(N^{2}\)개에 값을 더하므로 \(N^{3}\)에 비례합니다. 그래서 직접 푸리에 재구성이 외면받는 이유는 계산량이 아니라 보간 오차와 위의 어려움 2·3입니다.

영상 공간에서 처리하는 방법

CT의 해석적 재구성에서는 주파수 평면을 채우지 않고 영상 공간에서 계산하는 방법이 표준으로 쓰입니다. 그렇다면 보간 없이, 각도를 하나씩 처리하는 더 효율적인 방법은 없을까요? 있습니다. 푸리에 공간에서 하려던 일을 영상 공간에서 각도마다 해 나가는 방법이고, 그 재료가 다음 페이지의 역투영입니다.

측정값을 되돌려 칠해 보기: 역투영의 직관

측정값 하나가 알려 주는 것은 광선 하나를 따라 \(\mu\)를 더한 값뿐입니다. 그 광선 위의 어디에 무엇이 있는지는 알려 주지 않습니다. 그렇다면 가장 단순한 추측은 그 값을 광선이 지나는 모든 점에 똑같이 칠하는 것입니다. 검출기 쪽에서 광원 쪽으로 붓을 한 번 쭉 그어 칠하는 것과 같습니다.

각도 하나의 투영을 이렇게 칠하면 광선 방향으로 뻗은 줄무늬가 생깁니다. 줄의 밝기는 그 광선의 측정값입니다. 이 칠하기를 모든 각도에 대해 하고 결과를 더하면, 물체가 있는 점은 여러 각도의 광선이 공통으로 지나므로 값이 쌓입니다. 물체가 없는 점은 일부 광선의 값만 받습니다. 이처럼 측정값을 광선을 따라 영상으로 되돌려 놓고 더하는 연산을 역투영(Back Projection)이라고 합니다. 투영이 영상에서 측정값으로 가는 계산이라면, 역투영은 측정값에서 영상으로 가는 계산입니다.

각도가 늘며 쌓이는 과정

아래 위젯은 각도 36개(\(5^{\circ}\) 간격)의 투영을 차례로 칠하며 더합니다. 왼쪽은 현재 각도의 투영 곡선이고, 오른쪽은 지금까지 칠한 결과입니다. 주황색은 방금 칠하는 줄이고, 점선은 붓이 지나가는 앞쪽 끝입니다.

  • 작은 점 하나. 각도마다 점을 지나는 줄이 하나씩 더해져 별 모양이 됩니다. 줄이 모두 점에서 만나므로 점의 자리가 가장 밝지만, 줄은 점 바깥으로도 끝없이 이어집니다.
  • 정사각형 두 개. 각도가 적을 때는 실제 위치뿐 아니라 0편 2장 페이지 7의 다른 배치 쪽에도 줄이 겹쳐 밝습니다. 각도가 늘면 실제 위치의 값이 다른 배치 쪽의 값보다 커집니다.
  • Shepp-Logan 팬텀. 각도가 늘수록 윤곽이 드러납니다. 그러나 물체 바깥에도 줄이 남아 있고, 모든 곳이 흐릿합니다.

각도를 늘려도 물체 밖에 남는 값은 사라지지 않습니다. 이 장에서는 투영값에 아무 처리도 하지 않고 역투영만 한 결과를 단순 역투영(Simple Back Projection)이라고 부르겠습니다.

역투영의 정의

페이지 5의 칠하기를 식으로 씁니다. 점 \((x, y)\)를 지나는 광선은 각도 \(\theta\)마다 하나씩 있고, 그 광선의 검출기 좌표는 \(s = x\cos\theta + y\sin\theta\)입니다. 3장 페이지 6에서 작은 물체가 sinogram에 그리던 사인 곡선이 이 식입니다. 역투영은 점마다 각도별 광선의 값을 읽어 모든 각도에 대해 더합니다. 측정 데이터 \(p(\theta, s)\)로 영상을 만드는 역투영은 다음과 같습니다.

\[(\mathcal{B}p)(x, y) = \int_{0}^{\pi} p(\theta,\ x\cos\theta + y\sin\theta)\,d\theta\]

  • \(\mathcal{B}\)는 역투영 연산의 기호입니다. 0편 2장의 투영 \(\mathcal{P}\)가 영상을 sinogram으로 보내듯이 \(\mathcal{B}\)는 sinogram을 영상으로 보냅니다. 3장의 타원 반축 \(B\)나 0편 3장의 측정 벡터 \(\mathbf{b}\)와는 다른 기호입니다.
  • \(p(\theta, s)\)는 각도 \(\theta\), 검출기 좌표 \(s\)에서 읽는 측정값입니다. 이 식은 측정 데이터가 아닌 다른 sinogram에도 같은 모양으로 쓰입니다.
  • 3장 페이지 9에 따라 평행빔은 \(0 \le \theta < \pi\)의 측정으로 모든 직선을 한 번씩 얻으므로 적분 구간을 \([0, \pi)\)로 잡습니다.
  • sinogram 위에서 보면, 역투영은 점 \((x, y)\)가 그리는 사인 곡선을 따라 sinogram의 값을 적분한 것입니다.

측정 데이터 \(p = \mathcal{P}\mu\)에 역투영을 적용한 \(\mathcal{B}p\), 곧 \(\mathcal{B}\mathcal{P}\mu\)가 페이지 5의 단순 역투영입니다.

격자 영상의 역투영

화소로 나뉜 영상에서는 광선 \(i\)의 투영값 \(p_i\)를 그 광선이 지나는 화소에 칠합니다. 화소 \(j\)에는 그 화소를 지나는 광선들의 값을 모두 더하는데, 광선이 화소 안에서 지난 길이 \(w_{ij}\)(0편 2장 페이지 5)를 곱해 더합니다.

\[(\text{화소 } j\text{의 역투영 값}) = \sum_{i} w_{ij}\,p_i\]

역연산이 아닌 이유

이름 때문에 역투영을 투영의 역연산으로 오해하기 쉽습니다. 역연산이라면 \(\mathcal{B}\mathcal{P}\mu = \mu\)여야 합니다. 0편 3장 페이지 1의 \(2\times2\) 화소(\(\mu_1 = 0.2,\ \mu_2 = 0.5,\ \mu_3 = 0.1,\ \mu_4 = 0.3\), 광선 ①~⑤)로 확인해 봅니다.

투영값 \((0.7,\ 0.4,\ 0.3,\ 0.8,\ 0.707)\)을 위의 식에 넣으면 화소 1은 ①·③·⑤에서 \(0.7 + 0.3 + \sqrt2\times0.707 \approx 2.0\)을 받습니다. 같은 방식으로 화소 2는 ①·④에서 1.5, 화소 3은 ②·③에서 0.7, 화소 4는 ②·④·⑤에서 2.2를 받습니다. 결과 \((2.0,\ 1.5,\ 0.7,\ 2.2)\)는 원래 값과 다르고 비례하지도 않습니다. 화소 1은 원래 값이 화소 2보다 작은데도, 대각선 광선 ⑤를 하나 더 받아 역투영 값은 더 큽니다. 역투영은 각 화소를 지나는 광선의 값을 모을 뿐, 그 값이 어느 화소에서 왔는지를 풀어 주지는 않습니다.

수반 연산

알고 가면 되는 것

역투영은 투영의 역연산이 아니라 수반(Adjoint) 연산입니다. 이 장에서는 이 정도만 알고 가면 됩니다.

  • 투영을 행렬 \(\mathbf{A}\)로 쓰면 역투영은 전치행렬(Transpose) \(\mathbf{A}^{\mathsf T}\)에 해당합니다. 엄밀한 표현은 아니지만, 이렇게 비유해서 이해해도 이 장을 따라가는 데 충분합니다. 위의 \((2.0,\ 1.5,\ 0.7,\ 2.2)\)가 \(\mathbf{A}^{\mathsf T}\mathbf{b}\)입니다.
  • 수반이 무슨 뜻인지 지금 이해하지 못해도 필터 역투영(FBP)을 이해하는 데는 큰 문제가 없습니다.
  • 수반이 정말 필요한 곳은 2편(대수적 재구성)입니다. 거기서는 \(\mathbf{A}\)와 \(\mathbf{A}^{\mathsf T}\)를 짝으로 되풀이해 쓰며, 이 짝은 2편 1장에서 다시 정리합니다.

수반의 뜻과 확인 방법은 아래 접기에 있습니다. 건너뛰어도 뒤의 내용은 이어집니다.

내적과 수반의 전개

내적. 성분이 실수인 두 벡터 \(\mathbf{a}, \mathbf{c}\)의 내적은 같은 자리의 성분을 곱해 더한 값입니다.

\[\langle\mathbf{a}, \mathbf{c}\rangle = \sum_{j} a_j c_j\]

2장 페이지 2에서는 이 합을 적분으로 바꾼 함수의 내적 \(\langle f, g\rangle = \int f(x)\,\overline{g(x)}\,dx\)를 보았습니다. 영상과 sinogram은 실수 값이므로 켤레는 필요 없습니다. 두 영상 \(\mu, \nu\)의 내적과 두 sinogram \(q_1, q_2\)의 내적은 다음과 같습니다. 여기서 sinogram은 측정 데이터와 상관없이 고른 임의의 것이므로, 측정 데이터 \(p\)와 구분해 \(q_1, q_2\)와 아래의 \(q\)로 씁니다. 두 내적에 같은 기호를 쓰고, 어느 쪽인지는 안에 든 함수로 구분합니다.

\[\langle\mu, \nu\rangle = \iint \mu(x, y)\,\nu(x, y)\,dx\,dy,\qquad \langle q_1, q_2\rangle = \int_{0}^{\pi}\!\!\int_{-\infty}^{\infty} q_1(\theta, s)\,q_2(\theta, s)\,ds\,d\theta\]

수반. 모든 영상 \(\mu\)와 임의의 sinogram \(q\)에 대해 다음이 성립하면, \(\mathcal{B}\)를 \(\mathcal{P}\)의 수반 연산이라고 합니다. 왼쪽은 sinogram끼리의 내적이고 오른쪽은 영상끼리의 내적입니다.

\[\langle\mathcal{P}\mu,\ q\rangle = \langle\mu,\ \mathcal{B}q\rangle\]

\(q\)가 광선 하나 근처의 아주 좁은 범위에서만 1이고 나머지는 0인 sinogram이라고 생각해 봅시다. 왼쪽은 그 광선의 측정값이고, \(\mathcal{B}q\)는 그 광선이 지나는 점들에서만 값이 있는 영상이므로 오른쪽은 \(\mu\)를 그 광선을 따라 더한 값입니다. 수반 관계는 측정값 하나를 영상 쪽에서 계산하는 방법을 알려 주며, 역투영 영상은 각 측정값이 영상의 어느 점들을 지나는 광선에서 얻어졌는지를 나타냅니다.

1단계. 델타 함수 표기 넣기. 왼쪽의 \(\mathcal{P}\mu\)에 3장 페이지 3의 이중적분 표기를 넣습니다.

\[\langle\mathcal{P}\mu,\ q\rangle = \int_{0}^{\pi}\!\!\int \left[\iint \mu(x, y)\,\delta(x\cos\theta + y\sin\theta - s)\,dx\,dy\right] q(\theta, s)\,ds\,d\theta\]

2단계. 적분 순서 바꾸기. 영상에 대한 적분을 바깥으로 꺼냅니다.

\[= \iint \mu(x, y)\left[\int_{0}^{\pi}\!\!\int \delta(x\cos\theta + y\sin\theta - s)\,q(\theta, s)\,ds\,d\theta\right] dx\,dy\]

3단계. Sifting 성질. 괄호 안의 \(s\)에 대한 적분은 \(s = x\cos\theta + y\sin\theta\)의 값만 남기므로, 괄호는 \(\int_0^\pi q(\theta,\ x\cos\theta + y\sin\theta)\,d\theta = (\mathcal{B}q)(x, y)\)입니다.

4단계. 정리. 남은 식 \(\iint \mu(x, y)\,(\mathcal{B}q)(x, y)\,dx\,dy\)가 \(\langle\mu,\ \mathcal{B}q\rangle\)입니다.

행렬의 경우. 격자 영상에서는 투영이 \(\mathbf{A}\mathbf{x}\)이고, 역투영이 \(\mathbf{A}\)의 행과 열을 맞바꾼 전치 행렬 \(\mathbf{A}^{\mathsf T}\)를 곱하는 계산입니다. 수반 관계는 다음과 같습니다.

\[\langle\mathbf{A}\mathbf{x},\ \mathbf{d}\rangle = \langle\mathbf{x},\ \mathbf{A}^{\mathsf T}\mathbf{d}\rangle\]

예를 들어 \(\mathbf{d} = (1, 0, 0, 0, 1)\)이면 왼쪽은 \(0.7 + 0.707 = 1.407\)입니다. \(\mathbf{A}^{\mathsf T}\mathbf{d}\)는 \(\mathbf{A}\)의 1행과 5행을 더한 \((1 + \sqrt2,\ 1,\ 0,\ \sqrt2)\)이므로 오른쪽은 \(0.2\times2.414 + 0.5 + 0.3\times1.414 \approx 1.407\)로 같습니다. 증명도 영상 쪽 전개와 같습니다. \(\langle\mathbf{A}\mathbf{x}, \mathbf{d}\rangle = \sum_i\bigl(\sum_j A_{ij}x_j\bigr)d_i = \sum_j x_j\bigl(\sum_i A_{ij}d_i\bigr) = \langle\mathbf{x}, \mathbf{A}^{\mathsf T}\mathbf{d}\rangle\)이고, 두 합의 순서를 바꾼 것이 2단계에서 적분의 순서를 바꾼 것에 해당합니다.

다른 책의 표기

역투영 연산을 투영 연산자에 위첨자를 붙여 \(\mathcal{R}^{\#}\)나 \(\mathcal{R}^{*}\)처럼 쓰는 책이 많습니다. 위첨자 별표는 수반을 나타내는 흔한 기호이지만, 이 책은 별표 \(*\)를 컨볼루션에만 쓰므로(2장) 역투영을 \(\mathcal{B}\)로 씁니다. 행렬로 쓸 때는 대부분의 책이 \(\mathbf{A}^{\mathsf T}\)를 씁니다.

4장 · 페이지 7

푸리에 공간에서 본 역투영

이 페이지의 결론은 하나입니다. 한 각도를 역투영하는 일은 푸리에 평면에서 원점을 지나는 직선 하나에 그 각도 투영의 푸리에 변환 값을 놓는 일입니다. 그래서 역투영은 푸리에 공간에서 직선을 하나씩 더해 나가는 연산입니다.

한 각도의 역투영과 푸리에 평면의 직선

한 각도 \(\theta\)만 역투영한 영상은 \(g_\theta(x, y) = p(\theta,\ x\cos\theta + y\sin\theta)\)입니다. 페이지 5에서 칠한 줄무늬 한 장이며, \(\theta\) 방향으로만 값이 변하고 그에 수직인 방향으로는 같은 값이 계속됩니다. 어떤 방향으로 변하지 않는 영상에는 그 방향으로 진동하는 성분이 없습니다. 그래서 \(g_\theta\)의 푸리에 변환은 \(\theta\)에 수직인 방향의 주파수가 0인 곳, 즉 원점을 지나 \(\theta\) 방향으로 놓인 직선 위에만 값을 가집니다. 그 직선 위의 값은 \(p(\theta, \cdot)\)의 1차원 푸리에 변환 \(P_\theta(\omega)\)입니다. 페이지 2에서 슬라이스 정리가 가리킨 직선과 같은 직선입니다.

줄무늬 영상의 푸리에 변환

1단계. 회전 좌표. 1장 페이지 1의 회전 좌표 \(x' = x\cos\theta + y\sin\theta,\ y' = -x\sin\theta + y\cos\theta\)로 쓰면 \(g_\theta = p(\theta, x')\)이고 \(y'\)에는 의존하지 않습니다. 주파수도 같은 방향으로 나눕니다. \(\omega_{\parallel} = \omega_x\cos\theta + \omega_y\sin\theta\)와 \(\omega_{\perp} = -\omega_x\sin\theta + \omega_y\cos\theta\)로 놓으면 \(\omega_x x + \omega_y y = \omega_{\parallel}x' + \omega_{\perp}y'\)입니다.

2단계. 변환. 이 변환의 행렬식은 1이므로 \(dx\,dy = dx'\,dy'\)입니다(1장 페이지 2).

\[G_\theta(\omega_x, \omega_y) = \int p(\theta, x')\,e^{-i2\pi\omega_{\parallel}x'}\,dx' \int e^{-i2\pi\omega_{\perp}y'}\,dy' = P_\theta(\omega_{\parallel})\;\delta(\omega_{\perp})\]

\(P_\theta\)는 페이지 1에서 정의한 \(p(\theta, \cdot)\)의 1차원 푸리에 변환입니다. \(y'\)에 대한 적분은 2장의 변환 쌍 \(1 \longleftrightarrow \delta\)입니다.

3단계. 읽기. \(\delta(\omega_{\perp})\)는 \(\omega_{\perp} = 0\)인 점들, 즉 \(\theta\) 방향 직선에서만 값을 가집니다. 그 직선 위의 위치는 \(\omega_{\parallel} = \omega\)이므로 값은 \(P_\theta(\omega)\)입니다.

직선이 하나씩 더해지는 모습

아래 위젯은 각도 36개(\(5^{\circ}\) 간격)를 하나씩 더합니다. 왼쪽 평면에서 주황 직선이 방금 더한 각도이고, 밝기는 직선 위에 놓인 값의 크기입니다. 오른쪽 곡선은 그 각도의 투영을 푸리에 변환한 값입니다. 푸리에 변환 값은 복소수이므로 그림에는 크기만 그렸습니다.

6

  • 직선이 모두 원점을 지나므로, 각도를 몇 개만 더해도 원점 근처에서는 여러 직선이 겹쳐 밝아집니다.
  • 원점에서 멀어질수록 이웃한 직선 사이가 벌어져 빈틈이 생깁니다.
  • 각도를 모두 더해도 중심이 가장 밝은 채로 남습니다. 역투영은 중심에 값을 많이 쌓는 연산이고, 이 쏠림이 다음 페이지의 주제입니다.

띠와 부채꼴

주 참고서(Kak & Slaney)에도 비슷한 구도의 그림이 있습니다. 각도 \(K\)개가 \(0^{\circ}\)부터 \(180^{\circ}\)까지를 고르게 나누면, 각도 하나가 평면에서 맡아야 할 영역은 폭 \(\Delta\theta = \pi/K\)의 부채꼴입니다. 그런데 투영 하나가 실제로 놓는 것은 원점을 지나는 폭이 일정한 띠 하나뿐입니다. 이 그림에서는 직선을 띠로 그립니다. 띠의 폭은 이상적으로는 0이지만, 실제로는 주파수 샘플 간격 \(\Delta\omega\)만큼의 폭을 갖는 얇은 띠로 생각하며, 직선은 그 띠의 중심선입니다.

아래 그림에서 띠와 판의 높이는 \(P_\theta(\omega)\)에 곱해지는 값, 곧 가중치를 나타냅니다. 실제 \(P_\theta(\omega)\)의 크기는 영상마다 다르지만, 그림에서는 그 차이를 그리지 않고 균일하다고 두어 가중치만 높이로 그렸습니다.

(b)는 \(P_\theta(\omega)\)를 그대로 더하는 경우입니다. 모든 \(\omega\)에서 가중치가 1이므로 띠의 높이가 어디서나 같고, 바깥쪽으로 넓어지는 (a)의 부채꼴을 채우지 못합니다. 부채꼴을 채우려면 바깥으로 갈수록 가중치(높이)를 키운 (c)와 같아야 합니다.

그림으로 떠올려 보면 다음과 같습니다. 모든 각도의 (b)를 겹쳐 더해 나가면 중심부에는 많은 띠가 겹쳐 많이 쌓이고 바깥쪽은 낮게 남습니다. (a)의 부채꼴이나 (c)를 모든 각도로 더하면 평면이 고르게 채워집니다. 엄밀한 설명은 아니고 직관으로 상상해 보기 위한 그림입니다. 얼마나 키워야 하는지는 이웃한 띠 사이 간격을 정확히 계산하는 다음 페이지에서 정합니다.

4장 · 페이지 8

중심에 값이 쌓이는 이유와 고치는 방법: 주파수 가중

페이지 7에서 직선을 겹치면 중심에는 많이 쌓이고 바깥에는 적게 쌓이는 것을 보았습니다. 이 페이지에서는 쏠림의 크기를 계산하고, 고르게 쌓이도록 고치는 방법을 찾습니다. 그 방법이 필터 역투영(Filtered Back Projection, FBP)입니다.

쌓이는 양의 계산

각도 \(K\)개가 \(0\)부터 \(\pi\)까지를 고르게 나누면 이웃한 두 직선 사이의 각은 \(\Delta\theta = \pi/K\)입니다. 원점에서 거리 \(|\omega|\)인 곳에서 이웃한 두 직선 사이의 간격은 호의 길이입니다.

\[(\text{이웃한 직선 사이의 간격}) = |\omega|\,\Delta\theta = \frac{\pi|\omega|}{K}\]

예를 들어 \(K = 180\)이면 \(|\omega| = 0.5\ \mathrm{cm}^{-1}\)에서 간격이 약 0.0087, \(|\omega| = 2\ \mathrm{cm}^{-1}\)에서 약 0.035입니다. 원점에서 4배 멀어지면 간격도 4배 벌어집니다.

띠의 폭은 어디서나 같으므로, 간격이 4배 벌어진 곳에서는 띠가 그 호를 덮는 비율이 4분의 1로 줄어듭니다. 한 점에 겹치는 직선의 수는 \(1/|\omega|\)에 비례해 줄어듭니다. 이것이 중심에 값이 쏠리는 이유입니다.

각도가 연속으로 모두 있을 때 이 쏠림을 정확히 쓰면, 단순 역투영 영상의 2차원 푸리에 변환은 원래 영상의 \(F\)를 원점에서의 거리 \(\sqrt{\omega_x^{2} + \omega_y^{2}}\)로 나눈 것이 됩니다. 아래에서 고치는 \(|\omega|\)의 곱셈은 이 나눗셈을 되돌리는 일입니다.

주파수 가중을 곱해 더하기

같은 사실을 부채꼴로 보면 무엇을 고쳐야 하는지 알 수 있습니다. 직선 하나가 맡을 부채꼴의 폭은 \(|\omega|\Delta\theta\)로 \(|\omega|\)에 비례합니다(페이지 7의 그림 (a)). 폭이 일정한 띠가 이런 부채꼴을 대신하려면, 띠의 가중치(높이)가 \(|\omega|\)에 비례해 커야 합니다(그림 (c)). 그러니 더하기 전에 각 투영의 푸리에 변환 \(P_\theta(\omega)\)에 \(|\omega|\)를 곱하면 됩니다.

이렇게 주파수에 따라 값을 곱하는 일을 필터링이라고 하고, 곱하는 함수 \(|\omega|\)가 주파수 응답인 필터를 램프 필터(Ramp Filter)라고 합니다. 투영마다 필터링한 뒤 역투영하는 순서는 다음과 같습니다.

  1. 각도 \(\theta\)의 투영 \(p(\theta, s)\)를 1차원 푸리에 변환해 \(P_\theta(\omega)\)를 얻습니다.
  2. \(P_\theta(\omega)\)에 \(|\omega|\)를 곱합니다.
  3. 1차원 역변환으로 \(p\)를 필터링한 투영 \(q(\theta, s)\)를 얻습니다.
  4. \(q\)를 역투영해 모든 각도에 대해 더합니다.

식으로 쓰면 다음과 같고, 이것이 필터 역투영 공식입니다.

\[\begin{aligned}q(\theta, s) &= \int_{-\infty}^{\infty} P_\theta(\omega)\,|\omega|\,e^{i2\pi\omega s}\,d\omega,\\ \mu(x, y) &= (\mathcal{B}q)(x, y)\\ &= \int_{0}^{\pi} q(\theta,\ x\cos\theta + y\sin\theta)\,d\theta\end{aligned}\]

  • \(q(\theta, s)\)는 \(p\)에 \(|\omega|\)를 곱해 필터링한 투영입니다. 페이지 6의 수반 관계에서 임의의 sinogram에 \(q\)를 쓴 것만 예외입니다.
  • 페이지 6의 역투영 \(\mathcal{B}\)는 측정 데이터가 아닌 sinogram에도 같은 식으로 쓰므로, \(q\)에도 그대로 적용합니다.
  • \(|\omega|\)를 곱하는 부분만 단순 역투영과 다릅니다. 곱하지 않으면 \(q = p\)이고 \(\mu\) 대신 단순 역투영 \(\mathcal{B}p\)가 나옵니다.

이 페이지의 논증은 간격이 \(|\omega|\)에 비례한다는 직관입니다. 각도 수가 한없이 많고 \(0\)부터 \(\pi\)까지 모두 측정했을 때 이 식이 정확히 \(\mu\)가 되는지, 곱하는 상수가 왜 1인지는 5장에서 유도합니다.

필터가 없을 때와 있을 때

아래 위젯은 작은 점 하나를 각도 \(K\)개로 측정해 두 방식으로 계산합니다. 왼쪽은 푸리에 평면에 쌓인 값, 가운데는 원점에서 거리별로 평균한 높이, 오른쪽은 영상 공간의 결과입니다. 필터 없음과 있음을 번갈아 눌러 비교해 보세요.

60

  • 필터 없음. 평균 높이가 \(1/|\omega|\)로 줄어드는 곡선이 되고, 영상 공간에서는 점 주변이 넓게 번집니다.
  • 필터 있음. 평균 높이가 거의 일정해지고, 영상에서 점이 선명해집니다. 필터링한 투영에는 음수 값이 생깁니다.
  • 각도가 적을 때. 3~6개에서는 직선 사이의 틈이 보이고, 영상에는 점에서 뻗는 줄이 남습니다. 두 방식 모두 같습니다.

높은 주파수의 증폭

\(|\omega|\)는 높은 주파수일수록 크게 곱하므로, 측정 잡음의 높은 주파수 성분도 함께 커집니다.

단순 역투영과 필터 역투영, 직접 비교해 보기

3장의 기준 팬텀에 두 방식을 적용해 비교합니다. 3장 페이지 5의 닫힌 식으로 정확한 투영을 만들고, 각도 \(K\)개(\(0\)부터 \(180^{\circ}\) 앞까지 같은 간격)로 다음 두 가지를 계산합니다.

  • 단순 역투영. 투영에 아무 처리도 하지 않고 역투영합니다(페이지 6의 \(\mathcal{B}p\)).
  • 필터 역투영. 투영마다 \(|\omega|\)를 곱해 필터링한 뒤 역투영합니다(페이지 8의 \(\mathcal{B}q\)). 각도 간격 \(\Delta\theta = \pi/K\)를 곱해 더하므로 값의 크기가 팬텀의 값과 같습니다.
각도 수

관찰

  • 단순 역투영은 흐립니다. 두개골의 얇은 테두리가 번져 안쪽과 이어지고, 값의 차이가 2% 안팎인 뇌실과 작은 구조는 묻힙니다. 물체 바깥에도 값이 남아 그림 끝까지 이어집니다. 각도를 180개로 늘리면 줄무늬만 사라질 뿐 흐림은 그대로입니다.
  • 필터 역투영은 선명합니다. 각도가 충분하면 윤곽이 또렷하고 바깥은 거의 0이 됩니다. 값도 팬텀의 값과 같은 크기로 돌아옵니다. 밝기 범위를 뇌 조직으로 좁히면 뇌실과 작은 구조가 보입니다.
  • 각도가 적으면 두 방식 모두 줄무늬가 생깁니다. 10개와 30개에서는 물체에서 뻗는 가는 줄이 보입니다. 필터 역투영은 흐림이 없는 만큼 이 줄이 더 뚜렷합니다.

필터 역투영의 필터링은 이 위젯에서 연속 식 \(|\omega|\)를 샘플에 그대로 옮긴 것입니다.

4장 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. 각도 \(\theta\)의 투영을 1차원 푸리에 변환한 \(P_\theta(\omega)\)는 영상의 2차원 푸리에 변환을 원점을 지나는 \(\theta\) 방향 직선에서 읽은 값 \(F(\omega\cos\theta,\ \omega\sin\theta)\)입니다(푸리에 슬라이스 정리).
  2. (심화) 이 직선들을 모두 모아 2차원 역변환하면 영상이 됩니다(직접 푸리에 재구성). 그러나 이산 데이터에서는 극좌표 격자를 직교 격자로 보간한 오차가 영상 전체로 퍼지고, 모든 각도가 모여야 시작할 수 있습니다. 연산량은 약점이 아닙니다.
  3. 역투영 \((\mathcal{B}p)(x, y) = \int_0^\pi p(\theta,\ x\cos\theta + y\sin\theta)\,d\theta\)는 광선의 값을 광선 위의 모든 점에 칠해 더하는 연산입니다. 역투영은 투영의 역연산이 아니라 수반 연산입니다. 투영을 행렬 \(\mathbf{A}\)로 나타내면 역투영은 그 전치 \(\mathbf{A}^{\mathsf T}\)에 해당합니다.
  4. 푸리에 공간에서 각도 하나의 역투영은 원점을 지나는 직선 하나에 \(P_\theta(\omega)\)를 더하는 일입니다. 각도 \(K\)개이면 원점에서 거리 \(|\omega|\)인 곳의 이웃한 직선 사이 간격이 \(\pi|\omega|/K\)여서, 값이 중심에 쏠려 쌓입니다.
  5. 각 투영의 푸리에 변환 \(P_\theta(\omega)\)에 \(|\omega|\)를 곱한 뒤 역투영하면 값이 주파수 평면에 고르게 쌓입니다. 이 방법이 필터 역투영(FBP)입니다. 단순 역투영은 각도를 늘려도 흐리고, 필터 역투영은 윤곽이 선명하며 값의 크기가 되살아납니다. 정확한 유도는 5장에서 합니다.

마무리 퀴즈 1

\(\theta = 90^{\circ}\)에서 측정한 투영의 1차원 푸리에 변환 \(P_{90^{\circ}}(\omega)\)는 영상의 2차원 푸리에 변환 \(F\)의 어느 값과 같을까요?

  1. \(F(\omega,\ 0)\)
  2. \(F(0,\ \omega)\)
  3. \(F(\omega/\sqrt2,\ \omega/\sqrt2)\)
  4. \(F(0,\ -\omega)\)

같은 정리는 3차원에서도 성립합니다. 전자현미경으로 단백질 입자의 구조를 구하는 분야에서는 2차원 투영 영상의 푸리에 변환이 3차원 주파수 공간에서 원점을 지나는 평면이 된다는 성질을 쓰고, 여러 방향의 투영으로 그 공간을 채워 3차원 구조를 얻습니다.

  3. 푸리에 슬라이스 정리가 샘플링한 이산 데이터에서는 성립하지 않아서 값을 얻을 수 없다

마무리 퀴즈 3

투영 \(\mathcal{P}\)와 역투영 \(\mathcal{B}\)의 관계로 옳은 것은 무엇일까요?

  1. 어떤 영상 \(\mu\)에 대해서도 \(\mathcal{B}\mathcal{P}\mu = \mu\)가 되어 원래 영상이 그대로 복원된다
  2. \(\mathcal{B}\)는 \(\mathcal{P}\)의 역행렬에 해당하는 연산이어서 \(\mathcal{P}\)의 효과를 정확히 되돌린다
  3. 각도와 검출기 칸을 충분히 많이 쓰면 \(\mathcal{B}\mathcal{P}\mu = \mu\)가 되어 원래 영상이 완전히 복원된다
  4. 임의의 \(\mu\)와 sinogram \(q\)에 대해 \(\langle\mathcal{P}\mu,q\rangle=\langle\mu,\mathcal{B}q\rangle\)이다

수반 관계는 프로그램 점검에도 쓰입니다. 투영과 역투영을 따로 구현했다면 무작위 영상 \(\mathbf{x}\)와 무작위 sinogram \(\mathbf{d}\)를 넣어 \(\langle\mathbf{A}\mathbf{x}, \mathbf{d}\rangle\)와 \(\langle\mathbf{x}, \mathbf{A}^{\mathsf T}\mathbf{d}\rangle\)가 계산 오차 안에서 같은지 봅니다. 두 값이 다르면 두 프로그램의 광선 가중이 서로 맞지 않는다는 뜻입니다.

  2. 푸리에 변환의 정의에서 나오는 상수를 맞춰 크기를 보정하기 위해서이다
  3. 주파수 평면에서 직선이 중심에 몰려 쌓이는 쏠림을 바로잡기 위해서이다

모범답안과 흔한 실수

1번. 페이지 3의 예에서 \(x_0 = 1,\ y_0 = 0\)이므로 \(s_0 = \cos\theta\)이고, \(p(\theta, s) = e^{-\pi(s - \cos\theta)^{2}}\), \(P_\theta(\omega) = e^{-\pi\omega^{2}}\,e^{-i2\pi\omega\cos\theta}\)입니다. \(\theta = 60^{\circ},\ \omega = 0.5\)이면 \(e^{-\pi/4} \approx 0.456\)이고, 위상은 \(-2\pi\times0.5\times0.5 = -\pi/2\)이므로 \(P = 0.456\,e^{-i\pi/2} = -0.456i\)입니다. 오른쪽은 \(\omega_x = 0.25,\ \omega_y \approx 0.433\)이고 \(F = e^{-\pi(0.0625 + 0.1875)}\,e^{-i2\pi\times0.25} = e^{-\pi/4}\,e^{-i\pi/2}\)로 같습니다. \(|P_\theta(\omega)| = e^{-\pi\omega^{2}}\)이므로 \(\theta\)와 무관합니다. 원점이 중심인 가우시안 함수와 크기가 같고 위상만 다릅니다.

2번. 화소 1은 ①·③에서 \(0.7 + 0.3 = 1.0\), 화소 2는 ①·④에서 \(0.7 + 0.8 = 1.5\), 화소 3은 ②·③에서 \(0.4 + 0.3 = 0.7\), 화소 4는 ②·④에서 \(0.4 + 0.8 = 1.2\)입니다. 크기의 순서(화소 2, 4, 1, 3)는 원래 값과 같지만 원래 값에 대한 비가 화소 1~4에서 5, 3, 7, 4로 제각각이어서 원래 영상의 상수배가 아닙니다. 수반 관계는 왼쪽이 \(\langle\mathbf{b}, \mathbf{d}\rangle = 0.4 + 0.3 = 0.7\)이고, \(\mathbf{A}^{\mathsf T}\mathbf{d}\)는 2행과 3행을 더한 \((1, 0, 2, 1)\)이므로 오른쪽은 \(0.2 + 2\times0.1 + 0.3 = 0.7\)로 같습니다.

3번. 이웃한 직선 사이의 간격은 \(\pi|\omega|/K = \pi|\omega|/60\)입니다. \(|\omega| = 1\)에서 약 0.052, \(|\omega| = 3\)에서 약 0.157이고 비는 1 : 3입니다. 직선의 폭은 같으므로 한 점에 겹치는 직선의 수는 간격에 반비례합니다. 원점에서 1 떨어진 곳은 3 떨어진 곳의 3배입니다. 고르게 쌓으려면 이 쏠림을 상쇄해야 하므로 두 주파수 성분에 \(|\omega|\), 즉 1과 3을 곱합니다. 곱하는 값의 비는 1 : 3이고, 곱한 뒤에는 두 곳에 겹치는 양이 같아집니다.

  • 1번에서 \(s_0\)를 \(\sin\theta\)로 쓰는 것입니다. \(s_0 = x_0\cos\theta + y_0\sin\theta\)이고 \(x_0 = 1\)이므로 \(\cos\theta\)입니다.
