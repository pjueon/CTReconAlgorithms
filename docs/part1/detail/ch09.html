9장 · 페이지 1

팬빔 FBP를 컴퓨터로 계산해 보기 (이산)

8장에서는 팬빔 FBP를 연속 식으로 유도했습니다. 이 장에서는 같은 식을 샘플링한 데이터로 계산하는 알고리즘을 만듭니다. 뼈대는 6장의 평행빔 이산 FBP와 같고, 팬빔에서는 가중 둘이 더해지며 역투영에서 읽는 위치가 화소와 선원 각마다 달라집니다. 이 페이지에서는 무엇을 어떤 간격으로 샘플링하는지 정하고, 이어지는 페이지에서 평면 검출기와 곡면 검출기의 계산을 차례로 봅니다.

결론: 평면 검출기의 이산 알고리즘

유도에 앞서 계산 식부터 적습니다. 선원 각 \(N_\beta\)개로 \(360^{\circ}\)를 돌며 평면 검출기(Flat Detector) 칸 \(N_t\)개로 잰 데이터 \(R[k, n]\)이 주어졌을 때, 알고리즘은 다음 두 식입니다. 첫째 식은 선원 각 \(k\)의 투영 한 줄을 필터링하고, 둘째 식은 필터링한 줄을 영상으로 되돌려 더합니다.

\[q_k[n] = \Delta t \sum_{m=0}^{N_t-1} R[k, m]\,\frac{D}{\sqrt{D^{2} + t_m^{2}}}\,h[n - m]\]

\[\mu(x, y) \approx \frac{\pi}{N_\beta} \sum_{k=0}^{N_\beta - 1} \frac{1}{U_k^{2}}\, q_k(t'_k)\]

  • \(R[k, n]\). \(k\)번째 선원 각 \(\beta_k\)에서 \(n\)번째 칸으로 가는 광선의 투영값 \(R_{\beta_k}(t_n)\)입니다. 칸의 위치는 \(t_n\)이고 \(D\)는 선원에서 회전 중심까지의 거리입니다.
  • \(D/\sqrt{D^{2} + t_m^{2}}\). 8장의 코사인 가중(Cosine Weighting)입니다. 칸 위치만으로 정해지므로 필터링 앞에서 측정값에 곱합니다.
  • \(h[n]\). 6장의 이산 램프 커널(Discrete Ramp Kernel)에서 검출기 간격을 \(\Delta t\)로 바꾼 수열입니다.
  • \(q_k(t'_k)\), \(U_k\). 화소 \((x, y)\)와 선원 각 \(\beta_k\)에서 정해지는 \(t'\)과 \(U\)는 8장 페이지 2에서 정의한 그대로입니다. \(q_k(t')\)는 필터링한 줄 \(q_k[n]\)을 \(t'\)에서 선형 보간(Linear Interpolation)해 읽은 값이고, \(1/U^{2}\)은 8장의 거리 가중(Distance Weighting)입니다.
  • \(\pi/N_\beta\). 선원 각 간격 \(\Delta\beta = 2\pi/N_\beta\)에 공식의 \(\tfrac{1}{2}\)을 곱한 값입니다. 같은 직선을 두 번 재는 \(360^{\circ}\) 데이터에 대응하는 각도 합의 상수입니다.

두 가중의 성격은 8장 페이지 4에서 확인한 대로입니다.

이 장의 수치 실험은 조건을 바꾸었을 때 오차가 어떻게 달라지는지를 기록합니다. 표와 목록의 수치는 그 조건에서 계산한 결과로 읽으면 됩니다.

9장 · 페이지 2

샘플 간격과 나이퀴스트 한계

평행빔 FBP에서는 검출기 간격 \(\Delta s\)가 차단 주파수 \(W \le 1/(2\Delta s)\)(나이퀴스트 한계, Nyquist Frequency)를 정했습니다(6장 페이지 2). 평면 검출기의 팬빔에서도 같은 일을 합니다. 다만 검출기 간격을 어디서 재는지, 검출기가 어디까지 덮어야 하는지, 그리고 간격이 영상의 위치마다 같은 뜻인지를 따로 확인해야 합니다.

가상 검출기의 칸 간격

8장의 식에 나오는 \(t\), \(t'\), 커널 \(h(t' - t)\)는 모두 회전 중심 \(O\)를 지나는 가상 검출기 위의 좌표입니다. 실제 검출기의 칸 간격이 \(\Delta d\)이면 가상 검출기 위의 간격은 선원–검출기 거리 \(\mathrm{SDD}\)와 \(D\)의 비로 줄어듭니다(7장 페이지 3).

\[\Delta t = \Delta d\,\frac{D}{\mathrm{SDD}},\qquad W = \frac{1}{2\Delta t}\]

\(\Delta d = 0.03\) cm, \(\mathrm{SDD} = 4.5\) cm, \(D = 3\) cm이면 \(\Delta t = 0.03 \times 3/4.5 = 0.02\) cm이고 \(W = 25\) cm\(^{-1}\)입니다. 이 장의 위젯과 표가 쓰는 값을 맞춘 것이며 실제 장치의 크기는 아닙니다. 커널 \(h[n]\)과 \(\tau = t'/\Delta t + (N_t - 1)/2\)는 모두 이 \(\Delta t\)로 계산합니다. \(\Delta d\)를 그대로 쓰면 영상의 크기와 값이 달라집니다.

회전 중심을 지나고 중심 광선에 수직인 면이 곧 가상 검출기입니다. 그 면 위에서 \(2\Delta t\)보다 가는 무늬는 검출기가 구분하지 못하며, 이 한계가 \(W = 1/(2\Delta t)\)입니다.

검출기가 덮어야 하는 범위

재구성할 영역을 회전 중심에서 반지름 \(R\)인 원이 덮는다고 합시다. 선원에서 이 원에 접선을 그으면 접점의 팬 각은 \(\sin\gamma_m = R/D\)이고, 가상 검출기에서의 위치는 다음과 같습니다.

\[t_{\max} = D\tan\gamma_m = \frac{D R}{\sqrt{D^{2} - R^{2}}},\qquad N_t = 2\Bigl\lceil \frac{t_{\max}}{\Delta t} \Bigr\rceil + 1\]

칸 수 \(N_t\)를 홀수로 잡으면 가운데 칸이 \(t = 0\)(중심 광선)에 놓입니다. 이 장의 위젯은 한 변이 \(2.2\) cm인 정사각형 영상을 쓰므로 모서리까지의 거리가 \(R = 1.1\sqrt{2} \approx 1.556\) cm입니다. \(D = 3\) cm이면 \(t_{\max} \approx 1.819\) cm이고, \(\Delta t = 0.08\), \(0.04\), \(0.02\) cm일 때 \(N_t\)는 47, 93, 183입니다. 검출기가 이보다 좁아 물체의 일부를 덮지 못하면 절단 데이터가 되어 5장 페이지 11의 문제가 생깁니다.

화소 근처에서 이웃한 광선의 간격

평행빔에서는 이웃 광선의 간격이 영상 어디서나 \(\Delta s\)로 같았습니다. 팬빔의 광선은 선원에서 퍼지므로 같은 \(\Delta t\)라도 화소에서의 간격이 위치마다 다릅니다.

닮은 삼각형에서 \(P\)의 높이에서 두 광선 사이의 가로 거리는 \(U\Delta t\)입니다. 광선은 중심 광선에서 \(\gamma'\)만큼 기울어 있으므로, 광선에 수직으로 잰 간격은 여기에 \(\cos\gamma'\)을 곱한 값입니다.

\[\text{이웃 광선 사이의 수직 간격} = a\,\Delta t,\qquad a = U\cos\gamma'\]

이 \(a\)는 8장 페이지 4의 \(a = U\cos\gamma\)에서 \(\gamma\)를 화소 자신의 팬 각 \(\gamma'\)으로 둔 값입니다. 광선 간격이 \(a\Delta t\)이므로 그 화소에서 이 방향으로 구분할 수 있는 무늬의 한계는 \(1/(2a\Delta t) = W/a\)입니다. \(D = 3\) cm, \(\Delta t = 0.02\) cm에서 화소 \((0.8, 0)\)을 선원 각 네 개에서 계산하면 다음과 같습니다.

알고리즘이 쓰는 차단 주파수와 8장의 근사

8장 페이지 4에서 자른 커널은 \(h_W(as) = h_{aW}(s)/a^{2}\)이므로, 알고리즘처럼 \(h_W(t' - t)/a^{2}\)를 쓰는 것은 근사라고 했습니다. 이 근사가 무엇에 해당하는지 풀어 봅니다. 자른 커널은 \(h_W(s) = W^{2}h_1(Ws)\) 꼴이므로 다음이 성립합니다.

\[\frac{h_W(u)}{a^{2}} = \frac{W^{2}h_1(Wu)}{a^{2}} = \Bigl(\frac{W}{a}\Bigr)^{2} h_1\!\Bigl(\frac{W}{a}\,a u\Bigr) = h_{W/a}(a u)\]

왼쪽은 알고리즘의 커널이고, 오른쪽은 광선에 수직인 거리 \(s = a(t' - t)\)에서 차단 주파수를 \(W/a\)로 둔 평행빔 커널입니다. 그 값 \(W/a\)는 위에서 구한 화소의 나이퀴스트 한계와 같습니다. 곧 알고리즘의 커널은 화소와 광선마다 차단 주파수를 그 자리의 샘플링이 담을 수 있는 한계에 맞춘 것과 같습니다. 이 접기 안의 \(a\)는 8장 페이지 4의 정본대로 \(a = U\cos\gamma\)이며 \(\gamma\)는 컨볼루션의 각 광선(칸 \(t\))의 팬 각입니다. 화소 근처를 지나는 광선에서는 \(\gamma \approx \gamma'\)이므로 위 본문의 \(a = U\cos\gamma'\)과 가깝습니다.

비교를 위해 차단 주파수를 모든 곳에서 \(W\)로 고정한 커널 \(h_W(a(t' - t))\)(8장 페이지 4의 정확한 식이며 \(a = U\cos\gamma\), \(\gamma\)는 각 광선의 팬 각)로 같은 데이터를 계산해 보았습니다. Shepp-Logan 팬텀, 평면 검출기, \(D = 3\) cm, \(\Delta t = 0.02\) cm, 선원 각 180개, Ram-Lak 커널, \(48 \times 48\) 격자에서 머리 안쪽(타원 \(x^{2}/0.6^{2} + y^{2}/0.8^{2} \le 1\))의 참값과의 rms는 알고리즘의 커널이 0.0017, 고정한 커널이 0.0208이었습니다.

이산 커널과 사전 가중

필터링 단계는 선원 각 번호 \(k\)의 한 행 \(R[k, \cdot]\)에 사전 가중을 곱하고 램프 커널과 이산 컨볼루션(Convolution)하는 일입니다. 6장의 평행빔 필터링에 사전 가중 한 단계가 앞에 붙은 것입니다.

이산 램프 커널 \(h[n]\)

커널은 6장 페이지 4의 \(h[n]\)에서 검출기 간격 \(\Delta s\)를 \(\Delta t\)로 바꾼 것입니다. 차단 주파수 \(W = 1/(2\Delta t)\)의 연속 커널 \(h_W\)를 \(n\Delta t\)에서 읽은 수열이며, 단위는 cm\(^{-2}\)입니다.

\[h[n] = \begin{cases} \dfrac{1}{4\Delta t^{2}} & n = 0 \\[1ex] 0 & n \neq 0\ \text{인 짝수} \\[1ex] -\dfrac{1}{\pi^{2} n^{2} \Delta t^{2}} & n\ \text{홀수} \end{cases}\]

윈도우 필터 커널도 6장 페이지 4의 식에서 \(\Delta s\)만 \(\Delta t\)로 바뀝니다. Shepp-Logan은 \(-2/(\pi^{2}\Delta t^{2}(4n^{2} - 1))\), Hamming은 \(0.54\,h[n] + 0.23\,(h[n-1] + h[n+1])\)입니다. 6장 페이지 4의 표에 있는 \(h[n](\Delta s)^{2}\) 값을 \(\Delta t^{2}\)으로 나누면 이 장의 값이 됩니다.

이산 사전 가중

8장 페이지 5의 코사인 가중을 칸 위치 \(t_n\)에서 읽으면 칸마다 정해지는 수열이 됩니다.

\[c[n] = \frac{D}{\sqrt{D^{2} + t_n^{2}}} = \cos\gamma_n,\qquad \tilde R[k, n] = R[k, n]\,c[n]\]

\(D = 3\) cm에서 \(c\)는 \(t = 0\)에서 1, \(t = 1\) cm에서 0.949, 위젯 영상이 요구하는 가장자리 \(t = 1.82\) cm에서 0.855입니다. \(c[n]\)은 선원 각에 의존하지 않으므로 한 번 계산해 둔 배열을 모든 \(k\)에 씁니다.

가중을 컨볼루션 앞에서 곱하는 이유는 8장 페이지 5와 같습니다. 컨볼루션 \(\sum_m \tilde R[k, m]\,h[n - m]\)의 안쪽 변수 \(m\)은 측정 위치이고 \(c\)는 측정 위치 \(t_m\)의 함수입니다. 출력 위치 \(n\)에서 곱하면 읽는 위치의 \(\cos\gamma\) 하나가 곱해져 다른 결과가 됩니다.

필터링의 계산 방법

필터링한 한 줄은 다음과 같습니다.

\[q_k[n] = \Delta t \sum_{m=0}^{N_t-1} \tilde R[k, m]\,h[n - m],\qquad n = 0, \dots, N_t - 1\]

\(|n - m|\)는 \(N_t - 1\)까지 가므로 커널은 \(-(N_t - 1)\)부터 \(N_t - 1\)까지 모두 씁니다(6장 페이지 4). 칸 수 \(N_t\)가 크면 직접 합이 \(N_t^{2}\)번의 곱셈이 되어, 6장 페이지 5와 같이 FFT로 계산합니다. 순서는 다음과 같습니다.

  1. 배열 길이 \(M\)을 \(M \ge 2N_t - 1\)인 2의 거듭제곱으로 잡습니다(제로 패딩, Zero Padding). \(N_t = 183\)이면 \(2N_t - 1 = 365\)이므로 \(M = 512\)입니다.
  2. 커널 \(h[-(N_t-1)], \dots, h[N_t-1]\)을 DFT 순서(음수 번호는 뒤쪽)로 길이 \(M\) 배열에 놓고 DFT합니다. 한 번만 계산해 모든 \(k\)에 씁니다.
  3. 선원 각마다 \(\tilde R[k, \cdot]\)를 길이 \(M\)으로 제로 패딩해 DFT하고, 커널의 DFT와 곱한 뒤 역 DFT합니다.
  4. 앞의 \(N_t\)개에 \(\Delta t\)를 곱합니다.

주파수에서 \(|\omega_j|\)를 바로 곱하는 방법은 쓰지 않습니다. 6장 페이지 5에서 영상 전체가 한쪽으로 치우친다는 것을 확인했기 때문입니다. 곡면 검출기에서는 커널이 \(h\)가 아니라 \(h_c\)라서 이 방법을 쓸 수도 없습니다.

단위 확인

\(R\)과 \(c\)는 단위가 없고 \(h\)는 cm\(^{-2}\), \(\Delta t\)는 cm이므로 \(q\)의 단위는 cm\(^{-1}\)입니다. 역투영에서 곱하는 \(\pi/N_\beta\)와 \(1/U^{2}\)도 단위가 없어서 \(\mu\)가 cm\(^{-1}\)로 나옵니다.

가중 역투영과 의사코드

페이지 2의 샘플링과 페이지 3의 필터링을 이으면 평면 검출기 팬빔 FBP의 이산 알고리즘이 됩니다. 역투영은 6장 페이지 7과 같은 Pixel-driven(화소 기준) 방식입니다. 영상의 화소를 하나씩 돌며 필터링한 줄에서 필요한 값을 읽어 오므로, 화소마다 선원 각 하나당 정확히 한 번 값을 받습니다. 팬빔에서 달라지는 것은 읽는 위치 \(t'\)와 읽은 값에 곱하는 \(1/U^{2}\)이 화소와 선원 각마다 정해진다는 점입니다.

  3. 2행 페이지 3의 \(h[n]\)을 \(-(N_t-1)\)부터 \(N_t-1\)까지 만듭니다. 윈도우 필터를 쓰면 여기서 Shepp-Logan이나 Hamming 커널로 바꿉니다. FFT로 필터링한다면 이 커널의 DFT도 이 단계에서 한 번 구해 둡니다.
  4. 6~7행 필터링 단계입니다. 6행에서 선원 각 하나의 행에 \(c[n]\)을 곱하고, 7행에서 커널과 이산 컨볼루션합니다. FFT를 쓸 때는 제로 패딩 길이 \(M \ge 2N_t - 1\)로 계산하고 앞의 \(N_t\)개만 \(q\)로 씁니다.
  5. 9~10행 8장 페이지 2에서 정의한 \(U\)와 \(t'\)입니다. \(t'\)을 \(D(x\cos\beta + y\sin\beta)/(D + x\sin\beta - y\cos\beta)\)로 쓰지 않고 앞 줄의 \(U\)로 나누어 짧게 썼습니다. 화소가 선원보다 뒤에 있는 경우(\(U \le 0\))는 \(D\)가 재구성 영역의 반지름 \(R\)보다 큰 장치에서 일어나지 않습니다.
  6. 11~12행 6장 페이지 7의 \(\tau\), \(i\), \(f\)에서 \(s/\Delta s\)를 \(t'/\Delta t\)로 바꾼 것입니다. 칸 번호가 \(0\)~\(N_t - 1\)이고 가운데 칸이 \(t = 0\)이므로 \((N_t - 1)/2\)를 더합니다.
  7. 13행 \(\tau\)가 검출기 밖이면 그 광선은 측정되지 않았으므로 더하지 않습니다. 페이지 2의 \(N_t\)로 영역 전체를 덮었다면 이 조건은 항상 참입니다.
  8. 14~15행 필터링한 값을 선형 보간으로 읽고, 거리 가중 \(1/U^{2}\)과 각도 가중 \(\pi/N_\beta\)를 곱해 더합니다. \(1/U\)를 한 번만 구해 두면 10행의 나눗셈과 15행의 \(1/U^{2}\)가 곱셈으로 바뀝니다.

곡면 검출기의 각 간격과 sin 보정 커널

8장 페이지 7의 곡면 검출기 공식을 샘플링한 데이터로 계산합니다. 곡면 검출기(Curved Detector)의 칸은 팬 각 \(\gamma\)가 같은 간격으로 놓여 있으므로 샘플링 변수가 \(t\)가 아니라 \(\gamma\)입니다. 사전 가중, 커널, 읽는 위치, 거리 가중이 모두 평면 검출기와 달라집니다.

결론: 곡면 검출기의 이산 알고리즘

\[q_k[n] = \Delta\gamma \sum_{m=0}^{N_\gamma-1} R[k, m]\,D\cos\gamma_m\,h_c[n - m]\]

\[\mu(x, y) \approx \frac{\pi}{N_\beta} \sum_{k=0}^{N_\beta - 1} \frac{1}{L_k^{2}}\, q_k(\gamma'_k)\]

  • \(R[k, n]\). 선원 각 \(\beta_k\)에서 팬 각 \(\gamma_n = (n - (N_\gamma - 1)/2)\Delta\gamma\)로 가는 광선의 투영값 \(R_{\beta_k}(\gamma_n)\)입니다.
  • \(D\cos\gamma_m\). 8장 페이지 7에서 야코비안 \(d\theta\,ds = D\cos\gamma\,d\gamma\,d\beta\)로 나온 사전 가중입니다. 평면 검출기의 \(\cos\gamma\)에 \(D\)가 더 곱해져 있습니다.
  • \(h_c[n]\). 곡면 검출기용 커널(Curved-Detector Kernel)의 이산 수열입니다(아래).
  • \(L_k\), \(\gamma'_k\). 선원과 화소 사이의 실제 거리 \(L = \sqrt{(D + \eta)^{2} + \xi^{2}}\)와, 화소를 선원에서 본 팬 각 \(\gamma' = \arctan(\xi/(D + \eta))\)입니다. \(\xi\), \(\eta\)는 8장 페이지 2의 정의 그대로입니다.

각 간격 \(\Delta\gamma\)와 칸 수

곡면 검출기의 칸은 선원을 중심으로 한 반지름 \(\mathrm{SDD}\)의 원호 위에 있으므로, 실제 칸 간격 \(\Delta d\)는 호의 길이이고 팬 각의 간격은 \(\Delta\gamma = \Delta d/\mathrm{SDD}\)(라디안)입니다. 차단 주파수는 \(W = 1/(2\Delta\gamma)\)이며 단위는 라디안당 주기입니다. \(\Delta d = 0.03\) cm, \(\mathrm{SDD} = 4.5\) cm이면 \(\Delta\gamma = 0.00667\) rad(\(0.382^{\circ}\))입니다. 평면 검출기 \(\Delta t = 0.02\) cm와 중심의 간격이 같고, \(\Delta t = D\,\Delta\gamma\)의 관계입니다.

덮어야 하는 범위는 접선의 팬 각 \(\gamma_m = \arcsin(R/D)\)로 정합니다. \(R = 1.556\) cm, \(D = 3\) cm이면 \(\gamma_m = 0.5451\) rad(\(31.2^{\circ}\))이고, \(N_\gamma = 2\lceil\gamma_m/\Delta\gamma\rceil + 1\)이므로 \(\Delta\gamma = 0.00667\) rad에서 \(N_\gamma = 165\)입니다(같은 중심 간격의 평면 검출기는 \(N_t = 183\)).

이산 커널 \(h_c[n]\)

\[h_c[n] = \Bigl(\frac{n\Delta\gamma}{\sin(n\Delta\gamma)}\Bigr)^{2} h[n] = \begin{cases} \dfrac{1}{4\Delta\gamma^{2}} & n = 0 \\[1ex] 0 & n \neq 0\ \text{인 짝수} \\[1ex] -\dfrac{1}{\pi^{2}\sin^{2}(n\Delta\gamma)} & n\ \text{홀수} \end{cases}\]

필터링과 윈도우 필터

곡면 검출기에서는 필터링을 직접 합이나 커널을 DFT하는 방식으로 합니다. 보정 인자가 공간에서 \(n\)마다 다르게 곱해지므로 \(h_c\)의 DFT는 \(|\omega|\)가 아니어서, 페이지 3에서 쓰지 않기로 한 주파수에서 \(|\omega_j|\)를 곱하는 방법은 처음부터 쓸 수 없습니다. 제로 패딩 길이는 평면과 같이 \(M \ge 2N_\gamma - 1\)입니다.

검출기 좌표를 바꾸는 재샘플링

측정한 검출기와 알고리즘이 요구하는 좌표가 다르면 선원 각마다 한 줄의 데이터를 다른 좌표의 격자로 옮깁니다. 7장 페이지 3에서 보았듯이 \(R_\beta(t)\)와 \(R_\beta(\gamma)\)는 \(t = D\tan\gamma\)로 이어진 같은 광선의 같은 값이므로, 옮길 때 값에 곱하는 인자는 없고 위치만 바꿔 읽습니다.

  • 평면 → 곡면. 곡면 격자의 \(\gamma_m = (m - (N_\gamma - 1)/2)\Delta\gamma\)마다 \(t = D\tan\gamma_m\)을 구하고, 평면 데이터의 이웃한 두 칸에서 선형 보간해 읽습니다.
  • 곡면 → 평면. 평면 격자의 \(t_n\)마다 \(\gamma = \arctan(t_n/D)\)를 구하고, 곡면 데이터의 이웃한 두 칸에서 선형 보간해 읽습니다.

보간은 선원 각마다 칸 수만큼이라 \(N_\beta N_t\)번입니다. 페이지 8의 예에서 \(1.06 \times 10^{6}\)번으로, 역투영의 화소 방문 \(3.8 \times 10^{8}\)번보다 훨씬 적습니다. 7장 페이지 8의 rebinning과 달리 선원 각 방향의 보간은 없고 검출기 방향의 1차원 보간 하나입니다.

같은 Shepp-Logan 데이터를 옮긴 뒤 알고리즘에 넣어 직접 방식과 비교해도, 어느 쪽이 항상 낫다고 할 차이는 없었습니다. 재샘플링한 쪽의 바깥 rms가 4조건 중 3조건에서 더 작았고, Hamming과 \(\Delta t = 0.04\) cm에서는 안쪽 rms가 늘었습니다. 이 장은 보간 단계가 없어 구현이 단순한 직접 방식을 기본으로 두고, 재샘플링은 다른 종류의 검출기를 가정한 기존 코드를 쓰는 경우에 씁니다. 이 책이 평면 검출기를 기준으로 삼는 것은 콘빔이 평면 검출기를 쓰기 때문입니다(8장 페이지 8).

선원 각은 몇 개가 좋을까요? 계산량과 수치 스케일

페이지 2~6에서 검출기 방향의 샘플링과 계산 순서를 정했습니다. 이 페이지에서는 선원 각을 몇 개 둘지, 계산에 얼마나 드는지, 결과의 크기가 \(\mu\)로 맞으려면 무엇을 빠뜨리지 말아야 하는지를 봅니다.

선원 각의 수 \(N_\beta\)

6장 페이지 6에서 반지름 \(R\)인 물체의 가장자리가 이웃한 두 각도에서 그리는 직선 사이의 간격 \(R\Delta\theta\)가 검출기 간격 \(\Delta s\)보다 크면 줄무늬가 생겼고, 그 조건에서 \(N_\theta \gtrsim \pi R/\Delta s\)를 얻었습니다. 팬빔에서도 같은 생각을 적용할 수 있습니다. 중심 광선(\(\gamma = 0\))만 보면 선원 각 \(\beta\)와 \(\beta + \pi\)가 같은 직선을 재므로, \(0\)~\(\pi\)의 방향이 간격 \(\Delta\beta\)로 놓입니다. \(R\Delta\beta \le \Delta t\)이면 다음과 같습니다.

\[N_\beta \gtrsim \frac{2\pi R}{\Delta t}\]

선원 각의 수가 평행빔의 두 배가 되는 것은 선원이 \(360^{\circ}\)를 돌기 때문입니다. 이 식은 중심 광선만 따진 어림이어서 \(\gamma \ne 0\)인 광선과 가중의 영향은 들어 있지 않습니다. 어림이 맞는지 \(D = 3\) cm, 반지름 \(R = 0.9\) cm인 원판으로 확인했습니다. 원판 바깥 \(r = 1.0\), \(1.05\), \(1.1\) cm 원 위 192개 점의 값(참값 0)의 rms는 \(\Delta t = 0.02\) cm의 평면 검출기에서 \(N_\beta = 180\)개일 때 0.0085, 어림값 \(2\pi R/\Delta t = 283\)을 넘긴 360개일 때 0.0016이었습니다. 어림값을 넘겨서 더 늘려도 오차는 계속 줄어 720개에서는 0.0003이었습니다.

검출기 간격을 절반으로 줄이면(\(0.02 \to 0.01\) cm) 같은 \(N_\beta\)에서 오차가 오히려 커졌고(360개에서 0.0016이 0.0062), 비슷한 오차에 이르려면 \(N_\beta\)가 두 배 정도 필요했습니다(0.02 cm의 360개 0.0016, 0.01 cm의 720개 0.0009). 곡면 검출기에서도 \(\Delta\gamma = \Delta t/D\)로 두면 같은 경향이었습니다. 어림값(\(\Delta t = 0.02\) cm에서 289) 근처의 360개 이후에는 \(\Delta t\)와 윈도우가 정하는 한계에 머뭅니다.

계산량

6장 페이지 8의 평행빔 예(\(N_\theta = 720\), \(N_s = 736\), \(N_x = 512\))와 같은 크기의 팬빔을 어림합니다. 선원 각 간격을 평행빔의 각도 간격과 같게 두면 \(N_\beta = 1440\)이고, 칸 수는 \(N_t = 736\), 영상은 \(512 \times 512\), 제로 패딩 길이는 \(M = 2048\)(\(\ge 2N_t - 1 = 1471\))입니다.

Shepp-Logan 팬텀의 재구성과 아티팩트

지금까지 정한 선택(검출기 종류, 칸 간격, 선원 각의 수, 필터)이 영상에 어떻게 나타나는지 Shepp-Logan 팬텀으로 확인합니다. 아래 위젯은 팬텀의 팬빔 투영을 닫힌 식으로 계산해 \(D = 3\) cm의 가상 검출기로 샘플링하고, 페이지 4 또는 페이지 6의 의사코드로 재구성합니다. 직접 합으로 필터링하므로 설정을 바꿀 때마다 잠시 걸립니다. 머리 안쪽 rms는 두개골 안쪽 타원 \(x^{2}/0.6^{2} + y^{2}/0.8^{2} \le 1\) 안의 화소에서 재구성값과 참값의 차이의 제곱평균제곱근이고, 두개골 바깥 rms는 6장 페이지 6과 같이 두개골 바깥(참값 0)에서 잰 값입니다.

설정에 따른 영상의 변화

기본 설정(평면 검출기, \(\Delta t = 0.02\) cm, 선원 각 360개, Hamming)에서는 머리 안쪽 rms가 0.0020, 두개골 바깥 rms가 0.0172이고 원본 1.02인 세 점이 1.019~1.020으로 나옵니다. 가중을 빠뜨렸을 때의 영상은 1편 빠르게 보기 7일차 페이지 2의 위젯에서 보았으므로, 여기서는 이산화의 선택을 하나씩 바꾸어 봅니다. 위젯에서 한 번에 하나만 바꾸고 영상, 차이 영상, rms를 비교해 보세요.

  • 칸 간격. \(\Delta t\)를 0.08 cm로 키우고 Ram-Lak으로 계산하면 두개골 바깥에 큰 물결 무늬가 생깁니다. 이 무늬가 링잉인지 에일리어싱인지는 설정 하나만 바꾸어서는 구분할 수 없습니다(6장 페이지 10).
  • 선원 각의 수. 선원 각이 45개이면 영상 가장자리에서 중심 쪽으로 뻗는 방사형 줄무늬가 보입니다. 두개골 바깥 rms는 0.1793으로 360개일 때(0.0172)의 10배 남짓이고, 머리 안쪽 rms는 거의 그대로입니다.
  • 커널. Ram-Lak은 Hamming보다 두개골 바깥 rms가 크고 머리 안쪽 rms는 작습니다.
  • 검출기 종류. 평면과 곡면의 차이는 페이지 7에서 비교한 대로 작습니다. 위젯에서 검출기만 바꾸어 확인할 수 있습니다.

회전 중심 오프셋

팬빔 데이터에는 검출기 위치의 어긋남이 영상에 크게 나타나는 아티팩트가 있습니다. 회전 중심을 지나는 광선(중심 광선)이 검출기의 중심 칸 위치(\(t_n\)의 기준 0)에 닿지 않고 \(\delta\)만큼 벗어난 상태를 회전 중심 오프셋(Center Offset)이라고 합니다. 위젯은 모든 선원 각에서 칸의 실제 위치를 \(t_n + \delta\)(곡면 검출기는 \(\gamma_n + \delta/D\))로 두고 측정값을 만든 뒤, 알고리즘은 \(\delta = 0\)이라고 가정하고 계산합니다. \(\delta\)는 칸 수로 표시하며 \(\delta = (\text{칸 수}) \times \Delta t\)입니다. 기본 설정의 한 칸은 0.02 cm입니다.

위젯에서 "중심 칸 오프셋"을 0.5칸부터 4칸까지 바꾸어 보세요. 보정은 "하지 않음"으로 둡니다.

  • 안쪽 rms는 오프셋이 클수록 늘었습니다. 머리 안쪽 rms가 오프셋이 없을 때 0.0020에서 2칸에서 0.0056, 4칸(0.08 cm, 영상 폭 2.2 cm의 3.6%)에서 0.0631로 30배 남짓입니다. 차이 영상에서는 두개골 띠가 있던 자리가 어둡고, 그 안쪽과 바깥쪽에 밝은 띠가 생깁니다.
  • 바깥 rms 하나로는 오프셋을 알아채기 어렵습니다. 1칸까지는 오히려 줄었다가(0.0172에서 0.0102) 2칸부터 커집니다(0.0297). 그래서 오프셋을 의심할 때는 안쪽 경계와 차이 영상을 봅니다.
  • 영상의 위치와 총합은 거의 변하지 않았습니다. 오프셋 0칸과 4칸에서 \((\Delta x)^{2}\Sigma\mu\)가 2.2020과 2.1998이고 무게중심의 \(x\) 좌표가 0.0002와 0.0005입니다. 머리가 한쪽으로 밀리는 것이 아니라 경계가 번지는 형태입니다.

회전 중심 근처에서는 \(U \approx 1\)이므로, 칸 위치의 어긋남 \(\delta\)는 영상에서 \(\delta(\cos\beta, \sin\beta)\) 방향으로 \(\delta\)만큼 옮겨 놓은 것과 거의 같습니다. 이 방향은 선원 각 \(\beta\)에 따라 한 바퀴 돌므로 모든 선원 각을 더하면 점 하나가 반지름 \(\delta\)의 고리 모양으로 퍼진다고 예상할 수 있습니다. 총합과 무게중심이 변하지 않은 것이 이 예상과 맞습니다.

퍼지는 거리도 맞습니다. 위젯에서 4칸(\(\delta = 0.08\) cm)으로 두고 가로줄 \(y = 0\)의 오른쪽 경계를 보면, 두개골 띠(중심 약 0.676 cm)가 있던 자리의 값은 원본(2.00)보다 낮아지고 그 안쪽과 바깥쪽에 밝은 띠가 생깁니다. 밝은 띠는 띠의 중심에서 \(\delta\)만큼 안쪽과 바깥쪽인 \(0.676 - 0.08 \approx 0.60\) cm와 \(0.676 + 0.08 \approx 0.76\) cm 근처에 놓입니다. 다만 이 설명은 \(U \approx 1\)의 근사입니다.

오프셋 값을 알고 있으면 위젯의 "오프셋 보정"으로 해결됩니다. 칸의 실제 위치를 \(t_n + \delta\)로 놓고 사전 가중을 \(D/\sqrt{D^{2} + (t_n + \delta)^{2}}\)로, 읽는 위치를 \(\tau = (t' - \delta)/\Delta t + (N_t - 1)/2\)로 계산하는 것입니다. 이 설정(평면, 2칸과 4칸)에서 보정하면 안쪽 rms가 0.0020, 바깥 rms가 0.0172로 오프셋이 없을 때와 같아졌습니다. 오프셋 값을 측정으로 알아내는 교정은 이 책의 범위 밖이고, 오프셋이 일부러 큰 검출기 배치는 이 장에서 다루지 않습니다.

핵심 요약

  1. 평면 검출기 팬빔 FBP의 이산 알고리즘은 사전 가중 \(D/\sqrt{D^{2} + t_n^{2}}\), 커널 \(h[n]\)과의 컨볼루션, \(1/U^{2}\)을 곱하며 \(t'\)에서 보간하는 역투영의 세 단계입니다. 6장의 평행빔 이산 FBP와 같은 뼈대에 가중 둘이 더해졌고, 각도 합의 상수는 \(\pi/N_\beta = \tfrac{1}{2}\Delta\beta\)입니다.
  2. 검출기 간격은 회전 중심으로 옮긴 가상 검출기에서 재어 \(\Delta t = \Delta d\,D/\mathrm{SDD}\)이고 차단 주파수는 \(W = 1/(2\Delta t)\)입니다. 이웃 광선의 간격은 화소에서 \(U\cos\gamma'\,\Delta t\)여서 화소와 선원 각마다 다릅니다.
  3. (심화) 곡면 검출기는 팬 각 간격 \(\Delta\gamma\)로 샘플링하며 사전 가중이 \(D\cos\gamma\), 커널이 \(h_c[n] = (n\Delta\gamma/\sin n\Delta\gamma)^{2}h[n]\), 거리 가중이 \(1/L^{2}\)입니다. \(h_c\)의 DFT는 \(|\omega|\)가 아니므로 커널을 DFT하는 방식으로만 필터링합니다.
  4. 선원 각의 수는 \(N_\beta \gtrsim 2\pi R/\Delta t\)가 어림이고, 계산량의 대부분은 역투영입니다. \(\Delta t\)를 곱하는 것과 \(\tfrac{1}{2}\)을 각도 가중에 넣는 것을 빠뜨리면 \(\mu\)의 크기가 어긋납니다.
  5. (심화) 이 장의 조건에서 같은 간격과 각도 간격이면 팬빔의 이산 오차는 평행빔과 비슷했습니다(페이지 9의 위젯). 팬빔에서는 검출기 중심 칸의 오프셋이 안쪽 경계를 번지게 하므로 알려진 물체로 확인해야 합니다.
  6. 이 알고리즘은 한 바퀴 데이터를 전제하며, 덜 돌린 데이터는 10~12장에서 다룹니다.

마무리 퀴즈 1

평면 검출기의 실제 칸 간격이 \(\Delta d = 0.05\) cm, 선원–검출기 거리가 \(\mathrm{SDD} = 120\) cm, 선원–회전 중심 거리가 \(D = 80\) cm입니다. 커널과 읽는 위치 계산에 쓸 \(\Delta t\)와 차단 주파수 \(W\)는 무엇일까요?

  1. \(\Delta t = 0.05\) cm, \(W = 10\) cm\(^{-1}\)
  2. \(\Delta t \approx 0.0333\) cm, \(W = 15\) cm\(^{-1}\)
  3. \(\Delta t = 0.075\) cm, \(W \approx 6.67\) cm\(^{-1}\)
  4. \(\Delta t \approx 0.0333\) cm, \(W = 30\) cm\(^{-1}\)

같은 검출기라도 \(\mathrm{SDD}/D\)가 클수록 회전 중심에서 보는 칸이 촘촘해져 \(W\)가 커집니다. 이 장치는 \(\mathrm{SDD}/D = 1.5\)이므로 실제 간격으로 계산한 \(W = 10\) cm\(^{-1}\)보다 1.5배 높은 15 cm\(^{-1}\)까지 회전 중심 근처의 무늬를 담습니다.

마무리 퀴즈 2

(심화) 곡면 검출기에서 \(\Delta\gamma = 0.2\) rad(설명을 위해 일부러 크게 잡은 값)일 때 \(h_c[3]\)은 얼마일까요? 보정 없는 커널은 \(h[3] = -1/(\pi^{2}\cdot 3^{2}\cdot 0.2^{2}) \approx -0.2814\)입니다.

  1. \(-0.2814\)
  2. \(-0.3178\)
  3. \(-0.2493\)
  4. \(-2.567\)

(심화) 이 문제의 \(\Delta\gamma = 0.2\) rad은 보정 인자를 눈으로 확인하려고 크게 잡았습니다. 실제 장치의 \(\Delta\gamma\)는 \(0.007\) rad 정도로 훨씬 작아서 \(n = 3\)에서 인자는 1.0001입니다. 그래도 인자가 1에 가까운 항이 많이 모이면 합에서는 보정이 값에 1.4~2.3% 차이를 냈습니다(페이지 5의 원판 표). 그 차이는 거의 \(|n| \le 40\)(인자 1.03 이하)의 항에서 생겼습니다.

마무리 퀴즈 3

반지름 \(R = 10\) cm인 물체를 회전 중심에서의 칸 간격 \(\Delta t = 0.05\) cm로 \(360^{\circ}\) 측정합니다. 페이지 8의 어림으로 필요한 선원 각의 수 \(N_\beta\)는 얼마일까요?

  1. 약 200개
  2. 약 628개
  3. 약 1257개
  4. 약 2513개

이 식은 중심 광선만 따진 어림이어서 이 값을 넘겨도 오차는 계속 줄어듭니다(페이지 8의 원판 예에서 \(\Delta t = 0.02\)의 어림값 283의 2.5배인 720개의 오차 0.0003이 360개의 0.0016보다 작았습니다). 어림값은 오차가 크게 줄어드는 구간의 시작을 알려 주는 정도로 씁니다. \(R\)이나 \(\Delta t\)가 바뀌면 \(N_\beta\)는 \(R\)에 비례하고 \(\Delta t\)에 반비례합니다.

마무리 퀴즈 4

평면 검출기, \(\Delta t = 0.02\) cm, 선원 각 360개, Hamming에서 알고리즘은 오프셋이 없다고 가정했지만 실제 데이터에는 2칸~4칸의 중심 칸 오프셋이 있었습니다. 이 장의 실험에서 나타난 결과로 알맞은 것은 무엇일까요?

  1. 총합과 위치는 거의 그대로이고 두개골 경계가 번져 머리 안쪽 rms가 커진다.
  2. 영상 전체가 오프셋 방향으로 평행 이동하고 안쪽 모양은 그대로이다.
  3. 두개골 바깥 rms가 오프셋에 따라 꾸준히 커져서 이 값만 보고 오프셋을 알 수 있다.
  4. 영상 전체의 값이 오프셋 칸 수에 비례하는 배율로 커지고 경계 모양은 그대로이다.

알려진 오프셋은 칸의 실제 위치를 \(t_n + \delta\)로 놓고 사전 가중과 읽는 위치를 계산하면 없앨 수 있고(페이지 9의 "오프셋 보정"), 이때 결과는 오프셋이 없는 경우와 같았습니다. 값을 모를 때는 이 보정을 쓸 수 없으므로, 측정 단계에서 중심 칸의 위치를 알아내는 일이 필요합니다.

(가) 평면 검출기의 \(\xi\), \(\eta\), \(U\), \(t'\), \(\tau\), \(i\), \(f\), 곱하는 가중 \((\pi/N_\beta)/U^{2}\). (나, 심화) 같은 화소를 \(\Delta\gamma = \Delta t/D\), \(N_\gamma = 165\)인 곡면 검출기로 계산한 \(L\), \(\gamma'\), \(\tau\), 곱하는 가중 \((\pi/N_\beta)/L^{2}\).

모범답안과 흔한 실수

1번. (가) \(\Delta t = 0.1 \times 60/100 = 0.06\) cm, \(W = 1/(2 \times 0.06) \approx 8.33\) cm\(^{-1}\)입니다. (나) \(t_{\max} = DR/\sqrt{D^{2} - R^{2}} = 60 \times 20/\sqrt{3600 - 400} = 1200/56.57 \approx 21.21\) cm이고 \(t_{\max}/\Delta t \approx 353.55\)를 올림하면 354이므로 \(N_t = 2 \times 354 + 1 = 709\)입니다. (다) \(2N_t - 1 = 1417\)이므로 \(M = 2048\)이고, \(2\pi R/\Delta t = 2\pi \times 20/0.06 \approx 2094\)입니다.

2번. (가) \(\xi = 0.3\cos 90^{\circ} - 0.5\sin 90^{\circ} = -0.5\), \(\eta = 0.3\sin 90^{\circ} + 0.5\cos 90^{\circ} = 0.3\)이므로 \(U = (3 + 0.3)/3 = 1.1\), \(t' = -0.5/1.1 \approx -0.4545\) cm, \(\tau = t'/\Delta t + 91 = -22.727 + 91 = 68.273\)입니다. 따라서 \(i = 68\), \(f \approx 0.273\)이고 \(q[68]\)과 \(q[69]\)를 \(0.727 : 0.273\)으로 섞어 읽습니다. 가중은 \((\pi/360)/1.21 \approx 0.007212\)입니다. (나, 심화) \(L = \sqrt{3.3^{2} + 0.5^{2}} = \sqrt{11.14} \approx 3.338\) cm, \(\gamma' = \arctan(-0.5/3.3) \approx -0.1504\) rad(\(-8.62^{\circ}\))입니다. \(\Delta\gamma = 0.02/3 \approx 0.006667\) rad이고 \((N_\gamma - 1)/2 = 82\)이므로 \(\tau = -0.1504/0.006667 + 82 \approx 59.444\), \(i = 59\), \(f \approx 0.444\)입니다. 가중은 \((\pi/360)/11.14 \approx 0.0007834\)입니다. 같은 화소에서 평면의 \(t'\)과 곡면의 \(\gamma'\)은 \(t' = D\tan\gamma'\)로 이어지며(\(3 \tan(-0.1504) \approx -0.4545\)) 가리키는 위치는 같습니다.

3번. \(h_c[0] = 1/(4 \times 0.01^{2}) = 2500\), \(h_c[2] = 0\)(짝수), \(h_c[1] = -1/(\pi^{2}\sin^{2}0.01) \approx -1013.25\), \(h_c[5] = -1/(\pi^{2}\sin^{2}0.05) \approx -40.56\)입니다. 보정 인자는 \(n = 1\)에서 \((0.01/\sin 0.01)^{2} \approx 1.00003\), \(n = 5\)에서 \((0.05/\sin 0.05)^{2} \approx 1.00083\)이고, 이 작은 \(\Delta\gamma\)에서는 \(h\)와 \(h_c\)의 차이가 작습니다.

흔한 실수.

  • 1번에서 \(\Delta d\)를 그대로 \(\Delta t\)로 쓰는 것입니다. \(\Delta t = \Delta d\,D/\mathrm{SDD}\)이고, \(\mathrm{SDD}/D\)를 곱하면 비율이 거꾸로입니다.
  • 1번 (나)에서 \(t_{\max}\)를 \(R\)로 쓰는 것입니다. 접선의 위치는 \(D\tan\gamma_m\)이고 \(\sin\gamma_m = R/D\)이므로 \(R\)보다 큽니다(21.21 cm 대 20 cm).
  • 2번 (가)에서 \(\eta\)의 부호를 바꾸거나 \(\tau\)에 \((N_t - 1)/2\)를 더하지 않는 것입니다. 가운데 칸의 번호가 91입니다.
  • (심화) 2번 (나)에서 \(1/L^{2}\) 대신 \(1/U^{2}\)을 쓰는 것입니다. 곡면 검출기의 거리 가중은 \(L\)로 계산하며, 같은 화소에서 \(U = 1.1\)과 \(L = 3.338\)은 단위도 값도 다릅니다.
  • 3번에서 \(h_c[1]\)을 \(h[1]\)과 같다고 쓰거나 짝수 \(n\)에서 0이 아닌 값을 쓰는 것입니다. 짝수 \(n\)의 0은 인자를 곱해도 0입니다.
