한 바퀴를 다 안 돌고 찍으면? Short scan과 Parker weight

10장에서 선원이 한 바퀴를 돌지 않아도 모든 직선이 적어도 한 번 측정된다는 것을 확인했고, 두 번 잰 직선의 가중 합이 1이어야 한다는 조건을 세웠습니다. 이 장에서는 그 조건을 만족하는 가중을 구체적으로 만들어 팬빔 FBP에 끼웁니다. 그 전에 한 바퀴를 다 돌지 않으려는 이유부터 봅니다.

한 바퀴를 도는 시간

선원이 한 바퀴를 도는 데 걸리는 시간을 회전 시간 \(T\)라고 하겠습니다. 스캔 범위가 \(B\)이면 데이터를 모으는 시간은 \(T\,B/(2\pi)\)입니다. 10장 페이지 1에서 같은 직선을 잰 두 광선의 값이 같다고 한 것은 물체가 가만히 있다는 전제였습니다. 숨 쉬는 폐나 뛰는 심장처럼 움직이는 장기를 찍을 때는 두 광선이 서로 다른 시점에 측정되므로 값이 달라지고, 재구성 영상이 흐려집니다. 데이터를 모으는 시간이 짧을수록 이 영향이 줄어듭니다. 10장의 최소 범위 \(B = \pi + 2\gamma_m\)만 도는 스캔을 short scan이라고 합니다.

10장 페이지 4에서 \(B = \pi + 2\gamma_m\)이면 모든 직선이 적어도 한 번 측정된다는 것을 보였습니다. \(\gamma_m = 20^{\circ}\)이면 \(B = 220^{\circ}\)이고 시간은 \(0.61\,T\)입니다. 예를 들어 \(T = 0.5\) s이면 \(0.5 \times 220/360 = 0.31\) s입니다.

선량

선원 각마다 쏘는 X선의 양이 같다면 환자가 받는 선량은 측정하는 선원 각의 수, 곧 \(B\)에 비례합니다. \(220^{\circ}\)는 한 바퀴의 61%입니다. 시간과 선량이 줄어드는 대가로, 한 번만 측정되는 직선이 많아지고 영상의 잡음이 늘어납니다.

이 장의 진행

  1. short scan의 범위와 측정 횟수를 정리하고(페이지 2), 가중 없이 줄인 스캔을 재구성해 어떻게 어긋나는지 봅니다(페이지 3).
  2. Parker 가중을 정의하고 세 구간으로 도출하며, 합이 1임을 확인합니다(페이지 4~6).
  3. 팬빔 FBP에 가중을 끼우는 위치를 정하고(페이지 7), 한계를 짚습니다(페이지 8).
  4. 스캔 범위가 더 클 때의 가중(페이지 9)과 시간 해상도(페이지 10)를 보고, 위젯으로 비교합니다(페이지 11).

측정 횟수 비율의 계산

한 직선의 두 광선은 팬 각이 \(\gamma\)와 \(-\gamma\)이므로, \(|\gamma| \le \gamma_m\)인 한 직선을 하나 고르면 두 광선의 선원 각은 \(\beta\)와 \(\beta + \pi + 2\gamma\)(\(2\pi\)를 법으로)입니다. 팬 각이 \(\gamma\)인 광선만 모아 \(\beta\)를 \(0\)에서 \(2\pi\)까지 고르게 놓으면, 광선과 그 짝이 둘 다 스캔 범위 \([0, B]\) 안에 들어오는 \(\beta\)의 길이는 시작 삼각형의 폭 \(B - \pi - 2\gamma\)와 끝 삼각형의 폭 \(B - \pi + 2\gamma\)의 합 \(2(B - \pi)\)입니다(10장 페이지 3). 이 길이를 \(2\pi\)로 나눈 값이 두 번 측정되는 광선의 비율이고, \(\gamma\)에 의존하지 않습니다.

\[\frac{2(B - \pi)}{2\pi} = \frac{B - \pi}{\pi}\]

\(B = \pi + 2\gamma_m\)이면 \(2\gamma_m/\pi\)입니다. 어느 쪽도 측정되지 않는 직선은 없으므로 나머지 \((2\pi - B)/\pi\)가 한 번만 측정되는 직선의 비율입니다.

다시 보기: 10장의 결과

  • 광선 \((\beta, \gamma)\)의 짝은 \((\beta + \pi + 2\gamma,\ -\gamma)\)입니다(10장 페이지 2).
  • \(B = \pi + 2\gamma_m\)에서 두 번 측정되는 영역은 시작 삼각형 \(0 \le \beta \le 2(\gamma_m - \gamma)\)와 끝 삼각형 \(\pi - 2\gamma \le \beta \le B\)이고 서로의 짝입니다(10장 페이지 3).
  • 가중은 짝의 합이 1이어야 하고, 점프 없이 이어져야 합니다(10장 페이지 8).
  • 시작 삼각형에서 \(\lambda = \beta/(2(\gamma_m - \gamma))\), 끝 삼각형에서 \(\lambda' = (B - \beta)/(2(\gamma_m + \gamma))\)로 두고 \(w = f(\lambda)\), \(w = f(\lambda')\)로 정하며, 경사 \(f\)는 \(f(0) = 0\), \(f(1) = 1\), \(f(\lambda) + f(1 - \lambda) = 1\)을 만족합니다.

이 구성이 평면을 어떻게 나누는지 아래 그림에 구간 번호를 붙였습니다. 상승(구간 1), 평탄(구간 2), 하강(구간 3)이라는 이름은 선원 각을 따라 가중이 오르고, 1로 유지되고, 내려오기 때문에 붙였습니다.

한 번만 측정되는 직선은 두 측정을 평균하는 효과를 얻지 못합니다.

Parker 가중의 정의

10장 페이지 8은 가중이 만족할 두 원리를 세웠습니다. 원리 1(짝의 가중 합이 1)과 원리 2(광선 위치에 따라 끊김 없이 변하는 가중)입니다. 두 원리를 만족하는 구성에서 경사 \(f\)를 \(f(\lambda) = \sin^{2}(\pi\lambda/2)\)로 정한 가중을 Parker 가중(Parker Weight)이라고 합니다. D. L. Parker는 팬빔 CT에서 \(180^{\circ}\)에 팬 전체의 각을 더한 범위만 돌려 재구성할 때 생기는 중복 데이터의 불균형을 부드러운 가중으로 보정하는 방법을 제안했습니다(D. L. Parker, Optimal short scan convolution reconstruction for fanbeam CT, Medical Physics 9(2), 1982, 254–257). 아래 식은 10장의 규약으로 직접 도출한 것이며, 주 참고서 Kak & Slaney 3.5절 식 (150)에 실린 Parker 가중과 기호(\(\gamma_m,\ \gamma,\ \beta\))까지 같습니다. 공개 구현 RTK는 원 논문 식 (12)의 분모에 인쇄 오타가 있어 바로잡았다고 밝히고 있으므로, 원문의 식을 옮겨 쓸 때는 짝의 가중 합이 1인지 먼저 확인합니다.

β–γ 평면에서 본 모양

\(\gamma_m = 20^{\circ}\), \(B = 220^{\circ}\)에서 Parker 가중 \(w(\beta, \gamma)\)를 평면 전체에 칠한 그림입니다. 세 점선을 따라 위에서 아래로 내려가며 읽은 밝기가 아래 1차원 그래프의 세 곡선입니다.

세 구간의 식

\[ w(\beta, \gamma) = \begin{cases} \sin^{2}\!\left(\dfrac{\pi}{4}\,\dfrac{\beta}{\gamma_m - \gamma}\right), & 0 \le \beta \le 2(\gamma_m - \gamma)\quad\text{(구간 1, 상승)}\\[2mm] 1, & 2(\gamma_m - \gamma) \le \beta \le \pi - 2\gamma\quad\text{(구간 2, 평탄)}\\[2mm] \sin^{2}\!\left(\dfrac{\pi}{4}\,\dfrac{\pi + 2\gamma_m - \beta}{\gamma_m + \gamma}\right), & \pi - 2\gamma \le \beta \le \pi + 2\gamma_m\quad\text{(구간 3, 하강)} \end{cases} \]

  • \(\beta\)는 선원 각, \(\gamma\)는 팬 각(\(|\gamma| \le \gamma_m\)), \(\gamma_m\)은 팬 반각입니다. 스캔 범위 밖(\(\beta < 0\) 또는 \(\beta > \pi + 2\gamma_m\))에서는 \(w = 0\)입니다.
  • 구간 1의 식은 10장의 \(\lambda = \beta/(2(\gamma_m - \gamma))\)로 쓴 \(\sin^{2}(\pi\lambda/2)\)와 같습니다. \(\tfrac{\pi}{2}\lambda = \tfrac{\pi}{4}\,\beta/(\gamma_m - \gamma)\)이기 때문입니다. 구간 3도 \(\lambda' = (B - \beta)/(2(\gamma_m + \gamma))\)로 같은 모양입니다.
  • 구간의 폭은 구간 1이 \(2(\gamma_m - \gamma)\), 구간 3이 \(2(\gamma_m + \gamma)\)이고 구간 2는 \(\pi - 2\gamma_m\)으로 \(\gamma\)에 관계없이 일정합니다. 세 폭의 합은 \(\pi + 2\gamma_m = B\)입니다.

다른 책의 표기

팬 각 \(\gamma\)의 부호 규약이 10장과 반대인 문헌에서는 \(\gamma_m - \gamma\)와 \(\gamma_m + \gamma\)가 서로 바뀌어 나타납니다. 또 \(\tfrac{1}{2}\)을 가중에 넣는지 따로 곱하는지, 선원 각을 어디에서 시작해 재는지도 문헌마다 다릅니다. 다른 책의 식을 가져올 때는 10장의 짝 \((\beta + \pi + 2\gamma,\ -\gamma)\)에서 두 가중의 합이 1이 되는지를 먼저 확인합니다.

세 구간의 도출

페이지 4의 식은 10장 페이지 8의 구성에서 경사 \(f\)를 정하면 나옵니다. 구간별로 무엇이 정해지고 무엇이 선택인지 나누어 봅니다.

구간 2: 한 번만 측정되는 광선

구간 2의 광선은 짝이 스캔 범위 밖에 있습니다(10장 페이지 3). 측정하지 않은 광선의 가중은 0이므로 원리 1의 \(w + w' = 1\)에서 \(w = 1\)이 됩니다. 이 구간에는 선택의 여지가 없습니다.

구간 1과 3: 경사 \(f\)의 조건

구간 1에서 \(w = f(\lambda)\), 구간 3에서 \(w = f(\lambda')\)이고, 구간 1의 광선과 짝인 구간 3의 광선은 \(\lambda' = 1 - \lambda\)입니다(10장 페이지 8). 이때 \(f\)가 만족할 조건은 다음과 같습니다.

조건이유
(가) \(f(0) = 0\)삼각형의 스캔 가장자리 변(구간 1은 \(\beta = 0\), 구간 3은 \(\beta = B\))에서 가중이 스캔 밖의 0과 이어집니다.
(나) \(f(1) = 1\)빗변에서 구간 2의 1과 이어집니다.
(다) \(f(\lambda) + f(1 - \lambda) = 1\)짝의 가중 합이 1입니다(원리 1).
(라) \(f'(0) = f'(1) = 0\)스캔 밖과 구간 2는 가중이 평탄하므로, 경계에서 기울기까지 이어지게 하는 조건입니다. 구간 1에서 \(\partial w/\partial\beta = f'(\lambda)/(2(\gamma_m - \gamma))\)이므로 \(f'(0) = f'(1) = 0\)이면 \(\beta\) 방향 기울기가 0으로 이어집니다.

(가)~(다)는 가중이 점프 없이 이어지고 합이 1이 되기 위한 조건이고, (라)는 기울기까지 이어지기 위한 추가 조건입니다.

\(\sin^{2}\)의 선택

(다)는 \(f(\lambda) - \tfrac{1}{2}\)이 \(\lambda = \tfrac{1}{2}\)을 중심으로 홀함수라는 뜻입니다. 가장 간단한 삼각함수 홀함수 \(\tfrac{1}{2}\sin(\pi(\lambda - \tfrac{1}{2}))\)를 쓰면 다음과 같습니다.

\[f(\lambda) = \tfrac{1}{2} + \tfrac{1}{2}\sin\!\left(\pi\left(\lambda - \tfrac{1}{2}\right)\right) = \tfrac{1}{2}\bigl(1 - \cos\pi\lambda\bigr) = \sin^{2}\!\left(\frac{\pi\lambda}{2}\right)\]

이 \(f\)에 \(\lambda = \beta/(2(\gamma_m - \gamma))\)를 넣으면 구간 1의 \(\sin^{2}\!\left(\tfrac{\pi}{4}\,\beta/(\gamma_m - \gamma)\right)\)이고, \(\lambda' = (\pi + 2\gamma_m - \beta)/(2(\gamma_m + \gamma))\)를 넣으면 구간 3의 식입니다. 두 식은 페이지 4의 식과 같습니다.

\(\sin^{2}(\pi\lambda/2)\)가 조건 (가)~(라)를 만족하는 이유
  1. (가) \(f(0) = \sin^{2} 0 = 0\)입니다.
  2. (나) \(f(1) = \sin^{2}(\pi/2) = 1\)입니다.

합이 1임과 연속성의 확인

Parker 가중이 10장의 두 원리를 만족하는지 구간별로 확인합니다.

짝의 합

  • 구간 1과 구간 3. 구간 1의 광선 \((\gamma, \beta)\)의 짝은 구간 3에 있고 \(\lambda' = 1 - \lambda\)입니다(10장 페이지 8). 그러므로 \(w + w' = \sin^{2}(\pi\lambda/2) + \sin^{2}(\pi(1 - \lambda)/2) = \sin^{2} + \cos^{2} = 1\)입니다.
  • 구간 2. 짝이 스캔 밖에 있어 \(w' = 0\)이고 \(w = 1\)이므로 합이 1입니다.
  • 두 번 측정되는 광선은 모두 구간 1 또는 3에 있고, 한 번만 측정되는 광선은 구간 2에 있습니다(10장 페이지 3). 따라서 모든 광선에서 합이 1입니다.
\(\beta\)로 쓴 식으로 계산하기

구간 1의 광선 \((\beta, \gamma)\)의 짝은 \(\beta' = \beta + \pi + 2\gamma\), \(\gamma' = -\gamma\)입니다. 구간 3의 식에 넣으면 다음과 같습니다.

  1. \(\pi + 2\gamma_m - \beta' = 2(\gamma_m - \gamma) - \beta\)이고 \(\gamma_m + \gamma' = \gamma_m - \gamma\)입니다.
  2. 구간 3의 인수는 \(\tfrac{\pi}{4}\cdot\dfrac{2(\gamma_m - \gamma) - \beta}{\gamma_m - \gamma} = \tfrac{\pi}{2} - \tfrac{\pi}{4}\cdot\dfrac{\beta}{\gamma_m - \gamma}\)입니다. 구간 1의 인수를 \(a = \tfrac{\pi}{4}\,\beta/(\gamma_m - \gamma)\)로 두면 이 인수는 \(\tfrac{\pi}{2} - a\)입니다.
  3. \(w' = \sin^{2}(\tfrac{\pi}{2} - a) = \cos^{2} a\)이고 \(w = \sin^{2} a\)이므로 \(w + w' = 1\)입니다.

수치 확인

  • \(\gamma_m = 20^{\circ}\), \(B = 220^{\circ}\)의 스캔 범위 안에서 무작위 광선 40만 개를 골라 \(|w + w' - 1|\)의 최댓값을 구하면 \(8 \times 10^{-14}\)였습니다. 이 크기는 부동소수점 계산의 오차입니다.
  • 페이지 4의 세 구간 식과 10장의 \(\lambda\), \(f\)로 구성한 가중은 같은 40만 개에서 최대 \(1 \times 10^{-14}\) 차이였고, 세 구간 식만으로 구한 짝의 합도 \(10^{-13}\) 이내에서 1이었습니다.

한 번만 측정된 직선은 잡음을 평균하는 효과가 없습니다(10장 페이지 1, 4). 투영값마다 표준편차 \(\sigma = 0.02\)의 독립인 잡음을 더해 재구성하고(0편 2장 페이지 8에서 투영값의 잡음은 광선마다 다르지만 여기서는 같게 두었습니다), 같은 광선 잡음에서 한 바퀴(\(360^{\circ}\), 모두 \(\tfrac{1}{2}\))와 short scan(Parker)의 영상 잡음을 비교했습니다. 서로 다른 잡음 100번을 재구성해 머리 안쪽 화소의 표준편차를 구한 결과입니다.

잡음이 1.37배가 되는 이유

독립인 잡음에서 영상 한 점의 분산은 그 점에 기여하는 광선 가중의 제곱합에 비례합니다. 직선 하나로 보면 두 광선의 가중 \(w, w'\)에 대해 \(w^{2} + w'^{2}\)입니다.

  1. \(360^{\circ}\)에서 모든 직선은 \(w = w' = \tfrac{1}{2}\)이어서 \(w^{2} + w'^{2} = \tfrac{1}{2}\)입니다.
  2. short scan에서 한 번만 측정된 직선은 \(w = 1\), \(w' = 0\)이어서 값이 1이고, 한 바퀴의 \(\tfrac{1}{2}\)보다 2배입니다.
  3. 두 번 측정된 직선에서는 \(\lambda\)가 0에서 1까지 고르게 퍼지므로 \(\sin^{2}\) 가중의 평균은 \(\int_0^1 (\sin^{4}\tfrac{\pi\lambda}{2} + \cos^{4}\tfrac{\pi\lambda}{2})\,d\lambda = \tfrac{3}{4}\)이고, 한 바퀴의 \(\tfrac{1}{2}\)보다 1.5배입니다. \(w + w' = 1\)이면 \(w^{2} + w'^{2}\)는 \(w = \tfrac{1}{2}\)일 때 가장 작습니다.
  4. 한 번만 측정된 직선의 비율은 \((2\pi - B)/\pi\), 두 번 측정된 직선의 비율은 \((B - \pi)/\pi\)이므로(페이지 2) 분산의 비는 다음과 같습니다.

\[\frac{\sigma_{\text{short}}^{2}}{\sigma_{360}^{2}} \approx 2\cdot\frac{2\pi - B}{\pi} + 1.5\cdot\frac{B - \pi}{\pi}\]

\(B = 220^{\circ}\)에서 \(2(7/9) + 1.5(2/9) = 1.889\)이고 표준편차의 비는 \(\sqrt{1.889} = 1.374\)로, 관측한 1.37과 맞습니다. 이 식은 직선마다 기여의 크기가 같다고 둔 어림이며 위치에 따른 변화는 다루지 않습니다. 선형 램프에서는 평균이 \(\tfrac{2}{3}\)이어서 1.361, 관측은 1.355였습니다.

두 영상에서 읽을 점은 다음과 같습니다.

  • 잡음이 위치마다 다릅니다. 한 바퀴 스캔의 안쪽 상대 표준편차는 0.94에서 1.10으로 비교적 고르지만, short scan은 위치에 따라 1.14에서 1.69까지 다릅니다. 한 번만 측정되는 직선이 지나는 비율이 화소마다 다르기 때문입니다.
  • 같은 선량으로 비교하면 차이가 줄어듭니다. \(220^{\circ}\)는 선원 각의 수가 61%이므로 총 선량이 같으려면 선원 각마다 \(360/220\)배의 선량을 써야 하고, 투영값의 잡음 분산이 선량에 반비례한다면(0편 2장 페이지 8) 광선 잡음의 표준편차가 \(\sqrt{220/360} = 0.78\)배가 됩니다. 그러면 영상 잡음의 비는 \(1.37 \times 0.78 = 1.07\)입니다. 같은 광선 잡음에서 1.37배 중 1.28배는 선량의 차이이고 나머지 7%가 가중 때문입니다.

움직임

합이 1인 가중은 짝의 두 측정값을 가중 평균해서 영상에 넣는다는 뜻입니다. 물체가 가만히 있으면 두 값이 같아 평균도 그 값이지만, 움직이면 두 측정이 서로 다른 시점의 값이어서 평균이 어느 쪽 시점에도 맞지 않는 값이 됩니다. 짝의 선원 각 차이가 \(\pi + 2\gamma\)이므로 짝이 측정된 시간 간격은 \(\gamma_m = 20^{\circ}\)에서 \((\pi + 2\gamma)T/(2\pi)\)로 \(0.39\,T\)에서 \(0.61\,T\) 사이입니다. 가중이 급하게 바뀌는 곳에서는 이 불일치가 행 안의 점프로 이어져 램프 필터가 키웁니다. 움직이는 물체를 재구성해 보이지는 않고, 움직임이 있는 데이터의 가중 설계는 다루지 않습니다.

후속 연구와 일반화 가중

Parker 가중을 다시 살펴본 후속 논문으로 S. Wesarg, M. Ebert, T. Bortfeld, Parker weights revisited, Medical Physics 29(3), 2002, 372–378이 있습니다. 초록에 따르면 이 논문은 스캔 범위가 \(\pi + 2\gamma_m\)에서 \(2\pi\) 사이일 때 쓸 수 있는 가중의 부류를 유도하고, Parker 가중이 그 특수한 경우임을 보였습니다. 또 스캔 범위가 넉넉할 때는 중복 구간 대부분에 \(\tfrac{1}{2}\)을 주고 경계에서만 부드럽게 바꾸는 가중이 잡음 면에서 낫다고 제안했습니다. 같은 학술지 29권 8호 1916쪽의 같은 제목 글은 M. D. Harpen이 이 논문에 단 짧은 의견(Letter)입니다.

이 페이지의 가중은 같은 원리(짝의 합이 1이고 이어진다)를 스캔 범위 \(B\)가 \(\pi + 2\gamma_m\)보다 클 때로 넓혀 직접 유도한 것입니다. 위 논문의 일반화 가중을 구현한 공개 코드(ODL)와 비교하면, 경사 폭의 비율을 정하는 매개변수 \(q\)를 1로 둔 경우와 같습니다. 논문이 제안한 새 가중은 \(q < 1\)인 경우로, 중복 구간의 가운데가 \(\tfrac{1}{2}\)로 평평합니다.

두 번 측정되는 영역의 확장

\(\pi + 2\gamma_m \le B \le 2\pi\)일 때 광선 \((\beta, \gamma)\)와 짝 \((\beta + \pi + 2\gamma,\ -\gamma)\)가 둘 다 스캔 범위 \([0, B]\) 안에 있는 경우는 두 가지입니다.

  • 시작부. 짝의 선원 각 \(\beta + \pi + 2\gamma\)가 \(B\) 이하입니다. 곧 \(0 \le \beta \le B - \pi - 2\gamma\)입니다.
  • 끝부. 짝의 선원 각을 \(2\pi\)로 줄인 \(\beta - \pi + 2\gamma\)가 0 이상입니다. 곧 \(\pi - 2\gamma \le \beta \le B\)입니다.
  • 한 번만 측정되는 구간. \(B - \pi - 2\gamma < \beta < \pi - 2\gamma\)이며 \(w = 1\)입니다. 스캔하지 않는 광선은 \(w = 0\)입니다.

\(B = \pi + 2\gamma_m\)이면 시작부와 끝부가 10장의 삼각형이고 페이지 4의 식이 됩니다. 두 부분의 \(\lambda\)를 폭으로 나눈 위치로 정의하면 같은 구성이 이어집니다.

\[\lambda = \frac{\beta}{B - \pi - 2\gamma}\ \ (\text{시작부}),\qquad \lambda' = \frac{B - \beta}{B - \pi + 2\gamma}\ \ (\text{끝부}),\qquad w = f(\lambda)\ \text{또는}\ f(\lambda')\]

시작부 광선의 짝은 \(\beta' = \beta + \pi + 2\gamma\), \(\gamma' = -\gamma\)이므로 끝부에서 \(\lambda' = (B - \beta - \pi - 2\gamma)/(B - \pi - 2\gamma) = 1 - \lambda\)입니다. 그래서 \(f(\lambda) + f(1 - \lambda) = 1\)이면 \(w + w' = 1\)입니다. \(f = \sin^{2}(\pi\lambda/2)\)로 \(B = 220^{\circ}\)에서 \(360^{\circ}\)까지 여러 범위에서 무작위 광선 30만 개의 \(|w + w' - 1|\)을 재면 모두 \(10^{-13}\) 이내였고, 한 번만 측정되는 광선의 가중은 정확히 1이었습니다.

\(B = 300^{\circ}\)의 가중입니다. 시작부와 끝부의 폭이 \(\gamma\)에 따라 \(B - \pi \mp 2\gamma\)로 넓어지고, 가운데 한 번만 측정되는 띠(\(w = 1\))는 좁아집니다.

\(B = 360^{\circ}\)이면 띠가 사라지고 모든 직선이 두 번 측정되지만, 이 가중은 \(\tfrac{1}{2}\)이 아니라 0과 1 사이에서 바뀝니다.

시간 해상도와 가중의 관계

시간 해상도(Temporal Resolution)는 영상 한 장에 들어가는 데이터가 측정된 시간의 폭을 뜻합니다. 폭이 짧을수록 움직임에 덜 흐려집니다. 데이터를 모으는 시간 \(T\,B/(2\pi)\)가 그 폭의 상한인데, 가중이 0에 가까운 구간의 데이터는 영상에 거의 기여하지 않으므로 실제 폭은 가중에 따라 달라집니다.

가중을 고려한 시간 폭

화소 \((x, y)\)를 지나는 광선의 가중 \(w\)가 \(\tfrac{1}{2}\) 이상인 선원 각 구간의 폭을 시간 폭의 척도로 삼습니다(반값 폭). 이 척도는 이 장의 정의이고, 장치나 문헌이 말하는 시간 해상도와 정의가 같다고 가정하지 않습니다.

  • 회전 중심의 화소. 회전 중심을 지나는 광선은 모든 선원 각에서 \(\gamma = 0\)입니다. 구간 1에서 \(w = \tfrac{1}{2}\)인 곳은 \(\lambda = \tfrac{1}{2}\), 곧 \(\beta = \gamma_m\)이고, 구간 3에서는 \(\lambda' = \tfrac{1}{2}\)이므로 \(\beta = B - \gamma_m = \pi + \gamma_m\)입니다. 두 점의 간격은 \(\gamma_m\)에 관계없이 \(\pi\)이므로 반값 폭이 \(180^{\circ}\), 곧 \(T/2\)입니다.
  • 한 바퀴(모두 \(\tfrac{1}{2}\)). 모든 선원 각에서 \(w = \tfrac{1}{2}\)이므로 반값 폭이 \(360^{\circ}\), 곧 \(T\)입니다.

같은 척도로 보면 short scan은 회전 중심에서 시간 폭을 절반으로 줄입니다. 데이터를 모으는 시간은 \(0.61\,T\)이지만 가중이 반 이상인 구간은 \(0.5\,T\)입니다.

화소 위치에 따른 차이

회전 중심에서 벗어난 화소는 그 화소를 지나는 광선의 팬 각 \(\gamma_x(\beta)\)가 선원 각에 따라 바뀌므로, 반값이 되는 선원 각이 \(\beta = \gamma_m - \gamma_x(\beta)\)와 \(\beta = \pi + \gamma_m - \gamma_x(\beta)\)에서 정해져 중심과 달라집니다. 위 세 화소의 반값 폭은 \(180^{\circ}\), \(212.7^{\circ}\), \(158.3^{\circ}\)이고, 회전 시간이 \(T = 0.5\) s이면 \(0.25\) s, \(0.30\) s, \(0.22\) s입니다. 영상 한 장 안에서도 위치마다 시간 해상도가 다릅니다.

심장 CT의 개념

심장은 박동하므로 움직임이 작은 시점을 골라 그 시점 둘레의 짧은 시간 창에서 측정한 데이터로 재구성하고 싶습니다. 영상 한 장에 필요한 데이터는 적어도 short scan의 범위(\(180^{\circ}\)에 팬 전체의 각을 더한 범위)이므로, 시간 창이 이보다 짧으면 데이터가 완전하지 않습니다. 시간 창을 더 줄이려면 회전을 빠르게 하는 것처럼 장치 쪽의 문제이며 범위 밖입니다.

시간과 잡음은 서로 맞바꾸는 관계입니다. 스캔 범위를 \(B = 220^{\circ}\)에서 \(360^{\circ}\)로 늘리면 잡음이 1.37배에서 1.22배로 줄지만(페이지 9) 데이터를 모으는 시간은 \(0.61\,T\)에서 \(T\)로 늘어납니다.

  • 선형 램프의 곡선은 구간 경계에서 꺾입니다. \(\sin^{2}\)와 \(3\lambda^{2} - 2\lambda^{3}\)는 경계에서 곡선이 부드럽게 이어집니다(페이지 6).
  • \(\gamma\)를 바꾸면 곡선의 상승·하강 폭이 달라집니다. \(\gamma\)가 \(\gamma_m\)에 가까울수록 상승은 짧고 가파르며, 하강은 길고 완만합니다(페이지 8).
  • 짝의 곡선은 가중을 \(1\)에서 뺀 모양입니다. 한 곡선이 오르는 곳에서 다른 곡선이 내려옵니다.

11장 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. short scan은 선원을 \(B = \pi + 2\gamma_m\)만 돌리는 스캔입니다. 데이터를 모으는 시간과 선량은 \(B/(2\pi)\)에 비례하고(\(\gamma_m = 20^{\circ}\)에서 0.61), 한 번만 측정되는 직선의 비율은 \(1 - 2\gamma_m/\pi\)입니다. 가중 없이 줄이면 총 가중이 1이 아닌 직선의 밝기 오차(\(\tfrac{1}{2}\)에서 안쪽 rms 0.375)나 점프의 줄무늬(계단 가중 0.0735)가 생깁니다.
  2. Parker 가중은 10장의 구성에서 \(f(\lambda) = \sin^{2}(\pi\lambda/2)\)로 정한 것이며, 구간 1은 \(\sin^{2}\!\bigl(\tfrac{\pi}{4}\,\beta/(\gamma_m - \gamma)\bigr)\), 구간 2는 1, 구간 3은 \(\sin^{2}\!\bigl(\tfrac{\pi}{4}\,(\pi + 2\gamma_m - \beta)/(\gamma_m + \gamma)\bigr)\)입니다. \(f\)는 \(f(0) = 0\), \(f(1) = 1\), \(f(\lambda) + f(1 - \lambda) = 1\)과, 기울기를 잇는 \(f'(0) = f'(1) = 0\)을 만족합니다.
  3. 합이 1인 것은 \(\sin^{2} + \cos^{2} = 1\)로 확인되고, 두 꼭짓점을 빼면 경계에서 가중의 값과 기울기가 이어집니다. 기울기가 이어지는 \(\sin^{2}\), \(3\lambda^{2} - 2\lambda^{3}\), 5차 경사의 재구성은 \(\sin^{2}\)와 나머지 둘의 차이가 \(5 \times 10^{-5}\) 이하이고, 기울기가 꺾이는 선형 램프만 간격이 성길 때 오차가 더 큽니다.
  4. FBP에서는 \(w\)를 필터링 앞에서 \(R\,w\,c\)로 곱하고 각도 합에 \(\Delta\beta\)를 씁니다. 필터 뒤에 곱하면 오차가 50배 커집니다(0.0016에서 0.083).
  5. 한 번만 측정된 직선 때문에 같은 광선 잡음에서 영상 잡음이 한 바퀴의 1.37배이고 위치마다 다릅니다(같은 총 선량이면 1.07배). 회전 중심 화소의 가중이 \(\tfrac{1}{2}\) 이상인 선원 각 구간은 \(180^{\circ}\)(\(T/2\))입니다. 스캔 범위를 늘리면 잡음은 줄고 시간은 늘어납니다.

마무리 퀴즈 1

\(\gamma_m = 20^{\circ}\), 스캔 범위 \(220^{\circ}\)에서 광선 \((\beta, \gamma) = (20^{\circ},\ -10^{\circ})\)의 Parker 가중 \(w\)는 얼마일까요?

  1. 0.75
  2. 0.333
  3. 0.25
  4. 0.5

짝 \((180^{\circ},\ 10^{\circ})\)는 구간 3이고 \(\lambda' = (220 - 180)/(2 \times 30) = 2/3\)이므로 \(w' = \sin^{2}(60^{\circ}) = 0.75\)이며, \(0.25 + 0.75 = 1\)입니다. 같은 광선을 선형 \(f\)로 구하면 \(w = 1/3\), \(w' = 2/3\)로 합은 같지만 가중의 모양이 달라집니다.

마무리 퀴즈 2

경사 \(f = \sin^{2}(\pi\lambda/2)\)가 만족하는 성질로 알맞은 것은 무엇일까요?

  1. 짝의 합이 1이 되는 \(f\)가 \(\sin^{2}\) 하나뿐이다.
  2. 구간 경계에서 값은 이어지지만 기울기는 꺾이도록 만든다.
  3. \(f(\lambda)+f(1-\lambda)=1\)이고 양 끝의 기울기가 0이다.
  4. 재구성 영상의 오차를 다른 어떤 \(f\)보다도 작게 만든다.

선형 \(f\)도 합이 1이고 값이 이어지지만 기울기가 꺾입니다. 선원 각 간격을 \(2^{\circ}\)로 키운 실험(\(\Delta t = 0.01\) cm)에서 선형 램프의 안쪽 rms는 0.0038, \(\sin^{2}\)는 0.0013이었습니다. 기울기 연속은 간격이 성길 때 오차를 줄이는 조건입니다.

마무리 퀴즈 3

\(\gamma_m = 30^{\circ}\), \(B = 240^{\circ}\)에서 회전 중심 화소를 지나는 광선의 가중이 \(\tfrac{1}{2}\) 이상인 선원 각 구간의 폭은 얼마일까요?

  1. \(240^{\circ}\)
  2. \(210^{\circ}\)
  3. \(150^{\circ}\)
  4. \(180^{\circ}\)

반값 폭은 \(\gamma_m\)이 달라도 \(\pi\)로 같습니다. 구간 1의 반값 위치가 \(\gamma_m\)이고 구간 3의 것이 \(\pi + \gamma_m\)이기 때문입니다. 회전 시간 \(T\)에서 \(T/2\)이며, 회전 중심에서 벗어난 화소는 \(\gamma\)가 선원 각에 따라 바뀌어 폭이 달라집니다.

마무리 퀴즈 4

투영값 하나하나의 잡음이 같을 때 short scan(Parker 가중) 영상이 한 바퀴(모두 \(\tfrac{1}{2}\)) 영상보다 잡음이 큰 이유로 알맞은 것은 무엇일까요?

  1. 측정한 선원 각이 적어 투영값 하나의 잡음이 커진다.
  2. 한 번만 측정된 직선은 평균하는 효과를 얻지 못한다.
  3. Parker 가중이 측정한 투영값마다 잡음을 더한다.
  4. 필터가 짧은 스캔에서 고주파를 더 크게 증폭한다.

\(220^{\circ}\)에서는 직선의 78%가 한 번만 측정되므로 분산비가 \(2 \times 0.78 + 1.5 \times 0.22 = 1.89\), 표준편차 비가 1.37입니다. 총 선량을 같게 맞추면 투영값 하나의 잡음이 \(\sqrt{220/360}\)배가 되어 비가 1.07로 줄어듭니다.

직접 해보기

  1. 팬 반각 \(\gamma_m = 25^{\circ}\)이고 회전 시간이 \(T = 0.4\) s입니다. (가) short scan의 스캔 범위 \(B\), (나) 데이터를 모으는 시간, (다) 광선마다 같은 선량으로 쏠 때 한 바퀴 대비 선량의 비, (라) 한 번만 측정되는 직선의 비율을 구하세요.
  2. \(\gamma_m = 20^{\circ}\), \(B = 220^{\circ}\)에서 광선 \((\beta, \gamma) = (30^{\circ},\ 0^{\circ})\)의 짝을 구하고, \(\sin^{2}\)와 선형 \(f\) 각각에서 두 광선의 가중과 합을 구하세요. 광선 \((150^{\circ},\ 10^{\circ})\)는 어느 구간인지도 쓰세요.
  3. \(B = 260^{\circ}\)(\(\gamma_m = 20^{\circ}\))에서 Parker형 \(\sin^{2}\) 가중의 영상 잡음 표준편차가 한 바퀴(모두 \(\tfrac{1}{2}\))의 몇 배일지 페이지 8의 식으로 예측하세요. 총 선량을 한 바퀴와 같게 맞추면 몇 배인지도 구하세요.
모범답안과 흔한 실수

1번. (가) \(B = 180^{\circ} + 2 \times 25^{\circ} = 230^{\circ}\)입니다. (나) \(0.4 \times 230/360 = 0.256\) s입니다. (다) 선량은 선원 각의 수에 비례하므로 \(230/360 = 0.639\)입니다. (라) \(1 - 2\gamma_m/\pi = 1 - 50/180 = 0.722\), 곧 72.2%이고 두 번 측정되는 직선이 27.8%입니다.

2번. 짝은 \((30^{\circ} + 180^{\circ} + 0^{\circ},\ 0^{\circ}) = (210^{\circ},\ 0^{\circ})\)입니다. \((30^{\circ},\ 0^{\circ})\)는 \(30 \le 2(20 - 0) = 40\)이므로 구간 1이고 \(\lambda = 30/40 = 0.75\)입니다. \(\sin^{2}\)에서 \(w = \sin^{2}(67.5^{\circ}) = 0.8536\)입니다. 짝은 \(210 \ge 180\)이므로 구간 3이고 \(\lambda' = (220 - 210)/(2 \times 20) = 0.25\), \(w' = \sin^{2}(22.5^{\circ}) = 0.1464\)이며 합은 1입니다. 선형 \(f\)에서는 \(w = 0.75\), \(w' = 0.25\)이고 합은 1입니다. \((150^{\circ},\ 10^{\circ})\)는 \(2(20 - 10) = 20 \le 150 \le 180 - 20 = 160\)이므로 구간 2이고 \(w = 1\), 짝 \((350^{\circ},\ -10^{\circ})\)는 스캔 범위 밖이어서 \(w' = 0\)입니다.

3번. 한 번만 측정되는 직선의 비율은 \((360 - 260)/180 = 5/9\), 두 번은 \(4/9\)입니다. 분산비는 \(2 \times 5/9 + 1.5 \times 4/9 = 1.778\)이고 표준편차 비는 \(\sqrt{1.778} = 1.333\)입니다(페이지 9의 표 관측 1.327). 총 선량이 같으면 투영값 잡음이 \(\sqrt{260/360} = 0.850\)배가 되어 \(1.333 \times 0.850 = 1.13\)입니다.

흔한 실수.

  • 1번 (가)에서 팬 반각을 한 번만 더해 \(205^{\circ}\)로 쓰는 것입니다. 팬 전체의 각 \(2\gamma_m = 50^{\circ}\)를 더해야 합니다.
  • 2번에서 \(\lambda\)를 선형 \(f\)에 넣어 \(\sin^{2}\)의 값을 0.75로 쓰는 것입니다. \(\sin^{2}\)는 \(f(0.75) = \sin^{2}(67.5^{\circ})\)입니다. 끝 삼각형의 \(\lambda'\)를 \(\beta'/(2(\gamma_m + \gamma'))\)로 구하는 실수도 흔합니다(\(B - \beta'\)를 써야 합니다).
  • 3번에서 분산비 1.778을 표준편차 비로 쓰는 것입니다. 제곱근을 취해야 합니다. 선량을 맞출 때 \(\sqrt{260/360}\)를 곱하지 않고 나누는 실수도 있습니다. 선원 각이 적은 쪽이 광선마다 선량을 더 쓰므로 잡음은 줄어듭니다.
