12장 · 페이지 1

검출기를 한쪽으로 밀어 놓으면? Displaced detector와 Wang weight

10장과 11장은 검출기가 물체 전체를 덮는다고 보고 선원을 얼마나 돌려야 하는지를 따졌습니다. 이 장에서는 선원을 한 바퀴 돌리되 검출기가 물체의 한쪽 일부만 덮는 경우를 다룹니다. 검출기를 한쪽으로 치우쳐 놓으면 같은 칸 수로 더 큰 물체를 찍을 수 있습니다. 이때 같은 직선을 두 번 잰 광선은 어디에 생기고, 가중은 어떻게 달라질까요?

검출기 폭과 시야

평면 검출기의 가상 검출기(Virtual Detector)는 회전 중심 O를 지나고 중심 광선(선원 S와 O를 잇는 광선)에 수직인 평면입니다. 그 위의 위치를 \(t\)로 쓰고, 칸 간격은 \(\Delta t\)입니다(9장 페이지 2). 검출기가 \(-t_{\max} \le t \le t_{\max}\)를 덮으면 팬 반각은 \(\gamma_m = \arctan(t_{\max}/D)\)이고, 선원이 어느 각에 있어도 팬 안에 들어오는 점은 O를 중심으로 반지름 \(D\sin\gamma_m\)인 원 안의 점입니다. 이 원이 시야(FOV)입니다(7장 페이지 4).

이 장의 예는 10장과 같은 평면 검출기 장치입니다. \(D = 3\) cm, 칸 간격 \(\Delta t = 0.02\) cm이고, 칸 수는 10장의 111칸(\(\gamma_m \approx 20^{\circ}\)) 대신 77칸으로 줄입니다. 대칭으로 놓으면 \(t_{\max} = 0.76\) cm, \(\gamma_m = 14.2^{\circ}\)이므로 시야의 반지름은 \(3\sin 14.2^{\circ} = 0.74\) cm입니다. Shepp-Logan 팬텀의 바깥 타원은 \(y\) 방향 반축이 0.92 cm여서(3장 페이지 4의 표) 머리의 위아래가 시야 밖으로 나갑니다. 시야 밖에 있는 물체의 일부는 그 부분을 지나는 직선이 측정되지 않으므로 재구성에 아티팩트가 생깁니다(절단).

검출기를 한쪽으로 옮기는 배치

칸 수를 늘리지 않고 시야를 넓히려면 검출기를 중심 광선에서 한쪽으로 옮겨 놓으면 됩니다. 중심 광선이 검출기의 한쪽 끝 가까이에 닿게 치우쳐 놓은 배치를 오프셋 검출기(Displaced Detector)라고 합니다. 중심 광선이 검출기의 끝에 닿아 팬의 절반만 측정하는 극단의 배치는 half-beam이라고 부릅니다.

가상 검출기 위에서 오프셋 검출기는 \(-t_o \le t \le t_{\max}\)를 덮습니다. \(t_o\)는 중심 광선에서 짧은 쪽 끝까지의 거리, \(t_{\max}\)는 긴 쪽 끝까지의 거리이고 \(0 \le t_o \le t_{\max}\)입니다. \(t_o = t_{\max}\)이면 대칭 검출기, \(t_o = 0\)이면 half-beam입니다. 각으로 쓰면 \(\gamma_o = \arctan(t_o/D)\), \(\gamma_m = \arctan(t_{\max}/D)\)입니다.

같은 글자 다른 뜻

이 장의 \(\gamma_m\)은 10장과 같이 팬 반각이지만, 대칭 검출기가 아니므로 긴 쪽의 반각을 가리킵니다. 짧은 쪽의 반각은 \(\gamma_o\)로 따로 씁니다.

9장 페이지 9의 오프셋과 구분

9장 페이지 9의 \(\delta\)는 중심 광선이 중심 칸에서 칸 몇 개만큼 벗어난 알 수 없는 어긋남이었고, 보정하지 않으면 경계가 번지는 아티팩트를 만들었습니다. 이 장의 \(t_o\)는 일부러 정한 값입니다. 장치의 배치로 알려져 있으므로 칸 위치 \(t_n\)에 그대로 넣고, 중복 구간의 가중을 정하는 데 씁니다.

이 장의 진행

  1. 오프셋 검출기의 시야와 필요한 스캔 범위를 정합니다(페이지 2).
  2. 같은 직선을 두 번 잰 광선이 어디에 생기는지 \(\beta\)–\(\gamma\) 평면과 직선의 공간에서 찾습니다(페이지 3~4).
  3. 가중이 만족할 조건을 세워 Wang 가중을 정하고(페이지 5), FBP에 끼워 확인합니다(페이지 6).
  4. Parker 가중과 비교하고(페이지 7), 이득과 한계를 짚은 뒤(페이지 8), 위젯으로 확인합니다(페이지 9).

시야의 확장과 스캔 범위

검출기를 옮기면 달라지는 것은 시야의 크기와 필요한 스캔 범위입니다.

시야의 크기

선원이 한 바퀴 도는 동안 긴 쪽 팬의 가장자리 광선(\(\gamma = \gamma_m\))은 O에서 \(D\sin\gamma_m\)만큼 떨어진 직선들을 모두 지납니다. 반지름 \(D\sin\gamma_m\)인 원 안을 지나는 직선은 \(|\gamma| \le \gamma_m\)이므로, 짝 가운데 하나는 \(0 \le \gamma \le \gamma_m\)에서 측정됩니다. 7장의 시야는 모든 선원 각에서 팬 안에 들어오는 원인데, 오프셋 검출기에서 그 원은 반지름 \(D\sin\gamma_o\)인 안쪽 원입니다. 이 장에서는 모든 직선이 적어도 한 번 측정되는 원을 시야로 보고, 반지름을 \(s_m = D\sin\gamma_m\)으로 씁니다. 식은 대칭 검출기와 같고, 같은 칸 수에서 달라지는 것은 \(\gamma_m\)이 커진다는 점입니다.

한 바퀴가 필요한 이유

11장의 short scan은 선원 각을 \(\pi + 2\gamma_m\)만 돌렸지만 오프셋 검출기에서는 한 바퀴가 필요합니다. 10장 페이지 2의 짝은 \((\beta, \gamma) \leftrightarrow (\beta + \pi + 2\gamma,\ -\gamma)\)이므로, \(\gamma > \gamma_o\)인 광선의 짝은 \(-\gamma < -\gamma_o\)여서 검출기 밖에 있습니다. 이런 직선은 광선 하나로만 측정됩니다. 그 광선의 선원 각은 직선이 정합니다. 팬 각이 \(\gamma\)인 직선의 방향 \(\theta\)가 \(0\)에서 \(2\pi\)까지 모두 있으므로 이 광선의 선원 각 \(\beta = \theta - \gamma\)도 \(0\)에서 \(2\pi\)까지 모두 필요합니다.

스캔 범위가 \(B < 2\pi\)이면 한 번만 측정되는 직선의 \((2\pi - B)/(2\pi)\)가 측정되지 않습니다(두 번 측정되는 직선도 두 광선이 모두 범위 밖이면 빠집니다). \(t_o = 0.30\) cm, \(t_{\max} = 1.22\) cm에서 시야 안의 직선(\(|s| \le s_m\)) 40만 개를 무작위로 골라 두 교점에서 나가는 광선이 검출기에 들어오는지 직접 센 결과, \(B = 220^{\circ}\)에서 28.6%, \(B = 300^{\circ}\)에서 12.3%의 직선이 한 번도 측정되지 않았습니다. 10장 페이지 6와 같이 측정되지 않은 직선은 가중으로 채울 수 없습니다.

short scan과 함께 쓰는 경우

한 바퀴를 도는 오프셋 검출기는 스캔 범위를 \(\pi + 2\gamma_m\)으로 줄여 시간과 선량을 아끼는 11장의 이득을 얻지 못합니다. 두 배치를 함께 쓰는 경우는 다루지 않습니다.

중복 광선이 생기는 위치

한 바퀴 스캔에서는 선원 각 \(\beta\)가 \(0\)~\(2\pi\)를 모두 지나므로, 광선 \((\beta, \gamma)\)의 짝 \((\beta + \pi + 2\gamma,\ -\gamma)\)는 선원 각 \(\beta + \pi + 2\gamma\)에 \(2\pi\)를 더하거나 빼서 \(0\)~\(2\pi\) 안에 두면 항상 측정 범위에 들어갑니다. 짝이 측정되는지는 팬 각 \(-\gamma\)가 검출기 안에 있는지에만 달려 있습니다. \(t = D\tan\gamma\)는 \(\gamma\)에 대해 증가하는 홀수 함수이므로, 위치 \(t\)의 짝은 위치 \(-t\)에 있습니다. 광선을 세 영역으로 나눌 수 있습니다.

10장 페이지 3과의 차이

short scan의 중복 영역은 삼각형 둘이어서 선원 각에 따라 중복 광선의 팬 각 범위가 달라졌습니다. 오프셋 검출기에서는 중복 영역이 \(\gamma\) 방향의 폭 \(2\gamma_o\)인 세로 띠이고 선원 각과 무관합니다. 짝 변환 \((\gamma, \beta) \mapsto (-\gamma,\ \beta + \pi + 2\gamma)\)는 띠를 \(\gamma = 0\)에 대해 뒤집고 \(\beta\)를 옮기므로 띠 안의 점은 띠 안의 점으로만 옮겨지고, 띠 밖의 점은 짝이 검출기가 덮는 범위 밖에 있습니다.

표의 판정이 맞는지는 직선과 선원 궤도의 두 교점을 직접 구해 확인했습니다. 시야 안의 직선 40만 개마다 두 교점의 선원 각과 팬 각을 구했습니다. 그중 \(t = D\tan\gamma\)가 \([-0.30,\ 1.22]\)에 드는 광선의 수를 세었습니다. 이 수가 위 표의 판정(\(|t| \le t_o\)이면 2, 아니면 1)과 다른 직선은 없었습니다.

팬 각 \(\gamma\)인 광선이 지나는 직선과 O 사이의 거리는 \(|s| = D\sin|\gamma|\)입니다(7장 페이지 4). 짝은 \(\gamma\)의 부호만 바뀌므로 같은 \(|s|\)를 가집니다. 따라서 \(|\gamma| \le \gamma_o\)는 \(|s| \le s_o\)와 같은 조건이고, \(s_o = D\sin\gamma_o\)로 둡니다.

가중의 조건

10장 페이지 8의 두 원리를 이 배치에 적용합니다. 원리 1은 짝의 가중 합이 1이라는 것이고, 원리 2는 광선의 위치에 따라 가중이 끊김 없이 변해야 한다는 것입니다. 페이지 3의 세 영역에서 가중이 만족할 조건은 다음과 같습니다.

  • \(t < -t_o\). 측정하지 않은 광선이므로 \(w = 0\)입니다.
  • \(t > t_o\). 짝이 검출기 밖에 있어 \(w' = 0\)이므로, 합이 1이려면 \(w = 1\)입니다.
  • \(-t_o \le t \le t_o\). 짝이 \(-t\)에 있으므로 \(w(t) + w(-t) = 1\)입니다.
  • 점프 없음. 필터링은 한 선원 각의 행 안에서 이루어지므로(10장 페이지 7) \(t\) 방향으로 점프하는 가중은 줄무늬를 만듭니다. 그러므로 \(w(-t_o) = 0\), \(w(t_o) = 1\)이어서 바깥의 0, 1과 이어져야 합니다.

짝의 위치가 모든 선원 각에서 \(-t\)이므로 가중은 선원 각 \(\beta\)에 의존하지 않고 검출기 위치 \(t\)만으로 정해집니다. 11장의 Parker 가중이 \(\beta\)와 \(\gamma\) 둘의 함수였던 것과 다릅니다.

조건을 만족하는 구성

겹침 구간 안의 위치를 팬 각으로 잽니다. 위치 \(t\)인 광선의 팬 각은 \(\gamma = \arctan(t/D)\)이고(페이지 3의 \(t = D\tan\gamma\)), 겹침 구간 \(|t| \le t_o\)는 \(|\gamma| \le \gamma_o\)입니다(\(\gamma_o = \arctan(t_o/D)\), 페이지 1). 이 구간 안의 위치를 다음 \(\lambda\)로 나타냅니다.

\[\lambda = \frac{\gamma + \gamma_o}{2\gamma_o}, \qquad \gamma = \arctan\frac{t}{D}\]

\(\lambda\)는 \(t = -t_o\)(\(\gamma = -\gamma_o\))에서 0, \(t = t_o\)(\(\gamma = \gamma_o\))에서 1입니다. 짝 광선은 \((\beta + \pi + 2\gamma,\ -\gamma)\)여서 팬 각이 \(-\gamma\)이므로 짝에서는 \(\lambda = 1 - \lambda\)가 됩니다. \(\arctan\)이 홀수 함수여서 팬 각의 짝 관계 \(\gamma \leftrightarrow -\gamma\)는 위치의 짝 관계 \(t \leftrightarrow -t\)와 같은 대칭입니다. 그래서 위에서 \(t\)로 세운 조건을 \(\gamma\)로 그대로 옮길 수 있습니다. 10장 페이지 8의 경사 함수 \(f\)로 \(w = f(\lambda)\)를 두면 다음이 성립합니다. 경사 함수는 \(f(0) = 0\), \(f(1) = 1\), \(f(\lambda) + f(1 - \lambda) = 1\)을 만족하는 함수입니다.

  • 합이 1입니다. \(w(t) + w(-t) = f(\lambda) + f(1 - \lambda) = 1\)입니다.
  • 가중이 이어집니다. \(w(-t_o) = f(0) = 0\), \(w(t_o) = f(1) = 1\)입니다.

\(\lambda\)를 \(t\)에 비례하게, 곧 \((t + t_o)/(2t_o)\)로 두어도 짝에서 \(1 - \lambda\)가 되므로 두 원리는 똑같이 성립합니다. 이 장에서는 아래의 Wang 가중과 같은 형태가 되도록 팬 각으로 잽니다.

Wang 가중

경사를 \(f(\lambda) = \sin^{2}(\pi\lambda/2)\)로 정한 가중을 Wang 가중(Wang Weight)이라고 하겠습니다. 이 경사는 11장의 Parker 가중(Parker Weight)과 같습니다.

\[ w(t) = \begin{cases} 0, & t < -t_o\\[1mm] \sin^{2}\!\left(\dfrac{\pi}{4}\,\dfrac{\gamma + \gamma_o}{\gamma_o}\right) = \dfrac{1}{2}\left[1 + \sin\!\left(\dfrac{\pi}{2}\,\dfrac{\gamma}{\gamma_o}\right)\right], & -t_o \le t \le t_o\\[2mm] 1, & t > t_o \end{cases} \qquad \gamma = \arctan\frac{t}{D},\quad \gamma_o = \arctan\frac{t_o}{D} \]

  • \(t\)는 가상 검출기 위의 위치(cm), \(t_o\)는 중심 광선에서 짧은 쪽 끝까지의 거리, \(D\)는 선원과 회전 중심 사이의 거리입니다. 가운데 줄은 \(\tfrac{\pi}{2}\lambda = \tfrac{\pi}{4}(\gamma + \gamma_o)/\gamma_o\)이므로 \(\sin^{2}(\pi\lambda/2)\)와 같습니다.
  • 기울기는 \(\dfrac{dw}{dt} = \dfrac{\pi}{4\gamma_o}\sin(\pi\lambda)\,\dfrac{D}{D^{2} + t^{2}}\)로 \(t = \pm t_o\)에서 0이고 \(t = 0\)에서 최대 \(\pi/(4D\gamma_o)\)입니다. \(D = 3\) cm, \(t_o = 0.30\) cm이면 최댓값은 \(2.63\ \mathrm{cm}^{-1}\)입니다.
  • 선원 각 \(\beta\)에는 의존하지 않습니다.

G. Wang은 검출기 배열을 회전 중심에서 한쪽으로 옮겨 시야를 넓히는 마이크로 CT를 제안했습니다(G. Wang, X-ray micro-CT with a displaced detector array, Medical Physics 29(7), 2002, 1634–1636). 위 식은 10장의 두 원리로 직접 도출한 것이고, Wang의 가중을 옮겨 적은 후속 논문(K. S. Sharma 외, Interior micro-CT with an offset detector, Medical Physics 41(6), 2014, 061915)의 식과 같은 형태입니다. 그 논문은 측정하는 쪽을 음의 쪽에 두고, 회전 중심 위치로 환산한 검출기 좌표 \(s\)와 겹침 반폭 \(\Theta\)로 겹침 구간의 가중을 \(\tfrac{1}{2}\bigl[1 - \sin\bigl(\pi\arctan(s/D) / (2\arctan(\Theta/D))\bigr)\bigr]\)로 적습니다. 이 장의 가상 검출기도 회전 중심을 지나므로(페이지 1) \(s = -t\), \(\Theta = t_o\)로 바꾸면 위 가운데 줄과 같습니다.

합이 1, ½[1 + sin] 꼴, 기울기의 전개

짝의 \(\lambda\). 짝의 팬 각은 \(-\gamma\)이므로 \(\lambda(-\gamma) = (-\gamma + \gamma_o)/(2\gamma_o) = 1 - (\gamma + \gamma_o)/(2\gamma_o) = 1 - \lambda(\gamma)\)입니다. 짝의 위치 \(-t\)의 팬 각은 \(\arctan(-t/D) = -\arctan(t/D) = -\gamma\)이므로 위치로 보아도 같습니다.

합이 1. \(\sin^{2}\bigl(\tfrac{\pi}{2}(1 - \lambda)\bigr) = \cos^{2}\bigl(\tfrac{\pi}{2}\lambda\bigr)\)이므로 \(w(t) + w(-t) = \sin^{2}(\tfrac{\pi}{2}\lambda) + \cos^{2}(\tfrac{\pi}{2}\lambda) = 1\)입니다.

½[1 + sin] 꼴. \(\sin^{2}x = \tfrac{1}{2}(1 - \cos 2x)\)에 \(2x = \pi\lambda = \tfrac{\pi}{2} + \tfrac{\pi}{2}\,\gamma/\gamma_o\)를 넣으면 \(\cos(\tfrac{\pi}{2} + a) = -\sin a\)이므로 \(w = \tfrac{1}{2}\bigl[1 + \sin(\tfrac{\pi}{2}\gamma/\gamma_o)\bigr]\)입니다. 이 꼴에서도 \(\sin\)이 홀수 함수여서 짝의 합이 1임이 바로 보입니다.

기울기. 연쇄 법칙으로 \(\dfrac{dw}{dt} = \dfrac{dw}{d\lambda}\,\dfrac{d\lambda}{d\gamma}\,\dfrac{d\gamma}{dt}\)이고 각 항은 다음과 같습니다.

\[\frac{dw}{d\lambda} = \frac{\pi}{2}\sin(\pi\lambda), \qquad \frac{d\lambda}{d\gamma} = \frac{1}{2\gamma_o}, \qquad \frac{d\gamma}{dt} = \frac{D}{D^{2} + t^{2}}\]

곱하면 \(\dfrac{dw}{dt} = \dfrac{\pi}{4\gamma_o}\sin(\pi\lambda)\,\dfrac{D}{D^{2} + t^{2}}\)입니다. \(t = \pm t_o\)에서 \(\lambda = 0, 1\)이어서 \(\sin(\pi\lambda) = 0\)이므로 기울기가 0입니다. \(\sin(\pi\lambda)\)는 \(\lambda = \tfrac{1}{2}\)(\(t = 0\))에서 최대 1이고 \(D/(D^{2} + t^{2})\)도 \(t = 0\)에서 최대 \(1/D\)이므로, 두 인자가 같은 곳에서 최대가 되어 최대 기울기는 \(t = 0\)에서 \(\pi/(4D\gamma_o)\)입니다. \(t_o \ll D\)이면 \(D\gamma_o \approx t_o\)여서 \(\pi/(4t_o)\)에 가깝습니다(\(t_o = 0.30\) cm에서 2.63과 2.62).

\(t\)에 비례하게 둔 \(\lambda\)와의 차이. 이 장의 장치에서는 \(|t|/D \le 0.1\)이어서 \(\gamma\)가 \(t\)에 거의 비례합니다. \(\lambda\)를 \((t + t_o)/(2t_o)\)로 둔 \(\sin^{2}\) 경사와 위 가중의 차이는 \(D = 3\) cm, \(t_o = 0.30\) cm에서 0.0008 미만, \(t_o = 0.60\) cm에서 0.003 미만입니다.

2π 데이터의 가중으로 보기

측정하지 않은 짧은 쪽(\(t < -t_o\))에 \(w = 0\)을 준 것은 검출기가 짧아서 어쩔 수 없이 비운 자리가 아닙니다. 검출기가 대칭으로 \(-t_{\max} \le t \le t_{\max}\) 전체를 덮는다고 생각해 보면, \(t > t_o\)에서는 \(w(t) = 1\)이고 짝 \(w(-t) = 0\)이며, 겹침 구간에서는 \(\sin^{2} + \cos^{2} = 1\)입니다. 그러므로 이 가중은 대칭으로 넓힌 검출기 전체에서 짝의 가중 합이 1이 되는 가중과 글자까지 같습니다. 짧은 쪽에는 애초에 측정값이 없습니다. 이 자리에 가중 0을 주면, 가중이 0이라서 결과가 0인 것과 측정값이 없어서 0인 것이 결과에서 구분되지 않습니다(페이지 6의 의사코드 8행처럼, 가중이 0이면 \(R\)이 무엇이든 0이 됩니다). 그러므로 이 방법을 "검출기(투영)가 좁다"는 식으로 볼 게 아니라, "\(2\pi\)로 찍은 데이터 가운데 측정 범위 밖은 0, 중복 구간은 매끄럽게 비균일하게 가중한 것"으로 볼 수 있습니다.

\(2\pi\)로 찍은 데이터를 합치는 가중은 유일하지 않습니다. 전체에 똑같이 \(\tfrac{1}{2}\)을 곱할 수도 있고(8장 페이지 2), Wang 가중처럼 중복 구간만 매끄럽게 비균일하게 가중할 수도 있습니다. 둘 다 10장 페이지 8의 두 원리 — 짝의 가중 합이 1이고, 가중이 끊김 없이 변함 — 을 만족하는 서로 다른 선택입니다.

12장 · 페이지 6

FBP에 끼우기

10장 페이지 6의 규약을 그대로 따릅니다. 가중 \(w\)는 광선에만 의존하므로 코사인 가중과 같이 필터링 앞에서 곱하고(\(\tilde R = R\,w\,c\)), 각도 합의 상수는 \(\Delta\beta = 2\pi/N_\beta\)입니다. \(\tfrac{1}{2}\)은 \(w\)에 들어 있으므로 따로 곱하지 않습니다. 11장과 다른 점은 둘입니다. \(w\)가 \(\beta\)와 무관하므로 선원 각 반복 밖에서 한 번만 계산하고, 필터링하는 행이 검출기 밖까지 넓어집니다.

필터링 행의 확장

램프 커널로 컨볼루션한 결과가 원래 투영보다 넓어지는 것은 늘 있는 일입니다. 원인은 램프 커널이 먼 칸까지도 0이 아닌 값을 갖는다는 것이고, 6장 페이지 5와 9장 페이지 3의 \(M \ge 2N_t - 1\) 조건도 같은 사실에서 나옵니다. 원형 컨볼루션에서는 이 퍼짐이 배열 반대쪽 끝과 섞이지 않아야 하므로 배열 길이를 그만큼 늘리지만, 늘어난 자리의 값 자체는 쓰지 않고 버립니다(위의 제로 패딩). 보통의 대칭 검출기에서도 \(q\)는 측정한 칸 밖에서 0이 아니지만, 그 구간이 가리키는 값은 시야(FOV) 바깥의 것이어서(5장 페이지 10~11의 검출기 반폭과 시야의 관계) 마찬가지로 무시해도 됐습니다. 그런데 이 장에서는 짧은 쪽으로 퍼지는 구간이 시야 안쪽 화소를 가리키므로, 이번에는 무시할 수 없고 반드시 채워 넣어야 합니다.

\(t < -t_o\)에서 \(w = 0\)이므로 가중을 곱한 \(\tilde R\)는 그 구간에서 0입니다. 그러나 램프 커널은 멀리까지 값이 있어서 필터링한 \(q\)는 그 구간에서 0이 아닙니다. 시야 안의 화소(반지름 \(r \le s_m\))가 선원 각마다 투영되는 위치는 \(|t'| \le D\tan(\arcsin(r/D)) \le t_{\max}\)이므로 음의 쪽으로 \(-t_{\max}\)까지 갈 수 있습니다. 그 화소는 측정하지 않은 구간의 \(q\)를 읽어야 합니다.

그래서 짧은 쪽에 0인 칸을 더해 행을 \(-t_{\max} \le t \le t_{\max}\)로 대칭으로 넓히고, 넓힌 행 전체에서 컨볼루션과 읽기를 합니다. 더하는 칸 수는 \(P = N_t - 1 - 2n_c\)이고, \(n_c = t_o/\Delta t\)는 \(t = 0\)인 칸의 번호입니다. 칸을 더하지 않고 측정한 칸에서만 \(q\)를 읽으면 \(t' < -t_o\)로 투영되는 화소가 그 선원 각의 기여를 받지 못합니다(아래 표의 마지막 줄).

9장의 제로 패딩과 구분

9장 페이지 3의 제로 패딩(Zero Padding)은 FFT로 컨볼루션할 때 원형 컨볼루션이 되지 않도록 길이를 \(M \ge 2N_t - 1\)로 늘리는 것이었습니다. 여기서 칸을 더하는 목적은 화소가 읽을 위치를 덮는 것입니다. FFT를 쓰면 두 가지가 모두 필요하고, 넓힌 행의 길이 \(N_e\)로 \(M \ge 2N_e - 1\)을 잡습니다.

잡음비 어림식의 유도

독립인 잡음에서 영상 한 점의 분산은 그 점에 기여하는 광선 가중의 제곱합에 비례합니다(11장 페이지 8). 직선 하나로 보면 두 광선의 가중 \(w, w'\)에 대해 \(w^{2} + w'^{2}\)입니다. 기준(모두 \(\tfrac{1}{2}\))은 모든 직선에서 \(\tfrac{1}{2}\)입니다. 오프셋에서는 한 번만 측정된 직선이 1이고, 겹침 직선은 \(w(s)^{2} + (1 - w(s))^{2}\)입니다.

반경 \(r\)인 화소를 지나는 직선은 \(|s| = r\sin\varphi\)(\(\varphi\)는 \(0\)~\(\pi\)에 고르게 분포)이므로 분산비는 다음과 같이 어림됩니다. 가중에 넣을 팬 각은 직선의 \(s\)에서 \(\gamma = \arcsin(s/D)\)로 구합니다(\(t = D\tan\gamma\)).

\[\frac{\sigma_{\text{offset}}^{2}}{\sigma_{\text{ref}}^{2}} \approx 2\,\Bigl\langle\, w^{2} + w'^{2} \,\Bigr\rangle_{\varphi}\]

\(r = 0.05,\ 0.2,\ 0.4,\ 0.6,\ 0.8\) cm에서 이 식의 표준편차 비는 1.017, 1.19, 1.324, 1.356, 1.371로 표의 100번 평균(1.03, 1.21, 1.32, 1.35, 1.37)과 맞습니다. 이 식은 거리 가중과 필터의 상관을 무시한 어림이고 절대 크기는 맞지 않아 비만 씁니다.

반경이 \(s_o\)보다 크고, 겹침 직선의 \(w^{2} + w'^{2}\)를 \(\int_0^1(\sin^{4}\tfrac{\pi\lambda}{2} + \cos^{4}\tfrac{\pi\lambda}{2})\,d\lambda = \tfrac{3}{4}\)로 어림하면 겹침 직선의 비율 \(\rho\)에 대해 분산비는 \(2[\tfrac{3}{4}\rho + (1 - \rho)]\)입니다. \(r = 0.6\) cm에서 \(\rho = 0.331\)이므로 1.834, 표준편차 비 1.354입니다.

이 비교는 광선당 잡음을 같게 두었을 뿐 선량을 맞춘 것이 아닙니다. 오프셋 스캔은 바깥 화소를 선원 각의 일부에서만 조사하므로 선량도 위치마다 다릅니다. 실제 장치의 잡음은 광선이 지나는 길이에 따라 다르므로(0편 2장 페이지 8) 중심을 지나는 광선의 잡음이 더 클 수 있습니다.

스캔 시간과 시야 밖

  • 스캔은 한 바퀴입니다. 시야가 같은 대칭 검출기는 칸이 더 필요하지만 short scan이 가능해 회전 시간과 선량이 \(224.3/360 = 0.62\)배입니다(\(\gamma_m = 22.13^{\circ}\), 11장). 오프셋 검출기는 칸 수를 늘리지 않는 대신 한 바퀴를 돌아야 합니다.
  • 시야 밖의 물체는 가중으로 고칠 수 없습니다. \(s_m\) 밖을 지나는 직선은 측정되지 않습니다(페이지 4).
  • 이 장은 2차원 팬빔만 다룹니다. 콘빔에서 같은 가중을 쓰는 방식은 14장에서 다룹니다.

오프셋 스캔 가중과 재구성 비교

겹침 폭 \(t_o\)(\(= n_c\Delta t\)), 가중의 종류, 필터링 행의 확장, 알 수 없는 오프셋 어긋남을 바꾸면서 가중 곡선과 재구성 영상을 비교합니다. 칸은 77개이고 \(n_c = 38\)이면 대칭 검출기입니다. 재구성은 \(D = 3\) cm, \(\Delta t = 0.02\) cm, \(1^{\circ}\) 간격, Ram-Lak, \(96 \times 96\) 화소의 Shepp-Logan 팬텀이며 조작할 때마다 브라우저에서 다시 계산합니다. 위젯에서 볼 수 있는 결과는 다음과 같습니다.

  • \(n_c = 15\), Wang, 행 확장, 어긋남 0에서는 영상에 줄무늬가 없고, 아래 곡선의 합 \(w(t) + w(-t)\)(점선)가 겹침 구간에서 1입니다.

12장 · 페이지 10

12장 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. 오프셋 검출기는 검출기를 중심 광선에서 한쪽으로 옮겨 같은 칸 수로 시야를 넓힙니다. 시야 반지름은 긴 쪽 반각 \(\gamma_m\)으로 \(s_m = D\sin\gamma_m\)입니다(77칸 예에서 대칭 0.74 cm, \(t_o = 0.30\) cm에서 1.13 cm). 한 바퀴가 필요하고 스캔 범위를 \(220^{\circ}\)로 줄이면(\(t_o = 0.30\) cm에서) 직선의 28.6%가 한 번도 측정되지 않아 가중으로 채울 수 없습니다.
  2. 중복 광선은 검출기의 \(|t| \le t_o\)(\(|\gamma| \le \gamma_o\)) 띠에만 생기고 선원 각과 무관합니다. 직선으로는 \(|s| \le s_o = D\sin\gamma_o\)가 두 번, \(s_o < |s| \le s_m\)이 한 번 측정되며, 반경 \(r\)인 화소를 지나는 직선 중 중복의 비율은 \(\tfrac{2}{\pi}\arcsin(\min(1, s_o/r))\)입니다.
  3. 가중의 조건은 \(t < -t_o\)에서 0, \(t > t_o\)에서 1, \(w(t) + w(-t) = 1\), 점프 없음입니다. 겹침 구간을 팬 각 \(\gamma = \arctan(t/D)\)로 잰 \(\lambda = (\gamma + \gamma_o)/(2\gamma_o)\)로 \(w = f(\lambda)\)를 두고 \(f = \sin^{2}(\pi\lambda/2)\)로 정한 것이 Wang 가중이며, Sharma 외(2014)가 옮겨 적은 Wang(2002)의 가중과 같은 형태입니다. 짝의 팬 각이 \(-\gamma\)여서 짝의 \(\lambda\)가 \(1 - \lambda\)이므로 합이 1입니다. 가중은 \(t\)(곧 \(\gamma\))만의 함수입니다.
  4. FBP에서는 \(\tilde R = R\,w\,c\)로 필터링 앞에서 곱하고 각도 합에 \(\Delta\beta\)를 씁니다. 행을 \(-t_{\max} \le t \le t_{\max}\)로 넓혀 필터링하고 읽어야 하며, 이 장의 예에서 안쪽 rms가 0.0017(대칭 77칸 0.286, 행 확장 없음 0.244)입니다.
  5. Parker 가중과 같은 원리(합이 1, 끊김 없음, 같은 \(f\))이고 중복이 생기는 기하가 다릅니다. 한계는 \(t_o\)를 줄일수록 가중이 가팔라지고 키울수록 시야가 줄어드는 것, 바깥 화소의 잡음이 한 바퀴 대칭 기준의 최대 1.37배인 것, 오프셋 어긋남에 오차가 비례하는 것(1칸에서 0.0199), 한 바퀴 스캔이 필요한 것입니다.

마무리 퀴즈 1

\(D = 3\) cm이고 검출기가 \(-0.4 \le t \le 1.4\) cm를 덮습니다. 시야 반지름 \(s_m\)은 얼마일까요?

  1. 1.40 cm
  2. 0.86 cm
  3. 1.27 cm
  4. 0.40 cm

이 배치에서 두 번 측정되는 직선의 비율은 \(s_o/s_m = 0.396/1.269 = 31.2\%\)입니다. 검출기 폭이 정해져 있으면 \(t_o\)가 커질수록 \(t_{\max}\)가 줄어 시야가 좁아집니다.

마무리 퀴즈 2

\(D = 3\) cm, \(t_o = 0.30\) cm인 Wang 가중에서 위치 \(t = 0.10\) cm인 광선의 가중 \(w\)는 얼마일까요?

  1. 0.667
  2. 0.249
  3. 1
  4. 0.751

선형 경사는 같은 위치에서 \(0.667\)과 \(0.333\)이고 합이 1입니다. 합이 1인 경사는 여러 가지이고 \(\sin^{2}\)는 그 가운데 양 끝의 기울기가 0인 것입니다. 이 장치에서는 \(\gamma\)가 \(t\)에 거의 비례해서 \(\lambda\)를 \((t + t_o)/(2t_o) = 2/3\)으로 어림해도 \(w = \sin^{2}(60^{\circ}) = 0.75\)로 0.001 안쪽에서 맞습니다.

마무리 퀴즈 3

오프셋 검출기에서 스캔 범위를 \(180^{\circ} + 2\gamma_m\)(이 장의 예에서 약 \(224^{\circ}\))로 줄이면 어떻게 될까요?

  1. 측정되지 않는 직선이 생겨 가중으로 채울 수 없다.
  2. 11장의 Parker 가중을 곱하면 모든 직선이 보정된다.
  3. 중복 구간이 넓어져 가중 없이 재구성할 수 있다.
  4. 시야는 줄어들지만 남은 데이터는 완전하다.

\(t_o = 0.30\) cm에서 직선 40만 개를 세어 보면 스캔 범위를 \(220^{\circ}\)로 줄일 때 28.6%, \(300^{\circ}\)로 줄일 때 12.3%가 빕니다. \(224^{\circ}\)도 비슷하게 큰 비율이 빕니다. \(2\pi - B\)에 비례해 한 번만 측정되는 직선(전체의 73.6%)이 빠집니다.

마무리 퀴즈 4

광선당 잡음이 같을 때 오프셋 스캔의 영상 잡음이 회전 중심 근처에서 바깥보다 작은 이유로 알맞은 것은 무엇일까요?

  1. 중심 근처 화소는 검출기 칸이 더 촘촘하게 지나가기 때문이다.
  2. 램프 필터가 중심 화소에서는 고주파 잡음을 덜 키우기 때문이다.
  3. 중심 화소는 두 측정을 평균하고, 바깥 화소는 한 번만 잰 직선이 많다.
  4. 중심 화소는 선원에 가까워서 받는 선량이 더 크기 때문이다.

페이지 8의 표에서 111칸 대칭 기준에 대한 잡음 비가 반경 0~0.1 cm에서 1.03, 0.7~0.9 cm에서 1.37이었습니다. 반경이 커질수록 중복 직선의 비율 \(\tfrac{2}{\pi}\arcsin(s_o/r)\)이 줄어 비가 커집니다. 이 비교는 선량을 맞추지 않았습니다.

직접 해보기

  1. \(D = 3\) cm이고 검출기가 \(-0.5 \le t \le 1.5\) cm를 덮습니다. (가) \(\gamma_o\)와 \(\gamma_m\), (나) 시야 반지름 \(s_m\)과 안쪽 원의 반지름 \(s_o\), (다) 시야 안의 직선 가운데 두 번 측정되는 직선의 비율, (라) 같은 폭(2.0 cm)을 대칭으로 놓은 검출기의 시야 반지름과 \(s_m\)의 비를 구하세요.
  2. \(D = 3\) cm, \(t_o = 0.30\) cm인 Wang 가중에서 위치 \(t = 0.20\) cm인 광선과 그 짝의 가중, 합을 구하세요. 선형 경사로 구한 값도 쓰세요. 위치 \(t = 0.45\) cm인 광선과 그 짝의 가중은 얼마입니까?
  3. \(t_o = 0.30\) cm(\(s_o = 0.299\) cm)인 배치에서 반경 \(r = 0.6\) cm인 화소의 잡음 표준편차가 \(360^{\circ}\) 대칭 검출기(모두 \(\tfrac{1}{2}\))의 몇 배일지 페이지 8의 접기 계산으로 예측하세요(광선당 잡음은 같습니다).
모범답안과 흔한 실수

1번. (가) \(\gamma_o = \arctan(0.5/3) = 9.46^{\circ}\), \(\gamma_m = \arctan(1.5/3) = 26.57^{\circ}\)입니다. (나) \(s_m = 3\sin 26.57^{\circ} = 1.342\) cm, \(s_o = 3\sin 9.46^{\circ} = 0.493\) cm입니다. (다) \(s_o/s_m = 0.493/1.342 = 0.368\), 곧 36.8%입니다. (라) 폭 2.0 cm를 대칭으로 놓으면 \(t_{\max} = 1.0\)이고 시야는 \(3\sin(\arctan(1/3)) = 0.949\) cm이므로 \(1.342/0.949 = 1.41\)배입니다.

2번. \(\gamma = \arctan(0.20/3) = 3.814^{\circ}\), \(\gamma_o = \arctan(0.30/3) = 5.711^{\circ}\)이므로 \(\lambda = (3.814 + 5.711)/(2 \times 5.711) = 0.8339\)이고 \(w = \sin^{2}(75.06^{\circ}) = 0.9335\)입니다. 짝 \(t = -0.20\) cm는 팬 각이 \(-3.814^{\circ}\)여서 \(\lambda = 0.1661\)이고 \(w' = \sin^{2}(14.94^{\circ}) = 0.0665\)이며 합은 1입니다. 선형 경사에서는 \(w = 0.8339\), \(w' = 0.1661\)이고 합은 1입니다. \(t = 0.45\) cm는 \(t_o\)보다 크므로 \(w = 1\)이고, 짝 \(t = -0.45\) cm는 검출기 밖이어서 \(w' = 0\)입니다.

3번. 중복 직선의 비율은 \(\rho = \tfrac{2}{\pi}\arcsin(0.299/0.6) = 0.331\)입니다. 겹침 직선의 \(w^{2} + w'^{2}\)를 평균 \(\tfrac{3}{4}\)로 두면 분산비는 \(2[\tfrac{3}{4}(0.331) + (1 - 0.331)] = 1.834\)이고, 표준편차 비는 \(\sqrt{1.834} = 1.354\)입니다. 페이지 8의 표에서 반경 0.5~0.7 cm의 관측 1.35와 맞습니다.

흔한 실수.

  • 1번 (나)에서 \(t_{\max} = 1.5\) cm를 시야 반지름으로 쓰는 것입니다. 광선이 O에서 떨어진 거리 \(D\sin\gamma_m\)이어야 합니다. 안쪽 원의 반지름도 \(D\sin\gamma_o = 0.493\) cm이며, \(t_o = 0.5\) cm를 그대로 쓰면 틀립니다.
  • 2번에서 \(\lambda\)를 \(\gamma/\gamma_o\)로 쓰는 것입니다. \(\lambda = (\gamma + \gamma_o)/(2\gamma_o)\)로 \(t = -t_o\)에서 0, \(t = t_o\)에서 1이어야 합니다. 팬 각 대신 위치를 그대로 넣어 \(\lambda = (t + t_o)/(2t_o) = 0.8333\)으로 계산하면 \(w = 0.9330\)으로 이 장치에서는 0.0005만 다르지만, 정의는 팬 각입니다. 짝의 위치를 \(+t\)로 읽는 실수도 흔합니다. 짝은 \(-t\)(팬 각 \(-\gamma\))입니다.
  • 3번에서 분산비 1.834를 표준편차 비로 쓰는 것입니다. 제곱근을 취해야 합니다. 겹침 직선의 \(w^{2} + w'^{2}\)를 \(\tfrac{1}{2}\)로 두면 \(r = 0.6\)에서 분산비가 1.669, 표준편차 비가 1.29가 되어 관측(1.35)과 맞지 않습니다. 겹침 구간 안에서 \(w^{2} + w'^{2}\)의 평균은 \(\tfrac{3}{4}\)이고 \(\tfrac{1}{2}\)은 \(\lambda = \tfrac{1}{2}\)인 한 점의 값입니다.
