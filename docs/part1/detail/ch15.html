15장 · 페이지 1

1편 돌아보기

1편은 광선마다의 투영값에서 영상을 구하는 해석적 방법을 평행빔에서 시작해 콘빔까지 넓혀 왔습니다. 마지막 장에서는 이 흐름을 한 장의 지도로 보고, 1편이 다루지 않은 것들을 짧게 짚습니다. 새로운 식은 나오지 않으며, 앞 장의 결과를 다시 가리킵니다.

문제 정의
0편 1~3장		화소 값은 감쇠계수 \(\mu\)이고 광선 하나의 투영값은 선적분 \(p = \int\mu\,d\ell\)입니다. 재구성은 \(p\)에서 \(\mu\)를 구하는 역문제이며, 푸는 접근은 해석적 방법과 대수적 방법으로 나뉩니다.0편 3장 페이지 1
Radon 변환(직선마다 선적분을 모은 변환)과 sinogram
3장		평행빔 데이터는 직선마다의 선적분 \(p(\theta, s)\)이고, 이를 각도 × 위치의 표로 쌓은 것이 sinogram입니다. \(p(\theta + \pi, -s) = p(\theta, s)\)이므로 평행빔은 \(180^{\circ}\)로 충분합니다.3장 페이지 6·9
푸리에 슬라이스 정리
4장		각도 \(\theta\)의 투영을 1차원 푸리에 변환한 값이 영상의 2차원 푸리에 변환을 \(\theta\) 방향 직선에서 읽은 값입니다. 단순 역투영은 흐린 영상을 주고, 주파수에 \(|\omega|\)를 곱하면 값이 고르게 쌓입니다.4장 페이지 2
필터 역투영
5·6장		연속 식 \(\mu = \int_0^\pi q\,d\theta\)는 모든 각도와 모든 \(s\)에서 잡음 없는 투영이 있으면 정확한 역공식입니다. 이산화에서는 검출기 간격 \(\Delta s\), 차단 주파수 \(W\), 제로 패딩 길이, 각도 수를 정했습니다.5장 페이지 1
팬빔
7~9장		팬빔 광선 \((\beta, \gamma)\)는 평행빔 직선 \(\theta = \beta + \gamma\), \(s = D\sin\gamma\)와 같습니다. 직접 방식은 코사인 가중, 램프 필터링, \(1/U^{2}\)을 곱하는 역투영의 세 단계이고, rebinning은 평행빔 FBP를 그대로 쓰는 대안입니다.8장 페이지 1
데이터 완전성
10~12장		같은 직선을 두 번 잰 광선(중복 광선)이 있어서 선원을 \(\pi + 2\gamma_m\)만 돌려도 모든 직선을 잴 수 있습니다. 중복 측정은 합이 1이고 끊김이 없는 가중(Parker 가중, Wang 가중)으로 합칩니다.10장 페이지 4
콘빔과 FDK
13·14장		3차원의 정확한 재구성 조건은 Tuy 조건이며 원형 궤도는 궤도 평면 위의 점에서만 만족합니다. FDK 알고리즘은 중앙 슬라이스와 \(z\)에 무관한 물체에서 정확하고 그 밖에서는 근사입니다.13장 페이지 6

1편이 다루지 않은 것

1편은 완전하고 잡음 없는 선적분 데이터라는 이상적인 조건을 세우고, 그 조건에서 영상을 구하는 수학적 이론 가운데 해석적 방법만 다뤘습니다. 다루지 않은 것은 크게 네 가지이며, 깊이 설명하는 대신 찾아볼 키워드만 적었습니다.

  • 대수적 알고리즘. 재구성을 \(\mathbf{A}\mathbf{x} = \mathbf{b}\)로 세우고 반복 계산으로 푸는 방법입니다. 정규화(Regularization)도 여기에 속합니다. 2편(대수적 재구성편)에서 다룹니다.
  • 실제 데이터에서 생기는 비이상적 문제. 빔 경화(Beam Hardening), 산란(Scatter), 금속에 의한 아티팩트, 다중 에너지(Spectral CT)의 필요성 같은 키워드로 찾아볼 수 있습니다.
  • 그런 문제를 개선하는 방법론. 빔 경화 보정, 산란 보정, 금속 아티팩트 저감(MAR) 같은 키워드로 찾아볼 수 있습니다.
  • 원형 궤도가 아닌 CT. 나선(Helical, Spiral) CT 같은 키워드로 찾아볼 수 있습니다.

1편에서 세운 모델(단색광, 산란 없음, 원형 궤도, 완전하고 잡음 없는 데이터)의 어느 전제가 깨지는 상황인지만 표시해 둔 것이며, 각 키워드의 내용은 1편의 범위 밖입니다(심화 주제로 남겨 둡니다).
