팬빔 FBP 공식 유도해 보기 (연속)

7장에서는 팬빔 데이터에 바로 쓰는 재구성(직접 방식)이 가중, 필터링, 가중 역투영의 세 단계라고만 보였습니다. 이 장에서는 그 식을 5장의 평행빔 FBP에서 유도하고, 두 가중이 어디서 나오는지 한 단계씩 확인합니다. 적분은 모두 연속 식입니다.

평면 검출기의 공식

유도는 뒤로 미루고 식부터 보입니다. 평면 검출기(Flat Detector)로 선원을 한 바퀴(\(0 \le \beta < 2\pi\)) 돌려 얻은 팬빔 데이터 \(R_\beta(t)\)에서 영상 \(\mu(x, y)\)를 구하는 식은 다음과 같습니다.

\[\mu(x, y) = \frac{1}{2}\int_{0}^{2\pi} \frac{1}{U^{2}} \int_{-\infty}^{\infty} R_\beta(t)\,\frac{D}{\sqrt{D^{2} + t^{2}}}\,h(t' - t)\,dt\,d\beta\]

  • \(R_\beta(t)\). 선원 각 \(\beta\)에서 가상 검출기(Virtual Detector) 위치 \(t\)로 가는 광선의 투영값입니다. 팬 각 \(\gamma\)와는 \(t = D\tan\gamma\)로 이어지며(7장 페이지 3), 값은 평행빔의 \(p(\beta + \gamma,\ D\sin\gamma)\)와 같은 선적분입니다.
  • \(D\). 선원에서 회전 중심까지의 거리입니다. 실제 검출기까지의 거리 \(\mathrm{SDD}\)는 이 식에 나오지 않습니다.
  • \(h(t' - t)\). 램프 필터 \(|\omega|\)의 커널 \(h(s) = \int |\omega|\,e^{i2\pi\omega s}\,d\omega\)입니다(5장 페이지 7). 실제 계산에서는 \(|\omega| \le W\)에서 자른 \(h_W\)를 쓰고, 이 장은 \(h\)로 씁니다.
  • \(U\), \(t'\). 영상의 점 \((x, y)\)와 선원 각 \(\beta\)에 따라 정해지는 두 값입니다. \(U = (D + x\sin\beta - y\cos\beta)/D\)는 선원에서 점까지의 벡터를 중심 광선 방향으로 사영한 길이(깊이)를 \(D\)로 나눈 비로, 직선 거리가 아니라 깊이의 비이고, \(t' = D\,(x\cos\beta + y\sin\beta)/(D + x\sin\beta - y\cos\beta)\)는 선원과 점을 잇는 광선이 가상 검출기에 닿는 위치입니다.
  • \(\tfrac{1}{2}\). 선원이 한 바퀴 돌면 같은 직선을 두 번 재므로 반으로 나눕니다. 덜 돌린 데이터에서는 이 상수를 광선마다 정한 가중으로 바꿔야 합니다.
  • \(D/\sqrt{D^{2} + t^{2}}\)와 \(1/U^{2}\). 두 가중입니다. 앞의 것은 코사인 가중(Cosine Weighting), 뒤의 것은 거리 가중(Distance Weighting)이라고 합니다.

세 단계의 순서

식을 안쪽부터 읽으면 평행빔 FBP(필터링, 역투영)에 가중이 하나씩 앞뒤로 붙은 세 단계가 됩니다.

출발점과 변수 바꾸기

팬빔 FBP는 새로 세운 식이 아니라 5장의 평행빔 FBP에서 적분 변수를 팬빔 좌표로 바꾼 것입니다. 변수를 바꾸면 달라지는 것이 두 가지 있습니다. 하나는 적분의 작은 조각의 넓이이고, 다른 하나는 필터 커널에 들어가는 거리(이 페이지)입니다.

출발점: 한 바퀴로 쓴 평행빔 FBP

5장의 FBP는 투영을 필터링해 \(q(\theta, s') = \int p(\theta, s)\,h(s' - s)\,ds\)를 만들고, 점 \((x, y)\)를 지나는 광선의 위치 \(s' = x\cos\theta + y\sin\theta\)에서 \(q\)를 읽어 \(\theta\)가 \(0\)~\(\pi\)인 동안 더했습니다. 이를 한 식으로 쓰고 \(\theta\)의 범위를 \(0\)~\(2\pi\)로 넓히면 다음과 같습니다.

\[\mu(x, y) = \frac{1}{2}\int_{0}^{2\pi}\int_{-\infty}^{\infty} p(\theta, s)\,h(x\cos\theta + y\sin\theta - s)\,ds\,d\theta \tag{A}\]

  • \(h\)의 입력. 직선 \(x\cos\theta + y\sin\theta = s\)의 단위 법선은 \((\cos\theta, \sin\theta)\)입니다. 그래서 \(x\cos\theta + y\sin\theta - s\)는 점 \((x, y)\)에서 직선 \((\theta, s)\)까지의 부호 있는 거리입니다. 커널의 값은 점과 광선 사이의 거리로 정해집니다.
  • \(\tfrac{1}{2}\). \(\theta\)를 \(0\)~\(2\pi\)로 돌리면 모든 직선이 \((\theta, s)\)와 \((\theta + \pi, -s)\)로 두 번 나오기 때문입니다. 아래 접기에서 확인합니다.
½이 붙는 이유

\(\theta\) 하나에 대한 안쪽 적분을 \(I(\theta) = \int p(\theta, s)\,h(x\cos\theta + y\sin\theta - s)\,ds\)로 둡니다. 5장의 FBP는 \(\mu = \int_0^{\pi} I(\theta)\,d\theta\)입니다. \(I(\theta + \pi) = I(\theta)\)임을 두 가지 성질로 보입니다.

  1. \(\cos(\theta + \pi) = -\cos\theta\), \(\sin(\theta + \pi) = -\sin\theta\)이므로 \(I(\theta + \pi) = \int p(\theta + \pi, s)\,h\bigl(-(x\cos\theta + y\sin\theta) - s\bigr)\,ds\)입니다.
  2. 적분 변수를 \(s \to -s\)로 바꾸면 \(\int p(\theta + \pi, -s)\,h\bigl(-(x\cos\theta + y\sin\theta) + s\bigr)\,ds\)입니다.
  3. 3장 페이지 9의 대칭 \(p(\theta + \pi, -s) = p(\theta, s)\)를 쓰면 \(\int p(\theta, s)\,h\bigl(-(x\cos\theta + y\sin\theta - s)\bigr)\,ds\)입니다.
  4. \(h\)는 \(|\omega|\)가 짝함수이므로 짝함수입니다. \(h(-u) = h(u)\)를 쓰면 \(I(\theta)\)와 같아집니다.

따라서 \(\int_0^{2\pi} I\,d\theta = 2\int_0^{\pi} I\,d\theta = 2\mu\)이고, \(\mu = \tfrac{1}{2}\int_0^{2\pi} I\,d\theta\)입니다.

팬빔 좌표로 바꿀 때 달라지는 것

7장 페이지 4의 대응 \(\theta = \beta + \gamma\), \(s = D\sin\gamma\)를 식 (A)에 넣습니다. 같은 직선이므로 투영값은 그대로여서 \(p(\beta + \gamma,\ D\sin\gamma) = R_\beta(\gamma)\)이고, 평면 검출기의 좌표로는 \(t = D\tan\gamma\)에서 \(R_\beta(t)\)입니다. 이 값은 팬빔 광선 하나의 선적분이고 어떤 인자도 곱해져 있지 않습니다. 달라지는 것은 두 곳입니다.

  1. 적분 요소 \(d\theta\,ds\)가 \((\beta, \gamma)\)의 요소로 바뀝니다.
  2. 커널의 입력 \(x\cos\theta + y\sin\theta - s\)를 팬빔의 양으로 써야 합니다. 아래에서 다룹니다.

커널에 들어가는 거리

평면 검출기에서 커널에 들어가는 거리는 검출기 위의 위치 차이 \(t' - t\)에 \(U\cos\gamma\)를 곱한 값입니다(식 (D)). 아래에서 이 식이 나오는 과정을 두 단계로 봅니다.

먼저 기하입니다. 점 \(P = (x, y)\)에서 팬빔 광선까지의 거리를 선원 \(S\)에서 바라보며 구합니다. 광선은 \(S\)를 지나므로, \(P\)에서 광선까지의 수직 거리는 선분 \(SP\)의 길이 \(L\)에 \(SP\)와 광선 사이 각의 \(\sin\)을 곱한 값입니다. \(SP\)가 중심 광선과 이루는 각을 \(\gamma'\), 광선의 팬 각을 \(\gamma\)라고 하면 두 방향 사이의 각은 \(\gamma' - \gamma\)입니다.

\[x\cos\theta + y\sin\theta - s = L\sin(\gamma' - \gamma) \tag{C}\]

다음은 검출기 위의 위치로 옮겨 쓰는 일입니다. 광선이 가상 검출기에 닿는 위치는 \(t = D\tan\gamma\), 선원과 \(P\)를 잇는 광선이 닿는 위치는 \(t' = D\tan\gamma'\)입니다.

여기에 \(U = L\cos\gamma'/D\)를 정의합니다. \(L\cos\gamma'\)는 \(SP\)를 중심 광선 방향으로 사영한 길이, 곧 \(P\)의 깊이 \(z\)이므로, \(U = z/D\)는 깊이를 \(D\)로 나눈 비입니다. 선원에서 \(P\)까지의 직선 거리 \(L\)가 아니라 중심 광선 방향의 성분만 쓴다는 점에 주의하세요. \(P\)가 가상 검출기 위(\(O\)를 지나 중심 광선에 수직인 직선 위)에 있으면 \(U = 1\)이고, 선원에 가까우면 \(U < 1\)입니다.

\(L = UD/\cos\gamma'\)를 식 (C)에 넣고 정리하면 다음과 같습니다.

\[L\sin(\gamma' - \gamma) = U\cos\gamma\,(t' - t) \tag{D}\]

식 (D)의 전개

\[\begin{aligned}L\sin(\gamma' - \gamma) &= \frac{UD}{\cos\gamma'}\bigl(\sin\gamma'\cos\gamma - \cos\gamma'\sin\gamma\bigr)\\ &= U\cos\gamma\,\bigl(D\tan\gamma' - D\tan\gamma\bigr) = U\cos\gamma\,(t' - t) \end{aligned}\]

첫 줄은 \(L = UD/\cos\gamma'\)를 넣고 \(\sin\)의 뺄셈 공식을 쓴 것입니다. 둘째 줄은 괄호를 풀어 \(\tfrac{UD}{\cos\gamma'}\sin\gamma'\cos\gamma = U\cos\gamma\cdot D\tan\gamma'\), \(\tfrac{UD}{\cos\gamma'}\cos\gamma'\sin\gamma = U D\sin\gamma = U\cos\gamma\cdot D\tan\gamma\)로 묶은 것입니다.

아래 위젯에서 \(\beta\), 점 \(P\), 광선의 위치 \(t\)를 바꾸며 세 가지 방법으로 구한 거리가 같은 값인지 확인할 수 있습니다. 처음 상태는 \(D = 3\) cm, \(\beta = 0\), \(P = (0.8, 0.6)\), \(t = 0.4\) cm입니다.

세 값은 서로 다른 방법으로 구한 같은 거리입니다. 첫째는 \(\theta = \beta + \gamma\), \(s = D\sin\gamma\)를 넣어 식 (A)의 원래 형태로 계산한 값, 둘째는 식 (D)의 \(U\cos\gamma\,(t' - t)\), 셋째는 식 (C)의 \(L\sin(\gamma' - \gamma)\)입니다. 위젯 값은 소수 넷째 자리까지 보입니다. 세 값의 실제 차이는 \(10^{-14}\)보다 작으므로 같게 보이며, 반올림 경계에서는 끝자리가 1 다르게 보일 수도 있습니다. 식 (D)의 \(U\cos\gamma\)는 점이 선원에 가까울수록, 그리고 광선이 중심 광선에서 멀수록 작아집니다.

좌표로 쓴 U, t′, L과 부호 확인

점 \(P\)를 검출기 방향 성분 \(\xi = x\cos\beta + y\sin\beta\)와 중심 광선 방향 성분 \(\eta = x\sin\beta - y\cos\beta\)로 나눕니다. 선원은 \((-D\sin\beta,\ D\cos\beta)\)에 있고 중심 광선의 방향은 \((\sin\beta, -\cos\beta)\), 검출기 방향은 \((\cos\beta, \sin\beta)\)입니다. \(SP\)를 이 두 방향으로 분해하면 다음과 같습니다.

  • 중심 광선 방향의 길이는 \(D + \eta\), 검출기 방향의 길이는 \(\xi\)입니다.
  • 따라서 \(L = \sqrt{(D + \eta)^{2} + \xi^{2}}\), \(\tan\gamma' = \xi/(D + \eta)\), \(U = (D + \eta)/D\), \(t' = D\xi/(D + \eta) = \xi/U\)입니다.

식 (C)의 부호는 다음 계산으로 확인합니다. \(\theta = \beta + \gamma\)를 넣고 덧셈 공식을 쓰면 \(x\cos(\beta + \gamma) + y\sin(\beta + \gamma) = \xi\cos\gamma - \eta\sin\gamma\)입니다. 여기서 \(s = D\sin\gamma\)를 빼면 \(\xi\cos\gamma - (D + \eta)\sin\gamma\)이고, \(\xi = L\sin\gamma'\), \(D + \eta = L\cos\gamma'\)를 넣으면 \(L(\sin\gamma'\cos\gamma - \cos\gamma'\sin\gamma) = L\sin(\gamma' - \gamma)\)입니다. 위젯의 처음 상태에서는 \(\xi = 0.8\), \(\eta = -0.6\), \(U = 0.8\), \(t' = 1.0\), \(\cos\gamma = 3/\sqrt{9.16} \approx 0.991\)이므로 거리는 \(0.8 \times 0.991 \times (1.0 - 0.4) \approx 0.476\) cm입니다.

변수를 바꾸면 넓이는 몇 배가 될까요? 야코비안

변수를 바꾸면 달라지는 첫 번째는 적분의 작은 조각의 넓이입니다. 변수를 바꿀 때 작은 조각의 넓이가 몇 배가 되는지를 야코비안(Jacobian)이라고 하며, 적분에는 이 배율이 곱해져 남습니다(1장 페이지 2). 5장에서는 푸리에 평면의 극좌표 변환에서 이 배율이 \(|\omega|\)가 되었습니다. 이번에는 직선의 좌표 \((\theta, s)\)를 \((\beta, \gamma)\)로 바꿉니다.

\[d\theta\,ds = D\cos\gamma\;d\gamma\,d\beta\]

작은 칸 하나의 넓이

\((\beta, \gamma)\) 평면의 작은 칸 \(d\beta \times d\gamma\)가 \((\theta, s)\) 평면에서 어떤 모양이 되는지 봅니다. 대응은 \(\theta = \beta + \gamma\), \(s = D\sin\gamma\)입니다.

  • \(\beta\)만 \(d\beta\) 바꾸면 \(\theta\)가 \(d\beta\)만큼 움직이고 \(s\)는 그대로입니다.
  • \(\gamma\)만 \(d\gamma\) 바꾸면 \(s\)가 \(D\cos\gamma\,d\gamma\)만큼 움직이고, \(\theta\)도 \(d\gamma\)만큼 움직입니다.

평행사변형의 넓이는 밑변에 높이를 곱한 값입니다. 세로 변이 \(d\beta\)이고 두 세로 변 사이의 가로 거리가 \(D\cos\gamma\,d\gamma\)이므로 넓이는 \(D\cos\gamma\,d\gamma\,d\beta\)입니다. 칸이 \(\theta\) 방향으로 기울어 밀려도 이 두 길이는 변하지 않으므로, 기울어짐은 넓이에 영향을 주지 않습니다.

행렬식과 적분 범위의 대응

1장 페이지 2에서 본 대로, 야코비안은 변환의 편미분을 모은 \(2 \times 2\) 행렬의 행렬식 절댓값입니다.

\[\begin{vmatrix} \partial\theta/\partial\beta & \partial\theta/\partial\gamma \\ \partial s/\partial\beta & \partial s/\partial\gamma \end{vmatrix} = \begin{vmatrix} 1 & 1 \\ 0 & D\cos\gamma \end{vmatrix} = D\cos\gamma\]

\(|\gamma| < \pi/2\)에서 \(\cos\gamma > 0\)이므로 절댓값을 취해도 같습니다. 식 (A)를 바꾸려면 적분 범위의 대응도 확인해야 합니다.

  1. \(\beta\)가 \(0\)~\(2\pi\), \(\gamma\)가 \(-\pi/2\)~\(\pi/2\)를 도는 동안 \((\theta \bmod 2\pi,\ s)\)는 \(|s| < D\)인 모든 직선을 정확히 한 번씩 지납니다. \(|s| < D\)인 \(s\)에는 \(\gamma = \arcsin(s/D)\)가 하나뿐이고, 그러면 \(\beta = \theta - \gamma\)가 \(2\pi\)를 법으로 하나로 정해지기 때문입니다.
  2. 식 (A)의 피적분 함수 \(p(\theta, s)\,h(x\cos\theta + y\sin\theta - s)\)는 \(\theta\)에 대해 주기 \(2\pi\)입니다. 그래서 \(\theta = \beta + \gamma\)로 두어 \(\theta\)의 구간이 \(\gamma\)만큼 밀려도 적분값은 같습니다.
  3. 팬이 물체를 덮으면(\(D\sin\gamma_m \ge r_0\), 7장 페이지 4) \(|\gamma| > \gamma_m\)에서 \(p = 0\)입니다. \(|s| \ge D\)인 직선도 물체를 지나지 않으므로 \(p = 0\)입니다. 그래서 \(\gamma\)의 적분을 \(\pm\gamma_m\)이나 \(\pm\pi/2\)로 두어도 값이 같고, \(t\)로 바꾼 뒤에는 \(\pm\infty\)로 쓸 수 있습니다.

평면 검출기의 좌표로

평면 검출기의 칸은 \(\gamma\)가 아니라 \(t = D\tan\gamma\)의 간격이 같습니다. \(dt = (D/\cos^{2}\gamma)\,d\gamma\)이므로 \(d\gamma = (\cos^{2}\gamma/D)\,dt\)이고, 이를 대입하면 다음과 같습니다. 마지막 등호에는 \(\cos\gamma = D/\sqrt{D^{2} + t^{2}}\)를 썼습니다.

\[d\theta\,ds = D\cos\gamma\cdot\frac{\cos^{2}\gamma}{D}\,dt\,d\beta = \cos^{3}\gamma\;dt\,d\beta = \frac{D^{3}}{(D^{2} + t^{2})^{3/2}}\,dt\,d\beta\]

\(\cos^{3}\gamma\)는 두 부분으로 읽을 수 있습니다. \(\cos^{2}\gamma\)는 같은 간격 \(dt\)의 칸이 가장자리로 갈수록 좁은 팬 각을 맡는다는 것이고(7장 페이지 3), \(\cos\gamma\)는 같은 팬 각이라도 가장자리에서는 \(s\)가 덜 움직인다는 것입니다. \(D = 3\) cm일 때 값은 다음과 같습니다.

8장 · 페이지 4

거리 가중의 정체

페이지 3의 식 (B)에서 커널 \(h\)의 입력에는 \(U\cos\gamma\)가 곱해져 있습니다. 평행빔 FBP의 커널처럼 \(h(t' - t)\)의 모양으로 되돌리려면 이 곱을 커널 밖으로 꺼내야 합니다. 이때 램프 커널의 스케일 성질(Scale Property)을 씁니다.

램프 커널의 스케일 성질

램프 필터 \(|\omega|\)의 커널 \(h\)는 입력을 \(a\)배(\(a > 0\)) 하면 값이 \(1/a^{2}\)배가 됩니다.

\[h(as) = \frac{1}{a^{2}}\,h(s)\qquad (a > 0)\]

\(1/a\)이 두 번 나오기 때문입니다. \(\omega' = a\omega\)로 바꾸면 \(|\omega| = |\omega'|/a\)에서 한 번, \(d\omega = d\omega'/a\)에서 한 번 나옵니다. 5장에서 극좌표로 바꿀 때 \(|\omega|\)가 나온 것처럼, 이 \(1/a^{2}\)도 적분 변수를 바꾸는 계산에서 생긴 인자입니다.

이 성질은 필터의 값이 \(|\omega|\)로 주파수에 비례하기 때문에 성립합니다. 윈도우 필터처럼 주파수에 따라 다른 모양을 곱한 필터에서는 그대로 성립하지 않습니다. 단계별 계산과 \(h\)의 정확한 뜻은 아래 접기에 있습니다.

치환의 단계와 극한 커널
  1. 정의에서 시작합니다. \(h(as) = \int_{-\infty}^{\infty}|\omega|\,e^{i2\pi(\omega a)s}\,d\omega\)
  2. \(\omega' = a\omega\)로 둡니다. \(a > 0\)이므로 적분 범위의 방향은 그대로이고, \(\omega = \omega'/a\), \(d\omega = d\omega'/a\)입니다.
  3. \(|\omega| = |\omega'|/a\)이므로 \(h(as) = \int \dfrac{|\omega'|}{a}\,e^{i2\pi\omega' s}\,\dfrac{d\omega'}{a} = \dfrac{1}{a^{2}}\int |\omega'|\,e^{i2\pi\omega' s}\,d\omega' = \dfrac{h(s)}{a^{2}}\)입니다.

적분 범위를 \(|\omega| \le W\)로 자른 \(h_W\)에서는 \(\omega'\)의 범위가 \(|\omega'| \le aW\)가 됩니다. 그래서 \(h_W(as) = h_{aW}(s)/a^{2}\)이고, 닫힌 식 \(h_W(s) = 2W^{2}\,\mathrm{sinc}(2Ws) - W^{2}\,\mathrm{sinc}^{2}(Ws)\)(5장 페이지 7)에 직접 대입해도 같은 결과가 나옵니다.

여기서 \(h\)는 5장 페이지 7의 극한 커널입니다. \(W \to \infty\)에서 \(h_W(0) = W^{2}\)이 한없이 커져 보통 함수로 수렴하지 않는 형식적인 커널이고(\(s \ne 0\)에서 꼬리의 평균은 \(-1/(2\pi^{2}s^{2})\)), 스케일 성질은 이 극한에서 성립합니다. 실제 계산은 자른 커널 \(h_W\)로 합니다.

자른 커널의 근사

실제 계산에서 쓰는 \(h_W\)는 \(h_W(as) = h_W(s)/a^{2}\)을 정확히 만족하지 않습니다. 정확한 관계는 \(h_W(as) = h_{aW}(s)/a^{2}\)이어서, 스케일 성질을 쓰면 차단 주파수가 \(W\)에서 \(aW\)로 바뀝니다. \(a = U\cos\gamma\)는 점과 선원 각, 광선마다 다른 값이므로 이 차이는 화소와 광선마다 조금씩 다릅니다. 팬빔 FBP의 계산에서는 이 차이를 무시하고 \(h_W\)를 그대로 쓰며, 이 장의 수치 확인은 그렇게 계산한 값입니다.

U cosγ를 커널 밖으로

\(a = U\cos\gamma\)로 두면 다음과 같습니다.

\[h\bigl(U\cos\gamma\,(t' - t)\bigr) = \frac{h(t' - t)}{U^{2}\cos^{2}\gamma}\]

페이지 2의 처음 상태(\(U = 0.8\), \(\cos\gamma = 0.991\), \(t' - t = 0.6\))에서는 \(a = 0.793\)이므로 \(h(0.476)\)이 \(h(0.6)\)의 \(1/0.793^{2} \approx 1.59\)배라는 뜻입니다.

식 (B)에 대입하면 \(\cos^{3}\gamma\)와 \(1/(U^{2}\cos^{2}\gamma)\)가 곱해져 \(\cos\gamma/U^{2}\)이 남습니다.

\[\begin{aligned}\mu(x, y) &= \frac{1}{2}\int_{0}^{2\pi}\int_{-\infty}^{\infty} R_\beta(t)\,h(t' - t)\,\frac{\cos^{3}\gamma}{U^{2}\cos^{2}\gamma}\,dt\,d\beta\\ &= \frac{1}{2}\int_{0}^{2\pi}\frac{1}{U^{2}}\int_{-\infty}^{\infty} R_\beta(t)\,\cos\gamma\;h(t' - t)\,dt\,d\beta\end{aligned}\]

남은 두 인자는 의존하는 것이 다릅니다. \(\cos\gamma\)는 측정 위치 \(t\)에만 의존하고, \(1/U^{2}\)은 화소와 선원 각에만 의존하며 \(t\)와 무관합니다. 그래서 \(1/U^{2}\)은 \(t\)에 대한 적분 밖으로 나옵니다. 필터링(\(t\)에 대한 적분)을 마친 뒤, 화소마다 값을 읽을 때 곱하는 인자입니다. 이 인자를 거리 가중(Distance Weighting)이라고 합니다. \(U\)가 선원에서 점까지 중심 광선 방향의 거리에 비례하므로 붙은 이름입니다. \(\cos\gamma\)의 의미는 다음 페이지에서 봅니다.

선량 보정이 아닌 이유

\(1/U^{2}\)은 선원에서 멀수록 X선이 약해지는 역제곱 법칙과 모양이 닮았고 이름에도 '거리'가 들어 있어서 선량을 고치는 인자로 읽기 쉽습니다. 그러나 이 가중은 보정이 아니라는 근거가 이 장 안에 네 가지 있습니다.

  1. 유도에 X선 세기가 나오지 않습니다. 쓴 것은 직선 좌표의 변수변환(야코비안), 점과 광선 사이 거리의 기하, 램프 커널의 스케일 성질뿐입니다. 입력인 \(R_\beta(t)\)는 로그 변환을 거친 선적분이고, 칸마다의 거리·입사각·이득 차이는 0편 2장 페이지 2의 플랫필드 보정에서 비 \(I/I_0\)로 이미 상쇄되었습니다.
  2. 좌표를 바꾸면 가중이 바뀝니다. 같은 광선, 같은 측정값이라도 곡면 검출기의 좌표 \(\gamma\)로 적분하면 가중이 \(D\cos\gamma\)와 \(1/L^{2}\)으로 달라집니다. 선량은 광선이 정하는 값이고 적분 변수를 어떻게 잡았는지와 무관하므로, 좌표에 따라 달라지는 이 가중은 식 쪽의 성질입니다.
  3. 데이터를 옮기면 가중이 필요 없습니다. rebinning은 같은 측정값을 평행빔 격자로 옮긴 뒤 5장의 식을 가중 없이 그대로 씁니다(7장 페이지 8, 9). 가중은 측정값이 아니라 식을 바꾼 데서 나옵니다.
  4. 세기 인자와 성격이 다릅니다. 칸 하나의 세기가 \(c\)배가 되면 \(-\ln(cI/I_0) = p - \ln c\)가 되어 투영값에 더해지는 항으로 나타납니다. 재구성 식의 가중은 투영값에 곱해지는 인자입니다.

보정이라고 가정하고 방향을 따져 보아도 맞지 않습니다. 선원에서 먼 화소(\(U > 1\))의 신호가 약해지는 것을 고치는 인자라면 1보다 큰 값을 곱해야 합니다. 그런데 \(1/U^{2}\)은 \(U > 1\)에서 1보다 작습니다. 다만 이 비교는 보정이라는 가정 위에서 한 추론이므로, 위의 네 근거가 핵심입니다. 코사인 가중에도 같은 네 근거가 적용됩니다. 그 출처는 다음 페이지에서 확인합니다.

8장 · 페이지 5

코사인 가중과 최종 공식

페이지 4의 마지막 식에는 측정 위치 \(t\)에만 의존하는 인자 \(\cos\gamma\)가 남아 있습니다. 이 인자의 정체를 확인하고 공식을 정리합니다.

코사인 가중

\(\tan\gamma = t/D\)이므로 \(\cos\gamma = D/\sqrt{D^{2} + t^{2}}\)입니다. 이 인자는 두 단계를 거쳐 만들어졌습니다.

  • 페이지 3의 야코비안에서 \(\cos^{3}\gamma\)가 나왔습니다. 하나는 \(s = D\sin\gamma\)의 기울기 \(\cos\gamma\)이고, 다른 하나는 \(dt = (D/\cos^{2}\gamma)\,d\gamma\)에서 온 \(\cos^{2}\gamma\)입니다.
  • 페이지 4의 스케일 성질에서 \(1/\cos^{2}\gamma\)가 나왔습니다. 커널의 입력 \(U\cos\gamma\,(t' - t)\)에 \(\cos\gamma\)가 들어 있었기 때문입니다.

\[\cos^{3}\gamma\times\frac{1}{\cos^{2}\gamma} = \cos\gamma = \frac{D}{\sqrt{D^{2} + t^{2}}}\]

이 곱을 코사인 가중(Cosine Weighting)이라고 합니다. 야코비안 하나만이 아니라 야코비안과 커널의 스케일 성질에서 나온 두 인자의 곱이라는 점에 주의해야 합니다. 필터링 앞에서 측정값에 곱하므로 사전 가중(Pre-weighting)이라고도 합니다.

두 가중 가운데 하나는 필터링 앞에, 다른 하나는 뒤에 오는 이유는 의존하는 변수에 있습니다. \(\cos\gamma\)는 \(t\)만의 함수이므로 측정값에 먼저 곱해 \(\tilde R_\beta(t) = R_\beta(t)\cos\gamma\)로 두면, 안쪽 적분이 \(\tilde R_\beta\)와 \(h\)의 컨볼루션이 됩니다. 이 컨볼루션은 화소와 무관하므로 선원 각마다 한 번만 하면 됩니다. 반면 \(1/U^{2}\)은 화소마다 값이 달라서 컨볼루션 밖에서 곱합니다.

최종 공식

페이지 1의 식을 세 줄로 나누어 쓰면 다음과 같습니다.

\[\begin{aligned} \tilde R_\beta(t) &= R_\beta(t)\,\frac{D}{\sqrt{D^{2} + t^{2}}} &&\text{(코사인 가중)}\\ q_\beta(u) &= \int_{-\infty}^{\infty} \tilde R_\beta(t)\,h(u - t)\,dt &&\text{(램프 필터링)}\\ \mu(x, y) &= \frac{1}{2}\int_{0}^{2\pi}\frac{q_\beta(t')}{U^{2}}\,d\beta &&\text{(가중 역투영)} \end{aligned}\]

평행빔 FBP(5장)와 비교하면 필터링은 같은 컨볼루션이고 커널도 같은 \(h\)입니다. 달라진 점은 세 가지입니다. 필터링 앞에 가중이 하나 있고, 필터링한 값을 읽는 위치가 \(x\cos\theta + y\sin\theta\) 대신 화소마다 다른 \(t'\)이며, 읽은 값에 \(1/U^{2}\)을 곱합니다.

두 가중의 모양

아래 위젯은 \(D = 3\) cm에서 두 가중이 무엇에 의존하는지 보여 줍니다. 왼쪽은 선원이 도는 궤도(점선 원, 반지름 \(D\)) 안에 영상 영역(\(\pm 1.1\) cm)의 \(1/U^{2}\)을 같은 비율로 그린 것입니다. 선원 S에서 회전 중심 O로 가는 화살표가 중심 광선이고, O를 지나 중심 광선에 수직인 굵은 선이 가상 검출기입니다. 점 P(파랑)를 고르면, S에서 P까지를 중심 광선 방향으로 사영한 길이가 깊이 \(z\)(초록)이고 \(U = z/D\)입니다. 오른쪽 곡선은 코사인 가중 \(\cos\gamma\)입니다. 선원 각과 점 P를 바꿔 보세요.

  • \(1/U^{2}\)은 선원 각에 따라 회전합니다. 값이 중심 광선 방향의 깊이로만 정해져서, 같은 색의 선이 가상 검출기와 나란합니다. 선원 쪽(깊이가 작은 쪽)이 크고 반대쪽이 작으며, 회전 중심은 어떤 선원 각에서도 \(U = 1\)이므로 값이 1입니다.

흔한 오해

  • "선원에 가까운 화소는 광선이 촘촘히 지나므로 가중이 작아야 한다"고 생각하기 쉽습니다. 실제로는 \(U < 1\)에서 \(1/U^{2}\)이 큽니다. 촘촘할수록 화소와 광선 사이의 거리 \(d\)가 작아지고, 램프 커널이 거리의 \(-2\)제곱에 비례하기 때문입니다(페이지 4).

곡면 검출기의 연속 공식

곡면 검출기(Curved Detector)는 칸 사이의 팬 각이 모두 같아서(7장 페이지 3) 측정값을 \(R_\beta(\gamma)\)로 다루는 것이 자연스럽습니다. 같은 식 (A)에서 출발하되, \(t\)로 바꾸지 않고 \(\gamma\)를 그대로 씁니다. 변수를 바꾸면 달라지는 두 곳, 곧 적분 요소와 커널의 입력을 이번에는 \(\gamma\)로 씁니다.

유도

  1. 적분 요소. 페이지 3의 \(d\theta\,ds = D\cos\gamma\,d\gamma\,d\beta\)를 \(t\)로 더 바꾸지 않고 그대로 씁니다.
  2. 커널의 입력. 페이지 2의 식 (C)에서 \(x\cos\theta + y\sin\theta - s = L\sin(\gamma' - \gamma)\)입니다. 평면 검출기처럼 \(U\cos\gamma\,(t' - t)\)로 옮기지 않고 이 형태로 둡니다.
  3. 스케일 성질. \(\varphi = \gamma' - \gamma\)로 두고 \(L\sin\varphi = \bigl(L\sin\varphi/\varphi\bigr)\,\varphi\)로 씁니다. 페이지 4의 성질을 \(a = L\sin\varphi/\varphi\)로 쓰면 \(h(L\sin\varphi) = h(\varphi)/a^{2} = (\varphi/\sin\varphi)^{2}\,h(\varphi)/L^{2}\)입니다.

세 단계를 식 (A)에 모으면 곡면 검출기의 연속 공식이 됩니다.

\[\begin{aligned}\mu(x, y) &= \frac{1}{2}\int_{0}^{2\pi}\frac{1}{L^{2}}\int_{-\infty}^{\infty} R_\beta(\gamma)\,D\cos\gamma\;h_c(\gamma' - \gamma)\,d\gamma\,d\beta,\\ h_c(\varphi) &= \Bigl(\frac{\varphi}{\sin\varphi}\Bigr)^{2} h(\varphi)\end{aligned}\]

  • \(L\), \(\gamma'\). \(L\)은 선원에서 점 \((x, y)\)까지의 실제 거리이고 \(\gamma'\)은 선원에서 그 점을 본 팬 각입니다. 페이지 2의 \(\xi\), \(\eta\)로 \(L = \sqrt{(D + \eta)^{2} + \xi^{2}}\), \(\gamma' = \arctan\bigl(\xi/(D + \eta)\bigr)\)입니다.
  • \(h_c\). 곡면 검출기용 커널(hc)입니다. 입력 \(\varphi\)는 각(라디안)이며, 램프 커널 \(h\)에 숫자 \(\varphi\)를 그대로 넣은 값을 씁니다.

평면 검출기 공식과 다른 점

  • 사전 가중이 \(D\cos\gamma\)입니다. 야코비안이 그대로 남습니다. 커널의 입력 \(L\sin(\gamma' - \gamma)\)에는 \(\cos\gamma\)가 들어 있지 않으므로 평면 검출기처럼 \(1/\cos^{2}\gamma\)가 곱해지지 않습니다. 사전 가중은 여전히 광선 \(\gamma\)에만 의존해 필터링 앞에서 곱할 수 있습니다.
  • 거리 가중이 \(1/L^{2}\)입니다. \(L\)은 선원에서 점까지의 실제 거리입니다. 평면 검출기의 \(U\)는 이 거리의 중심 광선 방향 성분을 \(D\)로 나눈 값이어서 \(L\cos\gamma' = UD\)입니다.
  • 필터 커널이 \(h_c\)입니다. 곡면 검출기에서는 같은 \(\varphi\)라도 실제 거리가 \(L\sin\varphi\)이어서 \(\varphi\)에 비례하지 않습니다. 이 차이가 \((\varphi/\sin\varphi)^{2}\)로 들어갑니다. 이 인자는 \(\varphi\)에만 의존하므로 필터링은 여전히 \(\gamma\) 방향의 컨볼루션입니다.

표를 읽는 법

  • 구조가 같습니다. 측정 위치만의 함수인 사전 가중을 곱하고, 컨볼루션으로 필터링하고, 점마다 필터링한 값을 읽어 점과 선원 각만의 함수인 가중을 곱해 더합니다. 이 구조가 평면과 곡면에서 같습니다.
  • 두 거리는 관계가 있습니다. \(L\)은 선원에서 점까지의 실제 거리이고 \(U\)는 그 거리의 중심 광선 방향 성분을 \(D\)로 나눈 값이어서 \(L\cos\gamma' = UD\)입니다. 따라서 \(1/L^{2} = \cos^{2}\gamma'/(U^{2}D^{2})\)입니다. 두 거리 \(L\)과 \(UD\)는 같은 선분 \(SP\)를 전체 길이와 중심 광선 방향 성분으로 잰 값이고, 두 거리 가중은 \(\cos^{2}\gamma'/D^{2}\)만큼 다릅니다. 이 차이는 사전 가중과 커널의 차이에 흡수됩니다.
  • 사전 가중과 커널이 함께 달라집니다. 평면 검출기에서는 커널의 입력 \(U\cos\gamma\,(t' - t)\)에 \(\cos\gamma\)가 들어 있어서 사전 가중이 야코비안 \(\cos^{3}\gamma\)를 \(\cos^{2}\gamma\)로 나눈 \(\cos\gamma\)가 됩니다. 곡면 검출기는 커널의 입력에 \(\cos\gamma\)가 없어서 야코비안 \(D\cos\gamma\)가 그대로 사전 가중이 되고, 대신 \(\sin\)에서 오는 인자가 커널 \(h_c\)에 들어갑니다.
  • 가중은 좌표의 선택에 따라 달라집니다. 같은 광선의 같은 측정값에 대해 표의 두 열은 서로 다른 가중을 씁니다. 페이지 4의 두 번째 근거를 이 표로 확인할 수 있습니다.

팬빔 데이터에서 영상을 만드는 두 방법은 7장에서 소개했습니다. 이 장의 유도를 마쳤으므로, 두 방법이 식 (A)의 어디를 바꾸는지의 관점에서 비교할 수 있습니다. 이 페이지는 연속 식의 관점만 봅니다. rebinning의 보간 오차는 7장 페이지 8에서 수치로 확인했습니다.

연속에서의 동일한 결과

rebinning은 팬빔 광선 하나하나를 같은 직선의 평행빔 좌표 \((\theta, s)\)에 놓는 일입니다. 연속 데이터에서는 이 대응이 값을 바꾸지 않고 이름만 바꾸므로 \(p(\theta, s)\)를 정확히 얻고, 식 (A)를 그대로 쓰면 \(\mu\)가 나옵니다. 직접 방식은 식 (A)의 적분 변수를 바꾸므로 같은 적분을 다른 좌표로 계산한 것입니다. 그래서 연속에서는 두 방법이 같은 영상을 주고, 차이는 이산 데이터를 다룰 때 나타납니다.

선원 각의 범위가 다른 이유

표에서 필요한 선원 각이 다른 것은 두 방법이 같은 직선을 다루는 방식이 달라서입니다. rebinning은 \((\theta, s)\) 격자의 칸마다 값을 한 번 채우면 됩니다. 그 칸을 잰 팬빔 광선이 한 개뿐이어도 칸의 값이 정해지므로, 이상적인 데이터에서는 \(180^{\circ} + 2\gamma_m\)이면 충분합니다. 직접 방식의 식은 모든 선원 각의 기여를 \(\tfrac{1}{2}\)씩 더하는 식입니다. 한 직선을 한 번만 재면 그 직선의 기여가 절반만 들어가므로, 선원을 덜 돌린 데이터에 쓰려면 \(\tfrac{1}{2}\) 대신 광선마다 정한 가중이 필요합니다.

두 방법의 우열

연속 식으로는 우열이 없습니다. 기존의 평행빔 코드를 그대로 쓰고 싶으면 rebinning이 간단하고, 보간을 한 번으로 줄이려면 직접 방식이 유리할 수 있습니다. 이산 데이터에서의 차이는 보간이 일어나는 횟수와 위치에서 나옵니다(표의 마지막에서 둘째 줄).

핵심 요약

  1. 평면 검출기 팬빔 FBP의 연속 식은 코사인 가중 \(D/\sqrt{D^{2} + t^{2}}\), 램프 필터링(평행빔과 같은 커널 \(h\)), \(1/U^{2}\)을 곱하는 역투영의 세 단계이고, 선원 각은 \(0\)~\(2\pi\)에서 \(\tfrac{1}{2}\)을 곱해 더합니다.
  2. 이 식은 한 바퀴로 쓴 평행빔 FBP에 \(\theta = \beta + \gamma\), \(s = D\sin\gamma\)를 대입한 것입니다. 달라진 것은 야코비안 \(d\theta\,ds = D\cos\gamma\,d\gamma\,d\beta\)(평면: \(\cos^{3}\gamma\,dt\,d\beta\))와, 커널의 입력이 점에서 광선까지의 거리 \(U\cos\gamma\,(t' - t)\)가 된 것입니다.
  3. 코사인 가중은 야코비안 \(\cos^{3}\gamma\)와 스케일 성질 \(h(as) = h(s)/a^{2}\)에서 나온 \(1/\cos^{2}\gamma\)의 곱이며, 측정 위치에만 의존해 필터링 앞에 옵니다. \(1/U^{2}\)은 같은 스케일 성질에서 나오며 점에 의존해 필터링 뒤에 옵니다.
  4. 두 가중은 변수를 바꾸면서 생긴 수학적 인자입니다. (심화) 곡면 검출기에서는 같은 광선에도 \(D\cos\gamma\), \(1/L^{2}\), 커널 \(h_c\)라는 다른 가중이 붙습니다.
  5. 이 식은 선원을 한 바퀴 돌려 모든 직선을 두 번씩 잰 데이터를 전제합니다. 덜 돌리면 \(\tfrac{1}{2}\) 대신 광선마다 정한 가중이 필요하며(10~12장), 샘플링한 데이터로 계산하는 방법은 9장에서 다룹니다. 검출기가 물체 전체를 덮지 못해(\(D\sin\gamma_m < r_0\)) 일부 투영값이 없는 절단 데이터가 되면 평행빔처럼 문제가 생깁니다(5장 페이지 11).

마무리 퀴즈 1

평면 검출기 공식의 코사인 가중 \(D/\sqrt{D^{2} + t^{2}}\)의 출처로 알맞은 것은 무엇일까요?

  1. 비스듬히 들어오는 광선에서 검출기 칸이 받는 세기가 줄어드는 것을 고치는 인자이다.
  2. 야코비안 \(\cos^{3}\gamma\)와 커널의 스케일 성질에서 나온 \(1/\cos^{2}\gamma\)를 곱한 결과이다.
  3. 곡면 검출기에서 쓰는 야코비안 \(D\cos\gamma\)를 평면 검출기에 그대로 가져온 것이다.
  4. 선원에서 검출기 칸까지의 거리가 멀수록 약해지는 세기를 고치는 인자이다.

코사인 가중을 필터링 뒤로 미루면 결과가 달라집니다. 공식에서는 컨볼루션 안의 측정값마다 그 측정 위치 \(t\)의 \(\cos\gamma\)가 곱해지는데, 필터링 뒤에 곱하면 읽는 위치 \(t'\)의 값 하나가 곱해지기 때문입니다. 이 가중이 필터링 앞에 오는 것은 \(t\)에만 의존하기 때문입니다.

마무리 퀴즈 2

\(D = 4\) cm, 선원 각 \(\beta = 0\)에서 영상의 점 \((x, y) = (1,\ -2)\)에 대한 \(U\), \(t'\), \(1/U^{2}\)은 얼마일까요? \(U = (D + x\sin\beta - y\cos\beta)/D\), \(t' = (x\cos\beta + y\sin\beta)/U\)입니다.

  1. \(U = 0.5\), \(t' = 2.0\), \(1/U^{2} = 4.0\)
  2. \(U = 1.5\), \(t' = 1.0\), \(1/U^{2} \approx 0.44\)
  3. \(U = 1.5\), \(t' \approx 0.67\), \(1/U^{2} \approx 0.44\)
  4. \(U = 1.5\), \(t' \approx 0.67\), \(1/U^{2} \approx 0.67\)

같은 선원 각에서 선원 쪽의 점 \((1,\ 2)\)는 \(U = 0.5\), \(1/U^{2} = 4\)입니다. 반대쪽 점 \((1,\ -2)\)의 9배입니다. 점이 선원 쪽으로 \(D\)의 절반만큼 가 있기 때문에 거리 가중이 이렇게 크게 다릅니다. 영상이 \(D\)에 비해 작으면 \(U\)가 1에 가까워져 거리 가중도 1에 가까워집니다.

마무리 퀴즈 3

(심화) 같은 팬빔 데이터를 곡면 검출기의 좌표 \(\gamma\)로 재구성하는 식이 평면 검출기의 식과 다른 점으로 알맞은 것은 무엇일까요?

  1. 사전 가중 \(\cos\gamma\)와 거리 가중 \(1/U^{2}\)은 그대로이고 커널만 \(h_c\)로 바뀐다.
  2. 사전 가중 \(D\cos\gamma\)와 거리 가중 \(1/L^{2}\)은 맞지만 커널은 \(h\)를 그대로 쓴다.
  3. 사전 가중 \(D\cos\gamma\)와 거리 가중 \(1/U^{2}\)으로 바뀌고 커널은 \(h\)를 그대로 쓴다.
  4. 사전 가중이 \(D\cos\gamma\), 거리 가중이 \(1/L^{2}\), 커널이 \(h_c\)로 바뀐다.

\(h_c\)의 보정 인자 \((\varphi/\sin\varphi)^{2}\)는 팬이 넓을수록 커집니다. 팬 반각이 \(30^{\circ}\)이면 \(\varphi = \gamma' - \gamma\)가 \(60^{\circ}\)(1.047 rad)까지 커져서 인자가 약 1.46이 됩니다. 팬 반각 \(20^{\circ}\)에서의 최댓값 1.18(페이지 7)보다 커서, 넓은 팬일수록 \(h\)와 \(h_c\)의 구분이 중요해집니다.

마무리 퀴즈 4

팬 반각 \(\gamma_m = 20^{\circ}\)인 장치로 선원을 \(220^{\circ}\)(\(= 180^{\circ} + 2\gamma_m\))만 돌려 얻은 데이터에 이 장의 식을 그대로 쓰면 어떻게 될까요?

  1. 한 번만 잰 직선(약 78%)의 기여가 \(\tfrac{1}{2}\)만 곱해져 절반만 들어간다.
  2. 모든 직선이 두 번씩 측정되므로 \(\tfrac{1}{2}\)을 곱한 식이 그대로 정확하다.
  3. 한 번도 측정되지 않은 직선이 약 22%여서 영상을 복원할 수 없다.
  4. 측정이 모자란 만큼 필터링의 커널만 바꾸면 되고 \(\tfrac{1}{2}\)은 그대로 쓴다.

두 번 잰 광선은 선원 각 범위의 처음 부분과 끝 부분에 있습니다. 가중은 이 부분에서 한 직선의 두 측정에 나누어 주어야 하므로, 가중을 0에서 1로 매끄럽게 바꾸는 방법이 중요해집니다.

직접 해보기

  1. \(D = 4\) cm, 선원 각 \(\beta = 30^{\circ}\)입니다. (가) 영상의 점 \((x, y) = (1,\ 0.5)\)에 대해 \(\xi = x\cos\beta + y\sin\beta\), \(\eta = x\sin\beta - y\cos\beta\), \(U\), \(t'\), \(1/U^{2}\)을 구하세요. (나) 가상 검출기 위치 \(t = 2\) cm인 광선의 팬 각 \(\gamma\)와 \(\cos\gamma\)를 구하세요. (다) 점에서 이 광선까지의 거리를 \(U\cos\gamma\,(t' - t)\)로 구하고, \(L\sin(\gamma' - \gamma)\)로 구한 값과 같은지 확인하세요. 부호가 음수인 것은 무엇을 뜻하나요?
  2. \(D = 2\) cm인 평면 검출기에서 \(t = 0\)인 칸과 \(t = 1.5\) cm인 칸이 \((\theta, s)\) 평면에서 대표하는 넓이의 비를 구하세요(칸 간격 \(\Delta t\)와 선원 각 간격은 같습니다). (심화) 같은 광선(\(\tan\gamma = 0.75\))을 곡면 검출기의 칸(팬 각 간격이 같음)으로 재면 이 비는 얼마인가요? 두 비가 다른 이유를 한 문장으로 쓰세요.
  3. 동료가 "거리 가중 \(1/U^{2}\)은 선원에서 먼 화소가 약하게 찍히는 것을 보정하는 인자"라고 말합니다. 이 장의 내용으로 반박하는 근거 두 가지를 쓰세요.
모범답안과 흔한 실수

1번. (가) \(\xi = \cos 30^{\circ} + 0.5\sin 30^{\circ} \approx 1.116\), \(\eta = \sin 30^{\circ} - 0.5\cos 30^{\circ} \approx 0.067\)이므로 \(U = (4 + 0.067)/4 \approx 1.017\), \(t' = \xi/U \approx 1.098\) cm, \(1/U^{2} \approx 0.967\)입니다. (나) \(\gamma = \arctan(2/4) \approx 26.57^{\circ}\), \(\cos\gamma \approx 0.894\)입니다. (다) \(U\cos\gamma\,(t' - t) \approx 1.017 \times 0.894 \times (1.098 - 2) \approx -0.821\) cm입니다. \(L = \sqrt{4.067^{2} + 1.116^{2}} \approx 4.217\), \(\gamma' = \arctan(1.116/4.067) \approx 15.34^{\circ}\)이므로 \(L\sin(\gamma' - \gamma) = 4.217\sin(-11.22^{\circ}) \approx -0.821\) cm로 같습니다. 음수는 점의 \(t'\)이 광선의 \(t\)보다 작은 쪽, 곧 \(\gamma' < \gamma\)인 쪽에 점이 있다는 뜻입니다.

2번. 평면 검출기의 비는 \(\cos^{3}\gamma = D^{3}/(D^{2} + t^{2})^{3/2} = 8/6.25^{3/2} = 8/15.625 = 0.512\)입니다. (심화) 곡면 검출기의 칸은 야코비안이 \(D\cos\gamma\)이므로 중심 칸(\(\gamma = 0\))과의 비는 \(\cos\gamma = 0.8\)입니다. 두 비가 다른 이유는 칸을 나누는 기준입니다. 평면 검출기는 칸 간격이 \(t\)로 같아서 가장자리 칸이 맡는 팬 각이 \(\cos^{2}\gamma = 0.64\)배로 좁아지고, 여기에 \(s\)가 덜 움직이는 \(\cos\gamma = 0.8\)이 곱해져 \(0.64 \times 0.8 = 0.512\)가 됩니다. 곡면 검출기는 칸마다 팬 각이 같아서 \(\cos\gamma\)만 남습니다.

3번. 예시 근거입니다. 첫째, 유도에 X선 세기가 나오지 않고 \(1/U^{2}\)은 램프 커널의 스케일 성질 \(h(as) = h(s)/a^{2}\)에서 나온 수학적 인자이며, 세기 차이는 플랫필드 보정이 재구성 전에 정리했습니다. 둘째(심화), 같은 광선이라도 곡면 검출기의 좌표로 적분하면 거리 가중이 \(1/L^{2}\)으로 바뀌고 사전 가중도 달라집니다. 선량은 좌표 선택에 따라 달라지지 않으므로 이 가중은 식 쪽의 성질입니다. 이 밖에 rebinning으로 데이터를 옮기면 가중이 필요 없다는 점, 세기 인자는 로그 뒤에 더해진다는 점도 근거가 됩니다.

흔한 실수.

  • 1번에서 \(\eta = x\sin\beta - y\cos\beta\)의 부호를 바꾸거나 \(U\)를 구할 때 \(D\)로 나누는 것을 빠뜨리는 것입니다. 점이 선원 쪽에 있을수록 \(\eta\)가 음수이고 \(U\)는 1보다 작습니다.
  • 1번에서 \(t'\)을 \(\xi\)와 같다고 쓰는 것입니다. \(t' = \xi/U\)이며 \(U = 1\)인 점(회전 중심을 지나 중심 광선에 수직인 직선 위)에서만 \(\xi\)와 같습니다.
  • (심화) 2번에서 곡면 검출기의 비를 평면과 같은 \(\cos^{3}\gamma\)로 쓰는 것입니다. 칸 간격이 \(t\)로 같은지 \(\gamma\)로 같은지에 따라 야코비안이 다릅니다.
  • 3번에서 \(1/U^{2}\)이 역제곱 법칙과 닮았다는 점만으로 보정이라고 답하는 것입니다. 모양이 닮은 것이 출처가 같다는 증거는 아닙니다.
