복습: 좌표 변환과 적분

뒷장의 유도에서 좌표를 바꾸는 계산이 여러 번 나옵니다. 이 장은 그 계산에 필요한 좌표 회전, 극좌표, 야코비안을 복습합니다. 좌표 회전은 2장, 3장, 4장에서 쓰고, 극좌표와 야코비안은 2장의 2차원 푸리에 변환과 5장, 8장의 변수변환에서 씁니다. 이미 아는 내용이면 건너뛰고 2장으로 가도 되며, 막힐 때 돌아오면 됩니다.

좌표 회전과 극좌표

같은 점도 어떤 기준으로 재느냐에 따라 좌표가 달라집니다. 이 페이지에서는 축을 돌린 좌표와 원점에서의 거리와 각으로 잰 좌표를 봅니다. 0편 3장의 규약대로 각은 \(x\) 축에서 반시계 방향이 양이고 단위는 라디안입니다.

회전 좌표

\(x\) 축과 \(y\) 축을 원점을 중심으로 반시계 방향으로 \(\theta\)만큼 돌린 축을 \(x'\) 축, \(y'\) 축이라고 하겠습니다. \(x'\) 축의 방향은 \((\cos\theta,\ \sin\theta)\)이고 \(y'\) 축의 방향은 \((-\sin\theta,\ \cos\theta)\)입니다. 길이가 1인 방향은 이런 꼴로 쓸 수 있으므로, 0편 2장의 광선 방향 \((u_x,\ u_y)\)도 어떤 \(\theta\)에 대한 \((\cos\theta,\ \sin\theta)\)입니다.

점 \((x,\ y)\)에서 새 축에 수선을 내린 발의 위치가 새 좌표 \((x',\ y')\)입니다. 이 좌표를 회전 좌표(Rotated Coordinates)라고 하고, 원래 좌표에서 다음처럼 구합니다.

\[x' = x\cos\theta + y\sin\theta,\qquad y' = -x\sin\theta + y\cos\theta\]

식이 맞는지 \(x'\) 축 위의 점으로 확인합니다. 이 축 위의 점은 \((x,\ y) = (t\cos\theta,\ t\sin\theta)\)입니다. 식에 넣으면 다음과 같습니다.

\[x' = t\cos^{2}\theta + t\sin^{2}\theta = t,\qquad y' = -t\cos\theta\sin\theta + t\sin\theta\cos\theta = 0\]

이 점의 새 좌표는 \((t,\ 0)\)이어서 \(x'\) 축 위에 있다는 뜻과 맞습니다. 반대로 새 좌표에서 원래 좌표를 구하는 식은 다음과 같습니다.

\[x = x'\cos\theta - y'\sin\theta,\qquad y = x'\sin\theta + y'\cos\theta\]

축을 돌려도 원점에서의 거리는 변하지 않으므로 \(x'^{2} + y'^{2} = x^{2} + y^{2}\)입니다. 직선 \(x\cos\theta + y\sin\theta = s\)는 새 좌표에서 \(x' = s\)인 직선입니다. 광선은 이 직선으로 나타냅니다.

축을 돌리는 것과 점을 돌리는 것

축을 반시계 방향으로 \(\theta\)만큼 돌리면 점의 새 좌표는 점을 시계 방향으로 \(\theta\)만큼 돌린 것과 같습니다. 예를 들어 \(\theta = 90^{\circ}\)이면 점 \((1,\ 0)\)의 새 좌표는 \((0,\ -1)\)입니다.

극좌표

점을 원점에서의 거리 \(r\)과 \(x\) 축에서 잰 각 \(\theta\)로 나타낼 수도 있습니다. 이 좌표를 극좌표(Polar Coordinates)라고 합니다. 극좌표 \((r,\ \theta)\)에서 직교좌표 \((x,\ y)\)로 가는 변환과 그 반대의 변환은 다음과 같습니다.

\[x = r\cos\theta,\quad y = r\sin\theta,\qquad r = \sqrt{x^{2}+y^{2}}\]

\(\theta\)는 \(\tan\theta = y/x\)를 만족하는 각 가운데 점이 있는 사분면에 맞는 것입니다. 같은 점을 두 번 세지 않도록 \(0 \le \theta < 2\pi\)로 잡습니다. 예를 들어 \((1,\ 1)\)은 \(r = \sqrt2,\ \theta = \pi/4\)입니다. 원점은 \(r = 0\)이고 \(\theta\)가 정해지지 않습니다. 프로그램에서는 atan2(y, x)가 사분면까지 반영한 각을 주고, atan(y / x)는 \(-\pi/2\)와 \(\pi/2\) 사이의 각만 주어서 제2·3사분면의 점에서 틀립니다.

두 좌표는 서로 이어집니다. 점의 극좌표가 \((r,\ \theta)\)이면 \(\theta\)만큼 돌린 회전 좌표에서 그 점은 \((x',\ y') = (r,\ 0)\)입니다. 위의 \(x'\) 축 위 점의 확인에서 \(t = r\)로 둔 경우입니다.

다중적분과 변수변환

영상의 값을 영역 \(D\) 전체에서 더하는 것이 이중적분(Double Integral)입니다. 영역을 작은 조각으로 나누어 \(f\)에 조각의 넓이 \(dA\)를 곱해 더한 값이고, 직교좌표에서는 \(dA = dx\,dy\)입니다.

\[\iint_{D} f(x, y)\,dx\,dy\]

원판처럼 경계가 곡선인 영역에서는 좌표를 바꾸는 편이 쉽습니다. 좌표를 바꾸면 조각의 넓이를 나타내는 식도 달라지므로 그 변화를 알아야 합니다.

극좌표의 넓이 요소

극좌표에서 \(r\)과 \(\theta\)를 각각 \(dr\), \(d\theta\)만 늘린 작은 조각은 변의 길이가 \(dr\)과 \(r\,d\theta\)인 직사각형에 가깝습니다. 호의 길이가 \(r\)에 비례하기 때문입니다.

그래서 극좌표에서는 넓이 요소가 \(dr\,d\theta\)가 아니라 \(r\,dr\,d\theta\)입니다.

\[dx\,dy = r\,dr\,d\theta\]

예를 들어 반지름 \(R\)인 원판에서 \(x^{2} + y^{2} = r^{2}\)이므로 다음과 같이 계산됩니다.

\[\iint_{x^2+y^2\le R^2}(x^{2}+y^{2})\,dx\,dy = \int_{0}^{2\pi}\!\!\int_{0}^{R} r^{2}\,r\,dr\,d\theta = 2\pi\times\frac{R^{4}}{4} = \frac{\pi R^{4}}{2}\]

피적분함수 \(r^{2}\)에 넓이 요소의 인자 \(r\)이 곱해져 \(\int r^{3}\,dr\)이 됩니다. 이 인자를 빠뜨리면 \(\int r^{2}\,dr\)이 되어 값이 달라집니다.

야코비안

좌표를 바꿀 때 조각의 넓이가 몇 배가 되는지를 알아야 합니다. 가장 단순한 예는 \(x = 2u,\ y = 3v\)입니다. \((u, v)\)는 새로 도입하는 변수이고 0편 2장의 광선 방향 \(u\)와 무관합니다. \((u, v)\) 평면에서 변이 \(du\)와 \(dv\)인 조각은 \((x, y)\) 평면에서 변이 \(2\,du\)와 \(3\,dv\)인 직사각형이 되므로 \(dx\,dy = 6\,du\,dv\)입니다. 극좌표에서 넓이가 \(r\)배가 되는 것도 같은 원리입니다.

\(x,\ y\)가 \(u,\ v\)의 일차식 \(x = m_{11}u + m_{12}v,\ y = m_{21}u + m_{22}v\)이면, 조각은 두 변 \((m_{11},\ m_{21})\,du\)와 \((m_{12},\ m_{22})\,dv\)가 이루는 평행사변형이 됩니다. 이 평행사변형의 넓이는 아래 식의 절댓값에 \(du\,dv\)를 곱한 것입니다. 계수를 \(\begin{pmatrix}m_{11}&m_{12}\\m_{21}&m_{22}\end{pmatrix}\)로 모은 것을 행렬(Matrix)이라 하고, 아래 식의 값을 행렬식(Determinant)이라고 합니다.

\[\det\begin{pmatrix}m_{11}&m_{12}\\m_{21}&m_{22}\end{pmatrix} = m_{11}m_{22} - m_{12}m_{21}\]

\(x = 2u,\ y = 3v\)도 행렬식이 \(2\times3 - 0\times0 = 6\)이어서, 모양이 달라도 넓이의 배율은 같습니다. 행렬식이 음수이면 도형이 뒤집힌 것이고 넓이의 배율은 그 절댓값입니다.

일차식이 아닌 변수변환도 \((u, v)\) 근처의 아주 작은 조각에서는 일차식에 가깝게 바뀝니다. 그 자리에서 조각의 넓이가 몇 배가 되는지를 같은 방식으로 구한 값을 야코비안(Jacobian)이라고 합니다. 일차식이면 야코비안은 행렬식의 절댓값이고, 변수를 바꿀 때는 이 야코비안을 곱합니다.

\[dx\,dy = (\text{야코비안})\,du\,dv\]

극좌표의 야코비안은 \(r\)입니다. 극좌표의 넓이 요소 \(r\,dr\,d\theta\)에서 곱해진 \(r\)이 이 값입니다.

극좌표의 야코비안 계산

\(r\)을 \(dr\)만큼 늘리면 점은 \((\cos\theta,\ \sin\theta)\,dr\)만큼 움직이고, \(\theta\)를 \(d\theta\)만큼 늘리면 \((-r\sin\theta,\ r\cos\theta)\,d\theta\)만큼 움직입니다. 이 두 변이 이루는 평행사변형의 넓이는 다음과 같습니다.

\[\left|\det\begin{pmatrix}\cos\theta&-r\sin\theta\\\sin\theta&r\cos\theta\end{pmatrix}\right| = \left|r\cos^{2}\theta + r\sin^{2}\theta\right| = r\]

두 변이 서로 수직이어서 직사각형이 되고 변의 길이가 \(dr\)과 \(r\,d\theta\)라는 앞의 설명과 같은 결과입니다.

이후 장과의 연결

푸리에 공간의 좌표를 극좌표로 바꾸면 \(d\omega_x\,d\omega_y = |\omega|\,d\omega\,d\theta\) 꼴의 식이 나옵니다. 이때 위의 \(r\) 자리에 \(|\omega|\)가 놓입니다. 광선의 좌표를 바꿀 때도 야코비안이 가중으로 나타납니다. 변수를 바꾸는 식에 낯선 곱셈 인자가 보이면 야코비안일 가능성이 큽니다.

1장 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. 축을 반시계 방향으로 \(\theta\)만큼 돌린 회전 좌표는 \(x' = x\cos\theta + y\sin\theta,\ y' = -x\sin\theta + y\cos\theta\)입니다. 직선 \(x\cos\theta + y\sin\theta = s\)는 \(x' = s\)인 직선입니다.
  2. 극좌표와 직교좌표는 \(x = r\cos\theta,\ y = r\sin\theta\)와 \(r = \sqrt{x^{2}+y^{2}}\)로 오가며, \(\theta\)는 점이 있는 사분면에 맞게 정합니다.
  3. 극좌표의 넓이 요소는 \(dx\,dy = r\,dr\,d\theta\)이고, 곱해진 \(r\)을 빠뜨리지 않아야 합니다.
  4. 야코비안은 변수변환에서 작은 조각의 넓이가 몇 배가 되는지를 주고, 일차식이면 행렬식 \(m_{11}m_{22} - m_{12}m_{21}\)의 절댓값입니다.

마무리 퀴즈 1

타원 영역 \(\dfrac{x^{2}}{4} + \dfrac{y^{2}}{9} \le 1\)의 넓이를 구하려고 합니다. \(x = 2u,\ y = 3v\)로 놓으면 이 영역은 \(u^{2} + v^{2} \le 1\)이 됩니다. 타원의 넓이는 무엇일까요?

  1. \(6\pi\)
  2. \(\pi\)
  3. \(36\pi\)
  4. \(5\pi\)

반축이 \(a,\ b\)인 타원의 넓이 \(\pi ab\)가 이 계산의 일반형입니다. 타원 하나의 투영값을 식으로 구할 때도 타원을 단위 원으로 옮기는 같은 변수변환을 쓸 수 있습니다.

마무리 퀴즈 2

\(\cos\theta = 0.6,\ \sin\theta = 0.8\)인 \(\theta\)만큼 축을 돌렸을 때 점 \((5,\ 5)\)의 회전 좌표 \((x',\ y')\)는 무엇일까요?

  1. \((1,\ 7)\)
  2. \((7,\ -1)\)
  3. \((3,\ 4)\)
  4. \((7,\ 1)\)

\(x' = 7\)이므로 이 점은 직선 \(0.6x + 0.8y = 7\) 위에 있고, \(y' = 1\)은 그 직선을 따라 잰 위치입니다. 광선 하나를 따라 더하는 적분이 이 \(y'\)에 대한 적분이 됩니다.

마무리 퀴즈 3

\(\displaystyle\iint_{x^2+y^2\le4}(x^{2}+y^{2})\,dx\,dy\)의 값은 무엇일까요?

  1. \(16\pi/3\)
  2. \(8\pi\)
  3. \(64\pi/5\)
  4. \(4\pi\)

적분 영역이 원, 부채꼴, 고리처럼 중심이 같은 모양이거나 피적분함수가 \(x^{2}+y^{2}\)에만 의존하면 극좌표가 쉽습니다. 영역이 직사각형이면 직교좌표가 쉽습니다.

직접 해보기

  1. 점 \((\sqrt3,\ 1)\)의 극좌표 \((r,\ \theta)\)를 구하세요. 이 \(\theta\)만큼 축을 돌린 회전 좌표 \((x',\ y')\)도 구하고, 극좌표와 어떤 관계인지 설명하세요.
  2. 극좌표로 \(\displaystyle\iint_{x^2+y^2\le R^2}e^{-(x^2+y^2)}\,dx\,dy\)를 구하고, \(R\to\infty\)일 때의 값을 쓰세요.
  3. \(x = 2u + v,\ y = 3u + v\)일 때 \(dx\,dy\)는 \(du\,dv\)의 몇 배인지 구하세요. \((u, v)\)의 단위 정사각형이 이 변환으로 어떤 도형이 되는지도 설명하세요.
모범답안과 흔한 실수

1번. \(r = \sqrt{3 + 1} = 2\)이고 점이 제1사분면에 있으며 \(\tan\theta = 1/\sqrt3\)이므로 \(\theta = \pi/6\)(\(30^{\circ}\))입니다. \(\theta = \pi/6\)에서 \(\cos\theta = \sqrt3/2,\ \sin\theta = 1/2\)이므로 \(x' = \sqrt3\times\tfrac{\sqrt3}{2} + 1\times\tfrac12 = 2\), \(y' = -\sqrt3\times\tfrac12 + 1\times\tfrac{\sqrt3}{2} = 0\)입니다. 회전 좌표는 \((2,\ 0)\)으로 \((r,\ 0)\)이고, 점이 새 \(x'\) 축 위에 있어서 \(x'\)가 곧 \(r\)입니다.

2번. 극좌표에서 \(\displaystyle\int_{0}^{2\pi}\!\!\int_{0}^{R}e^{-r^{2}}\,r\,dr\,d\theta = 2\pi\left[-\tfrac12e^{-r^{2}}\right]_{0}^{R} = \pi\left(1-e^{-R^{2}}\right)\)입니다. \(R\to\infty\)이면 \(e^{-R^{2}}\to0\)이어서 값은 \(\pi\)입니다.

3번. 행렬식은 \(2\times1 - 1\times3 = -1\)이고 절댓값이 1이므로 \(dx\,dy = du\,dv\)입니다. 단위 정사각형은 두 변 \((2,\ 3)\)과 \((1,\ 1)\)이 이루는 평행사변형이 됩니다. 넓이는 그대로 1이지만 도형이 뒤집힌 모양입니다.

흔한 실수.

  • 1번에서 \(\tan\theta = 1/\sqrt3\)의 각을 도와 라디안으로 섞어 쓰는 것입니다. 0편 3장의 규약대로 각은 라디안으로 쓰고, \(30^{\circ} = \pi/6\)입니다.
  • 1번에서 \(y'\)의 부호를 바꾸어 \(-\sqrt3\times\tfrac12 - 1\times\tfrac{\sqrt3}{2}\)처럼 계산하는 것입니다. \(y' = -x\sin\theta + y\cos\theta\)에서 부호가 붙는 것은 \(x\sin\theta\) 항입니다.
  • 2번에서 야코비안 \(r\)을 빠뜨려 \(\int e^{-r^{2}}dr\)을 쓰는 것입니다. 이 적분은 초등함수로 나타낼 수 있는 원시함수가 없어서 막히고, 막힐 때 \(r\)이 빠졌는지 확인합니다.
  • 3번에서 행렬식을 \(m_{11}m_{12} - m_{21}m_{22}\)처럼 첨자를 잘못 짝지어 계산하는 것입니다. 곱하는 것은 대각선 \(m_{11}m_{22}\)와 \(m_{12}m_{21}\)입니다.
  • 3번에서 \(-1\)을 넓이의 배율로 그대로 쓰는 것입니다. 넓이는 음수가 될 수 없고, 부호는 뒤집힘을 뜻하므로 절댓값 1을 씁니다.
