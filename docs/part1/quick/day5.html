평행빔 FBP를 컴퓨터로 계산해 보기

4일차 페이지 3의 FBP 공식은 모든 각도와 모든 검출기 위치에서 투영값을 안다고 보고 얻은 식입니다. 실제 장치가 주는 것은 정해진 각도와 검출기 위치에서 잰 숫자의 배열입니다. 오늘은 이 배열로 FBP를 계산하는 방법을 봅니다. 데이터의 격자와 시야(FOV), 검출기 간격이 정하는 주파수의 한계(페이지 1), 이산 램프 커널과 제로 패딩(페이지 2), 이산 역투영(페이지 3), 전체 의사코드와 재구성 결과(페이지 4)를 차례로 봅니다.

이산 sinogram

평행빔 장치는 \(0 \le \theta < \pi\)를 \(N_\theta\)개의 각도로 나누어 재고, 각도마다 검출기 칸 \(N_s\)개가 값을 하나씩 줍니다. 각도에 번호 \(k\), 검출기 칸에 번호 \(n\)을 붙이면 측정 데이터는 다음 배열입니다.

\[\theta_k = k\,\Delta\theta,\quad \Delta\theta = \frac{\pi}{N_\theta},\qquad s_n = \Bigl(n - \frac{N_s - 1}{2}\Bigr)\Delta s,\qquad p[k, n] = p(\theta_k,\ s_n)\]

  • \(k = 0, 1, \dots, N_\theta - 1\)은 각도 번호입니다. 이웃한 두 측정 각도의 차이 \(\Delta\theta = \pi/N_\theta\)를 각도 간격이라고 부르겠습니다.
  • \(n = 0, 1, \dots, N_s - 1\)은 검출기 번호이고, \(s_n\)은 \(n\)번째 검출기 칸 중심의 검출기 좌표입니다. 검출기의 한가운데가 \(s = 0\)(회전 중심)에 오도록 번호를 매겼습니다. 이웃한 두 칸 중심 사이의 거리 \(\Delta s\)(cm)를 검출기 간격이라고 부르겠습니다.
  • \(\Delta s\)는 길이(cm)이고 \(\Delta\theta\)는 각도(라디안)이므로 단위가 다릅니다. 간격 기호에는 샘플링하는 축의 이름(s, \(\theta\))을 붙입니다.
  • \(p[k, n]\)은 \(N_\theta\)행 \(N_s\)열의 배열이고, 행 하나가 각도 하나의 투영입니다. 대괄호는 정수 번호로 읽는 이산 값이고, 소괄호는 연속 함수입니다. 이 코스는 검출기 값을 칸 중심에서의 투영값으로 봅니다.

검출기 범위와 시야(FOV)

검출기의 폭은 \(N_s\Delta s\)이므로 \(|s| \le N_s\Delta s/2\)인 직선만 잽니다. 점 \((x, y)\)를 지나는 광선의 \(s = x\cos\theta + y\sin\theta\)는 각도에 따라 바뀌고, 크기가 가장 클 때 점과 회전 중심 사이의 거리와 같습니다. 그래서 회전 중심에서 \(N_s\Delta s/2\) 이내인 점은 모든 각도에서 광선이 검출기 안을 지납니다. 이 원을 시야(Field of View, FOV)라고 합니다.

4일차의 FBP 공식에는 \(-\infty\)부터 \(\infty\)까지의 적분이 들어 있습니다. 물체가 시야 안에 있으면 \(s\) 적분은 검출기가 잰 범위만으로 충분하고, 그 이유는 아래 접기에 있습니다. \(\omega\) 적분은 이렇게 줄일 수 없어 차단 주파수 \(W\)로 자르며, 이것은 아래에서 봅니다.

\(s\) 적분을 검출기 범위로 줄여도 되는 이유

물체가 회전 중심을 중심으로 반지름 \(R\)인 원 안에 있으면 \(|s| > R\)인 직선의 투영값은 0이므로, 투영의 푸리에 변환 \(P_\theta(\omega) = \int p(\theta, s)\,e^{-i2\pi\omega s}\,ds\)에서 \(s\) 적분은 \(-R\)부터 \(R\)까지면 됩니다. 물체가 시야 안에 있으면, 곧 \(R \le N_s\Delta s/2\)이면 이 범위를 검출기가 모두 재므로, 유한한 검출기로 계산해도 값이 같습니다.

물체가 시야 밖까지 있으면 일부 직선의 투영값이 없습니다. 이렇게 잘린 투영으로 재구성할 때 생기는 오류를 절단 아티팩트(Truncation Artifact)라고 합니다. FBP의 필터링은 투영 전체의 값을 쓰므로 시야 안의 값도 정확히 재구성되지 않습니다. 이 코스는 이를 보정하는 방법을 다루지 않습니다.

검출기 간격과 나이퀴스트 주파수

투영을 검출기 간격 \(\Delta s\)마다 하나씩만 읽으면 어떤 무늬까지 담을 수 있을까요? 3일차 페이지 1처럼 투영을 여러 주파수의 코사인 무늬가 더해진 것으로 보고, 무늬 하나씩 생각합니다.

간격 \(\Delta s\)로 샘플링할 때 담을 수 있는 가장 높은 주파수 \(1/(2\Delta s)\)를 나이퀴스트 주파수(Nyquist Frequency)라고 합니다. 이보다 높은 주파수의 성분은 그림 (b)처럼 샘플링 뒤에 낮은 주파수의 성분으로 바뀌어 섞이는데, 이 현상을 에일리어싱(Aliasing)이라고 합니다. 샘플만으로는 두 무늬를 구별할 수 없으므로, 에일리어싱은 샘플링한 뒤에 되돌릴 수 없습니다.

4일차 페이지 5의 차단 주파수 \(W\)를 이보다 크게 잡아도 그 주파수에는 쓸 측정값이 없습니다. 그래서 이 코스는 \(W\)를 나이퀴스트 주파수로 둡니다.

\[W = \frac{1}{2\Delta s}\]

예를 들어 검출기 간격이 \(0.05\) cm이면 \(W = 10\ \mathrm{cm}^{-1}\)이고, 주기가 \(0.1\) cm보다 짧은 무늬는 제 주파수로 측정되지 않고, 더 낮은 주파수의 무늬로 섞여 들어옵니다. 검출기 간격을 절반으로 줄이면 \(W\)는 2배가 됩니다. 곧 검출기 간격이 FBP가 쓸 수 있는 가장 높은 주파수를 정합니다.

이산 램프 커널과 제로 패딩

4일차의 필터링은 투영의 푸리에 변환에 \(|\omega|\)를 곱하는 계산이었습니다. 검출기 값 \(p[k, n]\)만 있을 때 이 곱셈은 어떻게 계산할까요? 먼저 같은 필터링을 주파수가 아니라 검출기 좌표 \(s\) 위에서 다시 씁니다.

가중합으로 쓰는 필터링

주파수 성분마다 배수 \(H(\omega)\)를 곱하는 필터링은, 검출기 좌표 위에서 보면 각 위치의 결과를 주변 투영값에 가중치를 곱해 더한 값으로 만드는 계산과 같습니다. 각도 하나의 투영을 \(p(s')\)로 쓰면(\(\theta\) 생략) 다음과 같습니다.

\[q(s) = \int_{-\infty}^{\infty} p(s')\,h(s - s')\,ds'\]

  • \(h(s - s')\)는 위치 \(s'\)의 투영값이 위치 \(s\)의 결과에 들어가는 가중치입니다. 가중치는 두 위치의 차이 \(s - s'\)에만 달려 있습니다.
  • \(h\)는 \(H(\omega)\)를 1차원 역 푸리에 변환한 함수이고, 필터의 커널이라고 부릅니다.

이런 계산을 컨볼루션(Convolution)이라고 합니다. 주파수에서 배수를 곱하는 것과 공간에서 커널과 컨볼루션하는 것이 같다는 사실을 컨볼루션 정리라고 하며, 여기서는 결과만 씁니다. \(|\omega|\)는 주파수가 커질수록 끝없이 커져서 이대로는 커널이 보통의 함수로 정해지지 않습니다. 페이지 1처럼 \(W = 1/(2\Delta s)\)에서 자른 Ram-Lak 필터(4일차 페이지 5)를 쓰면 커널이 정해지고, 검출기 값이 \(\Delta s\)마다 있으므로 거리 \(n\Delta s\)에서의 커널 값만 있으면 됩니다.

Ram-Lak 커널 h[n]

차단 주파수가 \(W = 1/(2\Delta s)\)인 Ram-Lak 필터의 커널을 거리 \(n\Delta s\)마다 읽은 값은 다음과 같습니다. 이 수열을 이 코스에서는 이산 램프 커널이라고 부릅니다.

\[h[n] = \begin{cases} \dfrac{1}{4(\Delta s)^{2}} & (n = 0) \\[6pt] 0 & (n \text{은 } 0\text{이 아닌 짝수}) \\[6pt] -\dfrac{1}{\pi^{2}n^{2}(\Delta s)^{2}} & (n \text{은 홀수}) \end{cases}\]

  • 가운데와 바로 옆. \(h[0]\)은 양수이고 \(h[\pm 1]\)은 그 약 0.41배인 음수입니다. 한 위치의 값에서 이웃 값을 빼는 모양이어서, 값이 급하게 바뀌는 경계가 강조됩니다.
  • 먼 곳의 값. 홀수 \(n\)에서만 음수이고 크기는 \(1/n^{2}\)로 줄지만, 멀리까지 0이 되지 않습니다.
  • 커널의 합. \(\Delta s h[n]\)을 모든 \(n\)에 대해 더하면 정확히 0입니다(양의 홀수 \(n\)에 대한 \(\sum 1/n^{2}\)이 \(\pi^{2}/8\)인 것을 이용). 4일차 페이지 4에서 본 \(\int q(\theta, s)\,ds = 0\)이 이산 계산에서 이렇게 나타납니다.
h[n]의 값을 얻는 과정

차단 주파수 \(W\)인 Ram-Lak 필터의 연속 커널은 다음과 같습니다(1편 5장 페이지 7). \(\mathrm{sinc}(u) = \sin(\pi u)/(\pi u)\)이고 \(\mathrm{sinc}(0) = 1\)입니다.

\[h_W(s) = 2W^{2}\,\mathrm{sinc}(2Ws) - W^{2}\,\mathrm{sinc}^{2}(Ws)\]

  1. \(W = 1/(2\Delta s)\), \(s = n\Delta s\)를 넣으면 \(2Ws = n\), \(Ws = n/2\)입니다.
  2. \(n = 0\)이면 \(2W^{2} - W^{2} = W^{2} = 1/(4(\Delta s)^{2})\)입니다.
  3. \(n \ne 0\)이면 \(\sin(\pi n) = 0\)이므로 첫째 항은 0입니다. 둘째 항의 \(\sin(\pi n/2)\)는 짝수 \(n\)에서 0이고, 홀수 \(n\)에서 \(\pm 1\)이어서 \(\mathrm{sinc}^{2}(n/2) = 4/(\pi^{2}n^{2})\)입니다. 따라서 홀수 \(n\)에서 \(h[n] = -W^{2} \times 4/(\pi^{2}n^{2}) = -1/(\pi^{2}n^{2}(\Delta s)^{2})\)입니다.

이산 컨볼루션

적분을 검출기 값의 합으로 바꾸면, 각도 \(k\)의 필터링한 투영은 다음과 같습니다.

\[q[k, n] = \Delta s \sum_{m=0}^{N_s - 1} p[k, m]\,h[n - m]\]

  • \(q[k, n]\)은 검출기 위치 \(s_n\)에서의 필터링한 투영입니다. 적분의 \(ds'\) 자리에 검출기 간격 \(\Delta s\)가 들어갑니다.
  • \(n - m\)은 \(-(N_s - 1)\)부터 \(N_s - 1\)까지이므로, 이 범위의 \(h\)를 모두 씁니다. 커널을 몇 개 값으로 짧게 자르면 합이 0에서 벗어나 영상 전체의 밝기가 틀어집니다.

4일차 직접 해보기 2번의 원판(반지름 0.5 cm, 값 1)으로 확인해 봅니다. 연속 계산에서는 원판 안쪽에서 \(q = 1/\pi \approx 0.3183\)이었습니다. 원판의 정확한 투영을 \(\Delta s = 0.01\) cm로 샘플링해 위 식으로 계산하면, 가운데 검출기의 \(q\)는 \(0.3183\)으로 같은 값이 나옵니다.

제로 패딩과 FFT

위 합은 검출기 위치 하나마다 곱셈이 \(N_s\)번이므로, 각도 하나에 \(N_s^{2}\)번의 곱셈이 듭니다. FFT로 투영과 커널을 주파수로 옮겨 곱하면 훨씬 빠릅니다. 그런데 FFT로 구한 주파수 값끼리 곱하는 계산은 배열이 끝없이 되풀이된다고 보고 한 컨볼루션이 됩니다. 이를 원형 컨볼루션(Circular Convolution)이라고 하며, 커널이 배열 끝을 넘어가면 반대쪽 끝의 투영값이 섞여 들어옵니다.

이를 피하려면 배열 끝에 0을 붙여 길이를 늘립니다. 이를 제로 패딩(Zero Padding)이라고 합니다. 위 합에 필요한 커널 값은 \(n - m = -(N_s - 1), \dots, N_s - 1\)의 \(2N_s - 1\)개입니다. 배열 길이가 \(2N_s - 1\) 이상이면 반대쪽에서 돌아온 값이 검출기 위치 \(0, \dots, N_s - 1\)의 결과에 섞이지 않습니다. 보통은 이보다 긴 2의 거듭제곱 길이를 씁니다.

위 원판을 \(\Delta s = 0.01\) cm, 검출기 \(N_s = 200\)개로 계산할 때 제로 패딩 없이 길이 200 그대로 FFT를 쓰면, \(q\)가 직접 합과 최대 \(0.049\)(\(1/\pi\)의 약 15%)만큼 다릅니다. 길이를 \(2N_s - 1 = 399\) 이상으로 늘리면 직접 합과 같은 값이 나옵니다. 주파수마다 \(|\omega|\)를 바로 곱하는 다른 방법과 그 차이는 1편 6장 페이지 3과 페이지 5에서 다룹니다.

이산 역투영과 각도 가중

필터링한 투영 \(q[k, n]\)도 검출기 위치 \(s_n\)에서만 값이 있습니다. 이 배열로 역투영 \(\mu(x, y) = \int_0^\pi q(\theta,\ x\cos\theta + y\sin\theta)\,d\theta\)를 계산하려면 두 가지를 정해야 합니다. 검출기 위치 사이에 떨어지는 \(s\)에서 \(q\)를 읽는 방법과, 각도 적분을 합으로 바꾸는 방법입니다.

화소마다 계산하는 역투영

영상도 화소의 격자이므로, 화소 중심 \((x, y)\)마다 각도 \(\theta_k\)에서 그 점을 지나는 광선의 검출기 좌표 \(s = x\cos\theta_k + y\sin\theta_k\)를 계산합니다(4일차 페이지 1). 이 \(s\)는 대개 두 검출기 위치 사이에 떨어집니다.

\(s\)를 검출기 번호로 바꾸려면 페이지 1의 \(s_n\) 식을 \(n\)에 대해 풀면 됩니다. 그 값의 정수 부분을 \(i\), 나머지를 \(f\)라고 합니다.

\[\tau = \frac{s}{\Delta s} + \frac{N_s - 1}{2},\qquad i = (\tau\text{의 정수 부분}),\qquad f = \tau - i\quad (0 \le f < 1)\]

\[q_k(s) = (1 - f)\,q[k, i] + f\,q[k, i + 1]\]

\(q_k(s)\)는 각도 \(k\)의 필터링한 투영을 위치 \(s\)에서 읽은 값입니다. 가까운 쪽 검출기 값에 더 큰 비중을 두어 두 값을 섞으며, \(f = 0\)이면 \(q[k, i]\) 그대로이고 \(f = 0.5\)이면 두 값의 평균입니다. 이 방법을 선형 보간(Linear Interpolation)이라고 합니다.

이처럼 화소를 하나씩 돌며 그 화소가 필요한 값을 검출기 쪽에서 읽어 오는 방식을 Pixel-driven(화소 기준) 방식의 역투영이라고 합니다. 모든 화소가 각도마다 정확히 한 번씩 값을 받습니다. 반대로 광선을 따라가며 화소에 값을 칠하는 방식을 단순하게 구현하면, 광선과 화소의 위치 관계에 따라 어떤 화소는 여러 번, 어떤 화소는 한 번도 칠해지지 않을 수 있습니다.

각도 합과 각도 가중

각도 적분은 각도 \(\theta_k\)마다의 값에 각도 간격 \(\Delta\theta = \pi/N_\theta\)를 곱해 더하는 합으로 바꿉니다. 넓이를 폭 \(\Delta\theta\)인 직사각형으로 나눠 더하는 것과 같습니다.

\[\mu(x, y) \approx \frac{\pi}{N_\theta} \sum_{k=0}^{N_\theta - 1} q_k(x\cos\theta_k + y\sin\theta_k)\]

\(\pi/N_\theta\)는 각도 하나가 차지하는 폭입니다. 이 인자를 빼면 같은 물체를 각도 수만 두 배로 늘려 재도 영상 값이 두 배가 됩니다. 이 인자를 곱하면 각도 수와 관계없이 같은 크기의 \(\mu\)가 나옵니다.

원판으로 확인합니다. 원판 안쪽의 점에서는 모든 각도에서 \(q = 1/\pi\)를 읽으므로 합은 \(N_\theta/\pi\)이고, \(\pi/N_\theta\)를 곱하면 1입니다. 페이지 2의 이산 커널과 선형 보간으로 실제로 계산하면(\(\Delta s = 0.01\) cm, \(N_\theta = 180\)) 원판 중심이 \(0.9998\), 점 \((0.3, 0)\)이 \(0.9997\), 원판 바깥의 점 \((0.8, 0)\)이 \(-0.001\)입니다. 각도를 18개로 줄이면 안쪽은 그대로 \(0.9998\)이지만 바깥의 점 \((0.8, 0)\)이 \(-0.19\)가 됩니다. 각도가 적을 때 바깥에 생기는 이런 값은 페이지 4에서 영상으로 봅니다.

5일차 · 페이지 4

전체 의사코드와 이산 아티팩트

페이지 2의 필터링과 페이지 3의 역투영을 이으면 이산 FBP 전체가 됩니다. 의사코드로 쓰고, Shepp-Logan 팬텀으로 결과를 확인합니다.

의사코드

이산 평행빔 FBP의 의사코드입력  p[k, n],  검출기 간격 Δs
출력  영상의 화소 중심 (x, y) 마다의 μ(x, y)

 1  h[n] ← 페이지 2 의 Ram-Lak 커널 (|n| ≤ N_s−1)
 2  μ ← 0
 3  각 각도 번호 k = 0 … N_θ−1 에 대해 되풀이한다:
 4      θ ← kπ/N_θ
 5      q[n] ← Δs · Σ_m p[k, m] · h[n − m]
 6      영상의 각 화소 중심 (x, y) 에 대해:
 7          s ← x cosθ + y sinθ
 8          τ ← s/Δs + (N_s − 1)/2
 9          i ← τ 의 정수 부분,   f ← τ − i
10          v ← (1 − f)·q[i] + f·q[i+1]
11          μ(x, y) ← μ(x, y) + (π/N_θ)·v
  1. 1행 이산 램프 커널입니다. 페이지 2의 식으로 \(|n| \le N_s - 1\)의 값을 한 번만 계산해 두고 모든 각도에 씁니다.
  2. 5행 첫째 단계인 필터링입니다. 각도 하나의 투영만 쓰는 1차원 계산입니다. FFT로 할 때는 배열을 길이 \(2N_s - 1\) 이상으로 제로 패딩합니다.
  3. 6~9행 둘째 단계입니다. 화소마다 그 점을 지나는 광선의 검출기 좌표를 구하고, 검출기 번호로 바꿔 이웃한 두 값의 위치를 찾습니다. \(i\)가 \(0\)~\(N_s - 2\)를 벗어나는 화소는 그 광선이 검출기 밖으로 나간 것이므로 그 각도에서 더하지 않습니다.
  4. 10~11행 셋째 단계입니다. 10행이 선형 보간이고, 11행에서 그 값에 각도 가중 \(\pi/N_\theta\)를 곱해 더합니다.

연속 FBP의 의사코드(1편 5장 페이지 4)와 순서는 같습니다. 달라진 것은 필터링이 커널과의 합이 된 것, 역투영이 보간이 된 것, \(d\theta\)가 \(\pi/N_\theta\)가 된 것입니다.

Shepp-Logan 팬텀의 이산 FBP

아래 위젯은 Shepp-Logan 팬텀의 정확한 투영을 검출기 위치 \(s_n\)에서 샘플링해 이산 sinogram을 만들고, 위 의사코드 그대로 재구성합니다. 커널은 Ram-Lak 커널 \(h[n]\)이고 차단 주파수는 \(W = 1/(2\Delta s)\)입니다. 각도 수와 검출기 간격을 바꾸어 보세요.

각도 수 \(N_\theta\)
검출기 간격 \(\Delta s\)

이산 계산에서 생기는 아티팩트

재구성 영상에서 원래 물체에 없는 무늬를 아티팩트(Artifact)라고 합니다. 이산 계산에서 생기는 아티팩트는 세 가지이며, 위젯에서는 앞의 둘이 잘 보이고 에일리어싱은 링잉과 겹쳐 따로 구별되지 않습니다.

  • 각도 부족의 줄무늬. 각도 18개에서는 두개골 바깥으로 가는 직선 줄이 사방으로 뻗습니다. 4일차 페이지 2의 주파수 평면에서 이웃한 직선 사이의 빈틈이 영상에 이렇게 나타납니다. 각도를 180개로 늘리면 바깥 점의 값이 거의 0이 됩니다.
  • 링잉. 검출기 간격 0.08 cm에서 밝기 범위를 뇌 조직으로 좁히면 두개골 안쪽 경계를 따라 물결 모양의 무늬가 보입니다. Ram-Lak 필터가 \(|\omega|\)를 \(W\)에서 갑자기 0으로 자르기 때문에 생기는 이 무늬를 링잉(Ringing)이라고 합니다. 물결의 폭은 검출기 간격에 비례해서, 0.02 cm로 줄이면 물결이 가늘어집니다. 4일차 페이지 5의 윈도우 함수를 곱하면 줄어듭니다.
  • 에일리어싱. 두개골의 경계처럼 급하게 변하는 곳은 \(W\)보다 높은 주파수 성분을 가집니다. 이 성분이 샘플링에서 낮은 주파수로 섞여 들어와(페이지 1), 경계 근처에 링잉과 겹친 얼룩을 만듭니다. 샘플링 뒤에는 필터로 되돌릴 수 없고, 검출기 간격을 줄여야 줄어듭니다.

검출기 간격과 각도 수는 함께 정해야 합니다. 각도 180개에서 검출기 간격을 0.08 cm에서 0.02 cm로 줄이면 뇌 조직의 오차가 줄어 경계가 또렷해집니다. 그러나 각도 18개에서는 검출기 간격을 줄일수록 바깥의 줄무늬가 오히려 강해집니다. 검출기 간격이 좁을수록 높은 주파수까지 쓰고, 주파수 평면의 높은 주파수 쪽은 이웃한 직선 사이의 빈틈이 넓기 때문입니다.

5일차 · 페이지 5

5일차 마무리: 요약·퀴즈·직접 해보기

핵심 요약

  1. 이산 FBP는 (1) 투영마다 이산 램프 커널 \(h[n]\)과 컨볼루션(또는 제로 패딩 FFT) (2) 화소마다 \(s = x\cos\theta + y\sin\theta\)를 계산해 보간 (3) 각도 합에 \(\pi/N_\theta\)를 곱하는 세 단계입니다. 검출기 간격이 쓸 수 있는 최고 주파수(\(W = 1/(2\Delta s)\))를 정합니다.
  2. Ram-Lak 커널은 \(h[0] = 1/(4(\Delta s)^{2})\), 0이 아닌 짝수 \(n\)에서 0, 홀수 \(n\)에서 \(-1/(\pi^{2}n^{2}(\Delta s)^{2})\)이고, 필터링은 \(q[k, n] = \Delta s\sum_m p[k, m]\,h[n - m]\)입니다. 커널 전체의 합은 0입니다.
  3. FFT로 필터링할 때는 원형 컨볼루션을 피하려고 길이 \(2N_s - 1\) 이상으로 제로 패딩합니다.
  4. 각도가 부족하면 바깥에 줄무늬가, 검출기 간격이 넓으면 경계 근처에 링잉과 에일리어싱이 생깁니다.

검출기 간격이 \(\Delta s = 0.025\) cm인 평행빔 데이터가 있습니다. 이 데이터로 FBP를 할 때 쓸 수 있는 가장 높은 주파수는 얼마일까요?

  1. \(40\ \mathrm{cm}^{-1}\)
  2. \(20\ \mathrm{cm}^{-1}\)
  3. \(10\ \mathrm{cm}^{-1}\)
  4. 한계가 없습니다

실제 검출기 칸은 폭이 있어서 칸 안의 값을 평균해 읽습니다. 이 평균은 높은 주파수 성분을 줄여 에일리어싱을 다소 줄이지만, 나이퀴스트 주파수 자체는 칸 중심 사이의 거리 \(\Delta s\)로 정해집니다.

검출기 \(N_s\)개의 투영을 제로 패딩 없이 길이 \(N_s\) 그대로 FFT 해서 램프 필터를 적용했습니다. 무엇이 문제일까요?

  1. 배열이 짧아 FFT 계산이 눈에 띄게 느려집니다.
  2. 쓸 수 있는 가장 높은 주파수가 낮아집니다.
  3. 각도 가중 \(\pi/N_\theta\)가 실제 각도 수와 맞지 않게 됩니다.
  4. 한쪽 끝을 넘은 커널이 반대쪽 끝의 값과 섞입니다.

투영의 양 끝이 물체 바깥이어서 값이 0이라도 이 문제는 남습니다. 램프 커널은 멀리까지 0이 아니므로, 반대쪽에서 돌아온 커널이 물체가 있는 가운데 부분의 값과 곱해져 결과에 더해지기 때문입니다.

각도 18개로 재구성했더니 물체 바깥으로 가는 줄이 사방으로 뻗었습니다. 무엇을 바꿔야 줄이 줄어들까요?

  1. 측정 각도의 수를 늘립니다.
  2. 검출기 간격을 더 줄입니다.
  3. 각도 가중 \(\pi/N_\theta\)를 뺍니다.
  4. 램프 커널 \(h[n]\)을 짧게 자릅니다.

각도 수를 늘릴 수 없을 때는 비어 있는 각도의 투영을 이웃 각도에서 보간해 채우거나, 2편에서 다루는 대수적 재구성처럼 측정과 맞는 영상을 반복 계산으로 찾는 방법을 씁니다.

직접 해보기

  1. 검출기 간격이 \(\Delta s = 0.05\) cm입니다. 차단 주파수 \(W\)와 Ram-Lak 커널의 \(h[0]\), \(h[\pm 1]\), \(h[\pm 2]\), \(h[\pm 3]\)을 구하세요. 또 \(n = -3, \dots, 3\)의 일곱 값만 남기고 나머지를 버린 커널로 \(\Delta s\sum_n h[n]\)을 계산하고, 이렇게 짧게 자른 커널로 재구성하면 영상이 어떻게 될지 설명하세요.
  2. 검출기 \(N_s = 736\)개의 투영을 FFT로 필터링합니다. 원형 컨볼루션을 피하는 최소 배열 길이와, 그 이상인 가장 작은 2의 거듭제곱 길이를 구하세요.
  3. 검출기 간격 \(\Delta s = 0.1\) cm, 검출기 \(N_s = 8\)개, 각도 \(N_\theta = 6\)개입니다. 각도 번호 \(k = 1\)(\(\theta_1 = 30^{\circ}\))에서 화소 중심 \((0.25, 0.1)\)의 \(s\), 검출기 번호 \(\tau\), \(i\), \(f\)를 구하고, 이 각도에서 이 화소에 더하는 값을 \(q[1, i]\), \(q[1, i+1]\)로 쓰세요.
모범답안과 흔한 실수

1번. \(W = 1/(2 \times 0.05) = 10\ \mathrm{cm}^{-1}\)입니다. \((\Delta s)^{2} = 0.0025\)이므로 \(h[0] = 1/(4 \times 0.0025) = 100\), \(h[\pm 1] = -1/(\pi^{2} \times 0.0025) \approx -40.53\), \(h[\pm 2] = 0\), \(h[\pm 3] = -1/(9\pi^{2} \times 0.0025) \approx -4.50\)입니다(단위 \(\mathrm{cm}^{-2}\)). 일곱 값의 합은 \(\Delta s\sum_n h[n] = 0.05 \times (100 - 2 \times 40.53 - 2 \times 4.50) \approx 0.497\ \mathrm{cm}^{-1}\)입니다. 커널 전체의 합은 0이어야 하는데, 버린 먼 곳의 음수 값만큼 양수가 남았습니다. 이 커널로 필터링하면 버린 음수 값이 하던 일, 곧 4칸 이상 떨어진 투영값을 빼는 일이 빠집니다. 그래서 \(q\)가 그만큼 커지고, 역투영하면 물체 안팎이 넓게 밝아집니다. 원판(반지름 0.5 cm, 값 1, \(\Delta s = 0.01\) cm, 각도 180개)에서 커널을 \(|n| \le 3\)으로 자르면 중심 값이 1 대신 약 7.8이 됩니다. 그래서 \(|n| \le N_s - 1\)의 값을 모두 씁니다.

2번. 필요한 커널 값은 \(2N_s - 1 = 1471\)개이므로 최소 길이는 1471입니다. 그 이상인 가장 작은 2의 거듭제곱은 \(2^{11} = 2048\)입니다.

3번. \(s = 0.25\cos 30^{\circ} + 0.1\sin 30^{\circ} \approx 0.2165 + 0.05 = 0.2665\) cm입니다. \(\tau = 0.2665/0.1 + (8 - 1)/2 = 2.665 + 3.5 = 6.165\)이므로 \(i = 6\), \(f = 0.165\)입니다. \(i + 1 = 7 \le N_s - 1\)이어서 두 값이 모두 검출기 안에 있습니다. 각도 가중은 \(\pi/N_\theta = \pi/6\)이므로 더하는 값은 \((\pi/6)\bigl(0.835\,q[1, 6] + 0.165\,q[1, 7]\bigr)\)입니다. \(f = 0.165\)로 작으므로 가까운 쪽인 \(q[1, 6]\)의 비중이 큽니다.

흔한 실수.

  • 1번에서 짝수 \(n\)에도 \(-1/(\pi^{2}n^{2}(\Delta s)^{2})\)을 넣는 것입니다. 짝수 \(n \ne 0\)에서는 0입니다.
  • 2번에서 \(N_s\)의 두 배인 1472를 최소 길이로 쓰는 것은 충분하지만 최소는 아닙니다. 반대로 \(N_s\)보다 조금 큰 1024를 쓰면 원형 컨볼루션이 남습니다.
  • 3번에서 \(\tau = s/\Delta s\)로만 계산해 검출기 한가운데의 번호 \((N_s - 1)/2\)를 더하지 않는 것입니다. 번호 0은 검출기의 한쪽 끝입니다.
