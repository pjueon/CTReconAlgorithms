# CT 재구성 알고리즘

CT 재구성(CT Reconstruction) 이론을 수식 유도까지 따라가며 배우는 한국어 학습 자료입니다.
투영 데이터에서 단면 영상을 구하는 알고리즘을 코드 없이 수식·순서도·의사코드로 설명합니다.

**읽기:** https://pjueon.github.io/CTReconAlgorithms/

## 구성

| 편 | 내용 | 코스 |
|---|---|---|
| 0편 · 기초 | CT가 무엇인지, 투영과 선적분, 재구성 방법의 큰 갈래 | 3장 |
| 1편 · 해석적 재구성 | Radon 변환, 푸리에 슬라이스 정리, FBP, 팬빔, 데이터 완전성(Parker·Wang weight), FDK | 빠르게 보기 7일 / 자세히 보기 15장 |
| 2편 · 대수적 재구성 | Ax = b, ART·SIRT·SART, 정규화와 TV, 압축 센싱, GPBB, ASD-POCS | 빠르게 보기 7일 / 자세히 보기 11장 |

처음이라면 0편 → 1편 빠르게 보기 → 2편 빠르게 보기 순서를 권합니다. 자세히 보기는 유도와 이산화를 빠짐없이 다루는 레퍼런스입니다.

## 대상 독자

미적분·푸리에 해석·선형대수의 기초를 배운 적이 있고 CT 재구성을 처음 배우는 분. 필요한 수학은 본문에서 복습합니다.

## 오프라인으로 보기

`docs/` 폴더를 내려받아 `docs/index.html`을 브라우저로 열면 됩니다. 수식 렌더러(KaTeX)와 글꼴이 포함되어 있어 인터넷 연결 없이도 볼 수 있습니다.

## 자료의 출처

공개된 교과서·논문·공개 구현 등 누구나 접근할 수 있는 공개 자료만을 바탕으로, 개인 학습 목적으로 작성했습니다. 특정 기관이나 회사의 비공개 정보·내부 자료는 포함하지 않으며, 내용은 작성자 개인의 이해와 의견입니다. 주 참고서는 A. C. Kak, M. Slaney, *Principles of Computerized Tomographic Imaging* (SIAM, 2001)이고, 인용한 문헌 전체는 [참고문헌 페이지](https://pjueon.github.io/CTReconAlgorithms/refs.html)에 있습니다.

작성자도 공부하며 정리한 자료라 틀린 부분이 있을 수 있습니다.
